# 호흡기계 병리(呼吸器系 病理) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/각론/호흡기계 병리` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 해수(咳嗽)는 어떤 축으로 변증되는가? (작성 예정)
- 천증(喘證)의 허실(虛實) 감별 기준은 무엇인가? (작성 예정)
- 폐기허(肺氣虛)와 반복 호흡기감염은 어떻게 연결되는가? (작성 예정)
