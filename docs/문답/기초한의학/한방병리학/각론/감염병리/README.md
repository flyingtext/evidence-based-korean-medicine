# 감염병리(感染病理) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/각론/감염병리` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 육음(六淫)과 병원체 감염은 어떻게 대응하는가? (작성 예정)
- 위기영혈(衛氣營血) 변증은 감염 경과의 무엇을 기술하는가? (작성 예정)
- 정기존내(正氣存內) 이론과 숙주 면역은 어떤 접점이 있는가? (작성 예정)
