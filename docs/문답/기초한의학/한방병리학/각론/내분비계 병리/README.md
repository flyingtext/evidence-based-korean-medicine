# 내분비계 병리(內分泌系 病理) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/각론/내분비계 병리` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 소갈(消渴)의 삼소(三消)는 무엇을 기준으로 나뉘는가? (작성 예정)
- 신양허(腎陽虛)와 갑상선기능저하증은 어떤 접점이 있는가? (작성 예정)
- 간울(肝鬱)과 스트레스 호르몬 축은 어떻게 연결되는가? (작성 예정)
