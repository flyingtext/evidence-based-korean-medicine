# 신경계 병리(神經系 病理) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/각론/신경계 병리` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 중풍(中風)의 병기는 어떻게 분류되는가? (작성 예정)
- 간풍내동(肝風內動)은 무엇을 설명하려 한 개념인가? (작성 예정)
- 담탁몽폐청규(痰濁蒙蔽淸竅)와 인지장애는 어떤 접점이 있는가? (작성 예정)
