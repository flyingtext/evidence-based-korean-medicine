# 종양병리(腫瘍病理) — 문답(問答)

이 폴더는 기초한의학 한방병리학 각론의 종양병리 분야에서 학습자와 임상가가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거를 우선하고 출처를 명시하는 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

문서는 종양 전반에 걸친 총론 문답과, 개별 암종(KCD-8 신생물 코드)별 각론 문답으로 나누어 `총론/`·`각론/` 하위 폴더에 배치한다.

## 목차

### 총론

- 징가적취(癥瘕積聚)는 종양의 무엇을 가리키는가? (작성 예정)
- 암독(癌毒)·어혈·담응 이론은 종양 미세환경과 어떻게 연결되는가? (작성 예정)
- 부정거사(扶正祛邪)는 항암 보조에서 어떤 위치인가? (작성 예정)

### 각론 — KCD-8 신생물 코드별

- [C15 식도암] 식도암은 왜 빨리 퍼지고 늦게 발견되는가 — 장막 부재라는 해부학적 함정, 편평세포암과 선암의 이원 구조, 분자병리 지형, 연하곤란의 삼중 기전, 악액질과 통합 염증·영양 지표, 열격(噎膈) 대응의 경계선 (6막 26문답, 인용 21편)
