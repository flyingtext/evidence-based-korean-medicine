# 세포사 (細胞死, Cell Death) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/총론/세포사 및 논점 대응` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 RUN.md 워크플로우(근거 우선·출처 명시)에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

세포가 죽는 방식이 하나가 아니라는 사실에서 출발한다. 괴사와 세포자멸사의 고전적 이분법은 파이롭토시스·네크롭토시스·페롭토시스가 밝혀지면서 여러 갈래로 확장되었고, 어떤 방식으로 죽는가가 뒤이은 염증 반응의 크기를 결정한다. 근거를 3층(①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비)으로 층화한다.

## 목차

- 괴사(壞死, necrosis)와 세포자멸사(apoptosis)는 어떻게 구분하는가? (작성 예정)
- 조절세포사(파이롭토시스·네크롭토시스·페롭토시스)의 임상적 의미는 무엇인가? (작성 예정)
- 자가포식(autophagy)은 생존 기전인가 세포사 경로인가? (작성 예정)
- 세포 노쇠(senescence)와 노쇠연관분비표현형(SASP)은 조직 환경을 어떻게 바꾸는가? (작성 예정)
- 형(形)의 소멸과 기(氣)의 이탈이라는 고전 서술은 세포 수준 기전을 기술한 것인가? (작성 예정)
- 탈증(脫證)·망양(亡陽)과 대량 세포사 상태는 어떻게 대응하는가? (작성 예정)
- 염증을 유발하는 세포사와 그렇지 않은 세포사의 구분이 열독(熱毒) 서술과 갖는 접점은 무엇인가? (작성 예정)
