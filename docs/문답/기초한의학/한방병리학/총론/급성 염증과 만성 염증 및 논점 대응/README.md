# 급성 염증과 만성 염증 (炎症, Acute and Chronic Inflammation) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/총론/급성 염증과 만성 염증 및 논점 대응` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

염증 그 자체의 일반 문법을 다룬다. 감염병리 폴더가 감염 맥락의 염증을, 각 계통 각론이 장기별 염증을 다루므로, 이 폴더는 어느 조직에서든 반복되는 염증의 문법에 집중한다. 근거를 3층(①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비)으로 층화한다.

## 목차

- 급성 염증의 혈관 반응(확장·투과성 증가)과 삼출액·누출액의 감별은 어떻게 하는가? (작성 예정)
- 백혈구 동원의 다단계(변연화·구르기·부착·통과·주화성)와 탐식·살균 기전은? (작성 예정)
- 염증 화학매개체(혈관작용 아민·아라키돈산 대사산물·사이토카인·보체·키닌)는 어떻게 상호 증폭하는가? (작성 예정)
- 장액성·섬유소성·화농성·궤양성·위막성 염증의 형태학적 유형과 대표 상황은? (작성 예정)
- 염증의 소산(리폭신·레졸빈)과 소산 실패가 만성화로 이어지는 경로는? (작성 예정)
- 만성 염증의 유발 경로(지속 감염·지속 노출·자가면역)와 세포 침윤의 특징은? (작성 예정)
- 육아종성 염증의 구성과 감별(감염성·이물성·원인불명)은 어떻게 하는가? (작성 예정)
- 홍종열통(紅腫熱痛) 사징과 급성 염증 징후는 어떻게 대응하는가? (작성 예정)
- 열독(熱毒)·창양(瘡瘍)과 화농성 염증의 대응 및 배농(排膿) 치법의 위치는? (작성 예정)
- 한열(寒熱) 변증과 염증 활성도는 등치할 수 있는가? 한증(寒證)을 동반한 염증 상태는? (작성 예정)
