# 세포 손상과 적응 (細胞 損傷·適應, Cellular Adaptation and Injury) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/총론/세포 손상과 적응 및 논점 대응` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

세포가 스트레스를 감당해 적응하는 방식과, 적응의 한계를 넘어 손상에 이르는 지점을 다룬다. 무엇이 가역이고 무엇이 비가역인가라는 물음이 임상에서 개입 시점을 결정한다. 근거를 3층(①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비)으로 층화한다.

## 목차

- 위축(萎縮)·비대(肥大)·과형성(過形成)·화생(化生)은 각각 어떤 적응 반응인가? (작성 예정)
- 세포 손상의 원인(저산소·물리화학적 인자·감염·면역·유전·영양)은 어떻게 분류하는가? (작성 예정)
- 가역적 손상과 비가역적 손상의 경계를 결정하는 요인은 무엇인가? (작성 예정)
- ATP 고갈·미토콘드리아 손상·세포내 칼슘 증가·활성산소종이 손상을 어떻게 매개하는가? (작성 예정)
- 허혈-재관류 손상은 왜 혈류 재개가 오히려 손상을 가중시키는가? (작성 예정)
- 세포내 축적(지방·단백질·글리코겐·색소)과 병적 석회화의 구분은 무엇인가? (작성 예정)
- 정기(正氣)와 세포 적응 예비능은 어떻게 대응하는가? 정기가 세포 지표로 환원되지 않는 한계는? (작성 예정)
- 사기(邪氣) 분류(육음)와 세포 손상 원인 분류는 같은 축을 기술하는가? (작성 예정)
- 허실(虛實) 도식으로 위축과 비대를 모두 적응이라 설명할 수 있는가? (작성 예정)
