# 조직 수복과 섬유화 (組織 修復·纖維化, Tissue Repair and Fibrosis) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/총론/조직 수복과 섬유화 및 논점 대응` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 RUN.md 워크플로우(근거 우선·출처 명시)에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

손상 이후 조직이 원래 모습으로 돌아가는가(재생), 아니면 흉터로 대체되는가(반흔)를 가르는 조건을 다룬다. 섬유화는 수복의 실패가 아니라 수복이 과도하게 성공한 결과라는 관점이 이 폴더의 축이다. 근거를 3층(①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비)으로 층화한다.
