# 노화의 병리 (老化 病理, Pathology of Aging) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/총론/노화의 병리 및 논점 대응` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 RUN.md 워크플로우(근거 우선·출처 명시)에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

노화를 "시간이 지나 낡는 것"이 아니라 항상성 예비능이 줄어드는 과정으로 다룬다. 같은 스트레스에도 회복하지 못하게 되는 지점이 노쇠(frailty)이며, 이 관점이 고령 환자 진료의 판단 기준을 바꾼다. 근거를 3층(①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비)으로 층화한다.

## 목차

- 텔로미어 단축·노쇠세포 축적·미토콘드리아 기능 저하는 노화의 어떤 층위를 설명하는가? (작성 예정)
- 만성 저강도 염증(inflammaging)이 노쇠·근감소증·다질환 동반과 어떻게 연결되는가? (작성 예정)
- 노쇠(frailty)와 예비능 감소는 임상에서 어떤 의사결정을 바꾸는가? (작성 예정)
- 신정휴허(腎精虧虛)·천계갈(天癸竭) 서술과 노화 기전은 어떻게 대응하는가? (작성 예정)
- 노쇠(frailty)와 허손(虛損) 서술의 접점은 무엇인가? (작성 예정)
- 보신(補腎)·항노화 연구의 대리지표(텔로미어·염증 지표·호르몬)가 임상 결과로 번역되는가? (작성 예정)
