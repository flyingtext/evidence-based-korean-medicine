# 면역병리 총론 (免疫病理 總論, General Immunopathology) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/총론/면역병리 총론 및 논점 대응` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 RUN.md 워크플로우(근거 우선·출처 명시)에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

과민반응·자가면역·면역결핍·이식 거부의 일반 기전을 다룬다. 계통 각론의 면역계 병리 폴더가 질환별 각론을 맡으므로, 이 폴더는 기전의 문법에 집중한다. 근거를 3층(①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비)으로 층화한다.
