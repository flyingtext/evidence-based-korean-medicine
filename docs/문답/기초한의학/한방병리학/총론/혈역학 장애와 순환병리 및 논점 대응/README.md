# 혈역학 장애와 순환병리 (血力學 障碍·循環病理, Hemodynamic Disorders) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/총론/혈역학 장애와 순환병리 및 논점 대응` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

체액이 어디에 얼마나 있어야 하는가, 혈액이 굳어야 할 때와 굳지 말아야 할 때를 다룬다. 부종·출혈·혈전·색전·경색·쇼크는 모두 같은 순환 항상성의 서로 다른 붕괴 양상이다. 근거를 3층(①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비)으로 층화한다.

## 목차

- 부종의 네 축(정수압·교질삼투압·림프 배액·혈관 투과성)은 어떻게 감별에 적용되는가? (작성 예정)
- 능동적 충혈과 수동적 울혈의 구분은 무엇인가? 만성 울혈의 조직 변화는? (작성 예정)
- 출혈의 형태학적 분류(점상·자반·반상·혈종)와 출혈 경향의 병태는? (작성 예정)
- 비르효 삼징(내피 손상·혈류 이상·과응고)은 혈전 형성을 어떻게 설명하는가? (작성 예정)
- 색전의 종류(혈전·지방·공기·양수·종양)별 임상상은 어떻게 다른가? (작성 예정)
- 빈혈성 경색과 출혈성 경색을 결정하는 요인은 무엇인가? (작성 예정)
- 쇼크의 분류(저혈량·심인성·분포성·폐색성)와 단계별 진행은 어떤 구조인가? (작성 예정)
- 어혈(瘀血)과 혈전·미세순환 장애는 어떻게 대응하는가? 어혈이 유변학 지표로 환원되지 않는 점은? (작성 예정)
- 수습정체(水濕停滯)·수종(水腫)과 부종 기전은 어떻게 대응하는가? (작성 예정)
- 망양(亡陽)·탈증(脫證)과 쇼크 진행의 대응 및 회양구역 치법의 위치는? (작성 예정)
