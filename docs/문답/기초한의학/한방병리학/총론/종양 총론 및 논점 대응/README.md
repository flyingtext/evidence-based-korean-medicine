# 종양 총론 (腫瘍 總論, General Neoplasia) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/총론/종양 총론 및 논점 대응` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 RUN.md 워크플로우(근거 우선·출처 명시)에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

신생물의 정의·명명·이형성·등급·병기라는 개념 틀을 다룬다. 발암기전·종양생물학·전이·종양면역의 상세는 각론의 종양병리 폴더에서 다루므로, 이 폴더는 개념 틀에 한정한다. 근거를 3층(①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비)으로 층화한다.

## 목차

- 신생물의 정의와 양성·악성 감별 기준은 무엇인가? 과형성·화생·이형성과 어떻게 구분하는가? (작성 예정)
- 종양의 명명법과 분류 체계는 어떤 구조인가? ICD-O 형태 코드와 KCD 부위 코드의 이중 구조는? (작성 예정)
- 이형성-제자리암-침습암의 연속선에서 선별검사가 겨냥하는 시간 창은 무엇인가? (작성 예정)
- 분화도·등급·병기(TNM)는 예후 예측에 어떻게 기여하는가? (작성 예정)
- 적취(積聚)·징가(癥瘕)의 유형(有形)·무형(無形) 구분과 양성·악성 종괴 구분은 어떻게 대응하는가? (작성 예정)
- 고전 병명(유암·열격·석저)과 현대 암종은 일대일 대응하는가? 대응 시 주의는? (작성 예정)
- 이형성-제자리암-침습암 연속선과 미병(未病) 개념의 접점과 층위 차이는 무엇인가? (작성 예정)
