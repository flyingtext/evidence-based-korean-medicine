# 변증논치와 논점 대응 (辨證論治, Pattern Differentiation and Treatment) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/총론/변증논치와 논점 대응` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

이 폴더는 병인(病因)·병기(病機)·변증(辨證)이라는 한의학 병리의 일반 문법과, 그 문법이 기혈음양·오장·복합병리·병리산물에서 어떻게 구체화되는지를 다룬다. 변증 층화를 반복 명시하며, 근거를 3층(①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비)으로 층화한다.

## 목차

- 병인(病因)·병기(病機)·변증(辨證)은 어떻게 구분되는가? (작성 예정)
- 삼인학설(三因學說)의 외인·내인·불내외인 분류와 현대 병인 분류는 어떻게 대응하는가? (작성 예정)
- 팔강변증·장부변증·육경변증·위기영혈변증은 서로 어떤 관계인가? (작성 예정)
- 어혈(瘀血)·담음(痰飮)은 병인인가 병리산물인가? (작성 예정)
- 허실(虛實)·한열(寒熱)의 판별 기준은 무엇인가? (작성 예정)
- 기혈양허(氣血兩虛)·기음양허(氣陰兩虛)·음양양허(陰陽兩虛)는 어떻게 감별하는가? (작성 예정)
- 변증(辨證)과 진단(diagnosis)은 어떤 관계인가? 증(證)과 병(病)이 서로 다른 축이라는 점은 무엇인가? (작성 예정)
- 허실 도식으로 포섭되지 않는 제3의 축(자가면역·조절 실패)은 무엇인가? (작성 예정)
- 오장(五臟) 개념과 해부학적 장기는 어떻게 구분되는가? (작성 예정)
- 비증(痺證)의 풍한습열 분류와 현대 류마티스 질환은 어떻게 대응하는가? (작성 예정)
