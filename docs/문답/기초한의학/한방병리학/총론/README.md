# 한방병리학 총론(總論) — 문답(問答)

이 폴더는 `기초한의학/한방병리학/총론` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

총론은 두 갈래로 병렬 구성한다. **제1부** 는 병인·변증·허실·장부·복합·병리산물 병리 문서를 『동의보감(東醫寶鑑)』의 편제 순서에 따라 재배열한 것이고, **제2부** 는 서양의학 일반병리학의 표준 주제(세포 손상과 적응, 세포사, 염증, 조직 수복, 혈역학 장애, 유전·환경 질환, 면역병리, 종양 총론, 노화, 진단병리)를 배치한 것이다.

제2부의 열 개 절과 제1부의 변증논치는 각각 `총론/` 아래 독립 하위 폴더를 갖는다. 각 폴더의 상세 목차·작성 현황·대응 논점은 해당 폴더의 README.md에 있다.

## 제1부 — 한의학 병인·병리 이론

| 절 | 하위 폴더 | 표제어 수 |
| --- | --- | --- |
| 1-1~1-6 병인·변증·허실·장부·복합·병리산물·비증 | `총론/변증논치와 논점 대응/` | 29편 |

> 간혈허(肝血虛)·간기울결(肝氣鬱結)·신양허(腎陽虛) 세 편은 저장소 전체의 서술 기준(구조·깊이·인용 밀도)으로 삼는 기준 문서다.
