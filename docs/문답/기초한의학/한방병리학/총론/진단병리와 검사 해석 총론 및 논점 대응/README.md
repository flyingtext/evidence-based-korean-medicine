# 진단병리와 검사 해석 총론 (診斷病理·檢査解釋 總論, Diagnostic Pathology and Test Interpretation) — 문답(問答)

이 폴더는 `기초한의의학/한방병리학/총론/진단병리와 검사 해석 총론 및 논점 대응` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

검사 소견이 무엇을 반영하는가, 위양성·위음성의 구조, 선별과 진단의 구분을 다룬다. 근거를 3층(①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비)으로 층화한다.

## 목차

- 육안·현미경 관찰의 기초(검체 처리·염색법·조직학적 판독)는 어떤 원리인가? (작성 예정)
- 면역조직화학과 분자병리는 표지자 기반 계통 추적을 어떻게 수행하는가? (작성 예정)
- 염증 지표·효소·자가항체·종양표지자는 각각 무엇을 반영하는가? (작성 예정)
- 위양성·위음성의 구조와 검사 전 확률은 진단 추론을 어떻게 바꾸는가? (작성 예정)
- 선별과 진단의 구분, 과잉진단의 병리학적 배경은 무엇인가? (작성 예정)
- 사진(四診) 자료와 검사 소견은 같은 층위의 자료인가? 하나를 다른 하나의 근거로 환원할 수 있는가? (작성 예정)
- 설진(舌診)·맥진(脈診)의 재현성과 객관화 연구는 어느 수준에 도달했는가? (작성 예정)
- 한의 임상에서 검사 결과지를 읽을 때 의뢰가 필요한 소견은 무엇인가? 임의 판단을 피해야 하는 영역은? (작성 예정)
