# 호흡기계(呼吸器系) — 문답(問答)

이 폴더는 `기초한의학/한방생리학/각론/호흡기계` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 폐주기(肺主氣)와 종기(宗氣)는 호흡생리의 무엇에 해당하는가? (작성 예정)
- 신주납기(腎主納氣)는 왜 폐-신 협동으로 설명되는가? (작성 예정)
- 선발숙강(宣發肅降)은 기도 생리의 무엇을 가리키는가? (작성 예정)
