# 순환기계(循環器系) — 문답(問答)

이 폴더는 `기초한의학/한방생리학/각론/순환기계` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 심주혈맥(心主血脈)과 심박출량 조절은 어떻게 대응하는가? (작성 예정)
- 맥(脈) 이론과 혈관내피 기능은 어떤 접점이 있는가? (작성 예정)
- 혈압은 어떤 기전으로 단기·장기 조절되는가? (작성 예정)
