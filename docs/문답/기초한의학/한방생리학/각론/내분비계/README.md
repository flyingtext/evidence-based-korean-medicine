# 내분비계(內分泌系) — 문답(問答)

이 폴더는 `기초한의학/한방생리학/내분비계` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 시상하부-뇌하수체 축 호르몬은 한의학 어느 이론과 대응하는가? (작성 예정)
- 인슐린·글루카곤 등 췌장 호르몬은 소갈병 이론과 어떻게 연결되는가? (작성 예정)
- 바소프레신과 옥시토신은 신주수(腎主水) 이론과 어떤 접점이 있는가? (작성 예정)
