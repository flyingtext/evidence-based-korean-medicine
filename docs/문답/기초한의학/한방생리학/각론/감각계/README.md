# 감각계(感覺系) — 문답(問答)

이 폴더는 `기초한의학/한방생리학/각론/감각계` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 오장 개규(五臟開竅) 이론과 감각기 생리는 어떻게 대응하는가? (작성 예정)
- 통증은 어떤 경로로 전달되고 조절되는가? (작성 예정)
- 침 자극의 득기(得氣) 감각은 무엇으로 설명되는가? (작성 예정)
