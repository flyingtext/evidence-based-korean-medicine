# 진단학(診斷學) — 문답(問答)

이 폴더는 `기초한의학/진단학` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 사진(四診: 망문문절)은 각각 무엇을 보는가? (작성 예정)
- 맥진에서 부맥·침맥·삭맥·지맥의 임상적 의미는? (작성 예정)
- 설진에서 백태·황태·흑태는 각각 무엇을 시사하는가? (작성 예정)
- 팔강변증과 장부변증은 어떻게 함께 쓰이는가? (작성 예정)
- 초음파·CT·MRI 소견은 변증과 어떻게 접점을 이루는가? (작성 예정)
