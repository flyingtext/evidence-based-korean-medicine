# 골반회음부(骨盤會陰部) — 문답(問答)

이 폴더는 `기초한의학/해부학/국소해부학/골반회음부(骨盤會陰部)` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 골반강의 경계와 내용물은 무엇인가? (작성 예정)
- 회음부의 구획은 어떻게 나뉘는가? (작성 예정)
- 골반저 관련 경혈의 해부학적 기초는 무엇인가? (작성 예정)
