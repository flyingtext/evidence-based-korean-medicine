# 소화기계(消化器系) — 문답(問答)

이 폴더는 `기초한의학/해부학/계통해부학/소화기계(消化器系)` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 소화관의 층 구조는 어떻게 이루어져 있는가? (작성 예정)
- 복막과 장간막의 배치는 어떠한가? (작성 예정)
- 복부 자침 시 유의할 장기 위치는 어디인가? (작성 예정)
