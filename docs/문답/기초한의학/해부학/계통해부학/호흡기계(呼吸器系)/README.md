# 호흡기계(呼吸器系) — 문답(問答)

이 폴더는 `기초한의학/해부학/계통해부학/호흡기계(呼吸器系)` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 기도의 분지 구조는 어떻게 되는가? (작성 예정)
- 흉막과 폐의 위치 관계는 어떠한가? (작성 예정)
- 배부·흉부 자침에서 기흉을 피하려면 어떤 해부가 필요한가? (작성 예정)
