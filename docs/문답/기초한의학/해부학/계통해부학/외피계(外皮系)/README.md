# 외피계(外皮系) — 문답(問答)

이 폴더는 `기초한의학/해부학/계통해부학/외피계(外皮系)` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 피부의 층 구조는 어떻게 되는가? (작성 예정)
- 피부 부속기의 해부는 어떠한가? (작성 예정)
- 피부분절(dermatome)과 십이피부(十二皮部)는 같은 개념인가? (작성 예정)
