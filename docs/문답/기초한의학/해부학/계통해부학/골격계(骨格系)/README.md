# 골격계(骨格系) — 문답(問答)

이 폴더는 `기초한의학/해부학/계통해부학/골격계(骨格系)` 과목·분야에서 학습자가 흔히 묻는 질문을 모은다. 개별 문답 문서는 근거 우선·출처 명시 원칙에 따라 작성하며, 아직 작성되지 않은 항목은 "(작성 예정)"으로 표기한다.

## 목차

- 뼈의 미세구조는 어떻게 이루어져 있는가? (작성 예정)
- 골격의 부위별 분류 기준은 무엇인가? (작성 예정)
- 경혈 취혈의 골도분촌법은 어떤 골격 지표를 쓰는가? (작성 예정)
