# 문답(問答)

학습용 질의응답(Q&A) 모음 폴더. 최상위 README.md의 프로젝트 구조(아스키 아트)와 동일한 깊이로 하위 폴더를 구성하여, `기초한의학/`·`임상한의학/`·`주제조사/`의 모든 과목·각과·세부 분야마다 별도 폴더와 README.md(그 분야의 문답 목차)를 둔다. 개별 문답 문서는 RUN.md 워크플로우(근거 우선·출처 명시)에 따라 작성한다.

```
문답/
├── 기초한의학/
│   ├── 경락경혈학/
│   ├── 기공학/
│   ├── 방제학/
│   │   └── 제형론/
│   ├── 본초학/
│   ├── 약리학/
│   │   ├── 자율신경계 약물/
│   │   ├── 중추신경계 약물/
│   │   ├── 심혈관계 약물/
│   │   ├── 호흡기계 약물/
│   │   ├── 소화기계 약물/
│   │   ├── 내분비계 약물/
│   │   ├── 신장이뇨제/

│   │   ├── 면역계 약물/
│   │   └── NSAIDs와 스테로이드/
│   ├── 예방한의학/
│   ├── 원전/
│   ├── 의사학/

│   │   ├── 결합조직/

│   ├── 추나의학/
```

각 하위 폴더의 `README.md`가 그 분야의 문답 목차다. 예: `기초한의학/본초학/README.md`, `임상한의학/내과/간계/README.md`.
