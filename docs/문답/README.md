# 문답(問答)

학습용 질의응답(Q&A) 모음 폴더. 한의과대학 각 과목·각과에서 흔히 접하는 질문을 모아, 기초한의학과 임상한의학의 분류 체계(`기초한의학/`, `임상한의학/` 폴더의 중분류)를 그대로 따라 목차화한다. 개별 문답 문서는 RUN.md 워크플로우(근거 우선·출처 명시)에 따라 작성하며, 이 README는 그 목차이자 로드맵이다.

**목차 구성 원칙**: ① 기초, ② 임상 두 대분류 아래 각 과목·각과별로 소절을 두고, 그 과목·과에서 학습자·초심자가 가장 흔히 묻는 질문을 나열한다. 각 질문은 "작성됨"(해당 문답 문서 존재)/"(작성 예정)"으로 상태를 표기한다. 개별 문답 문서 파일명은 질문 자체를 표제어로 삼는다.
