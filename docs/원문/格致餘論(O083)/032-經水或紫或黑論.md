# 經水或紫或黑論

<!-- source-id: O083:p032 -->
> 서명: 格致餘論
> 원본 파일: `O/O083.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

經水者，陰血也。陰必從陽，故其色紅，稟火色也。血為氣之配，氣熱則熱，氣寒則寒，氣升則升，氣降則降，氣凝則凝，氣滯則滯，氣清則清，氣濁則濁。往往見有成塊者，氣之凝也。將行而痛者，氣之滯也。來後作痛者，氣血俱虛也。色淡者，亦虛也。錯經妄行者，氣之亂也。紫者，氣之熱也。黑者，熱之甚也。人但見其紫者、黑者、作痛者、成塊者，率指為風冷，而行溫熱之劑，禍不旋踵矣。良由《病源》論月水諸病，皆曰風冷乘之。宜其相習而成俗也。或曰：黑，北方水之色也。紫淡於黑，非冷而何？予曰：經曰亢則害，承乃制。熱甚者，必兼水化。所以熱則紫，甚則黑也。況婦人性執而見鄙，嗜欲加倍，臟腑厥陽之火，無日不起，非熱而何？若夫風冷，必須外得，設或有之，蓋千百而一、二者也。
