# 人迎氣口論

六陽六陰脈，分屬左右手。心、小腸、肝、膽、腎、膀胱在左，主血；肺、大腸、脾、胃、命門、三焦在右，主氣。男以氣成胎，故氣為之主；女以血成胎，故血為之主。若男子久病，氣口充於人迎者，有胃氣也，病雖重可治；女子久病，人迎充於氣口者，有胃氣也，病雖重可治。反此者逆。或曰：人迎在左，氣口在右，男女所同，不易之位也。脈法贊曰：左大順男，右大順女，何子言之悖耶？曰：《脈經》一部，王叔和諄諄於教醫者，此左右手以醫者為主而言，若主於病者，奚止千里之謬！
