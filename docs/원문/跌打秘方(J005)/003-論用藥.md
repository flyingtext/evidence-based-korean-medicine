# 論用藥

自然銅乃接骨之要藥，惟敷藥不用，湯飲必須用之。以續斷、五加皮為佐；活血以紅花、當歸為主；理氣以青皮、枳殼為先；破血以桃仁、木通為君；補血以芍藥、生地為最。若欲疏風先須理氣，活血亦須順氣為要。在足木瓜為引經藥，在手桂枝、桑枝亦可。
