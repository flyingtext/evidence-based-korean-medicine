# 頭痛門

<ins>總括</ins>

小兒頭痛之證不一，當分在表在裡之別。如在裡者，屬內熱熏蒸也；在表者，外感寒風也。如風寒外閉，法宜疏散之；內熱熏蒸，以清解攻之。

<ins>風寒頭痛</ins>

風寒頭痛者，乃屬太陽經受邪也。其候上及巔頂，下連額角之傍，不時作痛，惡寒無汗身體發熱。法宜取汗，悉以清空膏主之。如痛甚者，於本方中加細辛；熱盛便秘者，於本方中加大黃。

<ins>內熱頭痛</ins>

內熱頭痛者，屬陽明胃經。因小兒肥甘無節，胃火上炎，故發時鼻乾目痛，上至頭，下至齒頰，疼痛無有定時。先清其火，用加味茶調散主之。如便閉，加入大黃攻之。
