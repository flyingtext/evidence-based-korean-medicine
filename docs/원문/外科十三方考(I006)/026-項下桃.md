# 項下桃

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

此症生於腮下, 結一大核, 形如胡桃, 若不受熱, 善於保重者, 其核即軟如棉, 若偶有惱怒時, 其核即硬大, 牽連舌根, 頗類重舌, 以重舌之方治之, 又多不效, 故此症必須取核, 方有痊愈希望. 可照前痰核法落核, 內服中九丸兼金蚣丸, 其他熏洗、生肌、平口、諸法, 皆與痰核相同.
