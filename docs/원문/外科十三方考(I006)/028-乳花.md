# 乳花

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

此瘡生於乳頭之上, 或左右二旁, 是名乳花, 亦名乳癰, 眼孔之多, 與蜂窩相似. 治法外用麻涼膏貼之, 內服中九丸兼托裡之劑; 至七天之後, 痛即漸止, 四圍破皮, 照前法熏洗, 生肌、平口, 須忌發物, 方保無虞. 或貼隔紙膏亦佳.
