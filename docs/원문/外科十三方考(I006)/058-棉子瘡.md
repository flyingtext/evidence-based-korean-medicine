# 棉子瘡

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

此症多因早年患楊梅毒時, 服食輕粉、汞劑過多, 欲求速效, 致後日發生此種粉霜毒氣, 遍身關節疼痛, 骨里潮熱, 氣逆則痰不行, 遂結成豆子大小之粒, 漸漸長大, 皮膚不紅, 肉內作痛, 延至日久, 醫者多以行痰順氣之劑治之, 屢治不效, 後遂潰而出水, 與棉絮相似, 此刻其痛更甚, 初不知其為誤服輕粉, 毒入骨髓之所致也. 治法內服中九丸兼金蚣丸, 再加托裡排膿之劑, 成膿者可治, 不成膿者難治. 成膿後, 用解毒膏貼之, 插藥線三次, 俟膿干, 取出絮團後, 以熏洗湯洗淨, 再摻加味天然散收功.
