# 孫真人枕上記

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

侵晨一碗粥，夜飯莫教足。
撞動景陽鍾，扣齒三十六。
大寒與大熱，且莫貪色欲。
醉飽莫行房，五臟皆翻覆。
艾火漫燒身，爭如獨自宿。
坐臥莫當風，頻於暖處浴。
食飽行百步，常以手摩腹。
莫食無鱗魚，諸般禽獸肉。
自死獸與禽，食之多命促。
土木為形象，求之有恩福。
父精母血生，那忍分南北。
惜命惜身人，六白光如玉。
