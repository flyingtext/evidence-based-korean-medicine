# 發狂

傷寒，發狂奔走，罵詈不避親疏，此陽有餘、陰不足，三一承氣湯（十三）加當歸、薑、棗名當歸承氣湯，以利數行，候微緩以三聖散（二十七）吐之，後用涼膈散（二十三），黃連解毒湯（二十一）調之。譫妄發狂，逾垣上屋，赴井投河，皆為陽熱極甚，用三一承氣合解毒下之。驚悸癲狂，三一承氣湯。發狂極甚，投河入井者，三下不過，不可攻下，便當湧之，以瓜蒂散（二十六），吐出痰涎、宿物，一掃而愈，後以甘露飲（三十四）之類調之。
