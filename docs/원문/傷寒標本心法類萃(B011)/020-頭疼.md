# 頭疼

頭疼之證，無問風寒暑濕雜病，自汗頭疼，俱宜白虎湯（二十二），或加川芎、荊芥尤妙。頭疼久不愈，必致喪明，宜先湧痰，次用白虎加減。風眩痰逆、喘嗽頭疼，茯苓半夏湯（三十八），頭疼、肢體痛，黃連解毒湯（二十一）；頭疼、口乾，桂苓甘露飲（三十四），風疾喘嗽頭疼，白虎（二十二）、半夏橘皮湯（三十七），風熱頭疼，心煩昏憒，人參石膏湯（三十五），傷寒壯熱頭疼，不臥散（四十五）。
