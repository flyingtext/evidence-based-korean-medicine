# 風寒俱中

風寒俱中之證：頭痛項強、肢體疼、手足溫，為中風；反無汗、惡寒、脈浮緊，為傷寒也。或頭項疼、腰脊強、身體拘急、指末微厥、不自汗，為傷寒；反煩躁而脈緩者為傷風也。風則傷衛，寒則傷榮，榮衛俱傷，則表裡熱甚者，通宜以大青龍湯（六），或雙解散（五十四）最妙。
