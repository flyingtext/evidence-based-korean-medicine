# 兩感

兩感謂一日太陽、少陰兩症俱見，二日陽明與太陰俱病，三日少陽與厥陰俱病，前六經之證是也。小柴胡湯（九）、涼膈散（二十三）、五苓散（二十四）、天水散（五十二）、通聖散（五十三）、雙解散（五十四）、大柴胡湯（八），可選用之。熱勢甚，欲可下者，三一承氣湯（十三），或解毒（二十一）合承氣湯。
