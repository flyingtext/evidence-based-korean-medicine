# 留飲

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

一切留飲不散，五苓散（二十四）、桂苓甘露飲（三十四）、黃連解毒湯（二十一）、涼膈散（二十三）、白虎湯（二十二）、小陷胸湯（十八）、三一承氣湯（十三）選用。傷寒表未罷，心下有水氣，乾嘔、發熱而咳，或嘔，或利，或噎，或小便不利，小腹滿，或喘者，小青龍湯（七）。
