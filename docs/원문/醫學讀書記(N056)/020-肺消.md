# 肺消

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

心移寒於肺, 為肺消; 肺消者, 飲一溲二, 死不治. 肺居上焦, 而司氣化. 肺熱則不肅, 不肅則水不下; 肺寒則氣不化, 不化則水不布. 不特所飲之水直趨而下, 且並身中所有之津, 盡從下趨之勢, 有降無升, 生氣乃息, 故曰: 「飲一溲二, 死不治. 」
