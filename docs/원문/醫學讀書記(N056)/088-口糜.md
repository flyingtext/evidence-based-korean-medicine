# 口糜

王肯堂治許少薇口糜, 謂非乾薑不愈, 卒如其言. 又從子懋鋙, 亦患此, 勢甚危急, 欲飲冷水, 與人參、白朮、乾薑各二錢, 茯苓、甘草各一錢, 煎成冷飲, 日數服, 乃已. 蓋土溫則火斂, 人多不能知. 此所以然者, 胃虛食少, 腎水之氣逆而乘之, 則為寒中, 脾胃虛衰之火被迫上炎, 作為口瘡. 其症飲食少思, 大便不實, 或手足逆冷, 肚腹作痛是也.
