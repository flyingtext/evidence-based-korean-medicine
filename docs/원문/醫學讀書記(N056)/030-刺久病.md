# 刺久病

刺久病者, 深內而久留之, 間日而復取之, 必先調其左右, 去其血脈. 愚謂此刺道也, 可通藥之用矣. 以其病久入深, 故必深內; 以其陰氣難得, 故必久留. 間日者, 休其氣也. 調其左右, 去其血脈者, 調其未病之處, 使血脈流通也. 以丸藥攻其病, 以甘藥養其正, 且進且止, 毋速其效, 以平為期, 藥之道盡矣.
