# 枳實梔子豉湯

<!-- source-id: N056:p076 -->
> 서명: 醫學讀書記
> 원본 파일: `N/N056.txt`
> 원본 SHA-256: `30a61a4d3caf63dcac78ba02533e8e28ae1a58498891a6049756f191f66e8dcd`
> 상태: 인터넷 판본·독립 자료 대조 교감 완료

仲景治大病瘥後, 勞復者, 枳實梔子豉湯主之. 廣劑加蔥白、粟米、雄鼠糞. 範汪加桂枝、大黃、麻黃; 又方去梔、豉, 加甘草、桂心、大黃、芒硝. 《千金》加石膏、鼠糞. 崔氏單加鼠糞一味. 《古今錄驗》加麻黃、大黃; 一加鼠糞、大黃; 一去梔、豉, 加鼠糞; 一加鼠糞、麻黃; 一去梔子, 加甘草、大黃、芒硝. 許仁則又加蔥白、生薑、乾葛、麥冬、生地. 或主表, 或主裡, 或兼主表裡, 或兼養, 或兼滋, 或表裡與滋養兼施, 凡十餘變, 而梔豉之法盡矣.
