# 麻黃湯

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

寒邪傷人陽氣, 鬱而成熱, 皮膚閉而成實, 麻黃輕以去實, 辛以發陽氣, 溫以散寒氣. 杏仁佐麻黃通肺氣, 使腠理開泄, 王好古謂其為治衛實之藥者是也. 然泄而不收、升而不降, 桂枝、甘草雖以佐之, 實監製之耳! 東垣云: 麻黃湯是陽經衛藥也, 開腠理使陽氣申泄, 此藥為衛實也.
