# 四肢不舉

<!-- source-id: N056:p022 -->
> 서명: 醫學讀書記
> 원본 파일: `N/N056.txt`

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

玉機真臟論云: 脾脈太過, 則令人四肢不舉; 其不及, 則令人九竅不通. 《靈樞》本神篇云: 脾氣虛則四肢不用; 實則腹脹、涇溲不利. 蓋脾虛則營衛涸竭, 不能行其氣於四肢, 而為之不舉; 脾實則營衛遏絕, 亦不能行其氣於四肢, 而為之不舉. 九竅亦然. 兩經互言之者, 所以窮其變也.
