# 寸口分診臟腑定位

脾與胃合, 肝與膽合, 腎與膀胱合, 皆足經也. 其臟腑皆相依附, 則其診候亦應同在一部. 如左關候肝、膽, 右關候脾、胃, 左尺候腎與膀胱是已. 肺與大腸合, 心與小腸合, 心包絡與三焦合, 皆手經也. 其臟腑不相依附, 則其診候亦不必同在一部. 按《內經》云: 尺外以候腎, 尺裡以候腹. 又云: 前以候前, 後以候後; 上竟上者, 胸喉中事. 是以大腸當候於右尺之裡, 小腸當候於左尺之裡, 三焦分立上、中、下三部. 如此, 則左心、小腸, 右肺、大腸之謬, 可不辨而自著矣.
