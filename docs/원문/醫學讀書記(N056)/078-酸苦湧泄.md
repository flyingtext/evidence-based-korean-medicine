# 酸苦湧泄

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

院河南治天行熱, 解毒多用苦酒、豬膽、生艾汁、苦參、青葙、葶藶之屬. 《外臺》單用苦參一兩, 酒煮, 並服, 取吐如烊膠便愈. 張文仲療傷寒、溫病等, 三日以上, 胸中滿, 用苦酒半升, 豬膽一枚, 和服, 取吐. 蓋即《內經》酸苦湧泄之義. 然今人之用此者罕矣.
