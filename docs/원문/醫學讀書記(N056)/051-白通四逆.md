# 白通四逆

白通、四逆, 俱用薑、附, 俱為扶陽抑陰之劑. 而白通意在通陽, 故用蔥白, 凡厥而下利脈微者用之; 四逆意在救里, 故用甘草, 凡厥而清穀不止者用之. 若通脈四逆, 則進而從陽, 以收外散之熱; 白通加人尿豬膽汁, 則退而就陰, 以去格拒之寒也.
