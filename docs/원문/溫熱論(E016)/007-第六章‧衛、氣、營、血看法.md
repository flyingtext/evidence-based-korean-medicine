# 第六章‧衛、氣、營、血看法

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

大凡看法：衛之後方言氣，營之後方言血。在衛汗之可也；到氣才宜清氣；乍入營分，猶可透熱，仍轉氣分而解，如犀角、元參、羚羊等物是也；至入於血，則恐耗血動血，直須涼血散血，如生地、丹皮、阿膠、赤芍等物是也。

若不循緩急之法，慮其動手便錯耳。
