# 不必忌而忌之過

張子和曰臟毒酒毒下血嘔血等症如婦人三十以下血閉及六七月間血痢婦初得孕擇食者以上皆不禁口凡久病之人胃氣虛弱者忽思葷茹亦當少少與之圖引漿水穀氣入胃此權變之道也若專以淡粥責之則病不悅而食減不進胃氣所以難復病所以難痊此忌之之過也智者通之
