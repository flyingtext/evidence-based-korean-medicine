# 消渴泄瀉

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

先用白朮、白芍藥, 炒為末. 調服後, 卻服消渴藥.

消渴, 養肺、降火、生血為主. 分上中下治.

黃連末、天花粉末、人乳、生藕汁、生地黃汁.

上二物汁為膏, 入上藥搜和, 佐以薑汁和蜜湯為膏, 徐徐留於舌上, 白湯少許送下.

能食加軟石膏. 栝蔞根治消渴神藥.
