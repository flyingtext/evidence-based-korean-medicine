# 第十一·里黑舌

舌見紅色。內有乾硬黑色。形如小長舌有刺者。此熱毒熾甚。堅結大腸。金受火制。不能平木故也。調胃承氣湯下之。

【介按】苔至黑色而有刺。舌上必然乾燥無津。臍腹必然硬滿耕痛。大便必然秘結。此是胃中津液將涸。熱結大腸。故用調胃承氣湯。以解邪熱而調胃液。但證既如是。不若用大承氣湯。奏效較速也。
