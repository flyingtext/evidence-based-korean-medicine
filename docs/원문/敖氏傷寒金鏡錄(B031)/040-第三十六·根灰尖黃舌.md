# 第三十六·根灰尖黃舌

舌見根微黑。尖黃隱見。或有一紋者。脈實，用大承氣湯下之。脈浮渴飲水者。用涼膈散解之。十可救其二三。

【介按】舌見根黑尖黃。或邊黃中心焦黑起刺。而脈實者。臍腹必脹滿硬痛。此係陽明實熱之症。故可用大承氣湯。苦寒以泄陽明之熱。急下以救津液之虛。若脈浮而口渴飲水者。邪未入腑。猶可用涼膈散以解熱也。
