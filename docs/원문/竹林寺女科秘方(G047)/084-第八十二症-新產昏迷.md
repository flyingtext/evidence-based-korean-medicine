# 第八十二症 新產昏迷

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

婦人新產，以至昏迷，不知人事。此症初產，不可妄投藥
劑。宜用芎歸湯，若有汗，宜用歸耆湯。

‧芎歸湯
川芎二錢 當歸一兩 生薑三片
水煎，溫服，臨用入酒下更好。

‧歸耆湯
當歸二兩 黃耆一兩 生薑三片
水煎服。黃耆恐氣逼，用時須當斟酌。
