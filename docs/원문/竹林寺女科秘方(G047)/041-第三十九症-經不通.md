# 第三十九症 經不通

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

婦人經水不通，兼寒熱，皆無別症，用通經丸破其血立安
。若有潮熱，形體瘦弱，不可服通經丸。如服無效，且要
退去潮熱，生其血，方可服通經丸。

‧通經丸
水蛭五錢 虻蟲炒，五錢 牛膝三兩
炒荊芥一兩
共研細末，早米糊為丸，每服三十丸，空心
酒送下。
