# 第十七症 帶如柑水

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

婦人白帶，如米柑水，太陰所出，肺乃太陰是也。四物合
二陳湯，服一月或半月，其白自收。忌魚，如食，必復發
矣。

△註：註：肺：似當為脾。

‧ 四物合二陳湯
當歸 白芍 半夏 陳皮 川芎 熟地 甘草 茯苓
等分
水煎服。
