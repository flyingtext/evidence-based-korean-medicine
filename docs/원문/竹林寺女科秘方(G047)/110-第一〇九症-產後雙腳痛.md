# 第一〇九症 產後雙腳痛

婦人產後，雙腳痛不可忍者，乃下血虛也。下元清冷，寒
邪入骨。宜用烏藥順氣散加法。

‧烏藥順氣散加法
烏藥一錢 僵蠶一錢 桔梗一錢 江枳殼一錢
天麻一錢 白芷五分 川芎五分 乾薑五分
石南藤生，一錢 乳香五分 陳皮五分
麻黃五分 甘草二分 桑寄生一錢 蔥頭帶根，
一根
加薑三片，用水煎服。
