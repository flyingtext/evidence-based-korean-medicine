# 第三症 經水或多或少

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

婦人月水不調，陰血內衰，面色萎黃，五心發熱，臨經之
際，小腹作痛，腹腿重酸，血來或多或少未定，頭目暈眩
，飲食不思。先用清涼散退去煩熱，後用調經四物湯，一
月有效。

‧清涼散
黃芩一錢 知母一錢 當歸一錢
丹皮二錢 白芍一錢 茯苓一錢
水煎，不拘時服。

‧調經四物湯
當歸一錢 生地一錢 丹皮一錢
白芍二錢 香附一錢 砂仁一錢 川芎五分
黃芩二錢
加生薑三片，水煎，空心服。
