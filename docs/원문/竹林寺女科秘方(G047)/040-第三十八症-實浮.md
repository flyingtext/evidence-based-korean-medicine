# 第三十八症 實浮

婦人肚大，四肢浮腫，青筋出見，大便堅實，人形瘦弱。
不思飲食。用醉公丸瀉之，三次後，用緊皮丸除根。

‧醉公丸
大戟五錢 三棱一兩 黑牽牛五錢
芫花一兩 甘遂五錢 莪朮一兩 江枳殼五錢
大黃一兩
共研細末，早米糊為丸，如桐子大，每服三
十丸，空心清水送下。

‧緊皮丸
厚朴一兩 香附一兩 青皮二兩 砂仁二兩
陳皮一兩 草果去殼，二兩
共研細末，米糊為丸，每服六十丸，空心清
湯送下。
