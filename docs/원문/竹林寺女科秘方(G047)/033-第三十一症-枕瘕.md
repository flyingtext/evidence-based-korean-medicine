# 第三十一症 枕瘕

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

婦人枕瘕，其血結成一塊，如肥皂大，或左或右走動，面
青，人形瘦弱，不思飲食。此症可治，宜用三棱丸，先破
其血，後進用四物湯，補其血，其病自癒。四物湯，見上
十六症。

‧三棱丸
三棱三兩 枳殼三兩 香附四兩 檳榔三枚
莪朮三兩
共研細末，醋糊為丸，空心清湯送下。
