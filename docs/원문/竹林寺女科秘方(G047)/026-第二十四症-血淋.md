# 第二十四症 血淋

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

婦人經來，小便痛如刀割，此症血淋也。先用牛膝湯一劑
止痛，後用海金砂丸。

‧牛膝湯
牛膝酒洗 麝香三分 乳香一錢
水煎，不拘時服。

△按： 牛膝：原本無藥量。

‧海金砂丸
海金砂二兩 豬苓二兩 澤瀉二兩 白朮二兩
車前子三兩 木通一兩 萆薢一兩
共研末，早米糊為丸，空心白湯送下。
