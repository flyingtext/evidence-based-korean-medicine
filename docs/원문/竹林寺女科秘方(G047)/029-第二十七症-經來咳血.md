# 第二十七症 經來咳血

婦人經來，吐血咳嗽，痰氣急滿吐紅，五心煩熱，乃傷生
冷，又觸熱毒，人皆作逆經治之，故不驗。治法宜用五虎
湯，次紫菀湯。

‧五虎湯
廣皮二錢 甘草二錢 桑皮一錢 桔梗一錢
蘇子三錢 石膏三錢 知母一錢 枳殼一錢
水煎，不拘時服。

‧紫菀湯
阿膠一錢 桑皮一錢 五味子一錢
紫菀一錢 杏仁一錢 冬花一錢 玉桔梗一錢
蘇子一錢 貝母一錢 知母一錢 廣陳皮五分
枳實一錢
水煎，臨臥時服。
