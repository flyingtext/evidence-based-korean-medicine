# 《醫驗隨筆》序

自古奉功偉節，奇才異能，非托之文字則閱世不足以傳。漢司馬遷修史，凡屬藝文不論钜細，一字不肯割愛，千有餘歲，吾人猶得取而讀之者亦云幸矣。英儒密納約翰向稱為辯雄泰斗，著作等身，嘗謂智者干慮必有尋失，愚者千慮必有一得，合者和之，否者正之，有寸長則不宜抹煞，閉塞民智，阻天下之言論自由，信斯言也。其巍然有濟世之功者，宜何如寶重乎？余輯《無錫醫學書目考》，深歎其有目無書，比校刊王旭高退思集類方歌注，益歎文獻之易湮。訪諸名醫後裔，或以無暇著述，僅存方薄，或則秘為手澤，無意付刊，久而佚散。是以書目所有，百僅一二可見傳佈流通，吾儕之責。梁溪沈奉江先生，文學世家，賦性穎悟，伉爽不群，超逸如神仙中人。醫學師事馬徵君培之，生平治驗，名公钜室，鹹相信服。而先生飄然物外，如幽蘭自芳，不以自炫，其心志之所存者大，形跡之所寄者小，而矯矯固足以名世也，先生醫學湛深，嘗慕遜清徐大椿，泰西裴乃德龍蒲束之為人，現為吾邑中醫友誼會理事。向所著《全球醫通》藏稿未刊，日久屢索不得，此則不即付諸手民之弊，殊為可惜。小兒逢儒讀岐黃書，從先生游而詔醫驗甚夥，欽遲無己，屬操筆劄，隨聞記錄，積久成冊，惟年湮歲遠者，四診或有闕略，錄寄《三三醫書》刊入專著，庶啟悟學者之性靈，裨益醫林，實非淺鮮也。因識其緣起如此。

民國第一甲子夏月無錫周小農別署伯華謹序
