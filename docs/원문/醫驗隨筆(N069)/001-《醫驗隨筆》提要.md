# 《醫驗隨筆》提要

方書所載之因症脈治有定，而臨床診治則變幻無定。是故醫生於精研方書之外，尤當熟玩醫案，庶幾神明變化，活法在人，不為疾病所困矣。本書系無錫中醫友誼會理事沈奉江先生口述，門人周逢儒君筆記。案雖不多，而診斷之精確，用藥之工穩，直可上追古人，下啟來學。蓋沈君為孟河馬培之徵君高足，學有根柢，識超儕輩，曾著《全球醫通》一書，日久遺失，知者惜之。
