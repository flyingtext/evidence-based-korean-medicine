# 《醫病簡要》序

<!-- source-id: N067:p002 -->
> 서명: 醫病簡要
> 원본 파일: `N/N067.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

張君畹香先生，家住紹城洗馬池。讀書時喜學醫，博覽群書。迨中年，求診輒效，由親戚而遍及陌路，著手成春，一時膾炙人口。憶余兄弟苕齡，時患病就醫。爾時見張公與先父傾蓋談心，視其白髮童顏，須長盈尺，年近古稀，此後不復再見。其哲嗣朴山先生，克紹薪傳，雖不及乃父之聲名廣遠，亦頗有妥當名譽，昕夕過從。今年秋，其賢孫晴岩兄前年由河南回來，出其乃祖手著《簡要》並附醫案兩卷，凡傷寒、溫邪、風溫、熱入血室、痢疾、瘧疾、伏暑等證，分門別類，細閱一遍，愛不釋手，其議論別有會心，衷諸古，而不泥古，俾後學一目了然，補前賢所未備，益後學於無窮，爰名其書曰《醫病簡要》。恨不醵資，付諸梨棗，以傳後世。茲先述其得是書之緣起云爾。民國貳年臘月後學包越瑚謹撰時年五十有六歲
