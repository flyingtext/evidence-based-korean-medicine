# 한의학 고전 원문 변환·번역 지침

`source/`의 TXT는 수정하거나 이동하지 않는 보존 원본이다. 자동 변환본은 먼저 `_가져오기/`에 생성하고 정본 대조 및 사람의 검수를 마친 뒤 정식 원서 폴더에 병합한다.

원자료는 jicheng.tw의 고전 의서 데이터를 기반으로 하며, 이 출처를 최상위 및 개별 원서 README에 명시한다.

## 변환 단계

전체 서지 목록만 만들 때는 다음 명령을 사용한다.

```bash
python3 scripts/convert_classics.py --catalog-only
```

특정 원서를 변환할 때는 원본 상대경로 정규식을 지정한다.

```bash
python3 scripts/convert_classics.py --include '^N/N000\.txt$'
python3 scripts/validate_classics.py
```

자동 변환기는 UTF-8 BOM과 줄바꿈을 정규화하고, `[book]` 서지 정보와 `[h2]` 이하의 구조를 Markdown으로 옮긴다. 원문의 글자, 이체자 및 결자를 임의로 바꾸지 않으며, 확인된 교정 오버레이만 파생본에 적용한다. 각 산출물에는 원본 경로, SHA-256, `source-id`를 기록한다.

결자와 깨진 문자 후보는 다음 명령으로 수집한다.

```bash
python3 scripts/audit_classics.py
```

후보는 인터넷에서 동일 조문과 신뢰 가능한 저본을 검색해 대조한다. 확인된 수정만 `data/classics_corrections/`의 원자료 계열별 JSON 조각에 전후 문자열, 예상 출현 횟수, 근거 URL과 사유를 기록한다. 변환기는 이 교정 오버레이를 합쳐 파생본에 적용하고 개별 원서의 `corrections-applied.json`에 이력을 남긴다. 검색으로 확정하지 못한 글자는 임의로 추정하지 않는다.

후보 목록은 GitHub 파일 크기 제한과 병렬 교감을 고려해 `_가져오기/correction-candidates/part-NNNN.jsonl`에 10,000건씩 나누어 저장한다.

## 표점 단계

원자료가 무표점이거나 표점이 현저히 적으면 원문 Markdown과 별도로 `표점본.md`를 만든다. jicheng.tw에 표점된 대응 판본이 있을 때는 한자열 길이와 순서 일치도를 검증한 뒤 우선 사용한다.

```bash
python3 scripts/generate_punctuated_classics.py
python3 scripts/validate_punctuated_classics.py
```

온라인 대응 판본 자체가 무표점이면 Codex 표점 작업 대상으로 넘긴다. 이 경우 모델은 문장부호만 삽입할 수 있고, 표점을 제거한 결과가 입력 원문과 문자 단위로 완전히 같아야 한다. 불일치한 작업 단위는 자동 폐기하고 재검토한다. 표점본에는 한국식 표점(`.`, `,`, `!`, `?`, `;`, `:`)을 사용하며 원문 보존본과 혼동하지 않게 별도 파일과 검증 보고서를 둔다.

## 번역 단계

각 원서 폴더의 `translation-tasks.jsonl`은 Codex 등 번역 도구에 전달할 작업 단위다. 한 줄이 하나의 번역 단위이며 다음 필드를 가진다.

- `source_id`: 원문과 번역을 결합하는 불변 식별자
- `book`: 원서명
- `heading`: 편·절 제목
- `source_path`: 보존 원본 경로
- `target_original`: 대응하는 Markdown 원문
- `text`: 번역할 한문 원문

번역 산출물은 원문을 수정하지 않고 별도 파일에 저장하며, 반드시 같은 `source_id`를 포함해야 한다. 한 번에 너무 긴 작업 단위는 문단 경계에서 나누되 기존 ID 뒤에 `:c0001`과 같은 하위 ID를 붙인다.

권장 번역 형식은 다음과 같다.

```markdown
<!-- source-id: N000:p003:s0001 -->

## 원문

昔在黃帝……

## 직역

옛날 황제가……

## 역자 해설

해석상 선택이나 이본 차이를 기록한다.
```

직역과 해설을 섞지 않는다. 판독할 수 없는 글자나 사설영역 문자는 문맥으로 복원하지 않고 원문 표기를 유지한 채 해설에 기록한다. 자동 번역 상태, 사람의 검수 상태, 정본 대조 상태는 서로 구분한다.

## 병합 기준

다음 조건을 모두 만족한 원서만 `_가져오기/`에서 정식 폴더로 병합한다.

1. `python3 scripts/validate_classics.py`가 오류 없이 완료된다.
2. 원본과 산출물의 대응 관계가 `manifest.json`에 기록되어 있다.
3. 미처리 태그와 깨진 문자를 사람이 확인했다.
4. 동일 원서의 기존 문서와 중복·충돌 여부를 확인했다.
5. 사용 판본과 디지털 원문의 출처를 확인했다.
