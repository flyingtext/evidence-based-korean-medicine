# 促（陽）

促脈，來去數，時一止復來（《脈經》）。如蹶之趣，徐疾不常（黎氏）。《脈經》但言數而止為促，《脈訣》乃云：並居寸口，不言時止者，謬矣。數止為促，緩止為結，何獨寸口哉！

〔體狀詩〕促脈數而時一止，此為陽極欲亡陰。三焦鬱火炎炎盛，進必無生退可生。

〔相類詩〕見代脈。

〔主病詩〕促脈惟將火病醫，其因有五細推之。時時喘咳皆痰積，或發狂斑與毒疽。促主陽盛之病。促、結之因，皆有氣、血、痰、飲、食五者之別。一有留滯，則脈必見止也。
