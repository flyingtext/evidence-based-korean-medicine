# 第三十二症  血瘕

婦人血瘕，其血結成塊，不時上衝，作痛吐痰，飲後發熱
，食後飽脹不消，遍身瘦弱。此病用通血丸，通其血，則
安而癒。

‧通血丸
三棱一兩  穿山甲二兩  赤芍一兩
蘇木五錢  莪朮一兩  川芎一兩  劉寄奴二兩  紅花
三兩  芫花五錢
共研細末，醋早米糊為丸，空心清水送下。
