# 第九十四症  產後中風

> 서명: 竹林寺女科秘方
> 원본 파일: `G/G047.txt`

> 상태: 자동 변환 원문·정본 미대조

婦人產後中風，忽然牙關緊閉，不知人事。急用通關散，
吹入鼻中，通其關竅。後進烏星湯。通關散，方見上五十
八症。

‧烏星湯
杏仁一錢  薑半夏一錢  制南星一錢
木香一錢  甘草三分  五味子八粒  制川烏一錢
茯苓一錢
水煎，溫服。
