# 第七症  經水如屋漏水

> 상태: 자동 변환 원문·정본 미대조

婦人經來，如屋漏水者，此症元氣虛寒，子宮有瘀血不淨
也。五心作熱，口苦舌乾，遍身疼痛，飲食少思，經盡之
時，略兼白帶。當服溫經湯，生血補血立效。

‧溫經湯
白朮五分  肉桂五分  乾薑七分  甘草二分
丹皮二錢  白芷五分  當歸一錢  熟地一錢
阿膠二錢  生薑三片
水煎，空心溫服。
