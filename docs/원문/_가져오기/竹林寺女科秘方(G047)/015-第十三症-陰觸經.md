# 第十三症  陰觸經

婦人月水，行來已盡，腹中虛空無血，飲食生冷，變成痰
氣，睡臥不得，惡寒，四肢厥冷，此乃陰症也。急用星烏
湯，後用丁胡三建湯。此藥如經服後，若出大汗不止，必
死。不治之症也。

‧星烏湯
杏仁去皮二錢  茯苓二錢  川烏五分
五味子三分  半夏二錢  南星二錢  木香一錢
粉甘草三分
水煎，熱服。

‧丁胡三建湯
丁香二錢  附子二錢  胡椒薑汁一錢
川烏一錢  肉桂二錢  天雄二錢  生薑七片
水煎，不拘時服。
