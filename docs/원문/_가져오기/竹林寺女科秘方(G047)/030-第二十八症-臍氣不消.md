# 第二十八症  臍氣不消

婦人月水，不行數月，臍結一塊，如肥皂形橫過。或痛或
不痛，人形瘦弱，面色青黃，飲食少進，人皆作癥痛，治
之不癒，宜用玄胡散，服半月，其塊自消。後服沉香丸。

‧玄胡散
玄胡索四錢  血餘炭二錢
共研細末，每服一茶匙，酒送下。

‧沉香丸
沉香一兩  小茴香二兩  砂仁三兩
玄胡四兩  烏藥三兩  大茴香二兩
共研細末，米糊為丸，空心酒送下。
