# 第二十二症  經水不止

婦人經來，如水崩不止，出有肉球，大如雞卵，用刀剖開
，內中如石，人迷昏不知人事。此症雖則驚人，無妨，可
治。宜用十全大補湯法治之。

‧十全大補湯
當歸二錢  川芎一錢  肉桂五分  白芍一錢
人參五分  熟地二錢  甘草五分  白朮一錢
黃耆二錢  茯苓一錢
水煎，空心溫服，忌食生冷。
