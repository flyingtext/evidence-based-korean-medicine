# 第十五症  月水前來

婦人月水前來，古云：先而行者，血熱也，宜用涼劑治之
。此症雖云實，亦有虛，看其虛實醫治。虛者內補當歸丸
，實者黃芩芍藥散。服之一月或半月見功矣。

‧內補當歸丸
當歸一兩  乾薑一兩  白芍一兩  肉桂一兩
川芎一兩  阿膠一兩  熟地酒洗一兩  附子一兩
茱萸五錢  甘草五錢  蒲黃一兩  續斷三兩
共研細末，蜜丸，鹽酒送下。
△註：註：內補當歸九：此方用川芎，第六症中此方用杜仲。

‧黃芩芍藥散
黃芩一錢  當歸一錢  升麻一錢  側柏葉二錢
白芍一錢  蒲黃一錢  生地五錢
水煎服。
