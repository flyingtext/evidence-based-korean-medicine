# 第二十一症  白帶成膜

> 상태: 자동 변환 원문·정본 미대조

婦人白帶，形如豬脂膜，此症傷食毒太過，血化成膜，不
可燥，宜服閉白丸。

‧閉白丸
海浮石一兩  海螵蛸一兩  蔻仁一兩
龍骨二兩  赤石脂一兩  砂仁一兩  茯苓二兩
牡蠣二兩
共研細末，早米糊為丸，空心酒送下。清湯
送下亦可。
