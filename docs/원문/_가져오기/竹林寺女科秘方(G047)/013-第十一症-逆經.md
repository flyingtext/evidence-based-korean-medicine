# 第十一症  逆經

婦人月水逆行，從口鼻而出，此症傷熱毒太過。血熱則亂
行，頭痛口燥，宜清血，不可補。宜用犀角黃芩湯，後服
黃連丸。神效。

‧犀角黃芩湯
犀角一錢  枳殼五分  百草霜一錢
生地二錢  白芍五分  橘紅一錢  淡青芩二錢
甘草二分  丹皮一錢  桔梗五分  加生薑三片
水煎服。

‧黃連丸
川黃連去鬚微炒，七錢五分  黃柏微炒，七錢五分
厚朴去皮生薑汁塗炙令香，七錢五分
當歸微炒，五錢  乾薑炮制，五錢  木香勿見火，五錢
地榆五錢  阿膠一兩
研為末，煉蜜和為丸，每服二十九丸。
