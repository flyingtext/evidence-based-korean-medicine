# 第五十八症  胎前中風

婦人胎前中風，牙關緊閉，不知人事。先用通關散吹入鼻
中，自然蘇蘇，後用挑風湯治之。

‧通關散
牙皂一錢  細辛三分  原麝一分
共研細末，吹入鼻內。

‧挑風湯
白朮一錢  白蘚皮二錢  麻黃五分
杏仁二錢  川芎五分  雲茯苓一錢  甘草二分
當歸二錢  獨活五分  青防風二錢
加大棗、生薑，水煎服。
