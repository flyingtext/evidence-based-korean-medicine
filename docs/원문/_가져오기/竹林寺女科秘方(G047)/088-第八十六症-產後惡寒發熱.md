# 第八十六症  產後惡寒發熱

> 원본 파일: `G/G047.txt`

> 상태: 자동 변환 원문·정본 미대조

婦人產後，惡寒發熱，此症外感內傷，宜用補血散，去其
風邪，後服五積散。

‧補血散
當歸二錢  肉蓯蓉二錢  附子一錢  川芎一錢
白芍一錢  茯苓一錢  甘草五分
酒煎，空心服下。

‧五積散
厚朴薑汁制，一錢  枳殼一錢  蒼朮
米柑水浸炒，五分  川芎五分  肉桂五分  桔梗五分
乾薑五分  陳皮一錢  甘草五分  白芍一錢  茯苓一錢
半夏制，一錢
加生薑三片，水煎七分，溫服。
