# 第四十症  痰核

婦人血衰，胃中有痰，嗽則氣逆，或左或右，頭面腫，次
結核，或臍上結塊如杯大，不入膜，不出皮，人形瘦弱。
此症宜運化為先。急用瓦龍丸，然後用鐵線草，上敷六七
次即消。

‧瓦龍丸
三棱一兩  大茴香一兩  海浮石一兩
枳殼一兩  莪朮一兩  川楝子三兩  瓦楞子鍛五錢
紅花一兩  檳榔一兩  台烏藥一兩  廣陳皮一兩
木香一兩
共研細末，面糊為丸，空心服二錢。
