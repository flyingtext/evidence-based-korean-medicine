# 第六症  月水色如豬肝

<!-- source-id: G047:p008 -->
> 서명: 竹林寺女科秘方

婦人月水，如豬肝色，此症生產勞傷，氣血變壞，五心煩
熱，頭目昏迷，遍身疼痛，飲食不思，惡心嘔逆。先用龍
腦湯退其潮熱，後用內補當歸丸調其經水，次月經來即癒
。

△註：昏迷：此指昏蒙。

‧龍腦湯
薄荷一錢  茯苓五分  人參五分 地骨皮二錢
白芍一錢  川芎五分
水煎服。

‧內補當歸丸
阿膠二兩  杜仲二兩  乾薑一兩  肉桂一兩
川斷二兩  當歸二兩  附子一兩  蒲黃一兩
白芍二兩  熟地二兩  茱萸五錢  甘草五錢
共研細末，米糊為丸，每服一百丸，空心鹽
酒湯送下。
