# 第三十五症  積瘕

婦人積瘕在脾，胃中如梅核隔住，胸中飽悶，口吐酸水，
飲食不進，若翻胃之症。宜用烏梅丸，後服九仙奪命丹，
其核自消，飲食方進。忌魚腥煎炒。如若不忌，即刻復發
。忌百日後，無妨矣。

‧烏梅丸
月石一錢  雄黃一錢  綠豆四十九粒
乳香一錢  朱砂一錢  草果一錢  胡椒四十丸粒
木香五分
共研末，烏梅肉為丸，如龍眼大，每服含化
一丸，一日服三丸。

‧九仙奪命丹
厚朴一錢  豆鼓一錢  茯苓一錢  山楂一錢
陳皮一錢  蒼朮一錢  枳殼三錢  草果一枚  木香一錢
共研末，滾湯送下。
