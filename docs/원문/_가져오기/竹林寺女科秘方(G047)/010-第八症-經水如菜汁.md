# 第八症  經水如菜汁

婦人月水，如菜汁，如銅綠水，此症子宮太冷，血大虛，
人形如肥，體盛血衰，不可用涼藥，急用烏雞丸散。旬日
或一月後，血盛，即有孕矣。

‧烏雞丸
天雄一兩  附子一兩  萸肉一兩  當歸二兩
白芍二兩  茯苓二兩  蓯蓉二兩  熟地二兩
川芎八分  肉桂五分  甘草五分  鹿血片一錢
用白絲毛烏骨雞肉四兩，同藥末曬乾，共研
細末，早米糊為丸，每服一百丸，空心酒送下。
