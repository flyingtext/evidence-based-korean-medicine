# 第四症  月水色黃

<!-- source-id: G047:p006 -->
> 서명: 竹林寺女科秘方
> 원본 파일: `G/G047.txt`
> 원본 SHA-256: `b16b52248bc70637df4f7e3126e6b5c18edd53067734e1b8ccbd9117c5495d3b`
> 상태: 자동 변환 원문·정본 미대조

婦人用水色如黃泥汁．肌肉消瘦，此症傷食，脾熱經燥，
土不能生血，故成此症。先用黃芩湯，降去五心煩熱，後
用理脾順氣丸。氣血調則經勻矣。

‧黃芩湯
蒼朮五分  川芎五分  當歸一錢
花粉二錢  甘草二分  黃芩一錢  白芍一錢
水煎服。

‧理脾順氣丸
沉香二兩  小茴香二兩  草果二兩
砂仁三兩  三棱一兩  大茴香二兩  枳殼一兩
良薑一兩  莪朮一兩  白豆寇一兩  烏藥二兩
陳皮一兩
共研細末，早米糊為丸，每服五十粒，空心
米湯送下。
