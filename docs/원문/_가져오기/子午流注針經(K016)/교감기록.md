# 子午流注針經 교감 기록

## 현재 상태

jicheng.tw 최신 전문과 Chinese Text Project 독립 전사를 대조해 결락·OCR 오기·자동변환 자형을 교정하고 표점을 검증했다.

## 대조 범위

- 원자료: `K/K016.txt`
- 전각 공백: 125자리 전수 판정(결자·오염 후보 70, 판면 공백 55, 미해결 0)
- 적용 내역: `corrections-applied.json`
- 표점 검증: `punctuation-report.json`

## 대조 판본

- https://jicheng.tw/tcm/book/%E5%AD%90%E5%8D%88%E6%B5%81%E6%B3%A8%E9%87%9D%E7%B6%93/index.html
- https://ctext.org/wiki.pl?chapter=385850

## 유보 사항

미해결 교감 후보는 없다. 후속 영인본의 이문은 별도 기록한다.
