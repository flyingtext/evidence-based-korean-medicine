# 勞復食復

> 원본 파일: `B/B011.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

汗下後，勞復，柴胡飲子（四十七）；飲酒復劇，黃連解毒湯（二十一），或雙解（五十四）加黃連；在裡者，三一承氣湯（十三）；在表者，益元散（五十二）或雙解；半表半裡，大柴胡湯（八）、小柴胡湯（九）、涼膈散（二十三）、解毒湯（二十一），隨證用之。食復三一承氣湯。
