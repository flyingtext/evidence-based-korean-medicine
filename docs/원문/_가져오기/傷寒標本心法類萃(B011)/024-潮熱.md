# 潮熱

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

潮熱屬陽明，一日一發，日晡而作也。陽明裡熱極甚，或吐下後不解大便五、六日至十餘日，日晡潮熱，心胸煩熱而懊憹，如瘧狀，脈沉實者，三一承氣湯（十三）。陽明、少陽合病，下利，日晡發熱如瘧者，大柴胡湯（八）。通宜三一承氣（十三）合解毒（二十一）。
