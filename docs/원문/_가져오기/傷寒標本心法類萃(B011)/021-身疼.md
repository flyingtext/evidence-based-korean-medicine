# 身疼

身疼之證，無問風寒，雙解散（五十四）。表熱甚，頭項肢體疼痛，黃連解毒湯（二十一）。傷寒瘟疫，遍身疼痛，少力，頭旋，腰腳麻重，嘔噦、壯熱、減食，三一承氣（十三）減硝加貫眾、紫河車，入金銀煎，名銀煎散。中濕一身盡痛，五苓散（二十四）。
