# 六字真言

> 상태: 자동 변환 원문·정본 미대조

無論外感內傷，無論出其右者，莫六字若也。曰表，裡，寒，熱，虛，實。三陽為表，三陰為裡。表中之裡，陽明是也，裡中之表，少陰是也。並各相表裡。三陽之腑主表，經主裡。三陰則心肺主表，脾肝腎主裡。外感者表宜汗，裡宜下。內傷者表宜清補，裡宜溫補。內傷陽則陰盛，陰盛者易感寒。內傷陰則陽亢，陽亢者易感熱。此所謂邪乘虛入也，虛為正虛，實乃邪實。故經云：「邪氣盛則實，精氣奪則虛。」醫能將此參伍錯綜，條分縷晰，則亦庶乎其可也。
