# 秘受不治法

<!-- source-id: J003:p002 -->
> 서명: 江氏傷科學
> 원본 파일: `J/J003.txt`
> 원본 SHA-256: `345e1c33f65c6d22017b5003ecaa3ae0c6b0819ccbbbc07a18601502c17f57ae`
> 상태: 자동 변환 원문·정본 미대조

凡天柱骨折不治；凡兩目損傷不治；凡口開氣出不收不治；凡口如魚口不治；凡傷食喉；凡打破頭鼻流黃白水不治；凡脊骨折斷不治；凡心胞緊痛紅色高腫不治；凡心口青色不治；凡小腹陰陽不分不治；凡小腹傷吐糞不治；凡跌打大小腹痛不治；凡腎子傷入小腹不治；凡孕婦傷犯胎不治；凡女人傷乳不治；凡男人兩乳堂傷不治；凡腰傷自笑不治；凡兩臂墮下，盡力叫嚎，汗出如油者不治；凡人手骨出，一脛可治，兩股齊出不可治。
