# 水腫門

<ins>總括</ins>

小兒水腫，俱屬水停於脾肺二經。如水停肺中則喘，水停脾中則脹，其間所腫部位，要分明也。若腰以上腫者，屬風，宜汗散之；腰以下腫者，屬濕，利水之法最靈；有通身上下俱腫者，治宜利汗並施。腫而喘不得臥，則逐肺飲，腫而脹滿便閉，則宜攻脾。水腫從腹起至四肢者可治，從四肢起至腹者不可治。當再辨有陽水與陰水之分。陽水屬實，法宜攻瀉，陰水屬虛，法宜溫補，臨證之時，貴變通焉。

<ins>風水腫</ins>

凡腫在腰以上，如頭面肩臂至腰腫者，病因外感風邪而起，急宜發汗，莫從容也。經云：開鬼門之法，以越婢湯中加蒼朮汗之。汗後全消，病即寧矣。

<ins>濕水腫</ins>

腫在腰臍之下兩足者，病因脾經濕熱而起，急宜利水可安然也。經云：潔淨府是也。先用外法，以藥貼臍，如神之妙，內服沉香琥珀丸。

<ins>風濕腫</ins>

通身頭面手足皆腫者，得病之由，乃屬外感風邪，內停濕飲，風濕相搏，水道不利，外攻肌表，因而作腫也。治法用外散內利，則最相宜。重者用峻攻之，則用疏鑿飲；輕者和解之劑，用茯苓導水湯醫之。若水停上攻於肺，喘急不得臥，用蘇葶丸以定其喘，亦最相宜。水停中州，脹滿喘急者，用舟車神　丸最攻之也。

<ins>陽水</ins>

陽水者，乃濕熱內郁，水道阻塞，外攻肌表，以致外腫內脹，身熱口渴，六脈沉數，小便赤澀，大便多難也。法當泄水，如熱盛心煩口渴者，用大聖　川散攻之；濕盛脹滿者，用舟車神　丸攻之。

<ins>陰水</ins>

陰水者，乃脾腎虛弱，脾虛不能制水，腎虛不能生水，以致外泛作腫，內停作脹。若二便利，心不煩，身不熱者，須服實脾散、金匱腎氣丸。若服溫補藥而無效驗，則是虛中有實，欲投攻下，恐小兒難堪；若不攻之；則坐以待斃。雖攻補兼施，或一補一攻，或三補一攻，或九補一攻，審其進退，俟有可攻之機，以意消息，始能逐邪而不傷正病可痊也，必忌鹽醬百日。
