# 黃膽門

<ins>總括</ins>

黃疽一證，乃濕熱郁蒸日久，外發肌膚而成也。其候遍身皆黃，及面目眼睛，亦甚深黃，面如煙熏之狀。其中又有陰陽之別：如陽黃尿赤色亮，面紅口渴，身多發熱是也，乃脾家濕熱之故；如陰黃，口不渴而色暗黃，身冷如冰是也，乃脾腎寒濕之故。醫者宜分別施治。

<ins>陽黃</ins>

陽黃一證，原因濕熱而成。如表實無汗，宜疏散其汗，用茵陳麻黃湯散發汗也，則黃從表解。如裡實腹滿，二便秘澀者，宜茵陳蒿湯攻下之。若表有汗，裡不便秘腹滿，是表裡無證，不可汗下，惟利小便，宜用茵陳五苓散治之，使黃從水道出，其方最驗。

<ins>陰黃</ins>

陰黃之證，最為危險，乃脾濕腎寒，兩虛而成。宜溫脾去黃，以茵陳理中湯治之；如溫腎去黃，以茵陳四逆湯治之最靈。
