# 發熱門

<ins>總括</ins>

小兒身體發熱，有表裡虛實之異。治亦有汗、下、補、瀉之殊，宜分別焉。須當觀形察色，辨其因由，審證切脈，臨證無遺缺也。

<ins>表熱</ins>

小兒表熱之證，因外感寒邪，脈浮發熱，惡風惡寒，頭疼身痛，而無汗出，此表熱也。宜十神湯主之，兼內熱者，用雙解通聖散為先。

<ins>裡熱</ins>

小兒裡熱之證，因肥甘過度，必生內熱，以致遍身蒸蒸發熱，小便澀紅，面赤唇焦，舌燥而渴，脈實有力者，失以調胃承氣湯下之；不愈用白虎湯，或黃連解毒湯清之。

<ins>虛熱</ins>

虛熱者，因小兒病後，營衛虛弱，氣血未調之故。其證神倦氣乏，宜用補中益氣湯治之。若口渴引飲而嘔，用竹葉石膏湯治之。又有陰盛格陽，外浮發熱者，其面色雖赤，而尿清白，四肢厥冷，宜用白通湯收斂陽氣，熱退自愈。

<ins>實熱</ins>

小兒實熱者，乃有餘積熱，以致午後潮熱，蒸蒸有汗，肚腹脹滿，尿紅大便難，煩渴啼叫，口舌生瘡，腮頰紅赤，脈洪數有力。法宜清熱通利，時時熱者，用涼膈散主之。午後潮熱者，大柴胡湯主之，其效通仙也。
