# 生死要論第十三

凡不病而五行絕者死. 不病而性變者死. 不病而暴語妄者死. 不病而暴不語者死. 不病而暴喘促者死. 不病而暴強厥（一作中. ）者死. 不病而暴目盲者死. 不病而暴耳聾者死. 不病而暴痿緩者死. 不病而暴腫滿者死. 不病而暴大小便結者死. 不病而暴無脈者死. 不病而暴昏冒如醉者死. 此皆內氣先盡（一作絕. ）故也. 逆者即死. 順者二年. 無有生者也.
