# 癩

此是感天地殺厲之氣。聲啞者，難治。

<ins>下蟲</ins>

　病在下，通天再造散。取蟲及穢物方：鬱金(一錢)　大黃(一兩)　白牽牛(六錢，半生半熟)　皂角刺(一兩，陳者)　共為末，酒下五錢。

<ins>取涎</ins>

　病在上，用醉仙散於牙縫中追毒取涎，方見後。

<ins>發散</ins>

　痛者，養血藥中加如聖散。

<ins>疏風清熱</ins>

　防風通聖散加生地、羌活、獨活、大力子、白芷、蔓荊子。

<ins>宣</ins>

　氣實痰壅者，宜吐、汗之。

<ins>換肌</ins>

　換肌丹方：當歸　苦參(各二兩)　川芎　撫芎　防風　荊芥穗　川羌活　獨活　金蠍　蟬蛻(各一兩半，共為末)　大楓子(三斤，取淨肉一斤)上楓肉搗如泥，和陳米飯為丸，每服四十丸，空心至晚各進一服。

<ins>針</ins>

　出惡血，取委中二穴，針之去惡血二三合。又黑紫疙瘩處，亦去惡血。

<ins>涼血瀉火</ins>

　四物加生地、荊芥穗、黃　、黃連、地骨、甘草、黃芩之類。

<ins>潤膚</ins>

　大楓子、枯礬、輕粉、苦參、白芷，為膏潤之。癢者，加白芨、硝、雄黃。

<ins>追涎</ins>

　鼻塞者，用豬牙皂角十條，微泡去皮，玄胡索大者三枚，青黛半錢，共為末，滴水丸如雞頭大，晒乾。

每一丸以水浸開，口含水，以藥搐鼻中，其涎自出，後以水漱口自止。

醉仙散方：服五七日後，牙縫中出涎。

胡麻　鼠黏子　枸杞子　蔓荊子(各一兩，同炒)　白蒺藜　苦參　防風　栝蔞根(各半兩)上為末，每十五錢入輕粉一錢，茶湯調下。

<ins>洗浴</ins>

　雄黃(研，生用，)　臨時下黃柏、槐花、麻黃、苦、乾薑(各一兩)，只為粗末，用水一桶許，浸五日，令藥水濃卻，煎數沸，去渣，入缸或大桶內，令滿，坐於內沒身，汗出為度，其蟲取下，遠去其水，於僻處理藏，換新衣著，大忌色欲、口味。

<ins>雙解</ins>

　烏蛇丸方：皂角去皮弦子二十定，酥炙；白花蛇、烏蛇各一條，並酒浸，去骨，焙乾；苦參四兩；大楓子三斤，內取淨肉一斤。共為細末，以皂角十三定捶碎，以水五升浸一宿，濾去渣，熬成膏，和前藥為丸，桐子大。每三十丸，欲利，溫酒下，以利為度；欲汗，通聖散汁送下，三日服一遍，汗出為度。

<ins>斂瘡藥</ins>

　風癢多用，尋常少用。

紫荊皮(四兩)　白芨　赤小豆　斑蝥(去足翅)　明礬　全蠍(各二錢半)上為細末，水調塗敷其瘡，直到了不換，痊後其痂自落。
