# 溺血

> 상태: 자동 변환 원문·정본 미대조

屬熱、氣虛、血虛。

<ins>涼榮</ins>

　四物加生地、牛膝，或四物加黃連、棕灰，六味地黃丸切要。

<ins>補氣</ins>

　莖痛用甘草梢，血藥中少佐以地榆、陳皮、白芷、棕灰。

<ins>劫</ins>

　瑞竹堂方蒲黃散：蒲黃(炒)　古鍛石(炒)　破故紙(炒)　為末調服。或單用蒲黃，或蔥白湯調鬱金末服之，文蛤灰入煎劑妙。
