# 暑

熱傷氣。火極陰虛。注暑，暑風，熱極也。　是陽症，暑是陰證。脈沉弱者，切不可用寒涼

<ins>補</ins>

　陰虛元氣不足者，清暑益氣湯。陽虛，補中益氣湯。挾痰加半夏，或生脈散。

<ins>宣</ins>

　挾火兼痰實者，可用吐法。暑風多痰。

<ins>清熱</ins>

　天水、白虎皆可用。熱悶，辰砂、五苓。脈弦實，黃連、香薷。有痰。消暑丸。

<ins>清神</ins>

　香薷、天水、東垣清暑益氣東加石膏。

<ins>清燥</ins>

　濕熱相合，而刑庚金，陽明病在下，東垣清燥湯方、消暑丸至妙，夏月不可無

<ins>分利</ins>

　熱甚，自汗而渴，便澀者，五苓分利之，桂苓甘露飲。

<ins>溫</ins>

　吐瀉，脈沉微甚者，可用附子、大順散、香薷丸、桂苓丸、水浸丹。伏熱傷冷，縮脾飲，冷香飲子。

<ins>瀉火</ins>

　黃連解毒湯、神芎丸。

<ins>劫</ins>

　治伏暑泄瀉，身熱脈弱，宜來復丹。
