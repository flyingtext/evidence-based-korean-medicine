# 鼓脹

<ins>消導</ins>

　氣脹，清熱行氣，中滿分消丸。寒脹，中滿分消湯。

<ins>補中行濕</ins>

　此脾虛之甚，大劑參、朮、陳皮、茯苓、仙術。

<ins>行血</ins>

　有血積。

<ins>潔淨府</ins>

　小便澀者，宜竟滲利之。

<ins>下</ins>

　脈實人壯盛者，下之便用收拾。

<ins>行氣</ins>

　濃朴治脹，因味辛散。一法，用大蝦蟆一個，入豬肚內煮熟，去蟆不用，病患一日吃盡，遂愈，神妙。

<ins>滋陰</ins>

　無陰則不能化，故脹，故藥加芩、連類。

<ins>針</ins>

　上脘、三裡、章門、陰谷、關元、期門、行間、脾俞、懸鐘、承滿。
