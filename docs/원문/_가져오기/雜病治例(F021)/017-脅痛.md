# 脅痛

肝火盛，木氣實，有死血，有痰流注，肝急。

<ins>行血</ins>

　輕者用桃仁紅花、川芎。肝苦急，急食辛以散之，用撫芎、蒼朮。

<ins>下</ins>

　龍會丸瀉火之要藥。木氣實者承氣。初痛脈氣實者十棗湯。

<ins>和解</ins>

　小柴胡加牡蠣。

<ins>導痰</ins>

　二陳加南星、川芎、蒼朮、柴胡。

<ins>行氣</ins>

　咳而脅痛，二陳、南星、多加香附、青皮、青黛、薑汁。木氣實，或血氣兩調

<ins>捷嚏</ins>

　用不臥散吹之。

<ins>針</ins>

　丘墟、中瀆。
