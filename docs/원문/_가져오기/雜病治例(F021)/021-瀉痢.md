# 瀉痢

氣虛兼寒熱，食積、風邪、驚邪、熱濕，陽氣下陷，痰積。當分治，瀉輕痢重。

<ins>升散</ins>

　胃風湯、防風芍藥湯、神術散、蒼朮防風湯、敗毒散皆可汗之。

<ins>攻裡</ins>

　濕熱用導水丸，兼郁承氣湯、和中丸。積滯用聖餅子、脾積丸。冷積局方蘇感丸。下後用藥調理。痢初得者，必用下，通因通用。濕熱甚者，宣明玄青膏。

<ins>和氣</ins>

　後重窘迫用木香檳榔。白屬氣，赤白者氣血受病，赤黑相兼屬濕熱，青綠雜風與火濕。

<ins>涼血</ins>

　下血者當涼血，歸、　。赤屬血，《保命集》四物加槐花、黃連、米殼。

<ins>溫</ins>

　脈沉弱而腹痛，用薑附加對五苓、理中丸、機要漿水散。色青者，寒兼風。

<ins>升提</ins>

　陽氣下陷，升陽益胃加桔梗，醋沃南星。用一葉梅外貼極效，起泡便止。

<ins>收斂</ins>

　實腸散、桃花湯、養臟湯、嚴氏烏梅丸、元戎烏梅散，如米殼、榴皮、龍骨之類。

<ins>勝濕</ins>

　平胃散、，曲芎丸之類。老人奉養太過，飲食傷脾，為脾泄，機要白朮芍藥湯、茯苓湯。濕勝，仙術炒用。

<ins>滲泄</ins>

　陰陽不分，淡以滲之，五苓、豬苓之類。或單用薏苡實炒為末服之。

<ins>補</ins>

　初不可便補。氣虛者補中益氣。血虛神弱，人參、白朮、當歸、川芎、炒芍藥、茯苓，少加黃連之類。錢氏白朮散、十全大補湯。

<ins>劫</ins>

　瀉痢，脈沉伏細弱下陷者，用來復丹、靈砂丹以劫之。

<ins>清暑</ins>

　中暑　而脈虛者，香薷散、桂苓甘露、清暑益氣湯。

<ins>灸</ins>

　陷下則灸之。脾俞、關元、腎俞、復溜、腹哀、長強、太谿、大腸俞、三裡、氣舍、中脘。

<ins>解熱</ins>

　外熱者先退熱，柴、芩、連。內熱者香連丸、芍藥柏皮丸、黃連阿膠丸。噤口者解毒。

<ins>分利</ins>

　胃苓湯，與淡滲同五苓。或獨用　香散。

<ins>外貼</ins>

　以一葉梅於印堂貼之。

<ins>宣</ins>

　有痰飲在膈上，氣不能降，以致大腸不能收斂而瀉利。痰在肺中，宣大腸之不固也，宜吐之。

<ins>盒臍</ins>

　噤口痢用田螺於臍中盒之，以引下其熱，黃連多加參術，終日呷之，如吐再進

<ins>補腎</ins>

　腎泄久不止，脈沉細無力，二神丸、本事五味子散、金鎖正元丹。

<ins>和脾氣</ins>

　脾氣不和，濁氣下干，不能愈者，問病患思食何物，與食之，脾氣和而愈矣

<ins>消積</ins>

　因積作者脾積丸，方見後。
