<ins>熏</ins>　初起者, 即愈, 用熟艾, 於小罐內燒煙燻之.

<ins>敷</ins>　大扎草灰貼. 蠟膏紙, 入油些少, 乳香些少更妙, 或只用文蛤末.

一方:黃連（五）　蛤粉（四）　輕粉（一）　黃丹（一）　枯礬（半）

<ins>下</ins>　顯仁丸. 下注瘡只用當歸拈痛湯效, 或作丸服.
