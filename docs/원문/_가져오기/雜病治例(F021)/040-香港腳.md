# 香港腳

<!-- source-id: F021:p040 -->

濕熱，食積，流注，風濕，寒濕。

<ins>勝濕</ins>

　仙朮、白朮、防己、川芎為主，或六物附子湯。濕熱，當歸拈痛湯。

<ins>下</ins>

　顯仁丸。兼氣鬱甚者，舟車丸、除濕丹。有飲者，東垣開始導飲丸。

<ins>劫</ins>

　如神救苦散、一粒金丹、應疼丸(方在後。)赤芍(半兩)　草烏(半兩)　各煨，去皮尖，酒糊為丸。

<ins>解表</ins>

　麻黃左經湯等藥，隨證選用。有兼痰氣、寒濕，五積散。

<ins>雙解</ins>

　大黃左經湯選用，東垣羌活導滯湯。

<ins>理血</ins>

　八味丸，四物東加羌活、天麻，或四物加黃柏、南星，或健步丸。

<ins>補陽</ins>

　黃　、防己、白朮、桂、南星、木瓜、茯菟。

<ins>通關透肌骨</ins>

　三因勝駿丸。

<ins>疏風養血</ins>

　獨活寄生湯。

<ins>外治</ins>

　敷貼，用薑汁，芥子、白芷等為末，敷糝。或用仙朮、羌活、獨活、白芷、細辛，為末，入帛內，　用。

<ins>熨</ins>

　腳心用附子末，津貼。涌泉穴，卻以熱熨之。

<ins>洗藥</ins>

　威靈仙、防風、荊芥、地骨、當歸、升麻、朔　。

<ins>針</ins>

　公孫二穴，衝陽二穴。

<ins>灸</ins>

　三裡。
