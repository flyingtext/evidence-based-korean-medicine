# 頭痛

<!-- source-id: F021:p015 -->
> 서명: 雜病治例
> 원본 파일: `F/F021.txt`
> 원본 SHA-256: `18c0a1ae2cf7089b99003f52964115421d9284f1e2923844da038974777b7e4a`
> 상태: 자동 변환 원문·정본 미대조

有風、風熱，多主於痰、濕、寒、破傷風、下實內閉之作痛。痛甚者火多。血虛難治。

<ins>發散</ins>

　風邪與寒、破傷風、如聖散蔥酒調服。

<ins>宣</ins>

　痰留膈上，氣實成郁壅盛者，宜吐之。

<ins>消風</ins>

　川芎茶調散。風熱防風通聖散。風寒仲景加味麻黃湯。

<ins>清熱</ins>

　清空膏，片子黃芩一味，為末調服。寶鑒石膏散。

<ins>散濕</ins>

　三因芎術湯。

<ins>補氣</ins>

　有因虛寶鑒順氣和中湯。陰虛用天雄、川芎類。只灸亦可。

<ins>補血</ins>

　血虛者，四物倍芎，加石膏、荊穗。陰虛用補陰丸。

<ins>導痰</ins>

　青州白丸子、秘藏半夏白朮天麻湯。

<ins>捷嚏</ins>

　用不臥散搐之。痛甚以豬牙皂角二錢，玄胡、青黛些少，搐鼻取涎。

<ins>灸</ins>

　疏風散寒。

<ins>針</ins>

　脈浮取腕骨、京骨穴。脈長取合谷、衝陽。脈弦取陽池、風府、風池。

<ins>下</ins>

　少陽偏頭痛，多便閉，宜下之。

<ins>敷瘠</ins>

　用傷寒汗後法，敷貼細辛、草烏。

<ins>各經主治藥</ins>

陽明(白芷、石膏)　少陽(柴胡、川芎)　太陽(　本、羌活)　太陰(蒼朮、半夏)　少陰(細辛、獨活)　厥陰(吳茱、當歸)
