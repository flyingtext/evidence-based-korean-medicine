# 心痛

有風寒、氣、血虛、食、郁熱。

<ins>散寒</ins>

　鐵刷湯或草豆蔻丸。輕者五積散。脈伏者薑附。

<ins>調血</ins>

　四物。有平日喜食熱物，或有沖擊，死血留於胃口作痛，用桃仁承氣下之。

<ins>行氣</ins>

　木香、乳香、玄胡、益智、薑黃、砂仁。氣虛加以二陳，中加炒薑以和之。實者枳殼之類。

<ins>補</ins>

　因虛而作，咸以軟之，牡蠣丸。牡蠣一味，淬為末，水丸。

<ins>化蟲</ins>

　蟲痛者，多面上白斑，唇紅能食，治以苦楝根、錫灰之類。

<ins>清熱</ins>

　胃口有熱而作，非梔子不可，佐以薑汁，此反佐也。金鈴子散，見《活法機要》。

<ins>針</ins>

　太谿、然谷、尺澤、行間、建裡、太都、太白、中脘、神門、涌泉。

<ins>消導</ins>

　元戎濃朴丸、感應丸。

<ins>宣</ins>

　銅青之類，蘿卜子三大合炒，擂細濾之，空心茶湯和下，大鐘漸漸濃服取吐。

<ins>下</ins>

　大實滿痛者，元戎濃朴丸、備急丹、大陷胸湯。蟲痛，三因集效方。
