# 咳嗽

風、寒、火、勞、痰、肺脹、濕、五臟咳，看痰例分六氣治為要。

<ins>發散</ins>

　風：消風散、金沸草散。寒：麻黃湯、乾薑五味子湯。

<ins>下</ins>

　濕：十棗湯、小胃丹、葶藶木香散。水：葶藶丸。胃實痰郁者，下後調理。

<ins>宣</ins>

　痰在膈上，或停郁胃中。重者，瓜蒂散。輕者，蘿卜子末吐之。

<ins>瀉火</ins>

　實者，解毒湯。輕者，知母、地骨、桑白皮、麥門冬、桔梗、甘草，礞石滾痰丸。上半日屬胃中有火，貝母、地骨。五更咳者，此胃中有食積，至此時流入肺中。

<ins>滋陰</ins>

　午後嗽多者，屬陰虛，四物、知母、黃柏、或四物入竹瀝，或六味丸，或八味丸為要藥。

<ins>收斂</ins>

　火氣浮於肺，不宜用涼藥，以五味、五倍斂而降之，或粟殼、烏梅之類。肺脹者，訶子、青黛、杏仁，久咳自汗宜用之。

<ins>瀉白</ins>

　肺氣有餘宜瀉之，桑白為主，半夏、茯菟佐之，瀉其有餘，補其不足。

<ins>清金</ins>

　肺燥當潤之。屬熱者，桔梗、大力、知母、雞清。聲啞者屬寒，細辛、半夏、生薑，辛以散之。

<ins>補</ins>

　肺虛者，人參膏補之，阿膠為主。陰不足者，六味丸為要藥，知母茯苓湯炒。咳而瀉者、痢者、用粟殼不必疑。

<ins>熏</ins>

　款花、雄黃、艾，燒煙熏入喉中，以散肺中邪氣。丹溪治久嗽風入肺者，用鵝管石、雄黃、鬱金，款花碾末和艾中，以生薑一片留舌上灸之，以煙入喉中為度。

<ins>灸</ins>

　天突、肺俞、肩井、少商、然谷、肝俞、期門、行間、廉泉、扶突。

<ins>針</ins>

　曲澤，治咳喘出血立已。前谷穴兼胸滿。面赤熱咳，支溝。多唾，三裡。

<ins>導痰</ins>

　食痰，瑞竹堂方化痰丸。熱：滾痰丸。濕：葶藶、桑白。風痰：青州白丸子。

<ins>行氣</ins>

　二陳加南星、紫蘇、桔梗、枳殼之類，桑白皮。燥者，杏仁、蘇子。熱者兼荊、芩、連、知母。

<ins>涼血</ins>

　熱傷血分，宜生地、地骨、知母、麥門冬、阿膠、甘草、桑白皮、桔梗、紫菀、五味、荊、芩。

<ins>劫藥</ins>

　五味(半兩)　甘草(二錢半)　五倍(一錢)　風化硝(一錢)　上為末，干含化。

一方：粟殼(四兩，炒)　烏梅(一兩)　人參(半兩)　款花(半兩)　苦梗(半兩)　兜苓(一兩)　南星(薑製，一兩)上為末，蜜丸彈子大，含化。汗多者用之。
