# 調鼎吟

<!-- source-id: F021:p006 -->
> 서명: 雜病治例

> 원본 SHA-256: `18c0a1ae2cf7089b99003f52964115421d9284f1e2923844da038974777b7e4a`
> 상태: 자동 변환 원문·정본 미대조

茫茫宇宙一乾坤，調鼎工夫輩輩傳。指鹿心機徒造偽，問牛氣象實調元。貪人敗俗淳風變，良相匡時化日全。四海雍熙民物阜，春風花柳保年年。

上二詩，一以見醫術行道之用心，戒慎如此；一以見大道之本，調元之意如斯。所謂達為良相，不達則為良醫，非流俗工技之比，實非小材小智所可窺也。

<ins>時永樂六年歲在戊子十月望後一日中山劉宗濃甫謹識</ins>
