# 發熱

有寒熱、潮熱、煩熱、往來熱、皆與傷寒中兼看。如勞役熱、溫疫熱、痰熱，傷食、腳氣發熱，皆不得與傷寒初治，誤則殺人。生斑、尸疰、勞瘵、鬼疰，皆為寒熱發熱。蓋病本不同，其標多相似，故舉諸例於下。

<ins>瀉火</ins>

　氣實脈盛，身熱煩擾，宜三乙承氣湯、涼膈等藥下之。熱在中，四順、清涼飲。在下，八正之類。

<ins>涼血</ins>

　夜熱多，或有汗，或鼻衄，身熱而便難，四物去芎，加黃連、生地、地骨皮之類，柴胡、生草、知母。勞熱骨蒸，血，青蒿、蛤蚧、鱉甲、小麥。

<ins>清氣</ins>

　日熱多，熱在氣分，柴胡飲子、白虎湯。有暑熱。從前例。蒸熱氣，烏梅、秦艽、柴胡。

<ins>清肌</ins>

　在輕手按之甚熱，重手取之不甚熱，此熱在肌表，宜清之，竹茹、竹葉、地骨皮、麥門冬之類。

<ins>清神</ins>

　有神氣怫郁而熱，宜清神散。

<ins>抑火升水</ins>

　熱在上而陰水不升，虛火沸騰，宜升陽瀉火法，虛者補之。

<ins>養陰退陽</ins>

　初病陽症而失於下，至變似陰而不可下，用白虎之類。

<ins>瀉黃</ins>

　因脾熱也。實則調胃、瀉黃，虛則人參黃　散。

<ins>導赤</ins>

　心熱，實則瀉心湯，虛則朱砂安神丸。

<ins>瀉白</ins>

　肺熱，實則涼膈散，虛則人參白虎湯。

<ins>瀉青</ins>

　肝熱實，柴胡飲子。

<ins>滋陰</ins>

　腎熱實則滋腎丸，本滋陰法也。無實不可瀉。

<ins>下食</ins>

　有食傷太陰而熱，或停食而下之。

<ins>導痰</ins>

　痰液不散，郁結成熱，宜導開之。

<ins>消積</ins>

　因積滯而蓄熱，當先消積而熱自退。

<ins>解毒</ins>

　有丹毒熱腫，氣鬱結滯，並可解散，隨證用藥。此候欲發瘡毒，分六淫治。

<ins>鎮墜</ins>

　柴雪、朱砂、琥珀、犀角之□□墜浮溜之火。

<ins>益精</ins>

　陰虛精耗，元氣脫者，用滋陰藥。

<ins>潤燥</ins>

　俱前燥法下。

<ins>逐血</ins>

　有蓄血證，宜下之。

<ins>分利</ins>

　小便降火急速，或有與小便單服。又，解肌生津例、虛者補中例加木通。

<ins>水沃</ins>

　以水沃於外，或令坐水中，當審脈證而行之。

<ins>揭越</ins>

　汗下後，元氣虛而下陷，陰陽之氣揭薄而不起，為虛熱，宜與來復丹、靈砂以揚之。

<ins>與地漿</ins>

　汗下後，脈躁身熱，大渴，飲水不已者，新掘井泉，取水飲之。

<ins>消風</ins>

　有郁冒諸風為熱，宜防風通聖、川芎、石膏之類。

<ins>清金</ins>

　有肺燥郁熱，或火乘之者，宜清之，白虎加地骨。

<ins>補</ins>

　元氣不足，胃氣下陷為熱，補中益氣湯。血虛者加血藥。

<ins>漬形</ins>

　血虛氣弱，邪不能散。

<ins>針</ins>

　導氣。熱病汗不出，商陽、合谷、陽谷、俠谿、厲兌、勞宮、腕骨泄血。熱無度不可止，陷谷出血。

<ins>從治</ins>

　藥使酒煎，或溫熱為佐使。

<ins>反治</ins>

　蜜煎烏頭之類。

<ins>升散</ins>

　其候欲發斑疹，身熱，宜升麻湯等藥發之。

<ins>涼骨肉分勞瘵熱主治藥</ins>

　氣血見前。

肝(當歸，柴胡)　心(生地，黃連)　脾(芍藥、木瓜)　肺(石膏、桑白)　腎(知母、生地)膀胱(滑石、澤瀉。)

<ins>HT　劫</ins>

　柴胡梅連散：治骨蒸勞熱，三服除根。

胡黃連　柴胡　前胡　烏梅(各三錢)上咀片，每服三錢。童便一盞，豬膽一枚，豬脊髓一條，韭根白半盞，同煎至七分，不拘時，候溫服。熱住後，可別調理。
