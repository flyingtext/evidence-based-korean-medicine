# 唯亭陸

陰虧之體，腎家一水本來不勝兩火。此《內經》僅道其常也。此間更有變者，煩勞之下，火從內起；炎暑之時，火自外加，內外兩邪合而為一。以腎水久虛者當之，則陽絡受傷，血從外溢，溢而未清，變為咳嗽。甚至有聲有痰連連不已，飲食雖可，肌肉暗削。自秋徂冬，正屬金水相生之候。是以見症尚和，自覺相安於無事，而不知仲春水旺亦反侮金。金者肺也，肺失清肅則音不揚，咽中痛，其喉為痹，以昭一陰一陽之火氣內結，金受其累矣，漸成損症也。然脈形細數，尚未見促，陰火雖旺，陰液未竭，緩以圖之，日進滋補，俾得夏至陰生，可卜其旋元吉。現下脈虛火甚，物雖下咽，最為吃緊之時。非清不可，非補亦不可，斟酌於二者之間，惟有錢氏阿膠散法可以加減用之，以合式。擬候政。
