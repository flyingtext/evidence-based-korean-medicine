# 濃腐與濃膩不同辨

<!-- source-id: M202:p014 -->
> 서명: 察舌辨症新法
> 원본 파일: `M/M202.txt`
> 원본 SHA-256: `73d395b7314c2664f3467b7401278cdc5dc629f0d3b7c17befc21b1329a42cf1`
> 상태: 자동 변환 원문·정본 미대조

濃腐與濃膩不同，腐者如腐渣，如腐筋如豆腐堆鋪者，其邊濃為陽有餘，能鼓胃中腐化濁氣上升，故有此象。若濃膩則中心稍濃，其邊則薄，無毛孔，無顆粒，如以光滑之物刮一過者，此為濃膩，為陽氣被陰邪所抑，必有濕濁、痰飲、食積、瘀血、頑痰為病，宜宣化。一為陽氣有餘，一為陽氣被抑，差之毫厘，失之千裡，可不慎哉今人多誤認膩字，故特論辨，以分別之。
