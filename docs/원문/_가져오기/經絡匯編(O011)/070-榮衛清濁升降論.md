# 榮衛清濁升降論

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

清氣為榮. 清者, 休之上也, 陽也, 火也, 離中之陰降, 午後一陰生, 即心之生血, 故曰清氣為榮. 濁氣為衛. 濁者, 體之下也, 陰也, 水也, 坎中之陽升, 子後一陽生, 即腎陽舉而使之, 故曰濁氣為衛. 地之濁不能升, 地之清能升為陽, 舉而使之上也. 天之清不降, 天之濁能降為陰, 驅而使下也. 經曰: 地氣上為云, 天氣下為雨, 此之謂也.
