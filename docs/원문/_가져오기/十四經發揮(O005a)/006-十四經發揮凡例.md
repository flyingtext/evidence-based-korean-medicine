# 十四經發揮凡例

<!-- source-id: O005a:p006 -->
> 서명: 十四經發揮
> 원본 파일: `O/O005a.txt`
> 원본 SHA-256: `b9171dc9179a77acbb8f6328863e892c0f4e7533c81df07930926aa05461c972`
> 상태: 자동 변환 원문·정본 미대조

一、十二經所列次第，並以流注之序為之先後，附以任督二奇者，以其有專穴也。
總之為十四經云。
一、註者，所以釋經也。其訓釋之義，凡有三焉；訓字一義也，
釋身體府藏名物一義也，解經一義也。其載穴法分寸，則圈以別之。
一、各經既於本經詳註處所，其有他經交會處，但云見某經，不必復贅。
一、經脈流注，本經曰歷，曰循，曰至，曰抵；其交會者曰會，曰過，曰行。
其或經行之處，既非本穴，又非交會，則不以右例統之。
一、奇經八脈，雖不若十二經之有常道，亦非若諸絡脈之微妙也。任督二脈之直行者，
既已列之十四經，其陰陽維，蹻，衝，帶六脈，則別具輯編，以參考。
