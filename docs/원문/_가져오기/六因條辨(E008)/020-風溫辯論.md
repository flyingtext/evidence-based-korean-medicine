# 風溫辯論

<!-- source-id: E008:p020 -->

> 상태: 자동 변환 원문·정본 미대조

夫風者天之陽氣，溫者天之熱氣，若非其時而見之，即為戾氣，人或染之，即為病氣。都由冬春久暖，雨澤愆期，風陽化燥，鼓蕩寰宇，而人於氣交之中，素稟陰虧者，最易湊襲。故風溫一症，良由先伏溫邪，後再感風，風與溫合，是為風溫。然溫則應火，風則應木，二氣相煽，化為壯火，動輒傷肺。故其見症，必面赤舌乾，身熱神迷，鼻鼾多寐，默默不語，不思飲食，卻與中風相似。過一二日後，神志反清，語言反出，似乎欲解，但口渴喜飲，舌乾煩熱，較甚者何也?以風由外解，而熱自內蒸也。故初起即宜外疏風邪，內清溫熱，須步步照顧陰液，勿泛泛治風而已。倘治失其宜，傳變最速，較諸溫熱則尤險也。
