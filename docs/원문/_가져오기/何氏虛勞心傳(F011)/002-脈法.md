# 脈法

勞極諸虛，浮軟微弱（虛症宜見虛脈為順）。土敗雙弦，（兩手俱弦，木克土敗。若左手脈細若六至以上必死。）骨蒸發熱，脈數為虛，（虛數二脈，是其本象。）熱而澀小，必殞其軀，（發熱脈靜，不可救藥。）氣結或代，亦死何疑﹗失血諸症，脈必見芤，緩小可喜，（身涼脈靜易治。）數大堪憂，（身熱脈大者，為難治。）
