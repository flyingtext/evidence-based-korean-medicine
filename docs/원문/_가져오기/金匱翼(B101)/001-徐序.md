# 徐序

《傷寒》而外，《金匱》一書，又雜症之大法門也。吾吳尤在涇先生，學術淵深，天機敏妙；說，參以論斷，所謂廣長舌大法輪，可想見先生濟世婆心矣。余生也晚，不獲親炙先生討論，讀其書如見其人焉。聞諸故老云，先生鍵戶著書，絕意榮利，一時名宿，如方東華、顧秀野、沈歸愚、李客山諸君，相與結城南之社，其詩采入《國朝別裁集》，為時所誦集者已久。

於星門陳子處借校，訛正補缺，名之曰《金匱翼》，竊仿《傷寒附翼》之義。夫科舉之學，揣摩家猶曰中式，況於病乎。則是書為《金匱》羽翼，而先生為仲聖功臣矣。是為序。

<ins>嘉慶十有八年癸酉三月長洲後學徐錦書於心太平軒</ins>
