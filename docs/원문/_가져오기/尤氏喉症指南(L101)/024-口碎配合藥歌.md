# 口碎配合藥歌

<!-- source-id: L101:p024 -->

> 상태: 자동 변환 원문·정본 미대조

口碎兒茶赤石三，朱硼膏各一錢研，二分冰片臨時下，口中碎爛霎時痊。

<ins>口碎方</ins>

兒茶（三錢）　赤石脂（三錢）　朱砂（一錢）　硼砂（一錢）　石膏（一錢，　）　冰片（二分，臨用）

如遇走馬疳加牛黃（一分）、龍骨（一錢）、珍珠（二分）、元丹（二分），研吹立愈。
