# 辨症總訣

<!-- source-id: L101:p008 -->
> 서명: 尤氏喉症指南
> 원본 파일: `L/L101.txt`
> 원본 SHA-256: `f7ad7ac52244fe94fec4e8e19f318d004cb37e878ba08f0dd828cad3dd4a0ba7`
> 상태: 자동 변환 원문·정본 미대조

喉症屬痰屬風火，乳蛾等症總因之，去風消痰解熱毒，更開郁結愈堪期。若然初發寒戰起，發後身涼即便安，口無重舌唇不裂，切勿誤將熱藥施。蓋緣陰氣虛寒發，其身津液化痰兮，慎勿將痰多去盡，恐竭精神必致危。先以吹藥通喉脹，散風和解莫煎遲，次服溫補滋陰劑，虛寒治法只如斯。三日後再發寒戰，心寒脅痛命如絲，發時口碎閉失緊，重舌便難熱症知，治用石膏敗毒散，症雖險凶易痊除。惟有牙關不緊閉，嚴如無急反稀奇，舌腫胡桃如茄子，服如卻熱總非宜，以箸按舌見白色，起箸見紫死無疑，喘咳痰稠頸俱赤，口臭色黑命難全，口舌腐爛如無血，更有無痰總莫宜。
