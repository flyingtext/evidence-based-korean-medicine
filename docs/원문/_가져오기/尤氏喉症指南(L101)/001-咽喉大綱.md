# 咽喉大綱

<!-- source-id: L101:p001 -->
> 서명: 尤氏喉症指南
> 원본 파일: `L/L101.txt`

> 상태: 자동 변환 원문·정본 미대조

夫咽喉，左為咽屬胃，右為喉屬肺，乃一身之總要。通百節之關隘，呼吸出入，所由從也。經云：一陰一陽結，謂喉痹。痹者，閉也。有風、寒、暑、濕、燥、火、陰虛、實熱之症，盡皆有毒，或相搏相聚，其症不一，變幻不測。經云：聖神功巧，望問聞切，以此推之，治咽喉者，庶無誤矣。喉者，氣之關隘，通則利．塞則閉，無問其表本，當急治之。此風毒之氣，客於咽喉，與氣血相搏，結腫成毒，如熱入心包，煩亂不食，死矣。
