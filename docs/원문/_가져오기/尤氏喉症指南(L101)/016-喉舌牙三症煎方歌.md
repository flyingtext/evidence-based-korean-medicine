# 喉舌牙三症煎方歌

<!-- source-id: L101:p016 -->
> 서명: 尤氏喉症指南
> 원본 파일: `L/L101.txt`
> 원본 SHA-256: `f7ad7ac52244fe94fec4e8e19f318d004cb37e878ba08f0dd828cad3dd4a0ba7`
> 상태: 자동 변환 원문·정본 미대조

喉症梔翹桔薄荷，芩元蒡子草僵前，銀花口渴加冬母，郁悶須加貝芍先，頭痛石膏胸悶殼，身如寒熱入柴胡，倘然大便難通利，枳殼元明不可倫。

舌症知連草地冬，翹犀赤芍粉丹通，痰郁定當加貝母，口唇須藉石膏功。

牙症元丹地草知，地骨車前芍柏梔，發熱石膏升炒黑，虛加　杞最相宜。
