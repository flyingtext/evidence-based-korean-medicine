# 針灸避忌太一之圖序

<!-- source-id: K018:p015 -->
> 서명: 針經指南
> 원본 파일: `K/K018.txt`
> 원본 SHA-256: `d4eafd422308a679edf3d35cfd71c82abf128d264b9c7ddd857c8980440a7e74`
> 상태: 자동 변환 원문·정본 미대조

經曰：太一日游，以冬至之日，始居於葉蟄之宮。從其宮數所在，日徙一處，至九日復一。常如是無已，周而復始，此乃太一日游之法也。其旨甚明，別無所隱。奈行針之士，無有知者，縱有知者，秘而不傳，致使聖人之法，罕行於世，良可嘆也。仆雖非醫流，平昔嘗留心於醫，言之聞之徹知其詳。知而不述豈仁乎？輒以短見，遂將逐節太一所直之日，編次成圖。其圖如目，入節得主之日，從其宮至所在之處，首一終九，日徙一宮，至九日復反於一。周而復始，如是次而行之。計每宮各得五日，九之則一節之日悉備。今一一條次，備細具於逐宮之內，使觀者臨圖，即見逐節太一所直之日在何宮內，乃知人之身體所忌之處，庶得行針之士，知而避之，俾人無忤犯太一之凶，此仆之本意也。仆誠非沽名者，以年齒衰朽，恐身歿之後，聖人之法湮沒於世，故編此圖，發明厥旨，命工鐫石傳其不朽，貴得其造與時偕行焉，覽者勿以自炫見謂。曾人走丙子歲上元日，平水閉邪　叟述。
