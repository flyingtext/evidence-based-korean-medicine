# 古法流注

經云：其氣始從中焦注手太陰陽明，陽明注足陽明太陰；太陰注手少陰太陽，太陽注足太陽太陰；少陰注手心主少陽，少陽注足少陽厥陰；厥陰注還於手太陰。如環無端，周流不息，晝夜行流，與天同度。此法如氣血所王之經絡，於一經中井滎俞經合，迎隨而補瀉之。亦用東方實而西方虛，瀉南方而補北方是也。
