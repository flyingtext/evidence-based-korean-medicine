# 冬至葉蟄宮說

冬至葉蟄宮圖按周身立法，取九宮方位。離為上部，中州為中部，坎為下部，巽坤為二肩兌為左右脅，乾艮為左右二足。太一游至處，禁忌針灸。（若起葉蟄宮，取冬至一日為首，他皆仿此。）

*太一血忌之圖\p06-d17a1.bmp*

經曰：身形之應九野，左足應立春，其日戊寅、己丑；左脅應春分，其日乙卯；左手應，其日戊辰、己巳；喉首頭應夏至，其日丙午；右手應立秋，其日戊申、己未；右脅應秋分，其日辛酉；右足應立冬，其日戊戌，己亥；腰尾於竅應冬至，其日壬子；六腑膈下三藏應州，其大概禁太一所在之日及諸戊巳。凡此九者，善候入正，所主左右上下，身體有疾病瘡腫欲治，無以其所直之日刺之，是謂天忌日。
