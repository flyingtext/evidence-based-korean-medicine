（此方云寡婦服下. 且有孕. 神驗方也. ）

大熟地（二兩四錢）　肉蓯蓉（二兩四錢）　萆薢（四錢）　燈草（五尺）　木香（二兩四錢）　山萸肉（二兩四錢）　澄茄（二兩）　大茴香（二兩）　馬蘭實（陰乾研八分）　乾漆（二兩）　巴戟肉（二兩）　蛇床子（一兩四錢）　龍骨（二兩）　全當歸（一兩）　牡蠣粉（二兩）　母丁香（二兩）　桑螵蛸（二兩二錢）　全蠍（去毛五錢）　茯苓（一兩半）　蜘蛛（十四個）　威靈仙（二兩）　菟絲子（二兩）　沉香（二錢）　車前子（二兩）　木通（二兩四錢）　遠志肉（二兩）

上各味. 研細末煉蜜丸. 如綠豆大. 每日清晨服一二錢. 開水下.

又煎藥（每於經期轉時. 服一劑. 煎方如下. ）　桂枝（三分）　白芍（二錢）　甘草（二錢）　姜皮（三錢）　再加玉盆二錢棗三枚.
