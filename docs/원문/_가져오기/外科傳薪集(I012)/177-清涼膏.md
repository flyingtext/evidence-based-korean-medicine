# 清涼膏

（專治一切熱毒瘡癤. 此方是正. 其前抄是又方. ）

長頭髮（一斤）　菜油（四斤）　煎枯去渣. 再以活牛蒡.　甘菊　金銀藤　馬鞭草　蒼耳草　仙人對坐草（各一斤）入菜油十斤煎枯瀝出. 再加白芷　甘草　五靈脂　當歸（各八兩）　煎枯去渣. 再將煎熬髮油併入. 共見斤兩. 每一斤油. 入桃丹七兩. 熬膏攤貼. 熬嫩膏再添丹四兩. 煮和.
