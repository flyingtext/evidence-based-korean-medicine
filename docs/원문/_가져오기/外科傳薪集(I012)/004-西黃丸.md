# 西黃丸

> 상태: 자동 변환 원문·정본 미대조

（治乳癰瘰　。痰核流注。肺癰。小腸癰毒等。每服三錢。陳酒送下。上部臨臥服。下部空心服。）

炙淨乳香沒藥（各一兩）　麝香（一錢半）　西牛黃（三分）　雄精（五錢）

上藥共研末。取飯一兩。打爛。入末藥。再打為丸。如蘿卜子大。晒乾忌烘。每服三錢。熱陳酒送下。醉蓋取汗。

酒醒。癰消痛息。
