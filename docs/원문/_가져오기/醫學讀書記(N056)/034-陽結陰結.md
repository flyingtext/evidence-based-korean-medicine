# 陽結陰結

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

脈浮而數, 能食, 不大便者, 名曰陽結, 十七日當劇; 脈沉而遲, 不能食, 身體重, 大便反硬, 名曰陰結, 十四日當劇. 蓋天人之氣, 十五日一更, 更則結者當解, 設不解, 其病則劇. 云十七日者, 陽結能食, 故過期; 十四日者, 陰結不能食, 故不及期也. 成氏過結再傳之說, 失之泥矣.
