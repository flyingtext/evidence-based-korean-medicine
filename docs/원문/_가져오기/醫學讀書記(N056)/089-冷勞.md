# 冷勞

虛勞之人, 氣血枯耗, 生氣不榮, 則內生寒冷, 張雞峰所謂冷勞者是也. 宜建中、復脈、八味腎氣之屬, 甘溫辛潤, 具生陽化陰之能者治之. 亦有邪氣淹滯, 經絡瘀郁者, 元珠所謂體虛之人, 最易感於邪氣, 當先和解, 微利微下之, 次則調之. 醫不知而遽行補劑, 邪氣不解, 往往致死. 是故虛勞之治, 固不必專以補陰降火為事也.
