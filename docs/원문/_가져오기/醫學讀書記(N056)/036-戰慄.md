# 戰慄

邪氣入, 正氣抑, 則病; 正氣復, 邪氣退, 則汗出而愈矣. 然邪猶未強而未即服, 正猶微而未即勝, 此所以戰也.

邪氣外與正爭, 則為戰; 內與正爭, 則為慄. 慄者, 心內鼓慄. 經曰: 陰中於邪, 必內慄也. 若戰, 則但肢體戰搖而已. 戰者, 正氣勝, 則有得汗而解者; 慄者, 內氣虛, 不能御邪, 遂成厥脫也.
