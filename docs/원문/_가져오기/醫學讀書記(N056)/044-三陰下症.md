# 三陰下症

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

太陰, 有桂枝加大黃湯下之一症; 少陰, 有大承氣急下三症; 厥陰, 有小承氣下之一症. 夫邪入三陰, 病已深矣, 其幸而不死者, 其邪仍從陽而出耳! 張季明所謂太陰脾經, 溫燥不行, 亦當溫利自陽明出, 如桂枝加大黃是也; 少陰腎經, 雖用附子, 復使麻黃, 厥陰肝經用桂枝, 則知少陰亦自太陽出, 厥陰亦自少陽出; 及其太陽、少陽鬱閉不行, 則當自陽明出. 故三陰皆有下症也.
