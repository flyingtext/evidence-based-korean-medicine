# 耳聾治肺鼻塞治心

古云: 耳聾治肺, 肺主聲; 鼻塞治心, 心主臭. 愚謂耳聾治肺者, 自是肺經風熱、痰涎閉郁之症. 肺之絡會於耳中, 其氣不通, 故令耳聾, 故宜治其肺, 使氣行則聾愈. 夫聲從外入, 非無聲也, 有聲而不能入也, 而謂肺主聲何哉? 其鼻塞治心者, 經云: 心肺有病, 而鼻為之不利. 治心者, 蓋以利鼻, 豈曰致臭哉?
