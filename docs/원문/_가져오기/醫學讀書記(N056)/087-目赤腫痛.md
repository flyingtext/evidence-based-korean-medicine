# 目赤腫痛

目赤腫痛, 人知降火, 而不知活血, 所以多不得力, 只用四物湯, 內地黃用生, 芍藥用赤, 加酒蒸大黃、赤茯苓、薄荷葉, 治之甚妙, 此戴復庵法. 余謂目赤腫痛, 人知活血, 而不知治痰. 脾胃壅滯, 積熱生痰, 積痰生熱, 輾轉相因, 氣衝頭目, 昏痛不已者, 須用半夏、石菖蒲、黃芩、枳實、茯苓、陳皮, 微兼菊花、白蒺藜之屬治之.
