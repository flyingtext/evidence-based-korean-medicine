# 宣明人參白朮散方論

宣明人參白朮散, 治遍身燥濕相搏, 玄府緻密, 遂致忪悸, 發渴, 飲食減少, 不為肌膚. 方以人參、甘草, 甘以益虛也; 生地黃潤以滋燥; 石膏、黃芩、滑石, 寒以除熱也; 白朮、茯苓, 燥以除濕也. 而意特在濕熱, 故白朮、滑石、石膏數獨多焉. 其用參、地、甘草者, 熱積則真氣消, 濕聚則堅燥生也. 尤妙在薄荷、藿香以行表氣, 縮砂仁以行裡氣, 表裡氣通, 而後溫可行, 熱可去, 此畫龍點睛法也. 白朮湯方論, 與此略同, 學者宜究心焉.
