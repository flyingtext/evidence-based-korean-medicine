# 鳳髓丹方論

鳳髓丹為太陰濕熱下注, 少陰遺濁者設. 黃柏苦能燥濕, 寒能除熱, 故以為君, 濕熱易成壅滯, 砂仁之辛香可以利之; 脾邪不獨傷腎, 亦且自傷, 炙甘草之甘溫可以益之. 然諸治濕熱藥不用, 而獨取黃柏、砂仁者, 以其氣味兼通少陰也.
