# 胎前方訣

胎前妙藥橘甘陳，芍藥川芎生地青，歸腹二皮花粉殼，山楂蘇梗果黃芩。

胎漏地榆牡蠣艾，腹痛玄胡香附砂。

去紅去白如前藥，發熱柴胡急急加。

小便不通澤瀉木，若難大便郁檳麻。

骨痛二活濕蒼朮，傷風乾葛芷荊防。

頭痛川芎荊芥用，中熱還須薷藿香。

子腫木通蒼白卜，惡心半夏桂草果。

術茯苓治子虛，若還腰痛加添杜。

子脹枳殼用青皮，蘇梗再加萊菔子。

泄瀉木通豬苓澤，蒼朮濃朴山藥米。

咳嗽有痰半夏杏，天冬五味治此症。

若無痰嗽用款冬，蔞半燈芯蔥薑共。

痢紅痢白有良方，紅者芩連青木香，枳殼檳榔加藥內，三帖就去殼青榔。

痢白肉桂木香米，朴通蒼白藥檳榔。

腰痛陣陣有良方，楂殼青薑百草霜，茱萸歸尾通川滑，陳桔烏砂肉桂湯。

瘧疾青果柴半茯，砂草蒼朴豆檳榔。

中風荊防天麻葛，此是胎前神效方。
