# 烏金散治產後十八症

> 상태: 자동 변환 원문·정본 미대조

木香　烏大豆　肉桂　真蒲黃　當歸　血余炭　赤芍藥　青皮　凌霄花　大薊　小薊　棕毛灰　紅花蠶種幣　朱砂　血竭　大黃以上十八味，除灰外，俱研末，連灰、酒一處研勻，用薑湯或凌霄花湯，酒下亦可，病甚者，日進三服。

此藥治胎衣不下，難產，產後血暈，口乾心煩，產後寒熱，四肢浮腫，癲狂，言語無度，乃血邪也，並治之。失音不語，骨痛酸疼，胸膈氣滿，嘔吐，咳嗽，潮熱不定，或小便澀，或舌乾，鼻中出血，繞頂出斑，腰痛如刺，或腹疼痛，喉內蟬聲，並皆治之。
