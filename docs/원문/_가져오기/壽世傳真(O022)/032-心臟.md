# 心臟

形如未開蓮蕊, 中有七孔三毛. 位居背脊第五椎. 各臟皆有系附於心.

屬火, 旺於夏四、五月, 色主赤. 苦味入心. 外通竅於舌. 出汁液為汗. 在七情主憂樂, 在身主血與脈. 所藏者神, 所惡者熱.

面色赤者, 心熱也. 好食苦者, 心不足也, 怔忡善忘者, 心虛也.

心有病, 舌焦苦、喉干、不知五味, 無故煩躁, 口生瘡、作臭, 手心足心熱.
