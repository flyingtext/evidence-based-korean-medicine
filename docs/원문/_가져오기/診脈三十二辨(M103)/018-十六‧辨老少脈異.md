# 十六‧辨老少脈異

<!-- source-id: M103:p018 -->
> 서명: 診脈三十二辨
> 원본 파일: `M/M103.txt`

> 상태: 자동 변환 원문·정본 미대조

老弱之人。脈宜緩弱。過旺者病。少壯之人。脈宜充實。過弱者病。山甫以為猶有說焉。老者脈旺而非躁。此天稟之濃。引年之叟也。名曰壽脈。若脈躁疾。有表無裡。其死近矣。壯者脈細而和緩。三部平等。此天稟之靜。清逸之士也。各曰陰脈。若脈來細而勁直。前後不等。可與決死期矣。
