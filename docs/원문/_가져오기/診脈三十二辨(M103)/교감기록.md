# 診脈三十二辨 교감 기록

## 현재 상태

인터넷 판본과의 1차 결자 대조를 완료했다. 이 기록은 결락된 글자를 보충한 결과이며, 이체자·표점·판본 간 문구 차이까지 확정한 전면 교감본을 뜻하지 않는다.
