# 第二十九‧微紅黑灰舌

舌見四邊微紅。中央灰黑色者。此由失下而致。用大承氣湯下之。熱退可愈。必三四下方退。五次下之而不退者。

不治。

*微紅黑灰舌圖\pt101a29.bmp*

【介按】舌見灰色。病概不輕。均是裡症。無表症。有實熱症、無虛寒症。又有邪熱傳裡。時疫流行。郁結停胸。

蓄血如狂之諸證。治法不外寒涼攻下。今此舌系是應下失下之症。而見黑灰干燥之舌。急宜大承氣湯以下之。已無疑義。

即《舌鑒辨正》所謂「熱傳三陰。則有灰黑干苔。皆當攻下泄熱」者是也。但大承氣以苦寒勝熱之劑。倍濃朴以承氣機之變動。設或陽亢陰竭。已無氣之可承。則為脈澀。直視、喘滿而死矣。所以五次下之而舌色如故者。則為不治之症也。

然亦有舌心灰黑而膩者。是屬胃熱蒸動脾濕之症矣。故凡診舌。不論何色。皆當辨明燥、濕、干、潤之殊也。
