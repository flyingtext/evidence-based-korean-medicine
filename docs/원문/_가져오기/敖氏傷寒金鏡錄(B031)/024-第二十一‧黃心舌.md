# 第二十一‧黃心舌

舌有黃心色者。必初白苔而變黃色也。皆表而傳裡。熱已入胃。宜急下之。若下遲必變黑色為惡症。為惡亢害鬼賊。

邪氣深也。不治。宜用調胃承氣湯下之。

*黃心舌圖\pt101a21.bmp*

【介按】傷寒由表入裡。舌苔必然先白後黃。及至純黃無白。邪已離表入裡。即仲景所云「胃家實」也。因舌中屬胃。凡腸中有燥矢。舌心必然黃燥、或黃濃焦老。中心裂紋起刺。腹中硬滿脹痛。急用調胃承氣湯下之。否則由黃轉黑而燥。大便秘結。猶可以承氣下之。如若失治。舌變枯黑燥裂。堅斂焦刺。乃是腎津胃液俱竭。情勢危險。是屬不治之症矣。倘如不忍坐視。惟以大劑滋液清熱之品。希冀萬一而已。原文所謂「宜用調胃承氣湯」之句。應在「宜急下之」

之下。非在「不治」之下。古書文法。類多如是。不獨此條為然也。
