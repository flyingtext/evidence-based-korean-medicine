# 第十九‧白苔邊黃舌

舌中見白苔。外則微黃者。必作泄。宜服解毒湯。惡寒者。五苓散。

*白苔邊黃舌圖\pt101a19.bmp*

【介按】白苔屬肺。黃苔屬胃。茲因熱熾於胃。邪尚在肺。日久不解。則肺胃之邪熱。移於大腸而作泄。故用解毒湯以清熱解毒。如若外證惡寒者。則為寒濕作瀉。其舌必潤。故用五苓散以滲其濕也。
