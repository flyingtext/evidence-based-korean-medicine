# 第三十‧黃色黑點舌

舌見黃而黑點亂生者。其症必渴譫語。脈滑者生。脈澀者死。循衣摸床者不治。若下之，見黑糞亦不治。下宜大承氣湯。

*黃色黑點舌圖\pt101a30.bmp*

【介按】舌苔焦黃而起黑刺。症至大渴譫語。此是邪熱入裡。灼耗津液。病勢最險。惟脈滑則邪正俱實。尚有生機。

澀則津液劫盡。即俗語所謂「燈燼油干則必死」也。至於循衣摸床。乃是陽明之壞病。故曰不治。如在險象未露之先。

欲行施治。則用大承氣湯下之。服藥之後。如見黑糞。此系熱毒深重。滲入大腸。胃氣全消。故為不治之症也。
