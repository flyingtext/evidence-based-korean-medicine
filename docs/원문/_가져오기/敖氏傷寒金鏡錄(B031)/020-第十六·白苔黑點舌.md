# 第十六·白苔黑點舌

舌見白苔中有小點亂生者。尚有表證。其病求之雖惡。宜涼膈散微表之。表退即當下之。下用調胃承氣湯。

【介按】舌苔白而中有燥刺者。此係溫邪在手太陰肺經。外證初必惡寒。繼即發熱不已。症勢雖似惡候。治宜辛涼清解。宜用涼膈散先清上中二焦之熱。若熱退而大便未下者。即當改投攻下之劑。如欲下之。宜與調胃承氣湯。
