# 第十二‧死現舌

舌見黑色。水克火明矣。患此者。百無一治。右前舌。雖有色圖。恐其久而渝淡無辨。故注之。

*死現舌圖\pt101a12.bmp*

【介按】苔見黑色。病必不輕。不論寒熱。虛實諸症。皆有此色。惟舌至全黑。病已入裡。非臟腑極熱。即為臟腑極寒。若虛寒而舌黑。則必濕滑無苔。若真寒假熱而舌黑。則必全黑而不分經。如全黑無苔而底紋粗澀干焦。刮之不淨。

是為熱極之候。如全黑無苔而無罅點。干燥少津而光亮。此為絳色之變態。是腎虛液涸之證。如全黑而有罅有點。是熱極之實證。惟苔黑腐爛。為心腎俱絕。舌黑卷縮為肝臟已絕。皆為不治之證。茲謂水克火而百無一治者。即是臟腑極寒極虛之證也。
