# 序（三）

嘗聞古人多無病，間有病而治之，惟移精變氣而已。末世病治以藥，或愈或不愈。夫病而後藥亦晚矣，是故聖人不治已病治未病。吾邑張君精於岐黃之業，集為《仁術便覽》，得病之情，知治之體，雜合以治，各得所宜，誠可以濟世蒸人。第治已病耳，何取乎？蓋古人恬澹虛無，真氣從之，精神內守，邪不能深入，是以多無病。治病者，亦不藥而愈。今之人，知奉生之道者寡，情慕云為，逆於生樂，不得已而治之，《仁術便覽》之刻可已哉。嗚呼，使不能病病，動伐其根本，而曰《仁術便覽》乃已試之方。茲刻也，病天下矣。
