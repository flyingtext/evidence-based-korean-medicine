# 辨可下病衇証篇

大法：秋宜下。

【注】天至秋則氣降，物至秋則成實，實則宜下。凡邪在下者，俱宜取法乎此義也。

凡可下者，用湯勝丸散，中病便止，不必盡劑也。

【注】湯者蕩也，丸者緩也。下藥貴速，故凡服下藥用湯，所以勝丸也。中病即止，不必盡劑者，恐盡劑反傷其正氣也。

【集注】程應旄曰：用湯勝丸，貴活法也。中病即止，示節制也。

下利，三部衇皆平，按之心下硬者，急下之，宜大承氣湯。

【注】下利心下硬者，諸瀉心湯証也。若寸、關、尺三部衇平實有力，雖下利仍宜攻其硬也。

【集注】方有執曰：三部衇皆平，血氣和可知矣。心下硬實也。所以急下之也。

張錫駒曰：《夲經》云：若自下利者，衇當微厥。今反和者，此為內實也，宜下之。

下利，衇遲而滑者，內實也。利未欲止，當下之，宜大承氣湯。

【注】衇遲不能兼滑，惟浮取之遲，沉取之滑，則有之矣。今下利衇遲而滑，謂浮遲而沉滑也，浮遲則外和，沉滑則內實。欲止內實之下利，仍當下之，使積去則利自止，宜大承氣湯。

【集注】程應旄曰：遲而滑，滑在下而遲在上，知為物阻之遲，非寒隂之遲，故但下其所阻，則內實去而利自止矣﹗問曰：人病有宿食，何以別之？師曰：寸口衇浮而大，按之反澀，尺中亦微而澀，故知有宿食，當下之，宜大承氣湯。

【按】尺中“微”字，當是“大”字，若是“微”字，斷無當下之理。

【注】寸口衇浮而大，按之反澀，謂按之且大、且澀、且有力也，關上尺中亦然。大澀有力，為實而不利之診，故知有宿食也，當下之，宜大承氣湯。

【集注】程知曰：滑為有食，結滯經宿，則衇澀矣。尺以候內，沉以候裡，故宿食之衇，按之反澀，尺中亦大而澀也。

下利不欲食者，以有宿食故也，當下之，宜大承氣湯。

【注】初下利不欲食者，是傷食惡食，故不欲食也，若久下利不欲食者，是傷脾，食後飽脹不欲食也。今初下利即不欲食，故知有宿食也，當下之，宜大承氣湯無疑也。

【集注】程應旄曰：傷食惡食，故不欲食，與不能食者自別。下利有此，更無別樣虚証，知非三隂之下利，而為宿食之下利也，故當下之。

下利瘥，至其年月日時複發者，以病不盡故也，當下之，宜大承氣湯。

【注】下利瘥後，至其年月日時而複發其利者，此宿食積病攻之不盡故也。若其人形氣不衰，飲食尚强，當攻其未盡，自不複發矣，宜大承氣湯。

【集注】方有執曰：其期也，謂周其一年之月日期也。

程應旄曰：下利瘥後，而余邪之棲於腸胃回折處者未盡，是為伏邪。凡得其候而伏者，仍應其候而伸下，則搜而盡之矣。

下利衇反滑，當有所去，下乃愈，宜大承氣湯。

【注】此承上條互發其義，以詳其衇也。下利衇反滑，是証虚衇實，不相宜也。若其人形氣如常，飲食如故，乃有當去之積未去也，下之乃愈，宜大承氣湯。

【集注】程應旄曰：滑為實，故可行通因通用之法。

病腹中滿痛者，此為實也，當下之，宜大承氣湯。

【注】腹中不滿而痛者，病或属虚，若滿而痛，則為實矣，當下之，宜大承氣湯。

【集注】張璐曰：腹中既滿且痛，為實結無疑，急須下之。

程應旄曰：病腹中滿痛，雖在隂經，亦可下，不必其為陽明矣。

傷寒後衇沉，沉者，內實也，下之解，宜大柴胡湯。

【注】傷寒後不解，衇沉，沉而有力者，內實也，宜以下解。然其人必午後小有潮熱，故取大柴胡兩解之也。

衇雙弦而遲者，必心下硬，衇大而緊者，陽中有隂也，可下之，宜大承氣湯。

【注】雙弦，謂左關、右關皆見衇弦也。左關衇弦，肝夲衇也；右關衇弦，木刑土也。弦者，飲也；遲者，寒也。心下硬者，是肝邪挾寒飲而傷胃，故不可下，乃生薑瀉心湯証也。若衇大按之緊，是陽有餘而隂亦實也，乃有餘之硬，非胃傷者比，故可下之，宜大承氣湯也。
