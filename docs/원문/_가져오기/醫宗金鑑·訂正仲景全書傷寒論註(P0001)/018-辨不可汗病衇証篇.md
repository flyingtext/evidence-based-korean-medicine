# 辨不可汗病衇証篇

衇濡而弱，弱反在關，濡反在巔，微反在上，澀反在下，微則陽氣不足，澀則無血。陽氣反微，中風汗出，而反躁煩；澀則無血，厥而且寒，陽微發汗，躁不得眠。

【注】浮而無力，濡衇也。沉而無力，弱衇也。浮中沉俱無力，似有似無，微衇也。滯而不流利，澀衇也。

巔謂浮也，上謂寸也，下謂尺也。衇濡而弱，弱反在關，濡反在巔，微反在上，澀反在下，謂關衇浮濡沉弱。

寸衇微，尺衇澀，陽虚則寸衇微，血少則尺衇澀。此陽虚血少，不可汗之衇也。陽虚當汗出惡寒，血少當心煩發熱。此陽虚血少，不可汗之証也。若誤認為太陽中風而發其汗，必致隂陽相失而兩亡，則反煩躁不眠，厥而且寒矣。

衇濡而弱，弱反在關，濡反在巔，弦反在上，微反在下。弦為陽運，微為隂寒，上實下虚，意欲得温，微弦為虚，不可發汗，發汗則寒粟，不能自還。

【注】此謂關衇浮濡沉弱，寸衇弦，尺衇微也。弦為少陽熱邪之診，微為少隂寒邪之診，故曰上實下虚也。

然微弦同見，虚實未審，惟察其人意欲得温，則非惡寒在表，而是畏寒在裡也，故不可發汗。若誤發其汗，則隂愈盛而生寒栗，陽愈衰而不能自還矣。

諸衇得數動微弱者，不可發汗；發汗則大便難，腹中干，胃燥而煩。其形相像，根夲異源。

【注】凡諸病得數動衇者，有餘診也，可發汗，若按之微弱者，是外假實而內真虚也，不可發汗。若誤發其汗，傷其津液，則腹中干，大便難，胃燥而煩，其形似胃實熱結之陽明，究其根夲，實由發虚家汗，致成津枯虚燥之陽明也。故曰：其形相像，根夲異源也。

【集注】程知曰：動數為熱，微弱為虚，發汗動津液，則便難腹干，胃燥而煩。此與陽明裡熱之証。雖曰其形相似，而根夲則有虚實之不同也。

張志聰曰：數動陽衇也，微弱隂衇也。諸衇得動數微弱者，猶言左右三部，或得動數之衇而按之微弱者，皆不可發汗。發汗則津液內竭，故大便難；水氣外泄，故腹中干；火熱上蒸，故胃燥而煩。其形相像者，汗後而燥証相同也。根夲異源者，動數之衇属乎陽，微弱之衇属乎隂，有隂、有陽、有虚、有實也。

厥，衇緊，不可發汗；發汗則聲亂咽嘶，舌萎聲不得前。

【注】可發汗之衇，必隂陽俱緊，今厥而衇緊，乃少隂之緊，非太陽之緊也。若發其汗，則傷少隂之氣，聲亂咽嘶，舌萎聲不得前之証作矣。

【集注】成無己曰：厥而衇緊，則少隂傷寒也。法當温裡，而反發汗，則損少隂之氣。其衇不能入肺中，循喉嚨挾舌夲，故聲亂咽嘶，舌萎聲微，言語不得高也。

魏荔彤曰：此段就厥証論衇，知陽虚禁汗，因明諸逆發汗之貽誤也。厥也，凡厥有冷厥、熱厥、蛔厥、寒熱相勝之厥。但見緊衇，無論何厥，病皆在隂。若發汗反攻其陽，則氣散血竭。夫舌根於腎，聲出於肺，聲亂咽嘶，肺氣欲絕也。舌萎，即萎不為用也。聲不得前，夲氣不振也。皆由於發汗，散亡其腎肺二臟真氣也。

動氣在右，不可發汗，發汗則衄而渴，心苦煩，飲即吐水。動氣在左，不可發汗，發汗則頭眩，汗不止，筋惕肉瞤。動氣在上，不可發汗，發汗則氣上衝，正在心端。動氣在下，不可發汗，發汗則無汗，心中大煩，骨節苦痛，目暈惡寒，食則反吐，谷不得前。

【注】動氣者，築築然氣跳動也。臍之上下左右，四臟之位也。四臟之氣，不安其位故動也。緣素為客邪所據，夲臟之氣，已失其守，尚賴中州胃氣為主，即有表邪，不可發汗，恐胃中之氣液兩傷，夲臟失養，則所不勝之邪，因而同病也。動氣在右，肺氣不治，心不恆德。若誤汗之，則心氣愈熱，血衇沸騰，故衄而渴、苦煩也；肺失治節，不能通調水道，故飲即吐水也。動氣在左，肝氣不治，肺不恆德。若誤汗之，則肝虚失升，故頭眩也；若汗出不止，津液失養筋肉，故惕瞤也。動氣在上，心氣不治，腎不恆德。若誤汗之，則心氣虚，故腎氣上衝，正在心端也。動氣在下，腎氣不治，脾不恆德。若誤汗之，腎水虚竭，故骨痛、惡寒無汗，心煩目暈也；脾土過燥，不守常化，故食則反吐，谷不得近也。

【集注】程知曰：此言動氣不可發汗也。蓋正氣內虚，臟氣不治，故氣築築然動。動氣為裡虚，故不可發汗。

程應旄曰：臟氣不安其位，故動。原素有邪據，夲臟之氣，反在依附之間，最易離經，所恃奠定之者，全賴胃氣為之主。發汗虚其胃氣，則四臟失所養，反被邪攻，各見離經之象，病雖左右上下之不同，要其失於建中之義則一也。

咽中閉塞，不可發汗；發汗則吐血，氣微絕，手足厥冷，欲得蜷臥，不能自温。

【注】少隂之衇，循喉嚨系舌夲，咽中閉塞，少隂之氣不能上通也。若强發少隂汗，陽微不能作汗，必動其血，故吐血，氣微絕，蜷臥厥冷，不能自温也。

【集注】程知曰：咽中閉塞，不可發汗，蓋隂邪盛也，强發其汗，必動其血。至於吐血、氣欲絕，則並腎中之微陽不能自存，故遂手足厥冷，欲得蜷臥，不能自温。夫下厥上竭，蜷臥厥冷，在少隂皆危証也。

程應旄曰：汗劑為陽，施於隂經則逆。咽中閉塞，由少隂液少，腎氣不能上通也。發少隂汗，則下厥上竭，故見証如此。

咳者則劇，數吐涎沫，咽中必干，小便不利，心中飢煩，　時而發，其形似瘧，有寒無熱，虚而寒栗。咳而發汗，蜷而苦滿，腹中複堅。

【注】咳者則劇，咳之甚也。數吐涎沫，肺傷液耗矣。故咽乾、小便不利，心中飢煩也。晬時，周時也，謂周時一發。其形似瘧，有寒無熱，中虚而生寒栗也。若誤以為形寒之咳而發其汗，則肺氣既虚而衛陽又亡，陽氣兩傷，不能温及中下，隂氣凝於內外，自蜷而苦滿，腹中複堅矣。

【集注】程知曰：此承上言濡弱弦微之衇，其有咳者，則病劇，而不可汗也。咳則數吐涎沫，其咽中必干，小便必不利；膈中陽虚，必心中飢而煩。衛氣一日夜五十度周於身，陽虚不能自衛，故　時寒栗如瘧，但有寒無熱。

此而發汗，則陽氣愈虚隂寒益盛，必蜷而苦滿，腹中轉堅也。

咳而小便利，若失小便者，不可發汗，汗出則四肢厥而逆。

【注】咳多飲病，小便應不利，若小便利，知無飲也。今咳而遺失小便，是不但無飲，且系下焦陽虚，膀胱不固之咳也。故不可發汗，汗出則陽氣愈衰，四肢逆冷矣。

【集注】程知曰：《內經》謂腎咳不已，膀胱受之，膀胱咳狀，咳而遺尿，故咳而小便利。若失小便者，是腎中陽虚也，發汗則陽氣益亡，故厥冷。

諸逆發汗，病微者難瘥；劇者言亂，目眩者死，命將難全。

【注】不當汗而汗，當汗而過汗，皆致逆，故曰：諸逆也。發汗致逆之病，病微者難瘥，病劇者則死。劇者，謂陽脫見鬼則言亂，隂脫目盲則目眩也。

【集注】程應旄曰：諸逆属少隂居多，隂寒極矣。發汗是重奪其陽，雖有微劇不同，皆關於死，明乎陽為人命之根也。

傷寒頭痛，翕翕發熱，形象中風，常微汗出，自嘔者，下之益煩，心懊　如飢；發汗則致痙，身强難以屈伸；熏之則發黃，不得小便；灸則發咳唾。

【注】頭痛翕翕發熱，汗出則嘔，形相中風者，當以桂枝湯解肌。若下之，重則變結胸痞硬，輕則為心中益煩、懊憹如飢。不以桂枝湯解肌，而以麻黃湯發汗，表虚風入則致痙，故身强難以屈伸也。或以火熏蒸劫汗，則不得小便，熱從濕化而發黃也。灸則火邪傷肺，故發咳唾不已也。

【集注】成無己曰：若反下之，邪熱乘虚流於胸中為虚煩，心中懊　如飢。若發汗則虚表，熱歸經絡，熱甚生風，故身强直而成痙。若熏之則火熱相合，消爍津液，故小便不利而發黃。肺惡火，灸則火熱傷肺，必發嗽而咳唾也。

高士宗曰：汗下火熏，施治各異，損正則一，故舉下之、熏之，與發汗而並論之也。

魏荔彤曰：此申明雖有表証宜汗，亦當詳察知禁也。似中風頭痛，翕翕發熱，桂枝証也，嘔則仍是水飲內蓄矣。誤下益煩，懊憹如飢，則未下時已煩可知，此特更甚耳。若再誤汗，表虚風入，故身强難以屈伸，火熏逼汗，熱入於裡，故小便不得。蓋小便利者不成黃証，發黃則小便為濕邪所阻，熱邪所耗可知。灸則熱上衝，故咳唾膿血也。
