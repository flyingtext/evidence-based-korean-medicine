# 石斛非肝藥

<!-- source-id: O117:p018 -->
> 서명: 鱠殘篇
> 원본 파일: `O/O117.txt`
> 원본 SHA-256: `7f80f013094f47fd7170e98c31bedb3bade2b4c62e3fd148c5d75d1b65c131c0`
> 상태: 자동 변환 원문·정본 미대조

石斛生於水石之間，秋月開花，皮黃肉白，甘淡微鹹，故入心腎脾胃四經，能強陰益

精，除熱療痹。氣薄味厚，陽中之陰也。時人竟以為肝經藥，殊不知何所據？夫五色、五味、五氣入五臟，千古不易之理也。肝屬木而色青，味酸氣臊。凡物品如是者則入肝膽，未有黃白甘淡者而入肝也。然肝苦急，急食甘以緩之。石斛甘淡用以緩肝，為輔佐之品則可，若藉以為平肝之藥，則未之察也。因論左金治肝法，故連類而及之。
