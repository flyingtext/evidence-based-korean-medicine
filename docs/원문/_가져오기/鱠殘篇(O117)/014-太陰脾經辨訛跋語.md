# 太陰脾經辨訛跋語

> 상태: 자동 변환 원문·정본 미대조

余自束發客江寧，因水土變遷，嬰疾病臥兼旬，幾弊者屢，守中醫而獲愈。既愈，留心醫學，欲為卻病計，非敢存醫人志也。越數歲，稍出應酬，見人有稱病曰太陰脾經者，心竊異之，及其治法則令人餓而不食，藥則從乎蒼、朴、砂、蔻，香燥攻克而已。夫太陰脾乃手足十二經中之一耳，若論其經臟之病，則疸、腫、瀉利，嘔吐、脹滿，以致停痰、積食，種種不一，淪其治則，補瀉溫清，各各不同，何混乙太陰脾經命病名？而治則一例也，若以不思食為脾之病而概稱之，則咳嗽吼喘何又不稱之曰太陰肺經也？類此而推，則驚悸怔忡，亦可稱曰少陰心經，(病-丙C貴)疝癥瘕亦可稱曰厥陰肝經矣。雖仲景《傷寒論》有太陽、少陽、陽明、太陰、少陰、厥陰症，乃言是經之為病如某某等，亦並未有乙太陰脾經為病名也。在病家或不知名義，奈醫家亦侈口而稱，其不思也甚矣！且其不思食，屬傷食惡食者餓猶可也。若脾虛不運，胃弱饜飫，補之不暇，尚堪餓而消之乎？獨不顧得穀則昌、有胃氣則生之義，詎有令人長餓而更連旬累月之進攻克香燥藥以責效也耶？存疑迄今，役役四方，未得就有道而訂淪之。乙丑暫歸金陵舊館，得與王子村舟游，出其太陰脾經辨訛論以示余，讀之數過，其析理詳明，剖症纖悉，足破金陵習俗，而壽斯民，功匪淺鮮猗歟！人同此心，心同此理，使余積久疑團一旦而獲同聲之應，是用慫恿付梓，以公諸世，王子辭讓，且恐獲罪於同儕。噫！切磋琢磨，朋友之道也。苟有所得，出而丐正於同人，何莫非相長之道與？亦胡惙惙弗遑焉？爰為跋之篇末，惟村舟其圖之。
