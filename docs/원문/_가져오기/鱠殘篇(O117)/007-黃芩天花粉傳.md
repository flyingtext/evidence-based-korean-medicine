# 黃芩天花粉傳

> 서명: 鱠殘篇

> 상태: 자동 변환 원문·정본 미대조

山草黃芩者，蜀之秭歸產也。味苦，性寒，氣厚，味薄，陽中之陰，色青，專行少陽而兼入肺胃，可升可降，嘗與黃連、厚朴、柴胡善，而惡蔥實，畏藜蘆、丹砂、牡丹皮。其相與遊而協濟以成功者，則得酒上行，而消上焦積血，清痰利膈：得豬膽汁除肝膽火，而祛脾胃濕熱偕柴胡退寒熱之往來；同白朮為安胎之聖藥；佐桑皮瀉肺火，而須舊根枯片，即別名腐腸妒婦者；與芍、連、枳、朴除下利膿血。腹痛後重必選細實新根，即俗稱子芩、條芩者。仲景傷寒方治心下痞滿瀉心湯，凡四方皆用之。又如太陽症下之，利不止、喘而汗出者，有葛根黃芩黃連湯；太陽少陽臺病下利，有黃芩湯；少陽症下後，心下滿而不痛，有瀉心湯；少陽症之小柴胡湯，則本經藥也。迨張元素稱其功用有九，而李東垣、朱丹溪多闡發其妙，蓋火靖氣寧而胸隔暢，濕除滯化而腸胃通，上焦治則二便利。血閉痰凝，癰疽煩懣，清熱以澄其源。因勢利導，故事半而功倍，順病之情，不煩奇異，而效斯捷，審寒熱，慎予奪，故曰：藥貴中病，醫之寶也。大暑炎嫗，三黃、白虎不足以為暴，何獨於芩而斯懼哉？至蔓草中又有天花粉、栝蔞根者，秦之弘農所出也，甘微苦酸，微寒，清潤降下之品，金玉君子之質，除消渴，清暑熱，通小腸，散癰腫瘡癤，排膿止痛，消瘀生肌，其為肺與陽明藥也，最宜虛熱人。仲景用其實以治胸痹，痛引心背，咳唾喘息及結胸滿痛，乃取其甘寒不犯胃氣，能清上焦之火，使痰行氣降而治矣。若栝蔞散之治乳癰，其根下乳汁，拔箭鏃，及針入肉，退痘後目瘴，其以純粹之質，而能定倉猝乖戾之疾，其功可以想見矣。故其使枸杞子惡乾薑，畏牛膝，反烏頭，亦物以群分云爾。萍如子曰：黃芩、花粉《農經》中品，日用恒需之藥，以治四時常有之疾，不可一日廢也。乃世人好奇異，矜詭秘，競事玉紮，丹砂之貴重，侈談空青、狗實之無幾，何異舍菽粟、水火而他求養生具哉？天食人以五氣，地食人以五味。無虛虛，無實實，掊有餘，補不足。是在人為之，而有至理存焉。察理真則施用，當可免偏勝之患，詎可因施之不當而棄物之性，不亦冤乎？然盡信書，則不如無書，亦不可不察。若李之才云：山茱萸、龍骨為黃芩之使，得五味子、牡蠣令人有子之說，則吾未之深信。黃芩苦燥而寒，其於濕熱、瘡痍、瘧痢、血熱等症，實能勘亂定禍，因便乘勢以成功。管夷吾之流，而亦得桓公任之，當而能盡其才也。天花粉甘寒而潤，大宜虛熱人，其能出箭鏃，退目翳。殆平仲在莊公之世，而處崔杼之亂也。吾故仿龍門管晏傳而為芩粉傳。《詩》云：呦呦鹿鳴，食野之芩。又云：果羸之實，亦施於宇。睹二詩，可以窺二物尚矣。
