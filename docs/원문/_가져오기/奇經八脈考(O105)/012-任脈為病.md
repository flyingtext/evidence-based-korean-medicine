# 任脈為病

素問曰:任脈為病,男子內結七疝,女子帶下瘕聚.

又曰:女子二七而天癸至,任脈通,太衝脈盛,月事以時下,七七任脈虛,太衝脈衰,天癸竭,地道不通,故形壞而無子.

又曰:上氣有音者,治其缺盆中.（謂天突穴也,陰維、任脈之會,刺一寸,灸三壯）

脈經曰:寸口脈來緊細實,長至關者,任脈也.動苦少腹繞臍,下引橫骨、陰中切痛,取關元治之.

又曰:橫寸口邊,脈<ins>丸丸</ins>者,任脈也.苦腹中有氣如指,上搶心不得俯仰,拘急.
