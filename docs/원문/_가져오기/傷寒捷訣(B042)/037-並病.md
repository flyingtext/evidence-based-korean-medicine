# 並病

太陽原與陽明並。復病歸來作一家。尚有太陽宜各半。太陽症罷大承瘥。

並病者。謂一經先受病。又過一經病之傳者也。如太陽陽明若並而未盡。是謂未過。仲景所謂太陽病不罷。面赤。陽氣怫郁。在表不得越。煩躁短氣是也。猶當汗之以各半湯。若並之已盡。是謂傳過。仲景所謂太陽病罷。潮熱。手足汗出。大便硬而譫語是也。法當下之。以大承氣湯。

是知傳則入腑。不傳則不入腑。並病傳變有如此。
