# 咳嗽

太陽咳嗽用青龍。裡水還須十棗攻。寒熱柴胡加減治。陰邪真武總收功。

有聲無痰曰咳。有痰無聲曰嗽。經曰。肺主氣。形寒飲冷則傷之。使氣逆而不散。沖擊咽膈。今喉中淫淫如癢。習習如梗。而咳嗽也。凡傷寒咳嗽。有因太陽水氣在表而咳者。宜小青龍湯主之。有因太陽水氣在裡而咳者。宜十棗湯主之。有因少陽寒熱往來而咳者。宜小柴胡東加減治之。有因少陰水氣在裡而咳者。宜真武湯主之。大抵傷寒以嗽為輕。不與雜症同。須斟酌治之。
