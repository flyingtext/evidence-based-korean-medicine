# 狐惑

咽乾聲啞名狐惑。狐則食肛下唇瘡。上唇有瘡或食臟。黃連犀角可煎嘗。

狐惑者。謂傷寒失汗所致。食少胃虛。蟲嚙五臟。故唇口生瘡。蟲食其臟。則上唇生瘡為惑。蟲食其肛。則下唇生瘡為狐。喉咽乾。聲啞齒燥。惡食、面目乍赤、赤白、乍黑。舌上白苔。唇黑喜眠。四肢沉重。宜以黃連犀角湯主之。
