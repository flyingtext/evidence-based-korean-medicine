# 吐血

皆因邪熱中三焦。當汗醫家失審量。熱毒入深成吐血。桃仁承氣地黃湯。

吐血者。諸陽受熱。其邪在表。當汗不汗。致使熱毒入腑。積瘀於內。迫血妄行而吐也。宜以桃仁承氣湯主之。亦有服桂枝湯而吐血者。宜犀角地黃湯主之。大抵吐血衄血。有陽乘陰者。有陰乘陽者。陽乘陰者。血熱妄行是也。陰乘陽者。血不歸經是也。
