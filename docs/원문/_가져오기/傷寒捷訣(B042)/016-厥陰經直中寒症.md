# 厥陰經直中寒症

口吐涎沫不作渴。嘔逆腹疼四肢厥。爪唇青黑是真寒。回陽救急功尤捷。（此足厥陰直中寒症也。其脈沉遲無力宜溫之）

回陽救急半甘苓。熟附乾薑肉桂參。白朮陳皮五味子。治寒直中厥陰經。

夫傷寒三陰有傳經之熱症。有直中之寒邪。自是兩途。豈容混治。其可用不可用之理。

果何哉。若能辨其因。正其名。察其形。治法焉有不當者乎。
