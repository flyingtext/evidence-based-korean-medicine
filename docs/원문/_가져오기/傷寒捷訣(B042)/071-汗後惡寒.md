# 汗後惡寒

汗後惡寒宜芍藥。脈沉發熱下尤良。四肢疼痛仍兼利。厥冷須投四逆湯。

傷寒汗後。則寒邪自散。不當惡寒。然汗後猶惡寒者。何也。蓋陽微則惡寒。須芍藥湯以收斂之。倘脈沉屬裡。發熱惡寒者。恐內有積熱。宜下之為良也。若四肢疼痛瀉利厥冷。此陰症也。宜四逆湯溫之。
