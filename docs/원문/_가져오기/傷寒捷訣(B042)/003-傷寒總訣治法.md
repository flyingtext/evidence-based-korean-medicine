# 傷寒總訣治法

<!-- source-id: B042:p003 -->

> 상태: 자동 변환 원문·정본 미대조

一二日可發表而散。三四日宜和解而痊。五六日便實。方可議下。七八日不愈。又復。日傳二經。病名兩感。經傳六日。應無不痊。太陽無汗。麻黃為最。太陽有汗。桂枝為先。小柴胡為少陽之要領。大柴胡行陽明之秘堅。至三陰則難拘定法。或可溫而可下。宜數變以曲全生意。或可方而可員。
