# 嘔吐

胃家有熱難停食。胃冷無和納水漿。二證皆令人嘔逆。嘔家聖藥是生薑。若是上行為氣逆。胃家由是不安康。

有物有聲謂之嘔。有物無聲謂之吐。蓋由表邪傳裡。裡氣上逆。則為嘔吐水穀不下是也。然嘔吐症本不同。有因氣逆而嘔者。宜小柴胡東加生薑主之。有因水停心下而嘔者。宜茯苓甘草湯主之。有因胃熱而吐者。宜竹葉石膏東加生薑汁主之。有因胃寒而吐者。宜理中東加生薑主之。大抵嘔吐清水。即為寒症。若胃中有熱。必是涎液酸水。病機云。諸嘔吐酸。及水液混濁。皆屬於熱。諸病水液澄徹清冷。皆屬於寒。此可見矣。

竹葉石膏湯用參。麥冬半夏更加臨。甘草生薑加粳米。虛煩自利熱能清。
