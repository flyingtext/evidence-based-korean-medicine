# 行拳法分輕重論

向上為順氣，正打為塞氣，倒插為逆氣。三者之中，惟倒插拳最凶，各樣內傷終怕的倒插氣逆，其為患甚大，不可輕視。

兩眼白睛上血筋多，內瘀血亦多。或直視無神難治。扳　於中指甲，放手即還原者可治，不還原者不可治。或紫黑者不治。陽物縮者不治。腳指甲與手指甲同看腳底傷、色蠟黃者難治。五絕病內如一二件不犯者，亦或可治。
