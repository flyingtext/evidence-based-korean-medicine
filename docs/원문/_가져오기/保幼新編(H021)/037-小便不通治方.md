# 小便不通治方

急取生地龍數條，蜜少許，同研，敷陰莖上。又蠶退紙燒灰，朱砂、龍腦、麝香各少許，麥門冬、燈芯煎湯，調灌口中即通。如無腦、麝代入木通（去節）、赤茯苓、生地（酒炒），三味煎湯，只調朱砂，服之亦可。

一方：鵲腦髓和清，酒服之。

如大小便俱不通，蔥白汁、乳汁各半匕調勻，抹兒口中，即吮乳乃通。
