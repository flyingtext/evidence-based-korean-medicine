# 齒久不生（附發久不生）

（此由氣不足，芎黃散主之）

<ins>芎黃散</ins>

川芎　生地黃　當歸　山藥　白芍藥（各一兩）　沉香（五錢）　甘草（三錢）

為末，白湯調下，將干末擦齒上，日二次。（白湯調下，每五分）

發久不生，由血不足，蓯蓉丸主之。

<ins>蓯蓉丸</ins>

當歸　生地　肉蓯蓉　白芍藥（各一兩）　胡粉（五分）

蜜丸黍米大，每十丸，黑豆湯吞下，兼作餅敷頭。
