# 64.口舌方法

<!-- source-id: F028:p064 -->
> 서명: 七十二症辨治方法（手抄本）
> 원본 파일: `F/F028.txt`
> 원본 SHA-256: `4ab9091e42f990a6247df75a25af93fb72f881e4298b74509e430b60e977285a`
> 상태: 자동 변환 원문·정본 미대조

脾應中央戊己土，口舌同居通臟腑；口乾脾熱肝膽酸，肺辣心鹹心熱苦。
舌吐不收為陽強，舌縮難言令子母；口舌糜爛忽生瘡，咽喉涎漫苦難當。
重舌木舌舌本強，加減先鋒桔梗湯；己上赴宴湯堪用，金針刺疼造乾坤。
赴宴湯中用三黃，百煎梔子天麥門；乾薑細辛硼砂末，一杯揮去息燎源。
