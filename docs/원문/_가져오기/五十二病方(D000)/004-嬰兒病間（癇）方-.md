# 嬰兒病間（癇）方:

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

取雷尾〈癤（矢）〉三果（顆）,治,以豬煎膏和之.小嬰兒以水【半】鬥,大者以一斗,三分和,取（四八）一分置水中,撓,以浴之.浴之道頭上始,下盡身,四支（肢）毋濡.三日一浴,三日已.已浴,輒棄其（四九）水圂中.間（癇）者,身熱而數驚,頸脊強而復（腹）大.〔原帛缺文1字〕間（癇）多眾,以此藥皆已（五.）.
