# 五十二病方 교감 기록

## 현재 상태

jicheng.tw 최신 전문과 Chinese Text Project 전사·馬王堆帛書 연구 자료를 대조해 복원 가능한 결자와 OCR 오기를 교정하고 표점을 검증했다.

## 대조 범위

- 원자료: `D/D000.txt`
- 전각 공백: 492자리 전수 판정(복원·정리 후보 478, 판면 공백 14)
- 원백 물리 결락: 466구간 1,572자. 임의 보충하지 않고 `〔原帛缺文N字〕`로 결락 길이를 보존
- 적용 내역: `corrections-applied.json`
- 표점 검증: `punctuation-report.json`

## 대조 판본

- https://jicheng.tw/tcm/book/%E4%BA%94%E5%8D%81%E4%BA%8C%E7%97%85%E6%96%B9/index.html
- https://ctext.org/wiki.pl?chapter=197057
- https://square.umin.ac.jp/mayanagi/paper03/mawangtui.html

## 유보 사항

원백의 물리적 결락은 내용 미상으로 남기되 위치와 추정 글자 수를 명시했다. 새 판독 성과가 나오면 해당 표지를 근거와 함께 갱신한다.
