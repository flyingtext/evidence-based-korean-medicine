# 犬筮（噬）人傷者：

取丘（蚯）引（蚓）矢二升，以井上　斷處土與等，並熬之，而以美【醯】□□□□（六一）之，稍垸，以熨其傷。犬毛盡，敷傷而已（六二）。

一，煮莖，以汁洒之。冬日煮其本（六三）。

一，犬所嚙，令毋痛及易瘳方，令【嚙】者臥，而令人以酒財沃其傷。已沃而□（六四）越之。嘗試。毋禁（六五）。
