# 潘仕成序

昔陸宣公在南中撰《古今集驗方》五十篇，惜今不傳。而蘇端明復與沈存中撰《蘇沈良方》一書，後人力辨非端明之筆。顧端明雜著，時言醫理，於是事殆亦頗究心。蓋方藥之事，朮家蘇習共技，而不能知其所以然；儒者能明其理，而又往往未經試驗。即謂方出存中，而端明以博通物理而輾傳代傳，其功豈遽出存中下﹗宜迄今千百載，以蘇、沈齊稱矣。明‧焦弱侯亦嘗欲集古雜記諸藥方為一書，惜未成，只《筆乘》中載有數十條耳。周櫟園《書影》謂：古人非自驗之方，未必肯記於集。若依《筆乘》所載，再為推展，各分症類，都為一集，勝刻快書、清記，諸鄙俚無用之書多矣。此書亦不難成，留心醫術志之。近善化鮑君成

《驗方新編》一書，刻於粵西。其視葛洪《肘後方》、孫思邈《千金方》，未知何如？而平近人，隨地隨時均可濟物。予特重付剞劂，以分貽四方諸君子，庶益廣流布，更冀人同此心同此理。俾立方者與余之愿，力引伸於無窮。或又重刊，以輾轉代傳於通都大邑，以山陬，則彌溥功德於無量耳。
