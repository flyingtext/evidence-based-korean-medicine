# 梅啟照序

語云：醫不三世，不服其藥。夫藥不輕服者，亦恐其方之不驗耳。若有經驗之方，遇相合之症，而不廣其傳以濟之，非所以體好生之德也。然古人著書，多指一事。如《靈樞》、

《銅人》之言針灸，《直格》、《標本》之論傷寒，《衛生總微》之紀小兒，《衛濟寶書》之考癰背，《大全良方》之載婦科，《脈訣刊誤》之詳經絡，以及吳有性、盧之頤之徒，或或治　瘧，皆偏於一門，不能兼綜。惟張機《金匱要略》二十五篇，分二百六十二家雜症之祖，然世罕傳本，睹之者稀。他若葛洪《肘後備急方》，雖分五十三類，論，人或疑之。巢元方雖論《病源》，而又不載方藥，仍不足以征信。董汲《旅舍雖足救急，而其藥有不可理解者，似亦未善。獨王燾《外台秘要》先論後方，深王袞以家藏醫方七千余道，擇其精者為《博濟方》，用無不驗，其法與此正合

《類證普濟本事方》，吳彥夔《傳信適用方》，沙圖穆蘇《瑞竹堂方》，危亦皆由歷驗而著，同為慈篇所本，故以臉方名之。雖博洽不能如朱　《普余之多與欽定《醫宗金鑒》之富，而窮鄉僻壤，無從驟睹巨帙，得此一不致誤於庸醫。蓋方名為驗，則經歷者多，服者用者俱無疑義。昔善化潘氏序之，比為《蘇沈良方》。迨同治甲子重刻，馮序又以孫思邈《千寶貴至深矣。惟舊版日久浸廢，翻本又多魯亥，非所以傳廣遠而示征信士眼科書》，爰飭屬以此並刊，其附益諸方，則仿徐用誠《玉機微義》即以天士之書，列於所增各方之首，計原書十六卷，益以八卷，合之繁富過之。既成，同僚者乞為之序。余不敏，自束發受書，即愛岐風雨鏖突，士多勞疚，更留意於此。蓋不讀書不足以臨症，不臨症理來叩者，輒以此語答之，然此猶道其難。若得此篇，雖平日未三了然，其收效尤易。雖然，吾固愿斯民懲忿遏欲，疾　不生，並此不能必其俱無。倘得此書扶持其間，將見消　戾於無形，登閭閻於之簫可也。是為序。
