# 腸覃似孕證蓄血似孕論

<!-- source-id: G029:p023 -->

婦人腸覃似孕，乃寒氣客於腸外，與衛氣相搏，氣不得榮，因有所系，瘕而內著，惡氣乃起，肉乃生。其始生大如雞卵，稍以益大，狀如懷子，按之則堅，推之則移，月事以時下，此結氣大腸，為氣病而血不病，故月事不斷。當用散氣之劑治之。其蓄血似孕，因多郁怒，經閉不月，腹漸大，初時人以為孕，至過月不產，諸症漸見，此蓄血子門，為血病，當破血藥下之。
