# 產後藥誤須知

產後勿輕用烏藥、香附、木香，及耗氣、順氣等藥，用之反增滿悶，雖陳皮用不可過五分。

產後勿輕用青皮、濃朴、山楂、枳殼、陳皮消食藥，多損胃減食，即枳殼、香砂等丸，亦多損氣血。

產後勿用青皮、枳實、蘇子以下氣定喘，用之元氣必脫。

產後浮麥傷胃耗氣，五味能阻惡露，棗仁油滑致瀉，均為禁忌。

產後身熱，誤用黃芩、黃連、黃柏、梔子。損胃增熱，致不進飲食，且黃芩苦寒，無論惡露淨與不淨，皆非所宜。

產後四日內，未服生化湯以消血塊，勿先用人參、　、朮，致塊不除。

產後勿輕用牛膝、紅花、蘇木、枳殼等類以消塊，猶忌多用、獨用。至於三棱、莪朮、枳實、山楂等峻藥，更不可用，若誤用，舊血驟下，新血亦隨之而損、禍不可測也。

產後勿輕用生地黃以滯血路。

產後不可用大黃、芒硝以通大便，反成臌脹。

產後不可用五苓以通小便，用之愈閉。
