# 傷食論

產後形體勞倦，脾胃俱傷，是以新產之後，去膏粱，遠濃味，食粥、茹、蔬以為調攝。更有本不思食而強與之，胃雖少納，脾難運轉，易致食停痞塞，甚而傷食發熱，切勿誤認為陰虛。更有食滯腹痛，又勿錯疑為血凝。治斯症者體認正實，如發熱而飲食調者，方可補血；若惡食噯酸者，食滯之症，即當扶元為主，補氣、養血、健脾、助胃，審傷何物，佐以何藥。消導則脾氣復而轉輸，易滯物行而胃思穀矣。如此補消兼治，無有不安，故善治者，治法有先後緩急，論症因塊痛有無。產後有日數新久，能重產虛之本，而兼去停積之標，攻補如法，無不應手而愈。故有生化消食湯、健脾消食湯之分別施治。

<ins>生化消食湯</ins>

　即生化東加神麯（炒）、麥芽（炒各六分）

<ins>健脾消食湯</ins>

　治產後塊痛已除，停食痞塞。
