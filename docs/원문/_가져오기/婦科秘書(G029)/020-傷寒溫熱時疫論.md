# 傷寒溫熱時疫論

妊娠傷寒，時值冬令，為寒所傷，其輕者淅淅惡寒，翕翕發熱，微嗽鼻塞，數日即愈，不藥亦可。或用蔥白（連須）三、五莖，生薑三片，煎服即解。如所感者重，以致頭疼，先寒後熱，久必傷胎，藥多避忌，務宜謹慎，不可與常婦概治，竟用發表，以致損胎，誤其母子性命。但服蔥白香豉湯自愈，故《千金》治妊婦傷寒，用蔥白、生薑，水煎熱服，取汗即安。是以蔥白香豉湯、香蘇散可解表邪，又可安胎。況蔥白不惟性能解表，且善安生胎、下死胎。若感寒孕婦，胎傷未死，但用蔥一把，水煮食之，汗出即安。如胎已死，須臾自出，不應，加生薑、蘇葉，不可輕用表藥招尤。若妊娠邪在半表半裡，擇《綱目》內黃龍湯，即小柴胡湯變體用法，其加減亦可采擇而用。如表症已愈，但發熱大渴，用香蘇散，加金花湯。便結者，加入大黃。或用三黃解毒湯，所以胎前疫症，與傷寒陽明腑症，內實便秘，須急通大便，方不損胎。若大便自利，乃正氣下泄，胎必難保。惟大小便如常，知裡無熱，則不傷胎氣，至妊娠熱症，亦須急治，恐致落胎。《千金》用蔥白香豉湯，取汁即愈。又有用柴葛安胎飲者，如嘔吐煩躁，用生津葛根湯者，甚則斑出黑色，用梔子蔥豉湯者，密齋用加味化斑湯，此皆熱入於裡，陽明症之方藥也。《醫通》治孕婦溫熱時行，及傷寒邪氣內犯，熱毒逼胎，並宜《千金》石膏大青湯急救，庶可保全，遲則不救。又有石膏六合湯、升麻六合湯，立方甚穩，錄後以備采用。凡胎孕藥內，不得已而用大黃轉藥，須用酒製。

薑、桂、附子，用黃連、甘草制之，則無害矣。

<ins>蔥白香豉湯</ins>

　《千金》治時疫傷寒，三日以內，頭痛如破，及溫病初起寒熱。

蔥白（連須一握）　香豉（三合）

水煎，入童便一合，日三服。秋冬加生薑二兩。

<ins>黃龍湯</ins>

　治妊娠傷寒，得之三、五日後，有惡寒發熱，內有煩渴引飲，小便赤澀之症。此邪在半表半裡，宜此方主之。

柴胡（二錢）　黃芩（一錢半）　人參　甘草（各一錢）　薑、棗為引。

水煎服。如寒熱往來，無汗口乾，加葛根二錢，去棗，入蔥白三根，如頭痛不止，加川芎、白芷各一錢，去棗，加蔥白三根；如發熱，有汗口渴，加土炒白朮一錢半，栝蔞根一錢半；如脈浮大有力，大熱大渴，人參白虎湯去薑、棗。

<ins>柴葛安胎飲</ins>

　治孕婦熱病，骨節疼痛，如不急治則落胎。

柴胡　葛根　青黛（各八分）　石膏（一錢半）　升麻（五分）　梔子（一錢）　知母（七分）　蔥白（三根）

<ins>生津葛根湯</ins>

　治孕婦熱病，嘔吐不食，胸中煩躁。

人參　葛根　蘆根　麥冬　知母（炒）　梔子（炒各一錢）　竹茹（一團）　蔥白（三寸）

<ins>梔子蔥豉湯</ins>

　治孕婦熱病，斑出赤黑色，小便如血，氣急欲絕，胎落之症。

梔子（炒）　黃芩　升麻（各一錢）　生地（二錢）　青黛（八分）　豆豉（四十九粒）

<ins>加味化斑湯</ins>

　治孕婦傷寒，熱病不解，遍身發斑，赤如錦文者。

人參　知母　生地　黃芩　梔仁　甘草（各一錢）　石膏（二錢）　淡竹葉（二十片）　豆豉（半合）

食遠服。

<ins>《千金》石膏大青湯</ins>

　治妊娠傷寒，頭疼壯熱，肢體煩痛。此方既可散邪，又能安胎，允為孕婦傷寒溫熱時行神方也。

石膏（二錢）　大青　黃芩（各八分）　前胡　知母　梔仁（各一錢）　蔥白（一莖）

水煎溫服。

<ins>石膏六合湯</ins>

　治妊娠傷寒，身熱大渴而煩。

當歸　川芎　白勺　生地（各一錢）　石膏　知母（各五分）
