# 轉胞淋閉論

妊娠轉胞，乃臍下急痛，小便不通。凡強忍小便，或尿急疾走，或飽食忍尿，或忍尿入房，使水氣上逆，氣逼於胞，故屈戾不得舒張所致，非小腸、膀胱受病，而利藥所能利也。法當治其氣則愈。凡婦人稟受弱，憂悶多，性躁急，食濃味者，恆有之。因胞不自轉，為胎所壓，胎若舉起，胞系自流，水道自通矣。用二陳升提飲。又有用補中益氣湯，服後探吐，以提其氣自通。通後即用參、　大補，恐墜胎也。但子淋與轉胞相類，小便頻數，點滴而痛者，為子淋。膀胱、小腸虛熱也，虛則不能制水。熱則不能通利，故淋。若頻數出少不痛者，為轉胞，間有微痛，終與子淋不同耳。論中急痛，乃急欲便而痛，得便則止，間有微痛，與子淋點滴痛不同。

<ins>二陳升提散</ins>

　治孕婦臍腹作痛，小便淋閉不通，或微痛，與淋有別。由氣虛、胎壓水胞。
