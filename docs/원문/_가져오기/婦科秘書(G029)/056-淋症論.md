# 淋症論

產後淋症，此亦血去陰虛生內熱也。蓋腎為至陰，主行水道，去血過多，正陰虧損，故生內熱，小便成淋而澀痛。是以熱客於脬，虛則頻數，熱則澀痛也。氣血兼熱，血入胞中，則血隨小便而為血淋。但小便淋閉卻與不通當分別而治。不通者，屬氣虛，淋屬內熱澀痛，故密齋治淋，用知柏導赤散、調益元散治之。馮氏云：血虛熱郁，當用六味丸、逍遙散，補陰養血，滋其化源，佐以導血藥可也。
