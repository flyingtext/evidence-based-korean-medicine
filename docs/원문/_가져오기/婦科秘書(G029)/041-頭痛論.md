# 頭痛論

> 상태: 자동 변환 원문·정본 미대조

人身之中，氣為陽，血為陰，陰陽和暢，斯無病矣。夫頭者，諸陽之會也，產後去血過多，陰氣已虧，而虛陽失守，上湊於頭，則令頭痛，但補其血，則陽氣得縱，而頭痛自止。間有敗血停留子宮，厥陰之位，其脈上貫巔頂，作巔頂痛者，雖有身熱惡寒之候，是宜生化東加減，慎不可用羌、獨等藥，蓋由正陽虧損，濁陰得以犯上，陷入髓海，為脹為痛，是非清陽升復，則濁陰不降，在裡內起之邪為病，非若外入之邪可表而愈也。況生化湯中芎、薑亦能散表邪，桃仁亦能逐瘀血，是又可兼治。再少為因症加入，又何用另方施治乎？
