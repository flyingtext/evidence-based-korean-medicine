# 產後脈訣論

<!-- source-id: G029:p026 -->
> 서명: 婦科秘書
> 원본 파일: `G/G029.txt`
> 원본 SHA-256: `46c333f95f7cf49b9fe4331d5393f1a049c7e803c3984119b915b8e8f05b4327`
> 상태: 자동 변환 원문·정본 미대조

《脈經》云：產後之脈，寸口洪疾不調者死，況微附骨不絕者生。又曰：沉小緩滑者吉，實大堅弦疾者凶，牢革結代及澀滯不調者不治。丹溪曰：胎前脈當洪數，既產而脈仍洪數者死。又曰：胎前脈細小，產後脈洪大者多死。予見產後多有洪數而生者，要知血虛之脈浮洪而數者居多，產後血虛，故現此脈。若不明以告之，俗醫多誤認為外感，虛虛之禍，在此頃刻。然此洪數之中，自有和滑之象，非如牢疾而少胃氣之謂，故多死也。《產經》曰：胎前之病，其脈貴實；產後之病，其脈貴虛。胎前則順氣安胎，產後則補虛消瘀，此其要也。
