# 氣喘論

凡產後，若因風寒外感，邪氣入肺而喘急者，必氣粗胸脹，或多咳嗽，自與氣短似喘、上下不接者不同。治當疏散中兼補為主，宜金水六君煎，或六君子湯。若單以寒邪入肺，氣實、氣壅而本無虛者，宜六安煎，或二陳東加蘇葉之類主之。又有瘀血入肺，必面黑發喘，與氣短似喘大不相同，用二味參蘇飲治之。或有氣虛血痰泛上者，用六君子調服，失笑散亦效。
