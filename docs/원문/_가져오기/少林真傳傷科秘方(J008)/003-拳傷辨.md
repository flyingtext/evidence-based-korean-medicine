# 拳傷辨

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

向上為順氣，平拳為寒氣，倒插為逆氣最凶，各樣內傷總怕倒插。血隨氣轉，氣逆血只凝故也。心前背後相對處，傷久成怯，小膀肚腹打傷，久必成黃病。

凡人初打傷，七日之內血氣未曾積聚，只宜發散活血。十四日其瘀血或有停住在胸前，其勢方歸大腸，肚內作痛，要吃行藥。凡人打傷，要看指甲，黑亦有傷。其卵子上升，十分凶症。肝經脈數，胸傷有血，必然吐血。
