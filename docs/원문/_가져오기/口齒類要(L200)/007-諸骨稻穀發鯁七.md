# 諸骨稻穀發鯁七

<!-- source-id: L200:p007 -->
> 서명: 口齒類要
> 원본 파일: `L/L200.txt`

> 상태: 자동 변환 원문·정본 미대조

治諸骨鯁，用苧麻根杵爛丸，彈子大，將所鯁物，煎湯化下。

一方魚骨鯁，用細茶、五倍子等分為末，吹入咽喉，立愈。

一方以犬吊一足，取其涎，徐徐咽之，即消。

又方白萼花根搗爛取汁，徐徐咽之，不可著牙。

治稻芒糠穀鯁喉，將鵝吊一足取涎，徐徐咽下，即消。

治吞釘鐵金銀銅錢等物，但多食肥牛脂諸般肥肉等味，隨大便而下。

一方吞錢，燒炭末，白湯調下，數匙即出。或服蜜升許。或食茨菇，其錢自化。

治吞發繞喉不出，取自亂髮作灰，白湯調服一錢。

治吞鐵或針，用餳糖半斤濃煎，艾汁調和服之。

一方磁石，磨如棗核大，鑽眼，以線穿令吞喉間，針自引出，或吞錢金銀銅鐵，磁石須陰陽家用驗者。
