# 九宮尻神歌

尻神所在有根由，坤內外踝聖人留。震宮牙口　宜記，巽位還居乳口頭，中宮肩骨連尻骨，背面目從乾上游。手膊兌宮難砭灸，艮宮腰頂也須休。離膝肋脅針難下，坎肘還連肚腳求。為醫精曉尻神訣，萬病無干禁忌憂。

以上避忌，以逐日人神所在為主。如遇急病，其余不必避也。
