# 大便血痢（涼腸作主九十六）

> 상태: 자동 변환 원문·정본 미대조

大黃復花翹桔梗，枳荷力子連條芩，銀花槐梔栝蔞杏，荊芥升麻與苦參。

涼大腸利小便，蓋小便愈長則大便愈結，然亦不可強止。《經》云：毒以利泄，若利止則不能出而腹痛也。

干桔升荷枳木通，石蒲芩連胡天冬，知母豆根苓槐骨，滑石人中柏杏仁。
