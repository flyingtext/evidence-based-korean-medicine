# 余毒不清（七十五）

<!-- source-id: I205:p076 -->
> 서명: 經驗麻科
> 원본 파일: `I/I205.txt`

> 상태: 자동 변환 원문·정본 미대조

氣高而喘息作聲，掀胸抬肚者，余毒在於肺臟也。痰涎稠黏，切牙戈齒，泄不止，口臭者，余毒在於脾胃也。盜汗身熱不退，渴盛者余毒在於心經也。夢中多驚，攝手振動，目赤者，余毒在於肝膽也。耳　手足尖熱者，余毒在於腎臟也。身腫不消，壯熱不退，郁悶不舒，諸經皆有未盡之余毒也。
