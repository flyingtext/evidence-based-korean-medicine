# 疹後身瘦潮熱（一百十三）

<!-- source-id: I205:p114 -->
> 서명: 經驗麻科
> 원본 파일: `I/I205.txt`
> 원본 SHA-256: `e7e582f89a8cc637d3930043d842968c79445a136acca0c2c05b74148307296b`
> 상태: 자동 변환 원문·정본 미대조

疹後，身瘦潮熱而胃口欲食，甫食則飽，飽過即飢，而肚大痛，大小便利，口臭而身發疥，此乃誤服熱藥大八味故耳。如一月間，先宜石膏、條芩一大劑，次服熟地、百部、枳殼、沙參、知母、山梔、天冬、黃芩、穀芽二大劑，則愈矣。又服六味，方內去萸肉，加當歸、防風、麥門冬、沙參等分，可以收功。
