# 餘毒不清（七十五）

氣高而喘息作聲, 掀胸抬肚者, 餘毒在於肺臟也. 痰涎稠黏, 咬牙戈齒, 泄不止, 口臭者, 餘毒在於脾胃也. 盜汗身熱不退, 渴盛者餘毒在於心經也. 夢中多驚, 攝手振動, 目赤者, 餘毒在於肝膽也. 耳骫手足尖熱者, 餘毒在於腎臟也. 身腫不消, 壯熱不退, 鬱悶不舒, 諸經皆有未盡之餘毒也.
