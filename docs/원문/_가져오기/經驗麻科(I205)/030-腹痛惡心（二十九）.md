# 腹痛惡心（二十九）

<!-- source-id: I205:p030 -->
> 서명: 經驗麻科
> 원본 파일: `I/I205.txt`

> 상태: 자동 변환 원문·정본 미대조

疹出不透，脾胃有毒，邪正交攻，臟氣相擊，火毒郁結，凝滯而作腹痛。腹痛者毒郁於陰，臍以上屬太陰，當臍屬少陰，小腹屬厥陰，治直升發解利。《經》云：痛以利減，毒以瀉松，加枳殼、枳實、大黃、栝蔞仁之味，胃口有熱有痰而作乾嘔者，是為惡心，大便秘結忽作腹痛者，燥糞欲出也，用外導法，如平日原有蛔痛之症，此為內熱蛔不安而作痛也，宜用大黃、枳殼、栝蔞仁等味微微利之，瀉出即安，切勿妄用使君子等酸藥也。
