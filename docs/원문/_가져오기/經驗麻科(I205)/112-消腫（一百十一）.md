# 消腫（一百十一）

<!-- source-id: I205:p112 -->

> 원본 파일: `I/I205.txt`

> 상태: 자동 변환 원문·정본 미대조

《經》曰：肺主皮毛，脾胃主肌肉，故用石膏清胃火，黃芩瀉肺火，則皮毛開而肌肉平矣。宜服：知柏石膏麥門冬，生梔六一芩木通，百部枳實白百合，車澤赤苓貝杏仁，昆布海藻桑白皮，金銀葶藶與天冬，麻黃香薷荷鼻立，瓜蒂牙根紫菀茸，榆白皮煎蔓荊子，蘿卜子與燈草逢。
