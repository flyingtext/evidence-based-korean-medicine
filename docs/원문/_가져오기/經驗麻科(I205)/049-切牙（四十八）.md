# 切牙（四十八）

<!-- source-id: I205:p049 -->

> 상태: 자동 변환 원문·정본 미대조

心肝火旺，相戈而鳴，又有胃熱則切牙，肝熱則寒戰。肺熱而切牙者治宜清解散。切牙者，乃足陽明胃經主之，陽明主肌肉，其經走於上下齒齦，邪並陽明，故切牙且胃熱，非石膏不為功，黃芩次之。《經》云：毒火深藏腎與肝，升沉二臟擾何安，齒牙相戈聲何慘，透解潛藏自貼然。此痘疹兼論。

火毒在肝，肝則藏血而養筋。毒在腎，腎則主骨而生肝還以養血。猶唇齒之邦，兩受其虐而失其和，齒其妄劇而自斗矣，但虛者則聲松，實者聲緊，痘疹皆同。
