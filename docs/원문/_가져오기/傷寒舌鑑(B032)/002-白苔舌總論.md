# 白苔舌總論

傷寒邪在皮毛。初則舌有白沫。次則白涎白滑。再次白屑白　。有舌中、舌尖、舌根之不同。是寒邪入經之微甚也。

舌乃心之苗。心屬南方火。當赤色。今反見白色者。是火不能制金也。初則寒郁皮膚。毛竅不得疏通。熱氣不得外泄。

故惡寒發熱。在太陽經。則頭痛、身熱，項背強、腰脊疼、等症。傳至陽明經。則有白屑滿舌。雖症有煩躁。如脈浮緊者。猶當汗之。在少陽經者。則白苔白滑。用小柴胡湯和之。胃虛者。理中湯溫之。如白色少變黃者。大柴胡。大小承氣、分輕重下之。白舌亦有死症。不可忽視也。

*微白滑苔舌\pt108a1.bmp*

寒邪初入太陽。頭疼、身熱、惡寒、舌色微白有津。香蘇散、羌活湯之類發散之。

*薄白滑苔舌\pt108a2.bmp*

此太陽裡證舌也。二三日未曾汗。故邪入丹田漸深。急宜汗之。或太陽與少陽合病。有此舌者。柴胡桂枝湯主之。

*濃白滑苔舌\pt108a3.bmp*

病三四日。其邪只在太陽。故苔純白而濃。卻不干燥。其證頭疼發熱。脈浮而緊。解表自愈。

*干濃白苔舌\pt108a4.bmp*

病四五日。未經發汗。邪熱漸深。少有微渴。過飲生冷。停積胸中。營熱胃冷。故令發熱煩躁。四肢逆冷。

而苔白干濃。滿口白屑。宜四逆散加乾薑。

*白苔黃心舌\pt108a5.bmp*

此太陽經初傳陽明府病舌也。若微黃而潤。宜再汗。待苔燥裡證具。則下之。若煩躁嘔吐。大柴胡東加減。

亦有下淡黃水沫。無稀糞者。大承氣湯下之。

*白苔黃邊舌\pt108a6.bmp*

舌中見白苔。外有微黃者。必作泄。宜用解毒湯。惡寒者五苓散。

*干白苔黑心舌\pt108a7.bmp*

此陽明府兼太陽舌，其苔邊白中心干黑者。因汗不徹。傳至陽明所致。必微汗出、不惡寒、脈沉者。可下之。如二三日未曾汗。有此舌必死。

*白滑苔尖灰刺舌\pt108a8.bmp*

此陽明府兼少陽舌也。三四日自利脈長者生。弦數者死。如有宿食。用大承氣下之。十可全五。

*白苔滿黑刺干舌\pt108a9.bmp*

白苔中生滿干黑芒刺。乃少陽之裡證也。其證不惡寒反惡熱者。大柴胡加芒硝急下之。然亦危證也。

*白滑苔黑心舌\pt108a10.bmp*

白苔中黑。為表那入裡之候。大熱譫語。承氣等下之。倘食復而發熱、或利不止者。難治。

*半邊白滑舌\pt108a11.bmp*

白苔見於一邊。無論左右。皆屬半表半裡。宜小柴胡湯。左加葛根。右加茯苓。有咳嗽引脅下痛、而見此舌苔者。小青龍湯。夏月多汗自利。人參白虎湯。

*臟結白滑舌\pt108a12.bmp*

或左或右。半邊白苔。半邊或黑或老黃者。寒邪結在臟也。黃連東加附子。結在咽者。不能語言。宜生脈散合四逆湯。可救十中一二。

*白苔黑斑舌\pt108a13.bmp*

白苔中有黑小斑點亂生者。乃水來克火。如無惡候。以涼膈散承氣湯下之。十中可救一二。

*白苔燥裂舌\pt108a14.bmp*

傷寒胸中有寒。丹田有熱。所以舌上白苔。因過汗傷營。舌上無津。所以燥裂。內無實熱。故不黃黑。宜小柴胡加芒硝微利之。

*白苔黑根舌\pt108a15.bmp*

舌苔白而根黑；火被水克之象。雖下亦難見功也。

*白尖黃根舌\pt108a16.bmp*

邪雖入裡。而尖白未黃。不可用承氣。宜大柴胡東加減。下後無他證。安臥神清。可生。倘再有變證。多凶。

*白苔雙黃舌\pt108a17.bmp*

此陽明裡證舌也。黃乃土之色。因邪熱上攻。致令舌有雙黃。如脈長惡熱。轉矢氣煩躁者。大柴胡調胃承氣下之。

*白苔雙黑舌\pt108a18.bmp*

白苔中見黑色兩條。乃太陽少陽之邪入於胃。因土氣衰絕。故手足厥冷。胸中結痛也。理中湯瀉心湯選用。

如邪結在舌根。咽嗌而不能言者。死證也。

*白苔雙灰色舌\pt108a19.bmp*

此夾冷食舌也。七八日後見此舌而有津者。可治。理中四逆選用。無津者不治。如干濃見裡證。則下之。

得湯次日灰色去者安。

*白尖中紅黑根舌\pt108a20.bmp*

舌尖白而根灰黑。少陽邪熱傳腑。熱極而傷冷凍飲料也。如水停津液固結而渴者。五苓散。自汗而渴者。白虎湯。

下利而渴者。解毒湯。如黑根多、白尖少、中不甚紅者。難治。

*白苔尖紅舌\pt108a21.bmp*

滿舌白滑而尖卻鮮紅者。乃熱邪內盛。而復感客寒入少陽經也。小柴胡東加減。

*白苔中紅舌\pt108a22.bmp*

此太陽初傳經之舌也。無汗者發汗。有汗者解肌。亦有少陽經者。小柴胡東加減。

*白苔變黃舌\pt108a23.bmp*

少陽證罷。初見陽明裡證。故苔變黃色。兼矢氣者。大柴胡湯下之。

*白尖紅根舌\pt108a24.bmp*

舌尖苔白。邪在半表半裡也。其證寒熱、耳聾、口苦、脅痛、脈弦。小柴胡湯和解之。

*白苔尖灰根黃舌\pt108a25.bmp*

此太陽濕熱並於陽明也。如根黃色潤、目黃小便黃者。茵陳蒿東加減。

*白苔尖根俱黑舌\pt108a26.bmp*

舌根尖俱黑而中白。乃金水太過。火土氣絕於內。雖無凶證。亦必死也。

*熟白舌\pt108a27.bmp*

白苔老極。如煮熟相似者。心氣絕而肺色乘於上也，始因食瓜果冰水等物。陽氣不得發越所致。為必死候。

用枳實、理中。間有生者。

*淡白透明舌\pt108a28.bmp*

年老胃弱。雖有風寒。不能變熱。或多服湯藥。傷其胃氣。所以淡白透明。似苔非苔也。宜補中益氣加減治之。

*白苔如積粉舌\pt108a29.bmp*

此舌乃瘟疫初犯募原也。達原飲。見三陽表證。隨經加柴胡、葛根、羌活。見裡證。加大黃。
