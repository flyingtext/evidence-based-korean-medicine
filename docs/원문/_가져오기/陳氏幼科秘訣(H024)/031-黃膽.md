# 黃膽

<!-- source-id: H024:p031 -->

> 상태: 자동 변환 원문·정본 미대조

此皆濕熱蒸於脾胃，如合面相似。脾胃象土，其色黃，故發於外。生下黃名胎疸，母臟有熱熏蒸於胎故也。若黃膽變黑疸，難治。治疸以利小便為主，小便利則黃自退，從食積來者亦可行，方內加食積藥。

赤茯苓　陳皮　豬苓　澤瀉　木通　茵陳　黃芩　黃連　枳殼　山梔　山楂　蒼朮重加大黃、檳榔。
