# 熱

小兒稟賦純陽，血氣熱，易生熱。有五臟熱，五心煩熱，四肢壯熱，痰涎壅盛，目澀多渴。若上衝咽喉則與氣血相搏結成喉閉，宜涼膈散。

<ins>涼膈散</ins>

山梔　薄荷　黃芩　連翹　元參　桔梗　陳皮　花粉　甘草　石膏　竹葉甚者朴硝、大黃可加，或止加大黃。
