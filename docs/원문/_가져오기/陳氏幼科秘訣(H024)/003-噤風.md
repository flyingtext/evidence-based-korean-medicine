# 噤風

噤風者，初生七日內忽然目閉、口噤，啼聲不出，下青糞，舌上有　肉如栗，吃乳不得，口吐白沫，大小便皆通。由在胎受熱毒流入心脾，故見於喉舌之間。或初生時為風邪搏擊所致，名犯風噤。口中白栗用綿裹，指蘸水擦破。百二十日內俱有此患。一口噤不乳，腹急多啼，牙關緊閉與撮口相似，赤者心噤，白者肺噤。
