# 脫肛

夫肺與大腸為表裡。肛者，大腸之門。肺經實熱則秘結不通，肺若虛寒則腸頭出露。有因瀉痢久，脾土虛，不能生肺金，故肛門脫而不收。宜補脾溫胃，使金受母之益而氣實，次則內投固腸之劑，外用敷洗之藥。

<ins>敷肛散</ins>

龍骨（　）　赤石脂（　）　訶子肉（各三錢）

共為末，每用四五分敷上，每日敷三次即愈。先用荊芥穗、香附煎湯洗之。

又方　五倍子灰、鱉頭灰，敷妙。用淨舊鞋底烘熱托上。
