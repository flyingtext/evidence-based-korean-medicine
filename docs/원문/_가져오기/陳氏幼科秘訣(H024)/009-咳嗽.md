# 咳嗽

咳嗽屬肺，風熱郁於肺則生痰，故嗽有喉間作小雞聲者，先用小紅丸下之。不惟下痰，且肺與大腸相為表裡，腑不實臟不能實也。大率順氣化痰清肺為主，宜清金貝母湯。

<ins>清金貝母湯</ins>

貝母　杏仁　桑皮　花粉　桔梗　枳殼　甘草　黃芩　木通　蘇子　陳皮　茯苓痰甚加膽星；食積痰去貝母，加製半夏、山楂；痰而嗽甚加山梔；喘加馬兜鈴或紫菀；嗽而血加山梔、石膏；嗽而氣逆，倍蘇子；嗽不轉加麻黃、石膏；嗽久加款冬花、馬兜鈴，或瓜蔞仁、紫菀、五味、烏梅。

食枳痰須用製半夏、枳實、青皮、枳殼，嗽甚，眼白上有　肉生者，此嗽傷血分也，宜服生地、當歸入血分，檳榔下其氣。
