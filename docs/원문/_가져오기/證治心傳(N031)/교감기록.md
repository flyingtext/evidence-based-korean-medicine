# 證治心傳 교감 기록

## 현재 상태

jicheng.tw 최신 전문과 Wikisource·cloudtcm 독립 전문을 대조해 결락·OCR 오기·자동변환 자형을 교정하고 표점을 검증했다.

## 대조 범위

- 원자료: `N/N031.txt`
- 전각 공백: 16자리 전수 판정(결자·오염 후보 15, 판면 공백 1, 미해결 0)
- 적용 내역: `corrections-applied.json`
- 표점 검증: `punctuation-report.json`

## 대조 판본

- https://jicheng.tw/tcm/book/%E8%AD%89%E6%B2%BB%E5%BF%83%E5%82%B3/index.html
- https://zh.wikisource.org/zh-hant/%E8%AD%89%E6%B2%BB%E5%BF%83%E5%82%B3
- https://cloudtcm.com/shu/t1/785/3

## 유보 사항

미해결 교감 후보는 없다. 후속 판본의 이문은 별도 기록한다.
