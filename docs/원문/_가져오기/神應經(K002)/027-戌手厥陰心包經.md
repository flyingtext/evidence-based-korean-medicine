# 戌手厥陰心包經

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

曲澤　在肘內廉陷中，屈肘取之，大筋內側橫紋中動脈。針三分，灸三壯。

間使　在手掌後，橫紋上三寸，兩筋間陷中，去腕後三寸。針三分，灸五壯。

內關　在手掌後橫紋上二寸，兩筋間。針五分，灸三壯。

中衝　在手中指端，去爪甲如韭葉，針一分，灸一壯。

大陵　在掌後橫紋中，兩筋間陷中。針五分，灸五壯。

勞宮　在掌心，屈指取之，在無名指尖盡處是穴。
