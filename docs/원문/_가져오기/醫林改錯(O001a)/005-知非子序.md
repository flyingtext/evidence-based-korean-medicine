# 知非子序

余讀勛臣先生《醫林改錯》一書，而嘆天下事，有人力為之者，有天意成之者
，先生是書，功莫大於圖繪臟腑諸形。其所以能繪諸形者，則由於親見。其所以得
親見者，則由於稻地鎮之一游也。此豈非天假之緣，而使數千載之誤，由先生而正
之哉！惟隔膜一事，留心三十年，未能查驗的確。又得恆敬公確示一切，而後臟腑
諸形，得以昭晰無疑，此非有無意玉成其間哉！至先生立方醫疾，大抵皆以約治博
。上卷著五十種血瘀之症，以三方治之。下卷論半身不遂，以一方治之。並審出未
病以前四十種氣虛之形症，非細心何能至此。論吐瀉轉筋，治分攻補兩途，方由試
驗中來。論小兒抽風非中風，以大補元氣一方治之。以不能言之兒，查出二十種氣
虛之形症，平素細心，不同可知。論痘非胎毒、痘漿非血化，以六方治古人不治之
六十種逆痘，頗有效者。先生之書，大抵補前人之未及，而在氣虛血瘀之症為多，
今特揭諸篇首。知非子書。
