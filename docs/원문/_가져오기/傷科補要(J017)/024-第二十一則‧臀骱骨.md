# 第二十一則‧臀骱骨

胯骨，即髖骨也，又名髁骨。其外向之凹，其形似臼，以納髀骨之上端如杵者也，名曰機，又名髀樞，即環跳穴處也，俗呼臀骱。若出之，則難上，因其膀大肉濃，手捏不住故也。

必得力大者三、四人，使患者側臥，一人抱住其身，一人捏膝上拔下，一手撳其骱頭迭進；一手將大膀曲轉，使膝近其腹，再令舒直，其骱有響聲者，以上。再將所翻之筋向前歸之，服生血補髓湯，再服加味健步虎潛丸。若骱不上，則臀努斜行，終身之患也。慎之﹗
