# 第八則‧鼻梁骨斷

（附目傷）

鼻梁骨，下至準頭，傷而出血，可治。外將止血定痛散敷之，內服接骨紫金丹。或傷開孔竅，或鼻破歪落，用整端法，用藥敷貼可也。若骨破碎，內膜穿破，口鼻流血者，不治。中血堂，即鼻內　下脆骨空處也。若傷之，血流不止。神氣昏迷者，宜塞鼻丹塞於鼻中，用冷水淋進，氣虛目閉面黃者，八日而死。或睛明骨傷，眼珠掛落者，先將收珠散，用銀針蘸井花水，將藥點眼珠上，及點血筋上，用舊絹溫湯挪上，服還睛湯二、三劑；又服明目地黃湯，調理可愈。
