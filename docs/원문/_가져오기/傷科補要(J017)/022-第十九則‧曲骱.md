# 第十九則‧曲骱

肘骨者，胳膊中節上下支骨交接處也，俗名鵝鼻骨。上接　骨，其骱名曲　。自肘至腕，有正輔二根：其在下而形體長大連肘尖者，為臂骨；其在上而形體短細者，為轉骨。疊並相倚，下接於腕骨。其骱若出，一手捏住骱頭，一手拿其脈窩，先令直拔下，骱內有聲響，將手曲轉，搭著肩頭，肘骨合縫，其骱上矣。服生血補髓湯，或紫金丹。
