# 胃經

補胃需用蒼白朮，半夏扁豆綿黃耆，芡實蓮肉共百合，山藥還加廣陳皮。
瀉胃火，亦如脾，再加一味南枳實，更添芒硝與大黃，多加石膏謝更急。
溫胃木丁與藿香，益智吳萸與良薑，香附白肉草豆蔻，厚樸胡椒生乾薑。
涼胃葛根條黃芩，滑石黃連玄花粉，知母連翹石膏斛，梔子升麻竹茹尋，
十三味藥涼胃火；白芷升麻引胃藥。
