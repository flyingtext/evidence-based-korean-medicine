# 本草述鉤元自序

道光六年丙戌。余在京師。館於成果亭中丞家。瞿麗江比部持此書未訂本見贈。翻閱數過。愛不能釋。遂手自裝訂。暇即就其中論義。刪而約之。歷丁亥戊子。乃並其前後征引各條。旋就輯次。業未卒。自都還南。館於泰屬之康二如鹺尹署。二如喜談醫。館政最簡。遂出全力掇拾此編。其年冬。手鈔卷數自後半起。歷庚辛壬三載告成。猶病其末數卷未歸一律也。

<ins>道光癸巳十一月十二日冬至節楊時泰識</ins>
