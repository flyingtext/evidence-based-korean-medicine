# 重雕宋本《衛生家寶產科備要》敘

產科之有專書，始於唐楊師濃之《產乳集驗方》、《太和中昝殷產寶》。總之，北宋則有李師聖之《產育寶慶集》，沈虞卿之《衛生產科方》；南宋則有虞流之《備產濟用方》，陸子正之《胎產集驗方》，今皆不傳，

《寶慶集維》著錄。

《四庫全書》從《永樂大典》錄出，經陳言等增刪，亦非原本。醫書之鮮善本久矣，產科其尤甚者也。

《衛生家寶產科備要》八卷，宋朱瑞章輯《宋史藝文志》篇，於錄明《文淵閣書》目亦有其書。

《四庫全書》未收阮文達，亦未見錢遵王，《讀書敏術》記載有宋本，於瑞章仕歷則未詳也。朱瑞章，福建長樂縣人，淳熙中知江西南康軍，寬以愛民，廉以律己，護設官田於白鹿洞學以贍四方。來學人著有《衛生家寶方》六卷，《衛生小兒方》一卷，《衛生家寶湯方》二卷及此書，見《宋史藝文志》、《乾隆江西通志》。

蓋南宋良吏有心於濟世救民者，非醫士也。卷一入月安產法、體元子借地法、逐月藏衣、游神法，本之《外台秘要》；禁草、禁水、催生符法出《聖濟總錄》。卷二、卷三，皆采之孫真人《千金方》。卷四全錄《產育寶慶集》張世臣《累用經效方》。卷五則采之瀘江助教劉寶經驗名方者居多。卷六則全錄《備產濟用方》及許叔微《本事方》中胎產諸方；卷七則全錄《胎產經驗方》。卷八則雜采葛氏時後、巢氏病源、千金、外台、聖惠、萬全小兒集驗、嬰童寶鑒。錢乙、張渙諸書保育小兒諸法。李、陸兩集賴此以存虞張之方，尤為自來著錄所罕見。洵乎產科之薈萃，醫家之指南也。予少多疾病，喜讀方書，每當眾論荊棘之時，略試其技，亦嘗奏效。婦人小兒望問皆窮，尤難制劑。丙子之歲細君臨娩，胎死腹中，三日不下，諸醫束手。甲申九月，家婦將娩而瘧作，瘧發之際心痛欲死，醫亦無策。余細心診問，博考方書，幸賴此書，轉危為安。細君懲勇付梓爰雕印，以廣其傳。差乎，秦漢以來，醫書經林億、孫兆校定未必君合於古德，猶無大失也。明人一再重刊，無不妄刪、妄改，襲謬承訛，固已失之毫厘，繆以千裡。而況庸人，以醫為市，目不知書，迂儒食古不化，刻舟求劍乎。以此治疾，是益之危而速之死也。婦科為醫家九科之一，產又婦科之一端，自束實鮮，專書即有亦鮮善本。是編采摭宏富，持擇精詳，所愿家置一編而深求之，於保產全嬰之道，其庶幾乎。
