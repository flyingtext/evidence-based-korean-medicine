# 蟾砂散

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

治氣臌神方。

大蟾蟆（一個）　砂仁（不拘多少）

為末。將砂仁裝入蟆內令滿。縫口。用泥周身封固。炭火煅紅。候冷。將蟆研末。作三服。陳皮湯送下。俟下氣一通為效。二三服全愈。

此方殺生救命。不可輕用。不得已用之。須立願多放生命為是。
