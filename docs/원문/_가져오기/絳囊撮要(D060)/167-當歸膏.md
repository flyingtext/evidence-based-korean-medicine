# 當歸膏

專治發背癰疽。湯火傷。去腐生新。其肉搽至漸白方始毒盡。如外肉焮干。爬連好肉皴揭作痛。用之即愈。並治一切濕毒臁瘡。頭面疳瘡。膿窠瘡毒。小兒胎毒瘡癩。凡腐爛不堪之症。無不效驗。

當歸（一兩）　大生地（一兩）　黃蠟（五錢）　白蠟（五錢）　真麻油（五兩）

先將當歸生地浸油內一宿。煎至枯浮。用絹濾去渣。次以黃白蠟入油熬化。攪勻成膏。瓷罐收貯用。
