# 吐血除根奇方

<!-- source-id: D060:p032 -->
> 서명: 絳囊撮要
> 원본 파일: `D/D060.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

真童子雞（一隻男用雌女用雄）先擇無人走動處。掘一地潭。用竹刀將雞在潭內殺之。血滴潭中。干撏毛剖開。腸雜收拾乾淨。毛屎亦放潭中。不可狼藉。一點俱不可經勺水。只用乾布拭淨肚內。用六月雪草。每病人一歲。摘頭一個。同腸雜仍放在肚內。將新淨平底瓦缽一個。以雞放入蓋好。用麵糊封口。放干灶鍋內。亦蓋好封固。燒柴草把三個。約緩熱茶時許取出。雞已熟矣。去六月雪空口淡吃。一頓淨盡。將雞骨亦放潭內。泥蓋捶結。重物壓住。永不可開。重病吃兩次可除根。勿以草把三個。隔鍋缽乾燒為疑。已試過果然。
