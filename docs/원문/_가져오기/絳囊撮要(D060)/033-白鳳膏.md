# 白鳳膏

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

治久虛發熱。咳嗽吐痰咳血。火乘金位者。

黑嘴白鴨（一隻）　取血入溫酒量飲。使直入肺金。以潤補之。將鴨干撏去毛。脅下開竅。去腸拭淨。入大棗（二升去核）。參苓平胃散（一升銼碎）。紮好沙鍋內。用炭火慢煨。將陳煮酒一瓶。作三次。添入以干為度。取起食鴨及棗。或搗丸服。
