# 小兒赤遊方

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

糞坑底磚研末。麻油調塗。即愈。或用鱔魚血。塗之立效。須兼服煎藥。

煎方

天花粉（一錢）　生大黃（五分）　川通草（五分）　水煎服。

又方

黃柏（三錢）　黃連（一錢）　大黃（三錢）　冰片（三分）

為末。將豬苦膽一個。調敷患處。軟絹紮好。並治猴猻疳神效。
