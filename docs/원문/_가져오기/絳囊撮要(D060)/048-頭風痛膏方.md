# 頭風痛膏方

此病甚則害眼。左痛貼右太陽。右痛貼左太陽。兩首痛俱貼。

青黛　決明子　黃連　黃芩　桑葉　歸身　紅花　細生地　防風　紫蘇葉　加川貝母（去心各等分）

除青黛外。為粗末。油煎。用硃砂十分之三。紅丹十分之七。同青黛末收膏。青布攤貼。再另用黃菊花曬乾為細末。收貯。用時將菊花末少許。摻膏上貼之。
