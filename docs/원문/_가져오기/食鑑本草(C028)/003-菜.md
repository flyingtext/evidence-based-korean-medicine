# 菜

（菜性屬陰。職司疏泄。是謂之蔬。日用之不可缺。因著於穀次。）

<ins>【蔓菁菜】</ins>

菜中之最益人者。常食和中益氣。令人肥健。凡往遠方煮青菜豆腐食。則無不服水土病。

<ins>【菠菜】</ins>

多食滑大小腸。久食腳軟腰痛。

<ins>【芥菜】</ins>

多食動風發氣。不可同兔肉食。能生惡瘡。同鯽魚食。能發水腫。

<ins>【莧菜】</ins>

動風。令人煩悶。冷中損腹。同鱉食。都變為小鱉。急飲馬溺愈。亦不可食蕨。

<ins>【　角菜】</ins>

久食發病損經絡。少顏色。又令腳冷痹。傷腎。

<ins>【芹菜】</ins>

生高田者宜食。和醋食損齒。赤色者害人。

<ins>【　菜】</ins>

性冷發痔。

<ins>【紫菜】</ins>

多食發氣。令人腹痛。吐白沫。飲多醋即消。其中小螺螄損人須揀出。海菜亦然。

<ins>【茭白】</ins>

不可合生菜食。合蜜同食發痼疾。損陽氣。

<ins>【蕨】</ins>

食之令人　。弱陽。又令眼昏鼻塞。發落。小兒食之。腳弱不能行。氣冷人食之多腹脹。

<ins>【茄】</ins>

性寒滑。動氣發瘡。多食主腹痛下利。婦人傷子宮。

<ins>【蔥】</ins>

功能發汗。多食則昏神。與蜜同食。則下痢腹痛。蔥與雞雉犬肉同食。九竅出血害人。

<ins>【韭】</ins>

病患少食。多食助陽損神昏目。尤不可與蜜同食。若同牛肉食成瘕病。

<ins>【薤】</ins>

似蔥而細。食之生痰涕。動邪火。反牛肉。

<ins>【蒜】</ins>

唯辟惡氣。快胃消滯。久食生痰火。傷肝損目。弱陽。食蒜行房傷肝氣。令人面變顏色。

<ins>【葫荽】</ins>

久食損神。健忘。根大損陽。滑精。發痼疾。

<ins>【葵菜】</ins>

食之發宿疾。服一切藥俱忌食。同鯉食害人。

<ins>【白蘿卜】</ins>

消痰下氣。利膈寬中。多食耗脾氣。生食滲血　心。如服地黃何首烏人參者食之，須鬢發皆白。

<ins>【瓠子】</ins>

滑腸。冷氣人食之反甚。葫蘿匏有小毒。多食令人吐煩悶。苦者不宜食。

<ins>【筍】</ins>

性冷難化。多食動氣。不益脾胃。令人嘈雜。

<ins>【菌】</ins>

地生為菌。木生為薷。為木耳為蕈。凡新蕈有毛者。下無紋者。夜有光者。肉爛無蟲者。

煮熟照人無影者。春夏有蛇蟲經過者。誤食俱殺人。若食楓樹菌者。往往笑不止而死。犯者掘地為坎。投水攪取。清者飲之。即解。木菌唯楮榆柳槐桑棗木六樣耳可食。然大寒滯膈。

難消。宜少食。凡煮菌可同銀器燈草煮。如銀器黑者有大毒，不可食。

<ins>【生薑】</ins>

專開胃。止嘔吐。行藥滯。製半夏毒。諺云上床蘿卜下床薑。蓋晚食蘿卜。則消酒食之滯。清晨食薑。能開胃御風。敵寒解穢。九月食薑。傷人損壽。
