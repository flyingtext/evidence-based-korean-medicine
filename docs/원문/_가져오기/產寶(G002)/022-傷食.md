# 傷食

傷食必於補氣血藥中審所傷何物。以消導藥佐之。如傷穀食宜神麯穀芽。傷肉食宜麥芽山楂。傷果食腹內痛甚宜吳茱萸砂仁。世醫每遇此症。專消無補。反傷胃氣。不應又誤認為原傷。食物未消。倍加寬胸耗氣之品。甚至絕谷數日以垂危者。此際已無藥可用。惟煎獨參湯二三錢。調飯鍋焦末。漸漸與之。或可十救四五。
