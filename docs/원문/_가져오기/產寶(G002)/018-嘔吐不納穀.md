# 嘔吐不納穀

<!-- source-id: G002:p018 -->
> 서명: 產寶
> 원본 파일: `G/G002.txt`

嘔者聲與物俱出。吐者有物無聲。此由脾胃虛弱。或寒氣所客。或飲食所傷。以致氣逆而食不得下。在七日內塊痛未除。宜服安胃行血湯。塊痛已除。而嘔不止。穀氣不納。服加減六和湯。服前二方。胃和嘔止。服補中調胃湯。惟嘔吐而見呃逆者。是謂土敗木賊。大率難治。
