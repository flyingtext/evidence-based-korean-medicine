# 過食辛辣成毒

<!-- source-id: N086:p036 -->
> 서명: 景景醫話
> 원본 파일: `N/N086.txt`
> 원본 SHA-256: `c022fb83a384a092bd75e322f95e7e8f339a77531639ee79aaa6824fcce10e66`
> 상태: 자동 변환 원문·정본 미대조

又載烏程顧文虎，累葉簪纓，習享豐豫，忽一日，促家人持竹批，解褲受杖，後習為故常，用稍輕，輒加呵責，或反以杖杖之，必重下乃呼快心，如是數年，漸覺疼痛而止。醫者聞之曰「過嗜辛辣發物，則熱毒內訌？因成奇癢，適打散不致上攻，否則疽發背而死矣。」此富貴之人炯鑒也。
