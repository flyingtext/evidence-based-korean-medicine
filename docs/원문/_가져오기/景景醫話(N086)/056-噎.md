# 噎

吳江鈕玉樵誘《觚賸》載：武昌小南門外獻花寺僧自究病噎，百藥不效，臨歿，謂其徒曰「我毒[z]獨[/z]罹此患，胸臆必有物為祟，逝後剖去殮我，我感之入地矣。」其徒如教，得一骨如簪，收置經案，久相傳示。閱歲，適有戎帥寓寺，從者殺鵝。未斷其喉，偶見此骨，取以挑刺，鵝血噴發，而骨遂消滅。自究之徒亦病噎，因悟鵝血可治，數飲遂愈。遍以此方授人，無不驗者。燧按：蘇恭謂鵝毛灰治噎，不獨血也。
