# 淫字解

人身生氣通於天，凡風寒暑濕燥火六氣，皆與我身臟腑相感應，天地一陰陽五行也，人身亦一陰陽五行也。然則六氣皆為生入之具，而非殺人之物，何稱之曰六淫？曰。此惟過則為害耳。淫者，過也。大水曰淫，大雨曰霪，佚蕩曰侄，並義寓於聲。六氣苟不過極，即不得名之曰淫。
