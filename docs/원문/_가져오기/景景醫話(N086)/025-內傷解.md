# 內傷解

王孟英述其慈訓曰；「內傷證必求其所傷何病，而先治其傷，則病去而元自復。」古人不曰內虛而曰內傷，顧名思義，則純虛之證殊少也。徐洄溪亦云「大凡人非老死即病死，其無病而虛死者，千不得一。況病去則虛者亦生，病留則實者亦死。」孟英又云屍雖在極虛之人，既病即為虛中有實，然則近今醫家，一遇內傷，而專事蠻補者，其亦來明「傷」字之真諦乎。經曰「不能治其虛，焉問其餘。」既云虛矣，猶曰治而不曰補，讀書細心者盍昧之？
