# 西法化驗

<!-- source-id: N086:p004 -->
> 서명: 景景醫話
> 원본 파일: `N/N086.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

見某報紙載有人患恙，鄰予以單方藥兩味，係大辛大溫。發汗散氣者，服後即殞。某告諸公庭，命西醫取藥化驗，皆無毒。余按凡病之不在表者，及表分素虛者，皆忌表；病之不在裏者，及在裏而不實者，皆忌下，故麻黃、細辛，大黃，芒硝，並足以殺人，即和平之品，苟不對症，亦足以輕病變重，重病致死，取諸藥以化驗，豈必有毒乎？
