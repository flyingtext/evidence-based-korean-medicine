# 龜癥、產

<!-- source-id: N086:p057 -->
> 서명: 景景醫話
> 원본 파일: `N/N086.txt`
> 원본 SHA-256: `c022fb83a384a092bd75e322f95e7e8f339a77531639ee79aaa6824fcce10e66`
> 상태: 자동 변환 원문·정본 미대조

明·楊循吉《蓬軒吳記》載：葛可久國初名醫，有奇驗。一人患腹疼，延葛治，葛視之，謂其家曰「腹有肉龜，俟熟睡吾針之，勿令患者知，知則龜藏矣。」患者問故，家人誑曰「醫云寒氣凝結，多飲釀酒自散耳。」患者乃引觴劇飲，沉酣而臥，家人亟報葛，葛診其脈，以針刺其腹，患者驚寤，畀以藥，須臾，有物下，儼如龜，厥首有穴，蓋針所中也，病遂愈。又一鄰婦娠將娩，氣上逆，痛不可忍，就葛視，葛見之，遽以掌擊案，厲聲大叱，婦驚，產一子。葛慰曰「向見爾色青氣逆，是腹中兒上攻，少緩不可救矣。猝然被驚，故即產也。」其神驗如此。燧按：三屍為患，亦不能明告患者何病何藥，告則其蟲避不飲藥矣。又驚則氣下，故葛之治二病如此。
