# 足腫門

小兒足腫，用手按之成坑遲起者，水腫也。隨按隨起者，氣腫也。形色虛弱，關紋青淡，眼光散大者，主腎虛方，各方附下。

<ins>治水腫方</ins>

防己　黃　赤苓　丑牛（各一錢）　肉桂（五分）　甘草（七分）　水煎服。

<ins>氣腫方</ins>

防己　箭　升麻　當歸　焦術　炙草（各一錢）　水煎服。

<ins>治腎虛腫方</ins>

熟地（五錢）　澤瀉　云苓　棗皮　懷山藥（各二錢）　牛膝　附片（各一錢）　甘草（八分）　水煎服。

<ins>治鶴膝風方</ins>

虎脛骨　石欄藤　箭杆風　當歸　防己　酒煎服。

足上濕氣　石菖蒲、箭杆風、薑蔥共搗如泥，敷上即效。

<ins>足上凍　洗方</ins>

　用桐子葉或茄子根，煎水洗之。

<ins>足上濕爛方</ins>

　用水龍骨　為末摻之，即舊船底下練子灰。

足上繡爛　枯礬、甘石、掃粉、胡粉，細末摻之。
