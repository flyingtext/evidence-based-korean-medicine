# 腹脹門

<!-- source-id: H001:p032 -->
> 서명: 幼科切要
> 원본 파일: `H/H001.txt`
> 원본 SHA-256: `3bf24dcb9a82d6f1c016b53a729273d4da448f7fec6e8cb57f8b38f9fd8c6315`
> 상태: 자동 변환 원문·정본 미대조

凡氣脹水脹，用公雞屎干一升，炒焦黃色，退去火毒，為末，以水三升，煎沸，用布濾過，每服一杯，調木香、檳榔細末五分。此治中滿蠱毒，真奇方也。

治食脹氣脹，用萊菔子一兩，細末，開水調濾汁，將汁水浸砂仁一兩，浸一宿，將砂仁炒干，又浸，共浸七次，將砂仁為末，每服一錢，米湯調下。
