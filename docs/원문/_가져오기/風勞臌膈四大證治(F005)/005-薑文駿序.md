# 薑文駿序

<!-- source-id: F005:p005 -->
> 서명: 風勞臌膈四大證治

> 상태: 자동 변환 원문·정본 미대조

今夏檢校舊帙，將祖傳醫書數百冊，特為之分篋珍藏，免與諸書間雜也。中有一小冊，偶爾披閱，見書首有四大證全書，江陰薑禮天敘氏輯，孫健、曾孫大鏞參訂字樣，並有邑諸名宿傳題。閱竟不勝驚喜，以為吾先祖著作，至今日而始發現焉。惜僅存十數頁，末由窺見全豹，亦憾事也。猶憶余童年時，嘗聞先祖詠仙公云：「吾家祖遺醫書，不下數百種，著作滿室，富有五車。同治初，太平軍解放江城時，潰軍土匪竄擾，焚毀殆盡，然燼余尚存數千冊。伯祖蘊山、蔭喬兩公，所得約有千余冊。庚申春，故宅毀於火，煌煌巨制，從此都付諸劫灰。」嗚呼，先人累世之心血，歷年愈久愈湮沒而不彰矣﹗即今所存四大證全書，亦屬殘缺不完。詢諸伯叔，早稔原本失蹤無考。惋惜久之。詎今秋吾友陶君南鵬，肄業上海醫專學校，惠贈校出中醫雜志一冊，內載有薑天敘著風癆臌膈論。卒讀是篇，尚待續未竟。因念吾先祖之姓名奚為而在此耶？得毋姓名有同耶？繼而思余因業商，不明醫學，今日所見之風癆臌膈，莫非即所存之四大證全書。然乎否乎？即將舊稿悉心校對，果然一字不易，乃知此論實為先祖所著無疑也。於是昔日所黯然神傷者，今頓欣然色喜矣。

夫天敘公，龍砂薑氏二世祖也，生於順治十一年，好讀書，善醫術，立功過格，日記得失，終身不怠，旁及玄功，名噪大江南北，年七十有一而歿。邑志載有〔仁壽鏡〕、〔本草搜根〕行世，今已軼。家乘中只有〔四大證全書〕名目。此外，邑志家乘所未載，而為鄉賢藏匿者，則〔證治匯理〕一書是也，計抄本念余冊，今悉藏張少泉先生家。疇昔家伯省軒，因掌教於南通醫專校，曾親謁張公，云已什襲珍藏矣。他日如能合浦珠還，自當刊行以垂諸久遠。
