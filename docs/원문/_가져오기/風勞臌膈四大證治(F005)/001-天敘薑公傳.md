# 天敘薑公傳

<!-- source-id: F005:p001 -->

> 원본 파일: `F/F005.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

公諱禮，字天敘，姓薑氏，其先浙紹人也。父玉田公，始居江陰之華墅，生公，遂世為江陰人。公好讀書，善醫術，常立功過格，日記得失，終身不怠。每遇貧者施診，往來徒步，出囊中藥治之，不取值，以故邑中賢士大夫樂與締交。蓋非徒重其術，並重其德焉。華墅在邑東五十裡，龍砂兩山屏障於後，泰清一水襟帶於前，其山川之秀，代產良醫，迄今大江南北延醫者，都於華墅，而華墅之中又獨推薑氏，蓋自公一人開之也。韓子云：「莫為之前，雖美弗彰；莫為之後，雖善勿繼。」吾於薑氏亦云。公於岐黃外，旁及玄功。所善有瞿道人者，發不櫛，足不履，寒暑一衲，行止無定。迨卒之歲，謂道人曰：「三月之望，吾將逝矣，汝當來。」及期，瞿不至。諭諸子曰：「須之三日，道人必來。」是日命沐浴更衣坐，道人果至。時不能言，但手書「諷經」二字，瞿諾之，即奄然逝。記曰：「至誠之道，可以前知」。公可謂至誠者矣。

論曰：古云：「醫不三世，不服其藥。」謂醫者當讀三世之書也。余讀薑公所著四大證全書，理精詞約，非數十年之學力，焉能得心應手，活人無算乎？宜其子孫食報於無窮。小道云乎哉﹗
