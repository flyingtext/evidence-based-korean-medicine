# 承淡安序

醫學之在於我國，皆曰：「今不如古」。實則指庸人而言者，庸者皆不學無術之人也。

使其學而窮究古今之病源，精審古今之方略，其病之在標在本，病之或傳或變，方之宜補宜瀉，不執不拘，則可如古人云：「三年蓄艾，能治之於未病之先，」與夫「一七回生，能治之於已病之後。」故曰：讀書而不能醫者有之，決未有不讀書而能醫者也。

風癆臌膈，症之大者也。諺云：「風癆臌膈，實病難醫。」實病，乃邪實正虛之謂。經云：「清靜則肉腠閉拒，雖有大風苛毒，弗之能害。」不獨四大證如是，何病不然耶﹗要之，能詳察病源，精審其證，方以制宜，四大證有何畏哉﹗吾故鄉薑公天敘特著（風勞臌膈論），以闡明古聖先哲立論制方之精微。蓋聞薑公者，好讀書，善醫術，常立功過格，日記得失，終身不怠，探析性命之微，雅抱　KT　之痛，而以好學不倦之旨，　人以博施濟眾之術。

讀其論中，類多闡揚經旨，如中風一症，其力主非外風所中，抉奧發微，分疏清晰。如對虛癆一症，其旨當從〔難經〕治法，融合越人之脈法於仲景辨證之中。論治虛損，本於（難經）及丹溪、子和諸家學說，理精辭約。非數十年之學力，曷克臻此哉﹗再讀其臌脹釋義與治膈之方，都有獨特之見地。又附雜病論治，有非四證所能限者，博引各家學說，參以己意，極為詳確。其諄諄告誡後學之心，如大海明燈。

淡安與鄉先輩天敘公後裔文駿君，忝為葭莩之誼，據其敘述，薑氏家藏著作本豐，輾轉遷徙，又遭兵燹，盡付劫灰。久耳四大證全書之名，以是未獲卒讀為憾﹗茲蒙惠我中醫雜志所載風勞臌膈論全篇，得以拜讀全書。值此發揚祖國醫學文化遺產，一則提供海內同道之參考，一則對薑公畢生心血之巨著，庶不致湮沒而不彰，爰為之序。
