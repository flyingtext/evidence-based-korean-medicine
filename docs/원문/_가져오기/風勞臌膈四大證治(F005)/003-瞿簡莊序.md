# 瞿簡莊序

嗚呼，吾華市北鎮向以醫名世，至今衰墜不振者久矣﹗余髫年授庭訓，即從事於〔內經〕、

〔難經〕、〔金匱玉函〕諸書，訓以知之者為知，行之者為行，寧使知之而未能行，莫使行之而未能知。不為垂垂衰老，僅得略窺其皮毛，何曾咀拾其精髓。吾友蘇墅橋吳乃良先生曰：「薑體乾與葉天士同時行醫，體乾游蘇適居天士比鄰（凡有就葉診棄之者輒為之治），一日見墜淚咨嗟者曰：『勢將奈何？』急詢其故，知天士斷其木葉落時定難飛渡。體乾即為之診曰：『病固急矣，勉為處方。』不特璧其診資，並助以藥資，囑服十劑，果驗。天士聞而駭曰：『是誰能挽回斡旋歟？』因知我華市有薑體乾公之醫道。天士先生特來華市謁薑公，並謙曰：『昔日有眼不識泰山，今特來請出山。』體乾下榻曰：『余處窮鄉，貧病者多，不能出。』乃款留而去。」繇是知學無底止，而醫學更無底止。體乾之風，類都如此。而其乃祖天敘先生之醫學弘博，有非時下所能望其項背者。今其裔孫正從持天敘所著風勞臌膈四大證論稿囑為校正。據曹孝廉家達得之於仲九如望，曹公詳序之。正從深恐先人之心血手澤湮沒，他日付棗梨。吾知薑氏將來有繼興者焉。
