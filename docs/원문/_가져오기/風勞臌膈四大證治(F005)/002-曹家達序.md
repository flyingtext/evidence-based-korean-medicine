# 曹家達序

<!-- source-id: F005:p002 -->

> 원본 파일: `F/F005.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

鄉先正薑天敘先生，肆力於醫，慨念漢醫放失，斐然興著述之志。綜其生平所著，有四大證論若干卷，書中所論風癆臌膈，旁征博引，參以己意，至為詳審。曩者予於同鄉仲佩紳所設九如堂藥肆遇仲之外舅陳某，出以相示，因得窺其全豹。厥後中醫學會刊布雜志，門人王一仁見而悅之，因逐期刊布雜志中，易其名曰風癆臌膈論，從其實也。厥後其裔孫文駿，寓書中醫學會，略謂家藏舊本不知何緣遺失在外，冀得原稿，以保存先世手澤。薑氏固多賢子孫哉﹗然當時以刊布未完，欲歸趙而不果。嗣因薑君達夫之請，向中醫學會取原稿，而下卷業已遺失。幸一仁所刊雜志，並來書刊入卷尾，略無訛脫。一仁信有功於薑氏矣。今者達夫擬用單行本行世，索序於予，爰為略舉顛末，弁簡端以歸之。
