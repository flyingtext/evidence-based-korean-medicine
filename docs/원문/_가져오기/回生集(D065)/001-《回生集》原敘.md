# 《回生集》原敘

<!-- source-id: D065:p001 -->
> 서명: 回生集
> 원본 파일: `D/D065.txt`
> 원본 SHA-256: `e40281205b6cc342963754b70c8d1d79dedd76a6bf626950fa27b580334d96dd`
> 상태: 자동 변환 원문·정본 미대조

從來妙劑，多出仙傳，如千金等方，其尤著者也。余素患痰疾，後又左膝寒痛，二十載以來，屢治不瘥。戊申歲恭設乩壇，求治於葛仙翁祖師，乩示云，此膝痛即系積痰所致。幸賜方藥，宿疾頓除。嗣凡眷屬有恙，即虔禱仙方，無不立效，但祖師因人治病，故所得乩方，未敢廣傳。惟立愿遍訪世間經驗良方，無論已刻未刻，匯刊公世。尚恐成方中，或有一時偶驗，未可永為準則者，謹求祖師選定，得四百余方，並蒙乩批云。予有一片濟世之心，故凡有所求，借乩鸞以示。爾今備有成方，請予選定，予亦欣然。但病有虛實寒熱，藥有溫涼補伐。虛宜溫補，實宜瀉散。倘視症未明，誤投藥劑，為害非輕。今擇其必中者用之，自無不驗也，此書即定為《回生集》可耳。敬敘卷首，以體祖師普濟之慈心云。
