# 新刊續添是齋百一選方目錄

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

此集已盛行於世，近得是齋全本，其為方也一千有餘，分門析類，列之於目，井井可觀，皆系經驗不傳之秘。凡丈夫、婦人、小兒諸證纖悉委曲，靡所不備，鼎新刻梓，三復校正，並無訛舛，凡我尊生君子伏幸詳鑒。歲在癸未端陽前一日，建安劉承父謹咨。
