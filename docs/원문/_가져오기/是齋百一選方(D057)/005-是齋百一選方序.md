# 是齋百一選方序

<!-- source-id: D057:p005 -->

> 상태: 자동 변환 원문·정본 미대조

方書傳於世眾矣，其斷斷能已疾者蓋寡。古人方書，一藥對一病，非苟云爾也。後世醫家者流，不深明夫百藥和劑之所宜，猥曰醫特意爾，往往出己見，嘗試為之，以故用輒不效。

甚也。嗟乎﹗醫方所以除疾　而保性命，其何至是？得匪其擇之不精，處之不審故歟？是齋王史君　，博雅君子也。生長名家，蓄良方甚富，皆其耳目所聞見，已試而必驗者。

每集始就，乃鋟諸郡齋，目之《百一選方》，其精擇審處蓋如此，然則公之用心仁矣，是書之衍其傳也宜哉﹗慶元丙辰孟冬初吉，郡文學天台章楫序。
