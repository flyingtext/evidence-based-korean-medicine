# 傷食

《肘後》辨脾胃所傷變易形法: 凡諸脾脈, 微洪傷苦澀物, 經云: 咸勝苦. 微澀傷辣辛物, 經云: 苦勝辛. 微滑傷腥咸物, 經云: 甘勝咸. 洪緩傷甜爛物, 經云: 酸勝甘. 弦緊傷酸硬物, 經云: 辛勝酸. 微弦傷冷硬物, 經云: 溫以克之. 微遲傷冷痰積惡物, 經云: 溫胃化痰. 飲食過多, 脹痞不下, 尋常率以破氣之藥投之. （傷食惡食, 必有噫腐吞酸之候. ）是食物既傷之前, 藥劑又攻之於後, 脾氣安得而健暢也. 必須以平補之藥為主, 佐以他藥, 一升一降, 使脾腎交通, 而水火既濟, 自然腐化矣.
