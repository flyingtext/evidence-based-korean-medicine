# 秘受不治法

<!-- source-id: J015:p002 -->
> 서명: 傷科方書
> 원본 파일: `J/J015.txt`
> 원본 SHA-256: `099b5acf30b96a4c68463c229bbb851fcce9fe0bb5c84a293281f97221147592`
> 상태: 자동 변환 원문·정본 미대조

凡矢柱骨折。不治。

凡兩目損傷。不治。

凡口開氣出不收。不治。

凡口如魚口。不治。

凡傷食喉。不治。

凡打破頭鼻流黃白水。不治。

凡脊骨折斷。不治。

凡心胞緊痛。紅色高腫。不治。

凡心口青色。不治。

凡小腹陰陽不分。不治。

凡跌打大小腹痛。不治。

凡腎子傷入小腹。不治。

凡孕婦傷犯胎。不治。

凡女人傷乳。不治。

凡男人兩乳堂傷。不治。

凡腰傷自笑。不治。

凡兩臂墮下。盡力叫嚎。汗出如油者。不治。

凡人手骨出一脛可治。兩股齊出。不可治。
