# 病有十不治

操欲　淫，不自珍重，一也，窘苦拘囚，無瀟洒之趣，二也，怨天尤人，廣生煩惱，三也。今日預愁明日，一年常計百年，四也。室人噪聒，耳目盡成荊棘，五也。聽信師巫禱賽，廣行殺戮，六也。寢興不適，飲食無度，七也。

諱疾忌醫，使虛實寒熱妄投，八也。多服湯藥而滌腸胃，元氣漸耗，九也。以死為苦，與六親眷屬常生難割舍之想，十也。眾生諸苦，病居第一。愚者以苦生苦，如蠶作繭，智者於苦滅苦，如鳥脫籠。余悲眾生障深，難即解脫，書之以作方便法門耳。
