# 可惜歌

可惜許，可惜許，可惜元陽宮裡生，一點既出顏色枯，百神泣送真陽去。三魂喜，七魄無，血敗氣衰將何補，弄元真物屬他人，赤宅元君誰做主？勸世人，須慕道，休慕色，慕色貪淫有何益？不念形骸積漸枯，逢人強說丹砂力。丹砂力，人不識，誰人肯向身中覓，靈源經裡號真鉛，丹華訣內名金液。三茅真君喚作一，子得一時萬事畢，聖人秘一不能傳，不曉分明暗如漆。一神去，百神離，百神去後人不知，幾度欲說不欲說，臨時一點泄天機。一神離，百神悲，日後形悴卻如痴，我今念念說向汝，說時又恐泄天機。男子修成不漏精，女子修成不漏經，精不漏兮身不朽，經不漏兮可長生。若曉此玄玄外法，便是長生物外人。
