# 統論舌為心脾所主

心在竅為舌。（《素問》）心脈系舌本，腎液出舌端，脾脈系舌旁，肝脈絡舌本，雖分有五臟，而心脾實主之，故二臟不和，變生諸症。（《玉策》）膀胱經結舌本，三焦經系舌本。（日胗）

內因　心和則舌能知五味，聲音嘹亮。（《內經》）心絕則舌不能收，及不能語。（喬垂）脾主舌強，腎主舌乾。（岫云）誤食毒味，及冬月向火取暖過度，俱使舌變生病患。

外候　中風痰則舌卷難言，傷七情則舌腫難食，三焦蘊熱則舌胎燥而咽乾，心脾熱熾則舌粗重而口苦。

（《繩墨》）氣虛則麻、縱，陰火則點黑，濕痰則腫脹，郁熱則衄血，心火則生瘡脾熱則干澀，胃熱則木強，肝熱則卷且縮，肺熱則舌燥而咽門聲啞，腎熱則津竭而舌心干焦。（《匯補》）

治法　舌症有十五種，用藥不禁寒涼，然必帶辛散乃效。（日胗）舌屬火，其性炎上，治舌當降火滋陰。

（《繩墨》）凡治口舌輕症以鹽滾水為最便，且亦妥善，勿謂以其易而少效也。

用藥加減法　風痰用二陳加南星、竹瀝。郁痰加香附、青皮。三焦郁熱，涼膈散。心脾郁熱，三黃丸。思慮傷脾，血耗火動，歸脾湯。郁怒傷肝，血虛火旺，逍遙散。腎虛陰火，滋腎丸。（李惺庵）
