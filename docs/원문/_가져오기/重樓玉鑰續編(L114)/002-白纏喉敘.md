# 白纏喉敘

鄭子若溪，聰明好學士也，潛心於醫學有年矣。其於喉證尤究心焉，蓋喉科乃其家傳，然其書特言實症而虛症未之及也。至於白腐一證，近日更多，醫者罔察，自作聰明，不論色脈，每作實證治之，而夭枉者，不可勝數。

若溪心竊傷之，自出手眼，因辯證著方，以辟其謬，而病是證者，咸登壽域。書成持以示予，予讀之，不覺躍然因謂之曰：善哉﹗子能為白腐證辟一坦道，而以虛燥立方，子之功德遠矣。蓋白者，肺色也，腐者腎臭也，原非病也，形而出之外則病矣，白加腐則肺燥矣，腐且白則腎枯矣。既燥且枯，子母俱敗不有以潤之，補之而猶曰紫正敗毒，則將持雌失雄，棄陰負陽，其不至於載胥及溺不止矣，吾子之論是也。藏之名山，曷若傳之後世？好生之，德與人同之不亦善乎﹗因書之以，弁其簡端。
