# 記錄十四科

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

古醫十四科，而今亡之矣。自宋元以來，止用十三脈。其十四科者，中有脾胃一科也。今亦終莫之續。

考《醫政》，其一為風科，二為傷寒科，三為大方脈科，四為小方脈科，五為婦人胎產科，六為針灸科，七為眼科，八為咽喉口齒科，九為瘡瘍科（即是外科），十為正骨科，十一為金鏃科，十二為養生科（即今修養家，導引按摩咽納是也），十三為祝由科（《經》曰：「移精變氣者，可祝由而已」，即今符祝禳禱，道教是也）。
