# 自敘

兒侄輩從師羊城，余慮其功課之餘，風寒不慎，飲食不節，因訂外感、春溫、暑、濕、瀉、痢、瘧七症方與之，庶免臨渴而掘井。後據云服之多效，即館友亦有遵此法而除病者。余聞其驗，遂翻閱自著舊方，皆從平穩立法，既無伏邪之患，亦無傷元之變，始則欲便子侄，繼則思並益同人，因復增入頭、心、腰、腹、脅、腳，耳、牙、疝氣、痿壁諸痛，小便、大便、衄、吐諸血，又消渴、嘔吐、噎膈、反胃、霍亂、黃疸、淋濁、癃閉、遺精、咳嗽諸症。大抵少年輩，起居飲食不謹所致者，共成三十三症，此外症治雖尚多遺略，但此中數症，實人生所易患，且又每見時醫誤治，而世人受其害者不少，是以不必求其全，而思撮其要，擬付梓人，公諸同好，俾不知醫者，亦得自為調理，不致為庸醫所誤。凡初起輕恙按法服之，諒易就痊。至若久恙、重恙，又不敢謂能盡奏效也。

　　番禺潘名熊蘭坪氏自序於西村之評琴書屋
