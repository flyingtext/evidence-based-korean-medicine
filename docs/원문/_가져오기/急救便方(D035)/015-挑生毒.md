# 挑生毒

<!-- source-id: D035:p015 -->
> 서명: 急救便方
> 원본 파일: `D/D035.txt`
> 원본 SHA-256: `cba71ec2295177b1b5543a8b0c940cc79783b55ed50ab26a486799cc0e126929`
> 상태: 자동 변환 원문·정본 미대조

（嶺南人挑毒於飲食中以害人，其候初覺胸腹作痛，次漸攪刺，十日則物則胸痛，在下則腹痛）

在上者，用膽礬末五分，投熱茶內，化毒探吐之。在下者，用鬱金末二錢，米飲調服，當瀉下惡物。

後以四君子湯去甘草調理脾胃。有人脅下腫起，頃刻如碗大，此挑生毒也。五更時以生綠豆試嚼之，覺香甜即是。用升麻研細末，取開水冷定，調服六錢，連服二三次，痛泄中，蔥數莖，根須皆具，腫則消縮，仍服平胃散調補而愈。
