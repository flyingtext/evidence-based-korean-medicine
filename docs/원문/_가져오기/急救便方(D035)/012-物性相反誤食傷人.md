# 物性相反誤食傷人

<!-- source-id: D035:p012 -->
> 서명: 急救便方
> 원본 파일: `D/D035.txt`

> 상태: 자동 변환 원문·정본 미대조

甘草與　魚同食殺人。蟹與柿反。黃瓜與花生反。南瓜不可與羊肉同食，犯之立死。豬肉得胡荽爛人臍。羊肝得生椒爛人臟。河豚同鹿肉食殺人。河豚風栗並食有毒。羊肉同膾酪食害人。膾生同酥乳食之變諸蟲。鱉肉與莧菜食之還生鱉。荊花落魚羹即殺人。石膏與蕎麥面同食殺人。服木鱉子啖豬肉殺人。食黃嗓魚犯荊芥殺人。食驢肉亦最忌荊芥。蜜　並食有毒至死者。茅舍漏滴肉上，食之殺人。

獸有歧尾，蟹有獨螯，羊一角，雞四足，鱉三足，白鳥烏首，烏雞白首，白馬青蹄，黑馬白蹄，魚無腸膽，牛肝葉孤，飲瓶花水有毒，瓶浸臘梅尤甚。采草藥夾雜毒物能殺人。

魚昂頭出水二三寸者，有毒殺人。蛇虺涎滴入飲食中殺人。淘積糞坑穢水入口即死。淘古井須防冷毒致死。百足蟲毒殺人。服官粉殺人（即鉛粉。）

曼陀羅鬧陽花釀酒令人狂笑，昏沉不語。

多服仙茅，舌脹大難治，（以小刀刮之，至百十下，有血出乃縮，即用大黃、芒硝煎服二三碗，仍以蒲黃、青黛、黃柏末或冰硼散等藥搽之，可愈。）

老雞過數年有毒（養生家雞老不食，夏不食雞。）
