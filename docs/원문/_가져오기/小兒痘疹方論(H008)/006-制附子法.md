# 制附子法

附子重一兩三四錢。有蓮花瓣、頭圓底平者先備。童便五六碗。將附子先放在灶上煙柜中間良久。

乘熱投入童便。浸五七日。候潤透揭皮。切四塊。仍浸二三日。用粗紙數層包之浸濕。埋灰火半日。

取出切片。檢視有白星者。乃用瓦上炙熟。至無白星為度。如急用即切大片。用童便煮二三沸。熱瓦熟用之。
