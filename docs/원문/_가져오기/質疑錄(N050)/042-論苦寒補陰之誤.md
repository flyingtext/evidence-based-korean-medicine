# 論苦寒補陰之誤

<!-- source-id: N050:p042 -->
> 서명: 質疑錄
> 원본 파일: `N/N050.txt`
> 원본 SHA-256: `d97b404f426d47b222ae85ee0ca359b2094413e7e810276fc1f80b95698564f3`
> 상태: 자동 변환 원문·정본 미대조

凡物之死生，本由乎陽氣。顧今人病陰虛者，十嘗八九，不知此「陰」字，正陽氣之根也。陰不可無陽，陽不可無陰。故物之生也，生於陽；而物之成也，成於陰。則補陰者，當先補陽。自河間主火之說行，而丹溪以苦寒為補陰之神丹，舉世宗之。盡以熱證明顯，人多易見；寒證隱微，人或不知；且虛火、實火之間，尤為難辨。孰知實熱為病者，十不過三四；而虛火為患者，十嘗有六也。實熱者，邪火也。邪火之盛，元氣本無所傷，故可以苦寒折之，亦不可過劑，過則必傷元氣。虛火者，真陰之虧也。真陰不足，豈苦寒可以填補？人徒知滋陰之可以降火，而不知補陽之可以生水。吾故曰：使劉、朱之言不息，則軒岐之道不著。
