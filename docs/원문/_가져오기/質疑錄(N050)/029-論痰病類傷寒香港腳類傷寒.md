# 論痰病類傷寒香港腳類傷寒

<!-- source-id: N050:p029 -->
> 서명: 質疑錄
> 원본 파일: `N/N050.txt`
> 원본 SHA-256: `d97b404f426d47b222ae85ee0ca359b2094413e7e810276fc1f80b95698564f3`
> 상태: 자동 변환 원문·정본 미대조

《活人書》有云：中脘有痰，令人憎寒壯熱，胸膈痞悶，有類傷寒。又云：傷寒只傳足經，不傳手經。地之寒、暑、風、濕，皆作蒸氣，足常履之，遂成香港腳，所以病症與傷寒相類。此等議論，大是惑人。夫傷寒為熱病，有六經傳變之異。痰本人身津液血凝氣滯而成，未嘗有六經之變症。至於香港腳，為寒、濕、熱三氣之感，雖東垣有南北內外之分，而孫真人詳香港腳見症甚悉，亦未始有六經之別。何將此二證竟以類傷寒混同名之？似欲以治傷寒之法治痰與香港腳耶﹗凡治病必正證之名，名不正則治療無據矣。
