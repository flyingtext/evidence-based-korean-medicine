# 論右腎為命門

<!-- source-id: N050:p020 -->
> 서명: 質疑錄
> 원본 파일: `N/N050.txt`
> 원본 SHA-256: `d97b404f426d47b222ae85ee0ca359b2094413e7e810276fc1f80b95698564f3`
> 상태: 자동 변환 원문·정본 미대조

《內經》初無命門之名，命門之說始於越人之三十六難，而曰腎有兩，左為腎，右為命門，男子藏精，女子系胞。夫右腎既藏男子之精，則左腎將藏何物？女子之胞何獨偏系於右？此其說之不能無疑也。

命門居兩腎之中，而不偏於右，即婦人子宮之門戶也。子宮者，腎臟藏精之府也，當關元、氣海之間，男精女血皆聚於此，為先天真一之氣，所謂坎中之真陽，為一身生化之原。此命門在兩腎中間，而不可以獨偏於右。兩腎屬水，有陰陽之分，命門屬火，在二陰之中。故《脈經》以腎脈配兩尺，但當曰左尺主真陰，右尺主真陽，而命門則為陽氣之根，隨三焦相火，以同見於右尺則可，若謂左腎則主於腎，而右腎偏為命門，此千古訛傳之弊，而不得不亟正之者也。
