# 內外傷辯序

> 상태: 자동 변환 원문·정본 미대조

僕幼自受難素於易水張元素先生，講誦既久，稍有所得，中年以來，更事頗多，諸所診治，坦然不惑，曾撰內外傷辯惑論一篇，以證世人用藥之誤，陵谷變遷，忽成老境，神志既惰，懶於語言，此論束之高閣十六年矣，崑崙范尊師曲相獎借，屢以活人，為言謂此書果行使天下之人，不致夭折，是亦仁人君子，濟人利物之事，就令著述不已，精力衰耗，書成而死，不愈於無益而生乎？予敬受其言，僅力疾就成之，雖未為完備，聊答尊師慈憫之志，師宋文正公之後也，丁未歲，重九日，東垣老人李杲明之題。
