# 論不得眠

<!-- source-id: B038:p007 -->
> 서명: 劉河間傷寒醫鑑
> 원본 파일: `B/B038.txt`

> 상태: 자동 변환 원문·정본 미대조

《活人書》云：下後復發汗，晝日煩躁不得眠，夜而安靜，不嘔不渴，無表證，脈沉微，身無大汗者，乾薑附子湯主之。守真云：夫傷寒病，懊　心煩，反覆顛倒，不得眠者，燥熱怫郁於內，而氣液不得宣通也，梔子豉湯主之。《素問‧刺熱篇》云：肝熱甚，小便先黃，腹痛，多臥，身熱。熱爭則狂言及驚，脅滿痛，手足躁，不得安臥。
