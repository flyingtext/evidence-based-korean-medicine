# 勞嗽見紅

酈翁　摻用神機, 肝膽氣火偏旺, 上刑肺金, 肺失肅化之權, 咳嗽震動, 肺絡交節見紅, 木叩金鳴, 陽絡傷則血外溢是也, 脈小弦數, 右寸關弦滑數兼見. 治宜清金平木, 兼以理絡.

南沙參　真川貝　丹皮　枇杷葉　麋銜草　炒蘇子　旋覆花　懷牛膝　玫瑰花　藕節　白杏仁　生蛤殼　絲瓜絡　仙鶴草　青蘆根

或用丹參、參三七、陳阿膠亦可.

如洋參、麥冬、燕窩、冬花、白芍、阿膠、女貞子、旱蓮草之類隨加, 蓄血類傷寒, 宜從《指掌》.

跌傷者亦從蓄血法.

活蝌蚪治吐血大靈, 帶活吞半碗許即愈.

白麋銜治吐血大效, 浸陳好酒佳.

活曲蟮治傷血大效, 浸陳酒佳.
