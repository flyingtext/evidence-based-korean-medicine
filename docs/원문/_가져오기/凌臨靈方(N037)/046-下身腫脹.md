# 下身腫脹

許左（年三十一歲, 八月三日）　傷於濕者下先受之, 諸濕腫滿皆屬於脾, 脾失運化之權, 濕熱曾著陽明, 太陰陽明之脈皆從足經而起, 濕熱下注其經氣絡不和, 腫自足跗而起, 膀胱氣化失司, 腫及陰囊, 小溲不利, 脈象弦緩, 治宜分利, 方照陳孩水腫之方去香附大腹絨, 加漢防己、晚蠶沙.
