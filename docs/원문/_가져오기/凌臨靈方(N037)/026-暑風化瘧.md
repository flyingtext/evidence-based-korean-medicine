# 暑風化瘧

慶侄　暑風化瘧，寒熱交作，頭脹脘悶，氣絡不舒，脈弦滑數，治宜疏解。

連翹　川鬱金　建神麯　益元散　廣藿香　青蒿子　新會皮　青荷梗　白杏仁　地骨皮　半貝丸　鮮佛手吾師云：寒濕瘧，日日作，藿香正氣散為主。

無汗加蘇梗，豆豉，杏仁；寒多加草蔻，生薑；熱多加青蒿，地骨皮；腹脹加枳實，大腹絨。

又云：不可用扁豆，用之必復發也。

愚見如正瘧者宜當詳考《金匱》論諸條，柴胡湯等法，又不可廢也，亦不可拘處暑之前柴胡不可用。
