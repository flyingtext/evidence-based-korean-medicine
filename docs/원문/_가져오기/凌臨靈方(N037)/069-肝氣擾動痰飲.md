# 肝氣擾動痰飲

朱左（年五十余，菱湖）　吸煙之體，脾肺自虛，中焦留伏痰飲，加以肝氣擾動，痰阻肺氣，咳逆痰稠，潮熱腹脹，糾纏不已，脈右滑左小數而弦，治宜調理。

東洋參　麩枳殼　赤苓　戈半夏（五分）　生於朮　真紫沉水香（三分，刮片另燉分沖）　新會皮旋覆花　炒白蒺　玫瑰花　紫石英　東白芍　薑汁炒竹茹
