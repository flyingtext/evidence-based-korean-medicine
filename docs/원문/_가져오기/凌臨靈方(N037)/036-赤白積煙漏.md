# 赤白積煙漏

葉左（五十歲，七月二十五日）　暑濕侵脾下痢，赤白相雜，晝夜無度，更衣腹痛後重，脈小弦數，治宜泄木和肝。

生白朮　東白芍　半夏曲　炒丹皮　青荷蒂　炒枳實　煨木香　楂炭　赤白苓　炒條芩　新會皮　青蒿子　白槿花幼群兄（七月）　吸煙之體，胃氣與榮氣並虛，夏秋暑濕蘊留陽明，太陰脾經失運化之權，加以食滯壅遏。腑氣轉化敗濁，下痢灰色，更衣裡急後重，晝夜登圊數十次之多。古謂痢積稱滯下是也，前醫謂其煙體，進藥一味辛燥而氣火之勢益劇，是以裡急更甚，今診脈象左右三部弦數，兼見舌苔光紅根後黃膩，以脈參症，正虛邪實難治奚疑，拙擬宣氣導滯利濕清熱，一則附方可否，請高明酌政。

生米仁　廣木香　紫濃朴　澤瀉　焦鍋巴（五錢，連蒂青荷葉包）　佩蘭葉　炒枳殼　半夏曲車前草　金斛　大腹絨　赤白苓　架楠香（二分，挫末再研極細分沖）
