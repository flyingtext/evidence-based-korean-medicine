# 春溫逆入心包

曹（十七歲，二月二十四日）　春溫化斑，隱約不達，痰火自肺胃逆入心營，熱傷津液，神昏譫語，手指掣搐，唇齒燥裂出血，苔焦燥邊紅，脈弦滑數兼見，以脈參證，慎防痰升內閉之憂，擬清解為法以俟。高明酌奪。
