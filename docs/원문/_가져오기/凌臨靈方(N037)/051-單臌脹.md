# 單臌脹

刑云窯　濕熱侵脾，脾虛作脹，土不生金，肺失清肅，咳嗽便溏，單腹臌脹，青筋外露，（或腹笥膨脹，青筋外露，勢成單臌之候）脈雙弦而濡，治之非易易耳。

生於朮　大腹絨　陳香櫞　雞內金　小溫中丸　炒枳實　新會皮　沉香曲　楂炭便結易萊菔子　製香附　法半夏　赤苓　車前子李　單腹膨脹希冀萬一。

生仙居術（一錢）　陳新會皮（一錢五分）　二味煎湯，送丹溪小溫中丸三錢。
