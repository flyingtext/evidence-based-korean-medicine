# 辨不可下病衇証篇

衇濡而弱，弱反在關，濡反在巔，微反在上，澀反在下。微則陽氣不足，澀則無血；陽氣反微，中風汗出，而反躁煩；澀則無血，厥而且寒。陽微則不可下，下之則心下痞硬。

【注】此即前不可發汗之條。所謂關衇浮濡沉弱，寸衇微，尺衇澀，陽虚血少之診也。汗既不可，下亦不可，均為陽虚故也，若誤下之，則寒虚內竭，心下痞硬，必成太隂誤下下利之痞硬矣。

【集注】程應旄曰：誤汗亡陽分之陽，誤下亡隂分之陽，無陽則隂獨，而地氣得以上居，故心下痞硬。

衇濡而弱，弱反在關，濡反在巔，弦反在上，微反在下。弦為陽運，微為隂寒，上實下虚；意欲得温，微弦為虚，虚者不可下也。

【注】此亦前不可發汗之條。所謂關衇浮濡沉弱，寸衇弦，尺衇微，上實下虚之診也。微弦為虚，既不可汗，亦不可下，下虚故也。

【集注】成無己曰：虚家下之，是為重虚。

衇濡而弱，弱反在關，濡反在巔，浮反在上，數反在下。浮為陽虚，數為無血；浮為虚，數生熱；浮為虚，自汗出而惡寒；數為痛，振而寒栗；微弱在關，胸下為急，喘汗而不得呼吸，呼吸之中，痛在於脅。振寒相搏，形如瘧狀，醫反下之，故令衇數發熱，狂走見鬼，心下為痞，小便淋漓，少腹甚硬，小便則尿血也。

【注】此謂關衇浮濡沉弱，寸衇浮，尺衇數也。關濡弱為中氣虚乏，寸浮無力為陽虚，尺數無力為血虚。

陽虚故汗自出而惡寒，血虚故身痛振寒而栗，中氣虚乏故胸膈氣急，喘汗而不得呼吸，呼吸之中痛引於脅也。

振寒相搏，形如瘧狀，裡邪不實，表邪未解，醫反下之，虚陽未罷之表盡陷於裡，故令衇虚數無倫，發熱狂走見鬼，心下為痞，少腹甚硬，小便淋漓、尿血也。

【集注】張璐曰：寸口浮濡而關弱尺數者，以其人陽氣夲虚，虚陽陷於隂分也，若誤下傷血，必致狂走、痞滿、尿血也。

魏荔彤曰：前虚寒之忌下易知，此虚而兼熱之忌下難知，故兩條相映互言，以示禁也。

衇濡而緊，濡則衛氣微，緊則營中寒；陽微衛中風，發熱而惡寒；營緊衛氣冷，微嘔心內煩。醫為有大熱，解肌而發汗，亡陽虚煩躁，心下苦痞堅，表裡俱虚竭，卒起而頭眩，客熱在皮膚，悵怏不得眠。不知胃氣冷，緊寒在關元，技巧無所施，汲水灌其身，客熱因時罷，栗栗而振寒；重被而覆之，汗出而冒巔，體惕而又振；小便為微難，寒氣因水發，清谷不容間，嘔變反腸出，顛倒不得安，手足為微逆，身冷而內煩。遲欲從後救，安可複追還﹗

【注】衇濡而緊，謂浮濡而沉緊也。濡則衛表微，緊則營裡寒，外有發熱汗出惡寒之表，內有微嘔心煩之裡。醫為有熱，解肌發汗，表陽愈虚，而生煩躁，裡寒更急，心下痞硬，表虚裡冷，故卒起頭眩，悵怏不眠。若徒以客熱在膚，不知中寒在裡，而以冷水灌身，雖客熱因而時罷，但栗栗振寒，不容不重被而覆之，汗出必眩，惕振厥逆，下利清谷，煩躁不安而死，以中外之陽兩亡，不能複還也。

【集注】張錫駒曰：汗出而冒巔者，汗出則陽氣外亡，頭昏冒而目不明，故曰冒巔。小便為微難，陽亡而氣不施化也。清谷不容間，不利清谷無間隙之時也。嘔變者，嘔出之味變也。腸出者，下利而廣腸脫出也。

衇浮而大，浮為氣實，大為血虚；血虚為無隂，孤陽獨下隂部者，小便當赤而難，胞中當虚，今反小便利而大汗出，法應衛家當微，今反更實，津液四射；營竭血盡，干煩而不得眠，血薄肉消，而成暴液。醫複以毒藥攻其胃，此為重虚。客陽去有期，必下如污泥而死。

【注】衇浮而大，謂衇浮取有力，按之大而無力，乃革衇象也。浮為氣實外急，大為血虚中空，血虚甚則亡隂，隂亡則陽無偶也，故曰：孤陽獨下隂部。謂衛陽下就其隂，小便當赤而難，以胞中虚竭也。若陽不下就其隂，則小便反利而大汗出，是衛陽表虚，邪陽內入，無隂以化，故反更實，致津液四射，營竭血盡，肉消胃干，煩不得眠也。醫不知此，乃以中空暴液之陽明，誤為胃實，複以峻藥攻之，則為虚虚，胃陽之去可期，必下污穢如泥而死也。

【集注】程知曰：此言氣實血虚之衇，小便利而大汗出者，不可下也。

程應旄曰：無隂而孤陽獨下隂部，倘得小便赤而難，則胞中不虚，僅為陽摶。陽未離，則隂得滯而未散，今反小便利而大汗出，則衛氣更微矣。其反更實者，非衛陽之實，而客陽之實也。衛陽猶或抱隂，客陽則專於攻隂，故津液四射，而為小便利，為大汗出。熱甚逼隂，所以營竭血盡，干煩而不得眠，血薄肉消而成暴液。

暴液雲者，點滴皆火氣煎熬而出也。毒藥攻胃，則土敗而四臟無生，下如污泥而死矣。

傷寒，衇隂陽俱緊，惡寒發熱，則衇欲厥；厥者，衇初來大，漸漸小，更來漸大，是其候也。如此者，惡寒甚者，翕翕汗出，喉中痛；若熱多者，目赤衇多，睛不慧。醫複發之，咽中則傷；若複下之，則兩目閉，寒多便清谷，熱多便膿血；若熏之，則身發黃；若熨之，則咽燥。若小便利者，可救之；若小便難者，為危殆。

【注】傷寒，衇隂陽俱緊，惡寒發熱，太陽表証也。則衇欲厥，謂浮緊之衇，初大漸小，知為欲厥之衇也。

初來大，陽為之也，故發熱；漸漸小，隂為之也，故發厥。更大更熱，更小更厥，是其候也。如此者，當以寒熱別其厥。惡寒甚，翕翕汗出，咽中痛，是少隂寒厥也；發熱多，目赤衇多，睛不了了，是陽明熱厥也。寒甚熱多之厥，而誤發之，則咽痛似傷；而誤下之，則兩目多閉。凡厥者必下利，寒厥之利，下利清谷也；熱厥之利，下利膿血也。此又以利辨厥之寒熱也。若以熏蒸取汗，則發身黃，濕熱合也。若以火熨取汗，則咽燥，火甚傷津也。若小便利者，則隂未亡，故可救之；小便難者，則隂已亡，為危殆也。

【集注】程知曰：言外傷於寒，為濕熱之病，不可汗、下、熏、熨也。

張璐曰：衇來厥者，知厥逆之寒熱交勝也。初來大者，為邪氣鼓動；漸漸小，為正氣受傷；更來漸漸大，為邪氣複進也。蓋因其人正氣夲虚，不能主持，隨邪氣進退，故其衇亦隨邪氣進退，忽大忽小也。小便利者，津液未竭；小便難者，津液已絕，為危殆也。

傷寒發熱，口中勃勃氣出，頭痛目黃，衄不可制，貪水者必嘔，惡水者厥。若下之，咽中生瘡，假令手足温者，必下重便膿血。頭痛目黃者，若下之，則目閉。貪水者，若下之，其衇必厥，其聲嚶，咽喉塞；若發汗，則戰栗，隂陽俱虚。惡水者，若下之，則裡冷不嗜食，大便完谷出；若發汗，則口中傷，舌上白苔，煩躁，衇數實，不大便六七日，後必便血；若發汗，則小便自利也。

【注】傷寒發熱，口中勃勃氣盛而出，頭痛目黃，將欲作衄，衄不可制，以陽邪盛，故衄之甚也。貪水者，水與熱搏，故嘔也；惡水者，裡隂寒盛，故厥也。傷寒發熱，口中出氣盛者，若下之，熱邪入淺，咽中生瘡；入深，下重膿血。頭痛目黃者，若下之，則兩目閉，液傷干澀也。貪水者，若下之，熱去水停，故肢厥聲嚶，咽喉塞也；若發汗過多亡陽，故戰栗，表裡俱虚也。惡水者，若下之，裡寒更甚，故不嗜食，下利完谷也；若發汗動其虚陽，故口中瘡，舌上白苔煩躁也。若衇數有力，不大便而惡水，熱在於隂，故六七日後必便血也。

若更發其汗，隂陽俱虚，故小便自利也。

【集注】程知曰：傷寒發熱，熱在表也；口中勃勃氣出，熱在裡也。頭痛目黃，衄不可制，所感之寒與所郁之熱，共蒸於上也。此當以貪水惡水辨之；貪水者，隂虚而熱勝，水入而熱與之拒，故嘔也；惡水者，陽虚而寒勝，水入而陽氣不任，故厥也。蓋熱氣挾寒邪上蒸，法當辨寒熱多寡而用清解，設不知而妄下之，是强抑之而邪不服，必至咽瘡，若手足温而不厥者，其熱為勝，必以下而致便膿血也。頭痛目黃者，下之則熱內陷而目閉，若貪水者，隂虚為寒下所抑，其衇必厥，其聲必如嚶兒　塞不揚也。此而更發其汗，則亡陽戰栗，陽亦與隂俱虚矣。若惡水者，陽虚，加之寒下，則有裡冷不嗜食，大便完谷出之變也。此而更發其汗，則虚陽外發，必口爛、舌白苔而煩躁也。衇數實不大便者，至六七日後當便血，此當下之，若更發其汗，則非惟大便不行，並小便亦為之不利矣。

微則為咳，咳則吐涎，下之則咳止，而利因不休；利不休，則胸中如虫嚙，粥入則出，小便不利，兩脅拘急，喘息為難，頸背相引，臂則不仁，極寒反汗出，身冷若冰，眼睛不慧，語言不休。而谷氣多入，此為除中。

口雖欲言，舌不得前。

【注】陽盛為痰，陽虚為飲，咳而衇微為陽虚之咳，故咳則吐涎飲也。若衇實，下之可也，今衇微，下之寒虚更甚，故咳雖止，而利因不休也。胸中如虫嚙，是胃寒虫動，故粥入則出也。下利上吐，中寒也；小便不利，停飲也；兩脅拘急，喘息為難，頸背相引，臂則不仁，此皆中外寒飲之証。比之少隂停飲，此無身痛，彼無項背相引，臂則不仁也。若極寒而甚，則反汗出，身冷如冰，目睛不慧，語言不休而死也。以如是之証，而谷氣多入，此為除中。口雖欲言，舌短難伸，亦死也。

【集注】張璐曰：誤下之下利不止，胃中空虚，而反暴食，為除中。少隂虚寒而反冷汗，為外脫，及口雖欲言，舌萎不能前等死証皆起。誤下之害如是。

衇數者，久數不止，止則邪結，正氣不能複，正氣却結於臟，故邪氣浮之，與皮毛相得。衇數者，不可下，下之必煩，利不止。

【注】衇數者，謂久數不止，有熱之人也。若衇數動時一止，熱仍不退，是邪氣結，正氣不能複，正氣結於臟，邪氣浮於外故也。衇雖數促，不可下也，若誤下之，則邪熱乘虚入裡，必煩利不止也。

衇浮大，應發汗，醫反下之，此為大逆。

【注】衇浮大，此為表實之衇，應發其汗，若醫誤以大為裡實而反下之，此為大逆也。

【集注】程應旄曰：衇大與衇浮而大，差別盛實，純在表也，雖有裡証，仍宜從表發汗，下之則為大逆。

動氣在右，不可下；下之則津液內竭，咽燥鼻干，頭眩心悸也。動氣在左，不可下；下之則腹內拘急，食不下，動氣更劇，雖有身熱，臥則欲蜷。動氣在上，不可下；下之則掌握熱煩，身上浮冷，熱汗自泄，欲得水自灌。動氣在下，不可下；下之則腹脹滿，卒起頭眩，食則下清谷，心下痞也。

【注】動氣在右，肺失治矣。下之則肺先虚，津液內竭，故咽燥鼻干，頭眩心悸也。動氣在左，肝失治矣。

下之則肝氣益急，故食不下，腹內拘急，動氣更劇，表實未減，裡虚益甚，故雖有身熱，臥則欲蜷也。動氣在上，心失治矣。下之則隂液益傷，心火更甚，故掌心握熱，煩熱汗出，欲得水澆，即有身上浮冷，亦火盛格隂使然也。動氣在下，腎失治矣。下之則寒虚內甚，而腹脹滿，故卒起頭眩，心下痞滿，食則下利清谷也。

【集注】程應旄曰：動氣誤下，是為犯臟，左右上下，隨其經氣而致逆，故禁同汗例。

咽中閉塞，不可下；下之則上輕下重，水漿不下，臥則欲蜷，身急痛，下利日數十行。

【注】咽中閉寒，燥干腫痛者，少隂陽邪也，宜下之。今不燥干，不腫痛者，少隂隂邪也，不可下，下之則陽愈衰，隂愈盛，故曰上輕下重也。水漿不入，臥欲蜷，身急痛，下利日數十行，中外陽虚也。

【集注】張璐曰：言初病咽乾閉塞，以其人少隂之真陽素虧，故汗下俱禁，若下之，則少隂虚寒，諸証蜂起矣。

程應旄曰：腎邪上逆，故有咽中閉塞之証，下之陽氣益虚，隂氣益甚，故有上輕下重等証。

諸外實者，不可下；下之則發微熱。亡衇厥者，當臍握熱。

【注】諸外實者，裡必虚，即有不大便，無所苦之裡，亦不可下。若下之，外發之熱雖微，內虚之寒則盛，若無衇而厥，當臍握熱始暖，亦寒之甚也。

【集注】方有執曰：諸外實，指一切之邪在表而言也。發微熱，邪入裡也。無衇，陽內陷也。

程知曰：下之則表邪內陷，外不熱而內發微熱也。其亡衇而厥者，則寒氣內深，惟當臍一握熱耳。

太陽病，有外証未解，不可下，下之為逆。

【注】此重出，以申叮嚀告戒之意。

【集注】程應旄曰：未解較不解稍異，勢雖欲下，仍須俟之。

病欲吐者，不可下。嘔多雖有陽明証，不可攻之。

【注】欲吐者，邪在膈上，可吐之証也。嘔多者，邪在少陽，可和之証也。雖具裡証，戒人不可先攻下也。

夫病陽多者熱，下之則硬。

【注】陽病裡熱多者，宜乎下；表熱多者，宜乎汗。若表裡熱多，當兩解也。若單下之，表不解則裡虚，表熱內陷，因作硬也。

【集注】張璐曰：陽熱証多，即有陽明証見，亦属經証，不可下也。不當下而誤下之，則陽邪乘虚內陷，不作結胸，則為痞硬也。

程應旄曰：陽病，謂表裡熱俱多，下之則胃中水竭。其硬也，非轉属陽明之硬也。

無陽隂强大便硬者，下之，必清谷腹滿。

【注】亡陽隂盛，燥而無熱，雖大便硬者，此乃不大便無所苦之硬也，下之則中寒猶盛，故必利清谷腹滿矣。

【集注】成無己曰：無陽者，亡津液也。隂多者，寒多也。大便硬，則為隂結。下之虚胃，隂寒內甚，故清谷腹滿。

方有執曰：隂，以寒言。强，猶言多也。清谷，隂不能化也。腹滿隂寒，凝滯而內脹也。

傷寒，發熱頭痛，微汗出，發汗則不識人；熏之則喘，不得小便，心腹滿；下之則短氣，小便難，頭痛背强；加温鍼則衄。

【注】傷寒發熱，頭痛背强，微汗出，若不惡寒，非温病即邪傳陽明也。若誤發汗，不成風温，外熱如灼，必成陽明，熱甚神昏不識人也。以火熏、温鍼劫之，火氣入裡，壅塞於胸則喘，於腹則滿也。火傷衛分津液，則不得小便，火傷營分血衇，則必作衄也。若下之，則中氣傷，故氣短；津液傷，故小便難也。

【集注】程應旄曰：此証近於温，有熱無寒，汗下温鍼，均在所禁也。

下利衇大者，虚也，以强下之故也。設衇浮革，因爾腸鳴者，属當歸四逆湯。

【注】下利衇大，裡虚也，以其不當下而强下之故也。設衇浮革者，謂衇浮大，按之空虚，表急裡虚，因爾腸鳴，属當歸四逆湯，和其表而温其裡也。

【集注】成無己曰：浮為虚，革為寒，寒虚相搏，則腸鳴，與當歸四逆湯。
