# 辨瘥後勞複食複隂陽易病衇証並治篇

> 원본 파일: `P/P0001.txt`

傷寒新愈，起居作勞，因而複病，謂之勞複。强食谷食，因而複病，謂之食複。男女交接，複而自病，謂之房勞複。男女交接，相易為病，謂之隂陽易，謂男傳不病之女，女傳不病之男，有如交易也。蓋因其人新差，余邪伏於臟腑，未經悉解，故犯之輙複也。學人於臨証時，審其衇証而詳辨之，則施治自無誤矣。

大病瘥後，勞複者，枳實梔子豉湯主之。若有宿食者，加大黃，如博棋子五六枚。

【注】大病瘥後，謂傷寒病新瘥後也。勞複者，謂起居作勞複病，非房勞複也，宜枳實梔子豉湯主之。温覆，令微似汗自愈，不取其涌者，以熱不在胸而在經也。若因過食複病者，謂之食複，以有宿食也，宜枳實桅子豉東加大黃下之。

【集注】成無己曰：勞複則熱氣浮越，與枳實梔子豉湯以解之。食複則胃有宿積，加大黃以下之。

王肯堂曰：傷寒之邪自外入，勞複之邪自內發。

<ins>枳實梔子豉湯方</ins>

枳實（炙，三枚）　梔子（擘，十四枚）　豉（綿裹，一升）

上三味，以清漿水七升，空煮取四升，納枳實、梔子，煮取二升，下豉更煮五六沸，去滓，温分再服，覆令微似汗。

【方解】是方也，用清漿水七升，空煮至四升者，是欲水之熟而趨下，不欲上涌作吐也。下豉煮五六沸即去滓者，取其清腐之氣走表，易於取汗也。太陽用之以作吐，勞複用之以作汗。仲景用方之妙，藥品雖同，煎法各異，故施用不同也，於此可類推矣。

【集解】方有執曰：大邪初退，血氣新虚，起居作勞，複生余熱，乃用苦寒以發其微汗者，以勞傷之複熱，與初病之實熱不同倫也。方中用清漿水七升，空煮至四升，全是欲水之熟而趨下，不至上涌作吐，與太陽中篇下後身熱取吐之法不同，所以覆令微似汗也。

傷寒瘥已，後更發熱，小柴胡湯主之。衇浮者，以汗解之，衇沉實者，以下解之。

【注】此承上條詳言証衇，以別其治也。傷寒瘥已，後更複發熱者，雖有勞複、食複之別，然須分或宜和、或宜汗、或宜下之不同。如衇浮有表，當以汗解者，用枳實梔子豉湯汗之；衇沉有裡者，當以下解者，用枳實梔子豉加大黃湯下之；若無表裡証，當和解之者，用小柴胡湯和之。對証施治，斯為合法。

【集注】方有執曰：此示病後不謹調理，致複之大法。衇浮，有所重感者也。衇沉，飲食失節也。

魏荔彤曰：大病後不宜大汗，喻注謂用枳實梔豉湯以微汗是也。大病後不宜大下，喻注謂枳實梔豉東加大黃以微下是也。然亦有不能盡該者，凡於汗下之中，留心其為大病之後，庶治複病，而不礙於大病後也。

大病瘥後，從腰以下有水氣者，牡蠣澤瀉散主之。

【注】傷寒病瘥後，從腰以下腫者，是有水氣也，宜牡蠣澤瀉散，峻逐水氣，恐緩則水盛，必上犯陽部也。

【集注】成無己曰：大病瘥後，脾胃氣虚，不能制約腎水，水溢下焦，故腰以下為腫也。《金匱要略》云：腰以下腫，當利小便，與牡蠣澤瀉散，利小便而散水可也。

<ins>牡蠣澤瀉散方</ins>

牡蠣（熬）　澤瀉　栝蔞根　蜀漆（暖水洗去腥）　商陸根（熬）　海藻（洗去咸）　苦葶藶（熬，各等分）

上七味，異搗下篩為散，更入臼中治之。白飲和服方寸匕，日三服。小便利，止後服。

【方解】水停於內，外泛作腫，腰以上者，當汗之，小青龍、越婢是也；腰以下者，當利小便，此方是也。以牡蠣破水之堅，澤瀉利水之蓄，海藻散水之泛，栝蔞根消水之腫，又以蜀漆、苦葶藶、商陸根辛苦有毒之品，直搗其巢，峻逐水氣，使從大、小二便而出。然此方施之於形氣實者，其腫可隨愈也，若病後土虚，不能制水，腎虚不能行水，則又當別論，慎不可服也。

大病瘥後，喜唾，久不了了，胸上有寒，當以丸藥温之，宜理中丸。

【注】大病瘥後，喜唾，久不了了者，胃中虚寒，不能運化津液，聚而成唾，故唾日久無已時也，宜理中丸以温補其胃，自可已也。

【集注】程知曰：病後陽氣不足，胃中虚寒，不內津液，故喜唾不了了。前牡蠣澤瀉用散者，欲其戀肺而下水也；此理中用丸者，欲其温胃而收唾也。

喻昌曰：身中津液，因胃寒凝結而成濁唾，久而不清，其人必消瘦索澤，故不用湯藥蕩滌，而用丸藥緩圖也。

張璐曰：傷寒瘥後體虚，每有遺熱，故禁温補，即間有素稟虚寒者，只宜理中丸調理，未嘗輕用桂、附也。

傷寒解後，虚羸少氣，氣逆欲吐，竹葉石膏湯主之。

【注】傷寒解後虚羸，寒傷形也；少氣，熱傷氣也；氣逆欲吐，余邪挾飲犯胃也。故宜竹葉石膏湯，益虚清熱，以降逆氣也。

【集注】方有執曰：病後虚羸少氣，脾胃未强，飲食難化，則痰飲易生，飲停氣逆，故欲吐也。

程知曰：傷寒解後，津液不足，則虚羸；余熱不盡，則傷氣。與竹葉石膏湯，以調胃而去虚熱。蓋前條是治病後虚寒，此條是治病後虚熱也。

<ins>竹葉石膏湯方</ins>

竹葉（二把）　石膏（一斤）　半夏（洗，半升）　人參（二兩）　甘草（炙，二兩）　粳米（半升）

麥冬（去心，一升）

上七味，以水一斗，煮取六升，去滓，納粳米，煮米熟湯成，去米，温服一升，日三服。

【方解】是方也，即白虎湯去知母，加人參、麥冬、半夏、竹葉也。以大寒之劑，易為清補之方，此仲景白虎變方也。經曰：形不足者，温之以氣；精不足者，補之以味。故用人參、粳米，補形氣也。佐竹葉、石膏，清胃熱也。加麥冬生津；半夏降逆，更逐痰飲；甘草補中，且以調和諸藥也。

病患衇已解，而日暮微煩，以病新瘥，人强與谷，脾胃氣尚弱，不能消谷，故令微煩，損谷則愈。

【注】病患衇已解，謂病衇悉解也。惟日西微煩者，以病新瘥，强食谷早，胃氣尚弱，不能消谷，故令微煩，不須藥也，損谷自愈。

【集注】方有執曰：强與谷，謂强其進食也。損者，言當節減之也。

喻昌曰：注家牽引日暮為陽明之旺時，故以損谷為當小下。不知此論瘥後之証，非論六經轉陽明之証也。

日暮，即《內經》日西而陽氣已衰之意，所以不能消谷也。不可引前條宿食，輕用大黃，重傷脾胃也。

王鶴田曰：此言瘥後强食，而為虚中之實証也。病後起居坐臥，俱宜聼其自然，不可勉强，强則非其所欲，反逆其性而不安矣，不特一食也。

傷寒，隂陽易之為病，其人身體重，少氣，少腹裡急，或引隂中拘攣，熱上衝胸，頭重不欲舉，眼中生花，膝脛拘急者，燒　散主之。

【注】傷寒新愈之後，男女不謹，偶犯余事，發熱複病者，謂之房勞複。男以六味地黃湯主之，女以四物湯主之，隨証加減治之可也。若犯余事，男病傳女，女病傳男，相易為病，謂之隂陽易。其証身重少氣，少腹急痛，牽引隂中，膝脛拘急，或熱氣衝胸，頭重不欲舉，眼中生花等証，皆余毒乘虚傳易也，當以燒　散主之。

【集注】王肯堂曰：房勞複病，謂新瘥之後，或尚未愈，而男婦相交接複病者，若同隂陽易証，則從隂陽易治。亦有寒熱多汗，頭重目眩，腹中拘急，百節解離，經衇緩弱，筋骨痿軟，不能動移，精髓空虚，心神恍惚，遷延歲月方死者，宜當歸四逆湯。厥者加附子，寒者加吳茱萸、生薑，以治之。按：瘥後男女交合而病者，若無隂陽易証，而有表証，則不可從隂陽易治，當從房事後犯風寒治，汗、吐、下法，皆不可輕用。即有應汗、應吐之証，汗則以補中益氣東加麻、桂微汗之，厥者加炮附子；吐則以補中益氣東加淡豆豉探吐之。適可即止，總當識此為新病之後也。

方有執曰：傷寒，包中風而言也。易，猶交易變易之易，言大病新瘥，血氣未複，强合隂陽，則二氣交感，互相換易而為病也。身體重少氣，真元虧竭而困倦也。少腹裡急，或引隂中拘攣者，所易之氣內攻也。熱上衝胸，頭不欲舉，眼中生花者，虚陽生熱而上蒸也。膝脛拘急者，衇亂而筋傷也，　襠近隂處，隂陽二氣之氣聚也。男女易用，物各歸夲也。

喻昌曰：病傷寒之人，熱毒藏於氣血中者，漸從表裡解散，惟熱毒藏於骨髓之中者，無曲發泄。故差後與不病之體交接，男病傳不病之女，女病傳不病之男，所以名為隂陽易，即交易之義也。

<ins>燒　散方</ins>

婦人中　近隱處，取燒作灰。

上一味，水服方寸匕，日三服，小便即利，隂頭微腫，此為愈矣。婦人病，取男子　燒服。

【方解】男女　襠，濁敗之物也。燒灰用者，取其通散，亦同氣相求之義耳。服後或汗出，或小便利則愈。

隂頭微腫者，是所易之毒從隂竅而出，故腫也。
