# 治病

<!-- source-id: O074:p017 -->

> 원본 파일: `O/O074.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

凡人有病，需治在醫，醫者，人之司命也。既司人命，必知人身有形之經，又當知人身無形之氣；辨有形之有餘不足，察無形之離合逆從。有形者，臟腑經絡之定位；無形者，陰陽運氣之轉輸。臟腑經脈有病，而陰陽運氣，轉旋輸布不失其常，雖病可愈；若有形既病，而無形亦逆，便不治矣。蓋醫不能生人也，不殺人，便為良醫矣。所痛惜者，有形無形，全不之知，離合逆從，並未曾曉，見病即治，知其外，不知其內，究其末，不究其原，妄曰醫者意也，以妄為意，以妄為醫，是居盲瞶而云察秋毫也，豈其然哉！
