# 用藥禁忌

竊古有少陰甘桔湯治咽痛又仲景少陰病下利咽痛心煩者豬膚湯少陰病二三日咽痛者可與甘草湯不差者與桔梗湯少陰病咽中傷生瘡不能語言聲不出者苦酒湯少陰病咽中痛半夏散及湯主之數方皆清利咽喉之要藥今人見有喉症不審其源即用之而無疑嗟乎此猶抱薪救火也非能愈其疾而且更加其病何以言之夫今時咽喉之症皆寒火不均或受天時不正之氣風火之毒上攻須以去風瀉火為要甘草補中而不瀉火中宮既受其補則火愈熾於病亦重桔梗能引諸藥上行藥既上行其痰火與氣亦引之而上行則喉間壅塞於病更重故小兒驚痰大人風痰痰火桔梗所以忌也本草云升麻可代犀角引胃氣上升似乎可用不知氣一上行必挾痰火以俱上涌塞於咽喉間四肢厥冷喘急異常為害非淺若在他症猶或可用鎖喉風服之則必不救故猶當切忌之也半夏雖消痰之妙藥若咽喉症痰重者誤用之則傷生命蓋半夏能消脾胃之寒痰非能消肺中之熱痰故也生薑辛辣發散然喉症亦不以發散為主用之則以火益火亦不宜用此數味關系喉症甚重不可不明言而謹戒之至他藥中亦有禁忌者是在臨時時留意焉可也
