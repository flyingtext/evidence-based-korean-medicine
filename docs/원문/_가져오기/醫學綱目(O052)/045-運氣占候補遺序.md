# 運氣占候補遺序

夫五運六氣，上古聖人所以參三才而贊化育者也。故位天者天文也，位地者地理也，通乎人氣之變化者人事也。然天道有陰陽多少之殊，地理有高下，氣至有先後之異，人之壽夭生化之期，則損益盛虛之變也，此其上下參錯，而不可以定數求者焉。若夫五六之會，終期之日，刻漏而分數之，亦陳其梗概焉耳。至於氣至之先後，勝復之郁發，安可預擬乎﹗故曰：數之可數者，人中之陰陽也，天地之陰陽，不可以數推，以象見者也。

夫象者，占候之所始，道之所生，不可不通也。今夫天垂象，地成形，七曜緯虛，五行麗地。地者所以載生成之形類也，虛者所以列應天之精氣也。形精之動猶根本之與枝葉也，故形盛則精盛，形衰則精衰，五星明，大減小，即五運之太過不及可得而占也。今夫地道實，天道虛。實者氣之所寓，虛者色之所因也。五氣應於下，則五色彰於上，五天之經緯成，而後五氣之至，可得而占也。地為人之下，太虛之中，大氣舉之也。燥以干之，暑以蒸之，風以動之，濕以潤之，寒以堅之，火以溫之。故風寒在下，燥熱在上，濕氣在中，火游行其間，寒暑六入，故令虛而化生也。故煙埃云物之態，山川草木之容，皆可得而占焉。至於地理有高下，陰陽有多少。

至高之地，陰氣常在；至卑之地，陽氣常在，則高下異占也。又春氣始於東，夏氣始於南，秋氣始於西，冬氣始於北，行有逆順，至有遲速，則上下左右異占也。是皆形精之必效微而顯，信而不爽者歟。是故古之至人，仰以觀於天文，俯以察乎地理，中以通乎人事、然後所以定神明之紀而成變化之用也。世之學人，求陰陽於支干配合之間，論勝負於主客加臨之位，不效則以為古書不足信也，是豈書之罪也哉﹗間因讎校樓氏《醫學綱目》書，覽其後有運氣補注一篇，惜其用意甚勤，而尚遺古人占候之法，是以取諸《內經》之旨，列占候十五篇，命曰《運氣占候補遺》以續樓氏之後云。
