# 凡例

<!-- source-id: L112:p003 -->

─　是書原稿，本無凡例，茲特增入評注圈點，故列凡例。

─　是書雖為喉科而設，實於溫病傷寒，均有關系，能於此書貫通悟徹，不惟可治喉症，一切外瘍虛實標本之意，均可悟出。

─　是書凡著眼處，必加圈點，以使閱者醒目，間有竊附鄙意及治案，必加（諤按）二字，以醒眉目。

─　是書共分兩卷，其體例悉遵其舊，篇末另附治喉秘方，皆系諤搜羅諸家之精萃，並深心研究而得，幸無以淺近而忽之。

<ins>甲寅年原歷八月海虞張諤附識</ins>
