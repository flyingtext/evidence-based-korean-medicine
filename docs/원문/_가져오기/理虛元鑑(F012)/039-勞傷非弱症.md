# 勞傷非弱症

<!-- source-id: F012:p039 -->
> 서명: 理虛元鑑
> 원본 파일: `F/F012.txt`
> 원본 SHA-256: `94fa4cef83e5b968de1980665d9d8729a4120e3bd6e8a269f40fc475dd1f132b`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

有平時心腎不虧，並無弱症，偶有房勞，猝然嘔血者，其血從胃中來，不得以怯症論治。宜以分理安胃為主，不必用黃芩、花粉、元參等藥之涼，亦不必用黃耆、白朮、山藥之補，只須柴胡、貝母、桔梗、澤瀉、丹皮、白芍、麥冬之類治之。更有勞傷筋力而得者，只宜調其胃氣而自愈。
