# 看眼法

夫天地之五行，配人身之五臟，身之五臟，合目之五經也。如兩　屬心，心屬火，其色紅也。黑珠屬肝，肝屬木，其色青也。兩瞼屬脾，脾屬土，其色黃也。白珠屬肺，肺屬金，其色白也。瞳仁屬腎，腎屬水，其色黑也。

察其五色，觀其五臟，五經配於五臟者也。察乎五行，推其生克，審其所感所因，用藥醫治，無有不愈。但人之所稟有濃薄，病之所感有重輕。風寒暑濕，喜怒哀樂，無非有所因而發也。今以大概觀之，因氣感者，當蒙昧而色濁；因血而感者，多羞澀而色淡。飲酒發者，色必盛而連珠帶赤；好色而發者，紅必鮮而睛光恍惚。痛極者熱而帶虛，癢極者熱而加風。如有兩感，必至重犯。此皆初發之疾，大略如此。至於時作時止，日積月累。遷延歲月，或成紅障、白膜、雀目、青盲、痔蠹、　肉、漏突、頂睛、物傷、跌撲、痘疔、癤潰，千態萬狀，不能枚舉。

但是睛珠無損，瞳仁不失，不過障翳侵掩，皆為可治之症。至於珠塌、睛懸、淚枯、瞳涸、旋螺紋點，黑白混雜，此皆破壞之疾，不治之證也。有障翳賊翳，對視不見，必須斜眇。有干睛縮睛，目力難辨，必須借日。翳有堅浮濃薄，不過遲速，皆可去也。色有紅藍紫綠，不過傳變，皆是火也。拳毛倒睫，肺與脾而相搏，風熱有餘，瞼皮寬解，痰與氣而相搏，寒濕尤多。轉睛斗睛，無非風熱彌深。遠視近視，當分陰陽偏勝，此皆目前所見，有所異常者，不能細述。參其一定之規，用我活變之法，盡望聞問切之心，必得神聖工巧之驗也。
