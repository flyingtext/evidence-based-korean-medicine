# 制藥法

砂、丹、蘆，不制有毒，螵蛸、磁石，不制難研，務須研細。揀擇停當，或火煉，或水飛，或投入藥汁者，必煉　令蘇入汁，候干再入。如火煉者，必用瓦放藥在上，以炭火罩漏旺扇者，火候不可太過，不可不及。如水飛者，必須研細，放入水中，攪沉數次，將上浮起者，另傾別器，澄出清水，晒乾再研。其余草藥，不過煮浸淨洗而已。
