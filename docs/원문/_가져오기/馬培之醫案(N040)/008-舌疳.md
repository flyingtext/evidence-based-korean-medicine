# 舌疳

<!-- source-id: N040:p008 -->

腎陰不足，心火肝陽上亢，發為舌瘡。舌根破碎成窟，不時內熱，舌為心苗，腎脈貫肝膈，循喉嚨，挾舌本，腎陰不升，心火不降，未濟之象也。恐釀成舌疳大患，法當滋水制陽為治。

生地　石斛　元參　麥冬　女貞子　象貝母　甘草　桔梗　丹皮　玉露霜　甘蔗心脾火郁致發舌疳，舌根腫潰，連及咽喉，症非輕候。宜養陰清解。

細生地　丹皮　大貝　連翹　元參　生蒲黃　蛤粉　麥冬　甘草　桔梗　黃柏　竹茹舌糜於左，心火上盛，腎水不足，謹防舌疳之患。

西洋參　麥冬　甘草　青果　六味丸
