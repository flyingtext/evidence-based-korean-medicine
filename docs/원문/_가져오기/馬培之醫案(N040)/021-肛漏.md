# 肛漏

肛漏一年，陰氣耗泄於下，陽傷於上，冬春咳嗽惡寒，肝氣拂郁，肚腹作痛。入夏以來嗆咳益加，咽痛妨食，痰多作惡，腹痛頻頻，大便時溏，脈來尺寸弱而急，肺腎並虧，肝木侮土，勢入損門，殊屬重候。擬養榮柔肝，兼補肺滋腎。

東洋參　白芍　當歸　炙甘草　冬蟲草　淮山藥　蓮子　沙苑子　甜杏仁　大生地（蛤粉炒）　橘紅　大麥冬肛有漏卮，陰氣先虧於下，子病及母，致生喘咳，宜金水並調。
