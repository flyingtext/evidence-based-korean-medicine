# 盤槽癰

盤槽癰月余，自左及右間潰流膿，腮外堅腫，硬勢又將破潰，發熱便閉，食少噦惡，脈細神疲，陰傷胃熱不化，症屬不輕，擬以甘寒清解。

鮮石斛　貝母　銀花　桔梗　丹皮　使君子　元參　甘草　連翹　天花粉　橘紅　茯苓　枳殼　蘆根盤槽癰腮外腫，勢難消，究須外潰，精神雖起，而熱渴噦惡未減，飲食未增，陰分大虧。

症非輕候，姑擬養陰清胃。
