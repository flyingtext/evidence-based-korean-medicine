# 產後腸癰

<!-- source-id: N065:p044 -->
> 서명: 洄溪醫案
> 원본 파일: `N/N065.txt`
> 원본 SHA-256: `8da42f48ee7b4ba44d559b75a053e092596c8be3a0a81804149c89d03ee6d4f0`
> 상태: 자동 변환 원문·정본 미대조

洞庭某婦，產後小腹痛甚，惡露不止，奄奄垂斃。余診之，曰：惡露如此多，何以其痛反劇？更詢其所行之物，又如膿象。余曰：此乃子宮受傷，腐爛成癰也。宜令名手穩婆探之，果然。遂用綿作條，裹入生肌收口之藥，而內服解毒消瘀之方，應手而愈。凡產後停瘀，每多外證，如此甚多，不可不知也。
