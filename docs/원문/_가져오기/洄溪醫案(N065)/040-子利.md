# 子利

爛溪潘開於表弟，其夫人懷娠患痢，晝夜百余次，延余視。余以黃芩湯加減，兼養胎藥飲之，利遂減，飲食得進，而每日尚數十次，服藥無效。余曰：此不必治，名曰子利，非產後則不愈，但既產，恐有變證耳。病家不信，更延他醫，易一方，則利必增劇。始守余言，止服安胎藥少許，後生產果甚易，而母氣大衰，虛象百出。適余從浙中來，便道過其門，復以產後法消息治之，病痊而利亦止。蓋病有不必治而自愈，強求其愈，必反致害，此類甚多，不可不知也。 雄按：此所謂利，即是泄瀉。古人名曰利下，非今之痢也。痢疾古名滯下，若胎前久痢不愈，產後其能免乎？
