# 風痰致咳

<!-- source-id: N079:p054 -->

> 상태: 자동 변환 원문·정본 미대조

咳嗽一症，風寒暑熱，飲食鬱滯，思慮勞倦，皆能致之。醫宗必讀闡內經之旨，講此症最為詳盡，學者當究心，若一概施治，未有不致悖謬者。

同鄉郝某號秀山，在都作銀商，自秋發嗽至十一月，數醫之尚未愈也。余僑寓襄陵館，與郝某素昧生平。一日梁某偕之來求余治，問何病？對以咳嗽四月矣。問，曾治否？對以藥以百計而嗽如故。言次探手於懷，出藥方隆然一裹。細檢之，皆參苓耆朮等類。蓋郝素弱，又富於財，俗醫皆作虛論也。乃診之，余平平，肺獨浮滑。告之曰，浮者風象，滑者痰象。君素積痰，復感於風，風痰相搏，而嗽作矣。又以參耆固其腠理，腠理不開，風無去路，嗽何時已乎。數藥可愈，郝見余言易，進曰，年少時有唾血疾，體本虛，故畏克伐藥。曉之曰，此他醫之所以用參耆也。要知少年唾血，未必虛證。即虛，而此時血止而嗽作，醫不治嗽而治血，請問君見我為冶嗽乎？為治血乎？病者笑而是之。乃以杏蘇飲加山楂，枳實進。囑曰，不過五服病必愈，無煩再來也。病者持而去，越五日，投帖請余觀優戲，晚則筵席豐隆，殷勤周至。時余方以分發赴秦，因遣其同類，隨之到秦，開設銀肆，聽昔過從稱莫逆焉。
