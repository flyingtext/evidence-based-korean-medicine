# 論綿山血見愁

<!-- source-id: N079:p067 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 자동 변환 원문·정본 미대조

綿山為吾介一巨觀，峰巒秀美，洞壑幽深，而抱腹崖、蜂房泉尤為奇絕。夏秋間遊人如織，其山產奇花異草、藥材尤多，綿黃耆、汾甘草，載在本草，傳之古今，卓然不朽。惜介人性不辨藥，甘草尚有土人掘而市之，余則無采之者矣。其高山之陰，產一藥，名「血見愁」，土人游綿者，輒攜以歸，治血症，無不奇效。余家常藏之。其枝杆類枯蒿，味色極其平淡。

余十歲後，得便血疾，更數十醫無效。有老農以此藥遺之，煎而當茶飲，不數日，血竟止。後服理脾藥廿日遂瘥。乃珍視之。

後鄰人有患吐血者，以少許服之，吐亦止。庚申秋，內人產後血暈，諸藥無效，忽憶此藥，服之遂醒。越數日，余在縣署談及此藥，適比部劉麟甫在座，請曰，親患吐血數月矣，參茸服斤許，而血不止，君盍賜一撮。乃封寄兩許，數日而愈。又縣幕錢席賓季剛先生之侄媳，產後血暈、百藥無效，季剛已為置殮具矣，余以此藥遺之亦愈。後與鄰里談及，凡得此藥治血暈，無不愈。故婦人又呼為血暈草。

余以此藥名問之藥肆，持出，則自禹州來者，形類赤首烏，絕非綿產。後遍翻本草，亦無載此藥者。因思奇才異品，護世無窮，而味不經神農之口，品不列金匱之書，遂至淹沒深山窮穀，醫林無知之者，亦此物之不幸也。噫！獨血見愁也乎哉！附志於此，以補本草之缺，有心者，幸勿忽焉。
