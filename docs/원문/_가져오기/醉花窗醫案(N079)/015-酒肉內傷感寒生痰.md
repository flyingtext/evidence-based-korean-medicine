# 酒肉內傷感寒生痰

<!-- source-id: N079:p015 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`

> 상태: 자동 변환 원문·정본 미대조

裕州刺史李蓮舫，幼與余為文字交，以辛亥孝廉由議敘得州牧，在京候選，與余同住襄陵會館，寢饋共之，每日與各相好宴樂，暮出夜歸，風寒外感，且數中煤煙毒最可畏。一日余臥中夜尚來起，其弟小園促之曰：家兄病甚，速請一視。余急披衣視之，渾身顫汗，轉側不安。問之，則胸中煩悶特甚，欲吐不吐，且心頭突突動。急提左手診之，則平平無病狀，余曰：病不在此也。易而診右，脈寸關滑而泉湧。乃曰：此酒肉內薰，風寒外搏，且晚間煤火，漸而生痰。乃以二陳湯加麥芽、山楂、神麯，並芩、連、枳實等立進之，刻許安臥，至巳刻急起如廁，洞下紅黃色穢物數次，午後胸平氣定，進粥一盂。又欲趨車外出與友人作消寒之會，余急止之曰，朝來顛倒之苦竟忘之耶。一笑而罷。

後臘月蓮舫西歸，余移與小園同榻，一日天未明，聞小呻吟甚急，起而視之，病症脈象與蓮舫無少區別。乃曰：君家昆玉，真是不愧，乃以治蓮舫之藥治之，所下與蓮舫同，其愈之速亦同。晚間其僕乘間言曰，家主兄弟之病，幸老爺一人治之，若再易一醫，必別生枝節，支曼不清矣。其言近閱歷者，乃首頷之。
