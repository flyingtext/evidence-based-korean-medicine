# 外感風熱

> 상태: 자동 변환 원문·정본 미대조

馬景波孝廉，與余為文字交，又同出龍蘭簃先生門下，故稱莫逆。乙卯謀納粟作宰，都中有女校書才色超群，馬昵之。一日余赴同鄉之飲，在前門酒市，席未半，景波遣其僕，趨車迎余曰：家主得暴疾，危在頃刻，亟請視之。余頗驚駭，乃投箸登車而去，曲折經數處，見非景波所棲止。因問其車夫，車夫揚鞭掉臂曰：老爺至則自知。到陝西巷則景波依閭已久，捐余曰：校書病甚，惟恐君不來，故托於余以速之，急請入一施湯劑。余乃知為校書病。入其室，數媼環守之。啟衾看，則校書篷首赤體，昏不識人。捫其肌，熱可烙手，面赤氣粗，顛倒煩亂．提腕診之，六脈浮數，幾乎七至。乃曰：此外感風熱也，一發可愈。乃開防風通聖散易麻黃以桂枝。景波爭曰；硝黃劫藥，校書嬌姿恐不堪。余曰：君情深如此，宜校書之傾倒，然君解憐香，我豈好碎玉耶，有病則病當之，保無恐。急遣下走貨藥，煎而進之。屬曰：三更後，當大汗，渴，勿多與飲，明早必愈，我去矣。

越日申刻，余公退將入門。景波又遣車迎余曰：校書病益甚，請再視之。余駭曰：既病甚，則藥病枘鑿（不相合）。可請別人，余不必往也。其僕曰：家主望君如歲，不去，恐小人獲戾。不得已，隨之至。則景波顰惑曰：病益甚，當奈何？見校書仍擁衾臥，蒙其面。揭之則花妝簇簇，躍然而起。繼命媼輩，皆斂衽叩頭曰：昨宵服君藥，三更如夢醒，渾身出汗，到曉，病若失。服君之奇，感君之義，特設一筵，置酒為樂。恐君不來，故託辭招之耳。余故不喜此輩，擬托公而辭。校書跪留曰：自知垢汙之肴，不足染高賢之腹。然獻芹之忱，竊難自己。言之淚欲下。景波急進曰：勾欄（妓院）中一杯水，未必即阻兩廡特豚（古代祭禮）。何惺惺作態乃爾。余不敢再辭，相與狂飲．肴錯紛陳，至夜四更始罷。歸檢衣袱則羅香囊一對．絮絹方巾二事在焉。知為校書之遺．越數日，轉景波而還之。
