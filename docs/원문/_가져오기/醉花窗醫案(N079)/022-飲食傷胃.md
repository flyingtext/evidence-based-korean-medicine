# 飲食傷胃

<!-- source-id: N079:p022 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 자동 변환 원문·정본 미대조

商人曹某，忘其名，豪於飲，而食量亦復兼人。夏月奔走發渴，多食生冷，遂致停滯，頭痛發熱，腹脹神昏。他醫以為感冒，以風藥散之，不效。乃迎余視。其右關堅大，右尺弦緩，並無浮象。乃曰，此飲食傷胃也，必見食作嘔逆。弦者停飲之象，不去之不快也，此類傷寒中五症之一，視為外感，失之遠矣。急以對金飲子（方：桔紅厚朴蒼朮甘草生薑大棗）加大黃、檳榔等破之，二服而腹減熱退。五日後來謝曰：余未病時，常有嘔逆手顫疾，不知何故？告之曰：此酒積也。試服葛花解酲丸，當必愈。曹即服之至半斤而宿疾全清矣。
