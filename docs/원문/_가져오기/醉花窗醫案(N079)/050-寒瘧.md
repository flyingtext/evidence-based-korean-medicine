# 寒瘧

丁未歲，余讀於鄉之僧寺。是年太陰司天，五月後陰雨經旬，里中地極下濕，而農家露宿於野，外感風寒，必病瘧利。因先配常山酒一壇施之。六月半瘧果大作，凡十人而五六，取酒者接踵至，保全頗多。至七月中，瘧少息而酒亦罄矣，寺僧名昌裕，素無賴，以佘在寺稍斂跡。旋亦病瘧，向余求酒，余以酒已完，欲再制之非浸漬十數日不可，倉卒不能辦。昌裕似嫌余吝，乃招而來曰：子怒我錯矣，瘧雖一病，而人之虛實稟賦不同，余所施之酒，未必人人盡效。我為若治之何如？僧始轉怒為喜，乃診其脈，則弦而遲。告曰：弦是瘧正脈，而遲則寒象。子患寒瘧，發必多寒少熱，且先寒後熱，身痛無汗。僧曰：良是。乃以越婢湯發之，二日瘧少止，令五服則全愈矣。
