# 陰虧血熱

<!-- source-id: N079:p099 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 자동 변환 원문·정본 미대조

同譜張月翁之三弟，血燥食重，亦得熱病兼喉痛。清張寶玉視之，張嚇曰：此紅痧蛤蟆瘟也，病甚險，治亦恐不效。其母驚而不安。月翁邀余治。余曰無礙，非痧，非瘟。不過陰虧血熱四字耳，二藥可愈。月翁疾索方，因以六味地黃湯加芩連進之。次日往見月翁，則其三弟已笑迎於門矣。問其病，則曰，藥後酣睡至三更後，則心體具清；此時惟渾身稍軟。余戒之日，病初退，尚未痊癒，須節飲食，省奔走方可。不然，再發則無救矣。尚知信從，數日後，入學而讀矣。
