# 產後腹痛

<!-- source-id: N079:p030 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 자동 변환 원문·정본 미대조

友人盂嘻之妻，年四十餘，新產後，患腹中塊痛。延余診視，按其兩脈實大而堅，知非吉象，而以至好，不便明言。乃聊以人參澤蘭湯進，服之未效。又請余冶，余曰，痛不減，則藥不效，請延他醫視之。盂不肯，至余門者日三四次。不得已，實告曰，產後之脈，宜緩宜小，今見堅大，恐難愈也。盂曰：試再進一方，萬一不愈，亦不敢怨。余曰：豈在怨不怨，但竭力經營，徒費錢無益耳。盂憂疑而去。凡更十數醫，無毫髮效，五十餘日而歿。
