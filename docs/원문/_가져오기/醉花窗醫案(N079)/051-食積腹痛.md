# 食積腹痛

<!-- source-id: N079:p051 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 자동 변환 원문·정본 미대조

黑六，里中人，遺其名。一日腹痛欲絕，強步至門，跪求余治。余曰：何忽得此疾？泣訴曰，昨日吃蓧麵條半大碗，飯罷入瓜田渴甚，飲涼水二碗，歸家則腹痛作矣。胸中如碗鼓甚，按之如刺。余曰，此食積也。但汝胸中如石塞竇無隙可通，用藥治之，恐藥弱而病強，攻之不破也。痛者曰：然則聽之乎。余曰，爾欲病癒，須遣人扶掖，在田野中，往返疾行數百步乃可，病者辭以不能。余曰，不能則難治也。再三苦求，乃以大劑承氣湯加麥芽，檳榔疏之。告曰，三服乃可。病者歸，初服而胸中如墜，二服後下氣暴作，急如廁，則如桶脫底，胸腹空虛，負耒而耕矣。
