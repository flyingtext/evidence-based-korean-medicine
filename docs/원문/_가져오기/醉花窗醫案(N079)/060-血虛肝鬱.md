# 血虛肝鬱

<!-- source-id: N079:p060 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 자동 변환 원문·정본 미대조

同譜王丹文之母，夏月染疫症，留連數月。屢易醫，病漸去，而苦發熱頭痛，胸中煩擾。而性情反復，忽而不服藥，親鄰力勸之而不肯也。一日頭痛甚，丹文專車迎余，因視其病，以同譜故侄呼余，余亦伯母呼之。再三開導，乃許服藥。診脈則沉數，而肝部澀，左寸微。告丹文曰，此血虛肝鬱也。專滋陰以潤血，熱當已，且「乙癸同源」，血潤則肝亦舒，頭痛亦當止，乃開歸芍地黃湯，加薄荷、山梔以清之。二日後，丹文來，問之，則身涼而頭痛止矣。又不服藥，余以其病無礙聽之。
