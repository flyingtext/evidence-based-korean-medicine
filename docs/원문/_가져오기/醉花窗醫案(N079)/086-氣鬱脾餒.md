# 氣鬱脾餒

> 상태: 자동 변환 원문·정본 미대조

讀醫宗必讀一書有治病不失人情論一條。可謂老成練達，道盡醫家甘苦。

吾鄉張公景夷之弟，素短於才，在湖南作賈。年余而歸，益無聊賴，兼嗜洋藥，一切衣物日用，仰給於兄。性近侈，私累叢集，又不恭厥兄，終日憒憒抱悶氣，食不沾葷，而糖飴瓜果之類，時不離口。辛酉夏因而成疾，其兄延余診之，六脈平和，惟左關滑，右關弱，乃氣不伸而脾餒候也。因投以逍遙散。其兄以為頗效，而病者不任也，乃入城投榮醫者治之。榮素迂滯，問其形症，且恐貨藥無錢，遂以病不可為辭焉。張歸則涕零如雨，其母素溺愛，亦以為不復生矣，舉家驚啼。日詬誶，景翁不得已，又請余治，情辭急迫，乃曰：榮某以舍弟病為不起，請決之，如真不可為，身後一切好預備也。見其景象，本不欲診，以景翁誠懇相求。又診之，則脈象如故。乃告其家人曰，此病此脈，萬無不好之理，如別生他證，余不敢保，若單有此病，勿藥可愈，如有錯誤，當抵償也。榮某以庸術嚇人，勿為所惑。景翁頗喜。而其弟則大拂意，奮袂而出。景翁嗟悼再三，問何以處？余曰：此雖弱冠，其心反不如聰明童子，但日給錢數十，令其遊行自在，無拘無束，三兩月必無慮矣。景翁如言聽之，病者日日入城，頹然自放，不兩月病痊而更胖矣。景翁始信余言之不謬。即其弟亦自云悔不聽余言，致多費也。余笑而鄙之。
