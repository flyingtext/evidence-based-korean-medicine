# 內有積熱傷風致瘧

<!-- source-id: N079:p027 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 자동 변환 원문·정본 미대조

少司成馬介樵所狎伶人（戲子）名阿二，秋後發瘧疾，寒多熱少，精神困憊。介翁亦知醫，云是虛寒，施桂附補之，瘧不少減，而轉寒為熱，發則煩渴汗出。一日有友人在吟秀堂招飲，介翁命呼阿二車載以來，則坐立不能自主。介翁云：今日招爾非為侑酒，王老精於醫，擬令去爾病也。阿二請安將叩頭，余日：病體如此，何必拘拘。診其脈，則浮而緩，沉取之，內甚實。乃告介翁曰，瘧疾是外感病，阿二內有積熱，外傷於風，須先解其表，後清其熱。用桂附似未當，乃命服五積散（方：白芷川芎甘草當歸肉桂芍藥半夏陳皮桔梗麻黃蒼朮乾薑厚朴枳殼生薑）。以桂枝易麻黃。二日瘧少止，而煩渴依然，又進以桂枝白虎湯，十日而全清矣。後在文昌館文宴，阿二在三慶部，晚飯後，專為余演桂花亭一折。情深文明，的是佳劇。後余呼之必來，雖極忙促時，必勿勿一至也。
