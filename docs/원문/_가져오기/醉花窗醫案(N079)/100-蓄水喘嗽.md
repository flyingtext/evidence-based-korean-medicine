# 蓄水喘嗽

<!-- source-id: N079:p100 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`

> 상태: 자동 변환 원문·정본 미대조

月潭之女，年甫周歲，忽喘嗽交作，渾身發熱。月潭以為尋常感冒，忽之，越日益甚。適余視其弟病，亦請一視，見其面發赤，身發熱，喉中聲如鋸，臆斷曰痰也。必乳母令睡時吃乳，兼膈間有火，故食為火壅而生痰，但得白玉餅兩三枚則可矣。月潭令服之。熱稍退而腹作脹，喘嗽仍舊。又請余視，以為已愈，細視之，兩目昏閉，精神若無，喉間亦如故。月潭曰：看此形恐不救，余曰：何至此，乃視指紋，則紅絲出風關，兼按其膈，則胸中作聲漉漉然。頓悟曰，前以為痰，乃水也，必小便不利，眼胞虛腫，兼咳而作嘔，乳母曰，是。遂開五苓甘露飲，令當茶飲之。次日，月潭邀同進城，問之，則小便十餘次，腹減而精神作矣。因勸以再進一煎，兩日如初。
