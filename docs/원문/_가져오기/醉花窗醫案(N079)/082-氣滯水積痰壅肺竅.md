# 氣滯水積痰壅肺竅

<!-- source-id: N079:p082 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 자동 변환 원문·정본 미대조

痰之為病，甚則發厥，無故昏倒，一或誤治，便不能起，最為危險。推原其故，大抵多由氣鬱，以致痰壅胃口，因而不省人事。舊法以三生飲吐之，攻標之急治也。若不壅於胃，而壅於肺，則痰入清道，尤難措手。其證不昏倒，能知人，惟胸膈間氣，能出而不能入，時時作反張形，遂至湯水不能下嚥，咽則氣逆而哮。

里中布賈姓安名溶者，雖作商，人極推重。辛酉夏，其次子歲余而殤；其三女亦以癆症亡於家；未越月，其次女之婿與其甥男，一日間相繼亡。其次女年幼，婿之族人恐席捲而他適，置死人於不問，互爭產業。安知之，急與憤爭，族人乃散，前喪子女，已抱憂鬱，後次女事，又增其憤，故歸而得胸滿腹瀉之疾。求余治之，診其脈，弦而滯。告曰，此氣滯水積也。用香砂胃苓丸消之，病早愈，安嗇於財，不復服藥，余亦忘之。越十餘日，急遣人招余視其病，余以為瀉之未愈也。急視之，則氣格格作逆，口唾不能下嚥。問膈與胸中作滿否？曰否。提其腕，則兩手如冰，六部伏不見，惟有寸帶滑數。乃曰，此痰壅肺竅也。肺竅為氣所出入，今為痰壅，故氣不能入。如在胃，則卒然昏噤，三生飲吐之可也。今在肺管恐吐之不出，無可措手，急辭而出。安固請一方，乃以木香順氣飲敷衍之，出而告其夥曰：安某之病，必不起，可急為料理。其夥尚不信，因循至次早，乃來省視，安已口張氣促而不能言矣。其堂兄見其危，又邀余治，余固辭。乃請鄰人扶乩，服一方頗能言，遍召家人以身後屬之，轉側而歿。
