# 保胎增乳二方

胎至三月而墮，非損傷也，大抵婦人多憂鬱，乃肝臟結熱，因而腐化耳。達生篇保胎無憂散，最為靈應，屢試屢驗。初覺有胎，即按其方月服一付，不但無小產之患，即臨娩時，亦無橫生逆產，胞衣不下，產後血暈之症。誠仙方也。

至乳食不足，厥有數端，有氣血本虛而不足者；有乳竅未通而不足者；有因香辣等物，觸回不足者；有因憤怒氣鬱不足者；其他食積水停，風寒外搏，皆能致乳減少。蓋乳者血也。血隨氣行，氣盛則盈，氣衰則少，氣鬱則滯，氣熱則結。醫者但治其氣，使之流通，乳汁斷無不通之理。惟婦人年老，真氣已虛，是真減少，雖服參茸，究竟草木鳥獸、枯槁之物不能添作乳汁也。

古人下乳之方不下百十數，有驗有不驗者，緣病情不一耳。近得一方，補氣為主，而通竅散結，解熱活血諸品，無不畢具。已試數人，曆有成效。因錄二方於後，以備不時查考云。

保胎無憂散：潞參三錢、全當歸三錢、枳殼錢半、荊芥穗錢半、紫根朴錢半(薑汁炒)，川貝母二錢研末另衝、川芎三錢、羌活一錢、生黃耆錢半、菟絲餅二錢(酒泡)、白芍二錢半、祁艾錢半(醋炒)、生甘草錢半、生薑三片。水煎服。

下乳神方：生黃耆八錢、全當歸五錢、白芷四錢、陳皮三錢、木通片一錢、漏蘆錢半、通草錢半、紅花五分、薑炭五分、川芎二錢、王不留錢半、潞參四錢、炮甲珠三錢。水煎成加黃酒二樽熱服。
