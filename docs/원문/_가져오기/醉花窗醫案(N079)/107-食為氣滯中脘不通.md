# 食為氣滯中脘不通

<!-- source-id: N079:p107 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 자동 변환 원문·정본 미대조

裕州牧蓮舫兄之夫人，號杏云，靈石漪泉翁女也。工書畫，善音律，一切博奕棋酒，無所不通。適李時，蓮舫尚諸生，勸之讀書，不數年得鄉舉，後以譽錄議敘牧裕州。杏云隨之往，日行事件，多經其手。而蓮舫多萎靡，且好狎邪遊，並取二妓。以防撚不力失官，後雖開復，而空坐省城，益不自釋，日與夫人反目。辛酉秋，夫人不得已回介，家道式微，翁姑俱老，諸事賴之保全。余曾一次，即為余畫桃花春燕扇幅，至足感也。壬戌夏，忽遣人邀余，問之，則杏云病矣。急隨之往，則衣飾楚楚，診其脈，則六部沉伏。余曰：此鬱滯也，宜逍遙散。夫人亦知醫，點頭稱是。二服而全。又隔月，余赴捕廳之飲，先見曉圃，曉圃曰，兄來正好，五嫂又病矣，何不一視。入而問之，杏云曰，以為感冒，但覺憎寒發熱，肢體沉困，用柴胡四物湯，一服而腹作痛，昨夕猶緩，朝來無止時矣。時疫氣流行，恐其為疫，故請大哥一視。診之則余脈俱平，惟右關頗實而滯。告曰，此非外感，亦非瘟疫，仍是食為氣滯，故中脘不通。不惟增痛，且多脹也。況胸間作悶，時時作噯氣，以霍香正氣散疏之則無病矣。杏是之，稱不謬。乃處一方。越二日，遇曉圃於酒市，問之，則日二服全愈，家五嫂命致謝焉。
