# 氣鬱脅痛

<!-- source-id: N079:p102 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 자동 변환 원문·정본 미대조

里中張士美之妻，以夫不自立，常抱抑鬱，而性頗桀驁，一切衣食稍不遂意，輒負氣相爭。壬戌夏，其次子以食積胃熱致喉腫，請鄰人張寶玉治之，張不學無術，以針刺其喉，用新白布擦之。越日，益水汁不下，三日而歿。士美之妻因喪子而增病，乃胸膈作痛，飲食不思，終日昏睡，頭目眩暈，適余至其家，請一視之。診其六部沉鬱，肝臟尤甚，乃告之曰，此氣鬱也，數藥可愈。但須戒忿怒，不然雖愈將復發也。處以香砂四七湯，三服而痊。
