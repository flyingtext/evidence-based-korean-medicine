# 五不治（輕亦可治）

一皮死麻木不仁（易治）　二肉死刀剖不斷。（患處少亦可治）　三血死潰爛。膿水淋漓。

（可治）　四筋死手足脫落。

（不治）　五骨死鼻梁崩塌。（難治即治亦不能復原）　耳聾聲全啞者。（難治）　陽事不起者。（難治）

不斷房事者。（不必治）　正報者必不可治。又肝經受病。先損其目。不治。（曾以目疾各方治之亦無不愈）
