# 驗虎口法

小兒三歲以下有病，須看男左女右手叉處，名虎口。從第二指節側看，第一節名風關，第二節名氣關，第三節名命關。辨其紋色紫者屬熱，紅者屬寒，淡紅隱隱者屬虛寒，青者驚搐，黑者中惡，白者疳病，黃者脾之困。若現於風關為輕，氣關為重，過於命關則難治矣。

## 手指脈紋形

<!-- source-id: H025:p003:s0001 -->

*魚刺形\p03-b5a1.bmp*

魚刺形，主驚搐痰熱。

*懸針形\p03-b5a2.bmp*

懸針形，主傷風泄瀉積熱。

*水形\p03-b5a3.bmp*

水形，主食積客熱驚疳。

*乙字形\p03-b5a4.bmp*

乙字形，主肝病驚搐。

*蟲紋形\p03-b5a5.bmp*

蟲紋形，主肝蟲大腸氣積。

*環形\p03-b5a6.bmp*

環形，主疳積肚痛。

*亂紋形\p03-b5a7.bmp*

亂紋形，主蟲。

*珠形\p03-b5a8.bmp*

珠形，主無生理。

## 虎口三關

<!-- source-id: H025:p003:s0002 -->

三歲後，以一指按三部，六七至為平脈，四五至為寒，九十至為熱。脈弦急為氣不和，沉緩為傷食，促結為虛驚，浮為風，沉細為寒，脈亂者不治。
