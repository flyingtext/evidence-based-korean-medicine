# 破傷風

<!-- source-id: H025:p020 -->
> 서명: 慈幼便覽
> 원본 파일: `H/H025.txt`
> 원본 SHA-256: `e3d1d3bd1e7acce5b94659fe3a7456a7056afcd9516d2fe0cf99cffcf94f9b06`
> 상태: 자동 변환 원문·정본 미대조

小兒或因跌撲，或刀斧破傷，風邪暗襲，傷處發腫，謂之破傷風。速宜治之，不然則發痙矣。內服疏風活血散，外以紫金錠一塊磨水塗之。

<ins>疏風活血散</ins>

　治小兒出血破傷風，已痙未痙者。

全當歸　懷生地　赤芍藥　北防風（以上各一錢二分）　鮮紅花　正川芎　廣蘇木　炙甘草（以上各六分）　生薑（三片）　大棗（一枚）　水煎熱服。

<ins>紫金錠</ins>

山慈菇（三兩）　五倍子（三兩）　紅芽大戟（去蘆，一兩五錢）　明雄黃　鏡辰砂（各五錢）　真麝香（三錢）

共為細末，糕米飲和藥搗干，錘為錠，磨水塗之。
