# 保養生胎論

夫人也，受氣於父，成形於母，先生骨肉，乃生氣之本也，是元臟之所屬也。水生肝，肝屬木，木生心，心屬火，火生胃，胃屬土，土生大腸，大腸屬金，金生膀胱，膀胱生三焦，三焦有八脈，八脈有十二經，十二經生一百八十四絲絡，絲絡生三百六十五骨節，骨節生二百八十四條細脈，前後生毛髮肌膚，肌膚生血肉，上有毛髮，下為皮為肉，肉下為筋，筋下為骨，骨肉為髓，榮行脈中，衛行脈外，五臟和平者無病，如克太過不及，皆主有病。然五臟盈虧，所屬之症，自然明已。東方實，西方虛，瀉南方，補北方。蓋東方實者，木太過也，西方虛者；金不足也；瀉南方者，火太過也；補北方者，水不足也。故是五行太過不及，主受病也。若木升而火降，金清而木平，五行得中，脈息和平，何由乎病哉？今余之醫遵叔和之脈，述仲景之書，治百病之源，苟得有效，即曰書名為《試驗錄》也。傳之於後，鑒之用之，蓋可忽哉。
