# 婦人受胎

<!-- source-id: G004:p004 -->
> 서명: 錢氏秘傳產科方書名試驗錄
> 원본 파일: `G/G004.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

蓋婦人受孕，猶曳地之道，陰陽和而萬物生焉。夫婦之道，陰陽和而男女生焉。婦人經水勻調，百病不生，然後孕育成矣。夫受胎以血為主，叔和云：血旺氣衰應有體，血衰氣旺定無娠。尺微關滑數流利並雀啄，皆是胎脈見，孕母不知覺。左手帶縱，兩男子；右手帶橫，一雙女；左手脈逆生，三男；右手脈順還，三女；左手太陽浮，大男；右手太陰沉，細女。諸陽為男，諸陰為女。仲景云：脈有相承，縱橫逆順。何也？曰：水行乘火，金行乘木，曰縱；火行乘水，木行乘金，曰逆；金行乘水，木行乘火，曰順。或曰：脈有殘賊，何也？弦、緊、浮、滑、沉、澀，此六脈者，賊也。然諸賊作病，是為殘也。且孕脈夫乘妻虧縱氣露，妻乘夫虧橫氣助，子乘母虧逆氣恭，母乘子虧順氣護。夫陰陽二氣，若陰血先至，陽精後沖，縱氣來乘，如霧露之降升，血裹精，此為夫乘妻虧縱氣霧，則男形成矣；若陽精先至，陰血後恭，兩傍橫氣來助佐，而升精裹血，此謂妻乘夫虧橫氣助，則女胎成矣。凡胎氣驟聚，必帶縱橫逆順，方成胎也。
