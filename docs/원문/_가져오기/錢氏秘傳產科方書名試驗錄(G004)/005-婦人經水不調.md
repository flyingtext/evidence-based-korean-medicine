# 婦人經水不調

<!-- source-id: G004:p005 -->

> 원본 파일: `G/G004.txt`

男子以陽精為盛，女子以月水為調。陽精且水，各得其時，合乎陰陽之數矣。女子十四則月水行，男子十六則陽精具。婦人經水過期者，血少也，宜以芎、歸、參、朮。有痰，宜南星、半夏之類。經水不及期而來，血熱也，宜四物、黃連。過期作痛，紫黑色有塊，亦血熱也，宜四物、黃連、香附。過期色淡者，痰多也，宜二陳、川芎。有血虛過期，宜四物加黃　、陳皮、升麻。

有氣血俱熱，未期先至，宜柴胡、黃　、歸、芍、生地、香附。有經不調而血水淡白者，用參、　、芎、歸、香附、白芍，腹痛加膠珠、艾葉、玄胡。過期作痛，虛中有熱；將來作痛，血實也。

宜桃仁、黃連、香附、玄胡、紅花。臨行腹痛，有鬱滯瘀血，宜四物、紅花、桃仁、莪朮、玄胡、香附、木香，發熱加柴胡、黃芩。有痰多占住血海而下多者，目必漸昏。肥人加南星、蒼朮、川芎、香附，作丸服之。軀脂澀經閉者，導痰湯與黃連、川芎，不可服熟地，恐膩膈，故如用加薑汁炒之。臨期腹痛甚者，血實熱也。如有血實熱，行經作痛者，得孕遲也。
