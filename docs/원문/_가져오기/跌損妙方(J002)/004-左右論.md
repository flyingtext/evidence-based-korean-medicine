# 左右論

<!-- source-id: J002:p004 -->

> 상태: 자동 변환 원문·정본 미대조

凡受傷不知左右，若有吐血症，見血自明。血黑者左受傷，血鮮者右受傷，若無血吐出看眼珠，亦可知其定所。烏珠包丑者傷在左。白珠包丑又加紅大者傷在右。左屬肝，右屬肺。烏珠屬肝，白睛屬肺，瞳仁屬腎。常見右邊受傷，發時左邊便痛。不可單治一邊，必左右兼治，其病始愈。
