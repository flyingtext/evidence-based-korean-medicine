# 小兒白喉證

治法皆同。惟小兒為啞科。凡有發熱咳嗽。口流涎沫。飲乳便哭者。必須看喉嚨有無形跡。倘喉內紅腫。發有白點。如法施治。但血骨未充。服藥之分兩。宜視年歲之大小。體氣之強弱。而酌減之。然小兒好哭。難於吹藥。輕證即可以服藥而愈。其有危險重證。仍須吹藥。不可畏其啼哭而不用也。
