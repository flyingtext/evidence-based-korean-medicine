# 蛤蚧

雷公云: 凡使, 須認雄、雌. 若雄為蛤, 皮粗口大, 身小尾粗; 雌為蚧, 口尖, 身大尾小. 男服雌, 女服雄.

凡修事服之, 去甲上、尾上並腹上肉毛. 毒在眼. 如斯修事了, 用酒浸, 才幹, 用紙兩重, 於火上緩隔焙紙炙, 待兩重紙干, 焦透後, 去紙, 取蛤蚧於瓷器中盛, 於東舍角畔懸一宿, 取用, 力可十倍.

勿傷尾, 效在尾也.
