# 鹿茸

雷公云: 凡使, 先以天靈蓋作末, 然後鋸解鹿茸作片子, 以好羊脂拌天靈蓋末塗之於鹿茸上, 慢火炙之, 令內外黃脆了, 用鹿皮一片裹之, 安室上一宿, 其藥蒐歸也. 至明, 則以慢火焙之令脆, 方搗作末用之.

每五兩鹿茸, 用羊脂三兩, 炙盡為度.

又製法: 用黃精自然汁浸兩日夜了, 漉出, 焙令乾, 細搗用, 免渴人也.
