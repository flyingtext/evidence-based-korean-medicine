# 紫桂

雷公云: 凡使, 勿薄者, 要紫色、厚者, 去上粗皮, 取心中味辛者使. 每斤大厚紫桂, 只取得五兩. 取有味厚處, 生用; 如末用, 即用重密熟絹並紙裹, 勿令犯風. 其州土只有桂草, 元無桂心. 用桂草煮丹陽木皮, 遂成桂心.

凡使, 即單搗用之.
