# 妊娠傷寒腳腫證（四十三）

裡巷一婦人妊娠。得傷寒。自腰以下腫滿。醫者或謂之阻。或謂之香港腳。或謂之水分。予曰。

此證受胎脈也。病名曰心實。當利小便。醫者曰利小便。是作水分治。莫用木通葶藶桑皮否。曰當刺勞宮關元穴。醫大駭曰。此出何家書。予曰。仲景玉函經曰。婦人傷寒。妊娠。及七月。腹滿。

腰以下如水溢之狀。七月太陰當養不養。此心氣實。當刺勞宮及關元。以利小便。則愈。予教令刺穴遂瘥。
