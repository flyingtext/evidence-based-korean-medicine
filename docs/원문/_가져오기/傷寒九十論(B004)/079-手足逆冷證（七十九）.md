# 手足逆冷證（七十九）

酒家朱三者。得傷寒。六七日。自頸以下無汗。手足厥冷。心下滿。大便秘結。或者見其逆冷。

又汗出滿悶。以為陰證。予診其脈沉而緊。曰此證誠可疑。然大便結者為虛結也。安得為陰。脈雖沉緊。為少陰證。然少陰證多矣。是自利未有秘結。予謂此半在表。半在裡也。投以小柴胡湯。大便得通而愈。

論曰。傷寒。惡寒。手足冷。心下滿。口不欲食。大便　。脈細者。此為陽微結。必有表復有裡也。脈沉亦在裡也。汗出為陽微。假令純陰結。不得復有外證。悉入在裡。此為半在表半在裡也。脈雖沉緊。不得為少陰病。所以然者。陰不得有汗。今頭汗出。故知非少陰也。可與小柴胡湯。設不了了者。得屎而解也。難者曰。仲景云病患脈陰陽俱緊。及汗出者。亡陽也。此屬少陰。今云陰不得有汗。何也。今頭汗出。故知非少陰也。何以頭汗出。則知非少陰。予曰。此說正是議議處。謂四肢冷。脈沉緊。腹滿。全是少陰。然大便硬。頭汗出。不得謂少陰。蓋頭者三陽所聚。三陽自胸中而還。有頭汗出。自是陰虛。故曰汗出為陽微。是陰不得有頭汗也。若少陰有頭汗。則九死一生。故仲景平脈法云。心者火也。名火陰。其病。頭無汗者可治。有汗者死。

心為手少陰。腎為足少陰。然相與為病。以意逆志。是謂得之。
