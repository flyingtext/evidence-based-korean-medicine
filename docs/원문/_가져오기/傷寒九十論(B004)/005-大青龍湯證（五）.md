# 大青龍湯證（五）

何保義從王太尉軍中。得傷寒。脈浮澀而緊。予曰若頭疼。發熱。惡風。無汗。則麻黃證也。

煩躁。則青龍湯證也。何曰。今煩躁甚。予投以大青龍湯。三投。汗解。

論曰。桂枝。麻黃。青龍。皆表證發汗藥。而桂枝治汗出。惡風。麻黃治無汗。惡寒。青龍治無汗。而煩。三者皆欲微汗解。若汗多。亡陽。為虛。則煩躁不眠也。
