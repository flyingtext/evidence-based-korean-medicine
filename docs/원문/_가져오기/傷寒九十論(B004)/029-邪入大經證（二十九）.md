# 邪入大經證（二十九）

維揚謝康中。任儀真酒官。咽乾。煩渴。腰疼。身熱。脈細而微急。予診視之曰。此真少陰證也。

六經之中。少陰難治。少陰病傳之經絡。此證有補瀉法。仲景瀉者用承氣。補者用四逆。誤之則相去遠矣。此證當溫。勿以水證為疑也。予適以事出境。後七日歸。則為他醫汗之矣。經絡既虛。

邪毒流入大經之中。手足螈　。如驚癇狀。其家野狼狽求救。予曰。不可治也。予驗此甚多。是謂邪入大經。不旋踵。其家已哭矣。
