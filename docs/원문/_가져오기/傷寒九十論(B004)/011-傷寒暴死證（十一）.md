# 傷寒暴死證（十一）

己未歲。一時官病傷寒。發熱狂言煩躁。無他惡證。四日死。或者以為兩感。然其證初無兩感證候。是歲得此疾。三日四日死者甚多。人竊怪。予嘆之。曰是運使然也。己為土運。土運之歲。上見太陰。蓋太乙天符為貴人。中執法者。其病速而危。中行令者。其病徐而持。中貴人者。

其病暴而死。謂之異也。又曰臣為君則逆。逆則其病危。其害速。是年少宮土運。木氣大旺。邪中貴人。故多暴死。氣運當然。何足怪也。
