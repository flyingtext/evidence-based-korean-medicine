# 面垢惡寒證（七十五）

> 상태: 자동 변환 원문·정본 미대조

一尼病頭痛身熱。煩渴。躁。診其脈大而虛。問之曰小便赤。背惡寒。毛竦洒洒然。面垢中暑也。醫作熱病治。但未敢服藥。予投以白虎湯。數日愈。

論曰。仲景云脈虛身熱。得之傷暑。又云其脈弦細芤遲何也。素問曰寒傷形。熱傷氣。蓋傷氣不傷形。則氣消而脈虛弱。所以弦遲芤細。皆虛脈而可知矣。
