# 下肚角疽

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

此症生於臍下左右, 約離臍三寸處, 有硬塊一條, 橫過胯眼上下作痛, 醫者多誤作奔豚或小腸之氣, 故治鮮有效. 患此者多由酒色過度後, 乘熱臥於當風之處, 使氣遏痰不能周流所致, 其形狀與上肚角症相似, 治法亦同. 惟人體虛弱者當兼服三香丸, 敷麻涼膏, 經六、七日後, 皮膚腫起痛甚者, 可用化肉膏貼之, 至肉黑時, 用針撥開, 膿即隨手出矣. 若膿不幹者, 可用藥線三次, 其膿自干; 若膿成而不出膚, 必然內潰而由小便中出, 以燈心湯送中九丸服之, 即可痊愈.
