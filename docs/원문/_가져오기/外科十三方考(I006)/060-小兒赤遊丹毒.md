# 小兒赤遊丹毒

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

此症因胎中受熱, 致生此瘡, 或生兩膝眼上, 或生腎囊上不定, 皮膚赤腫, 破皮後則出血痛甚, 水洗至何處, 即爛至何處, 治方如下:

鉛粉（三錢火煆黃色）　乳香　沒藥　血竭　黃柏（各二兩）　輕粉（三錢）　冰片（一分）　白蠟（二錢）

上共為細末, 清油調搽, 切忌發物.

又方:

黃柏三錢, 豬膽一枚, 將膽汁搽於黃柏上炙乾, 又搽又炙, 數次之後, 取黃柏為末調搽之.
