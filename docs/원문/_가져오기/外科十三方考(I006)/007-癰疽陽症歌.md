# 癰疽陽症歌

陽症初起焮赤痛, 根束盤清腫如弓, 七日或疼或時止, 二七瘡內漸生膿, 毒隨膿出精神爽, 腐脫新生氣血充, 嫩肉如珠顏色美, 更兼鮮潤若榴紅, 自然七惡全無犯, 應當五善喜相逢, 須知此屬純陽症, 醫藥調和自有功.

凡癰疽初起, 焮熱赤痛, 根束者, 暈不散也; 盤清者, 不漫腫也; 如弓者, 高腫也, 易潰易斂, 此為順症. 詳察細審, 自易見功.
