# 馬刀痰核

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

此症生於下頦對喉嚨處, 形圓如卵、堅硬如石, 塞住喉嚨, 女人患者甚多, 一起惱怒, 即腫痛潮熱, 約七、八日後, 即又如常. 醫治之法, 以順氣行痰之劑為佳, 內服中九丸兼金蚣丸, 切戒針灸, 不可落核, 若微針破, 即血出不止, 且翻弦而不易收口, 慎之. 若子午潮熱, 又有火症者（防成骨癆）, 十難一痊.
