# 癰疽七惡歌

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

一惡神昏憒, 心煩舌燥干, 瘡色多紫黑, 言語見呢喃. 二惡身筋強, 目睛正視難, 瘡頭流血水, 驚悸是傷肝. 三惡形消瘦, 瘡形陷又堅, 膿清多臭穢, 脾敗食不甘. 四惡皮膚槁, 痰多韻不圓, 喘生鼻頻扇, 肺絕定歸泉. 五惡時引飲, 咽喉若燎煙, 腎亡容慘黑, 囊縮死之原. 六惡身浮腫, 腸鳴嘔呃繁, 大腸多滑泄, 臟腑敗之端. 七惡瘡倒陷, 如剝蟮一般, 時時流汙水, 四肢厥逆寒.
