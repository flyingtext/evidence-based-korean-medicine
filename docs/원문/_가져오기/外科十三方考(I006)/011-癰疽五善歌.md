# 癰疽五善歌

心善精神爽, 言清色潤鮮, 不躁不煩渴, 寤寐兩相安. 肝善身輕便, 不怒不驚煩, 指甲紅潤色, 起坐覺安然. 脾善唇滋潤, 知味喜加餐, 膿黃不臭穢, 大便不稀干. 肺善聲音響, 不喘無嗽痰, 皮膚光潤澤, 呼吸氣相安. 腎善不午熱, 口和齒不幹, 小溲清且白, 夜臥靜如山.
