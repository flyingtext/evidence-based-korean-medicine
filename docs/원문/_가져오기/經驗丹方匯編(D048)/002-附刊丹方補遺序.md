# 附刊丹方補遺序

余聞之：古人君子，出則為良相，處則為良醫。又曰：「一介之士，苟存心於利物，於人必有所濟。」嗟乎﹗良相其難矣，良醫豈易？易哉﹗夫羲農肇技於黃軒、扁盧；精能於白發、膏肓、督任之中，神其術而為良者，青年朱李由此選也。余不敏，少所指授，弗能為良醫。竊意濟人利物之事，隨可行。居當與四方君子咨諏藥石，又嘗周歷吳越諸邦所在，延訪古先名手，醫方若干，匯為一冊。試之輒效，用之通神，私竊自喜，藉此可以利物濟人矣。

比年秋，謀付梓人，流之於世。適新安俞君曉園重刻《經驗丹方類編》。余既重樂此書之大有利濟於人物也。余正重樂此書之適相浹恰於鄙裡也。爰揀生平編集奇方一冊，附刊於後。

夫故未敢妄附於為良之列，亦用自托於一介存心之意云爾。

<ins>乾隆十七年壬申秋九日金溪周郎</ins>
