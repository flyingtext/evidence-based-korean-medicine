# 凡例

一、古今方書不下數百種，而或效或不效，未堪盡攸。茲只取其經驗之最神者匯集一編。

因顏之曰：《丹方匯編》。

二、子自幼酷好單方，凡有見聞必勤筆登錄；或業醫之所珍秘者，亦不吝重物以購得之。

搜索十載約有八百余方，屢試輒效。今春發愿公世因遍采方書，熟知向所。秘錄者皆系古名醫之所制，故每方下明載之，欲人知所自由也。

三、諸症單方奇效者甚多，然太冗繁，恐反令人一時難擇，故每症只選十中之一，以備急需四、諸方或得效於實而不宜於虛者，或獲濟於寒而不利於熱者，俱不妄載以誤人。即有立見五、方藥若利害太甚者，不敢亂載。是編所登皆已所驗過，幸勿畏懼加減以致無效。

六、凡草藥人所難識者俱不載入；凡膏藥、丸、丹療疾固甚神異，然必先預備，一時不能救急，載亦無益。倘有發愿施濟者，至舍抄錄無吝。

七、予不善攝生，久患咯血，經驗神方難嘗修合。施濟而是編之，校謬訂訛，精力難勝。

悉托友人徐芸兄代為斧削，其苦心亦與予同偶也。今予舊患又作，精力益加衰疲，幸是書之得告成者，實賴徐友之力居多。

八、女科症候不一，而調經保產，最為緊要；而慈幼亦莫先於保嬰。

九、予每加意於斯，故先付剞劂，但尚未遍行，故又附列於後。

十、是編所載丹方無不神驗，只要專信服之，自必見功。久病久服，其病自愈；慎毋速期其十一、古今奇方不一，而一人搜羅有限，未經見聞者諒罄竹難書。同人果有累試歷驗之方，幸祈抄錄見示，嗣容補入是編。

十二、是書務期廣遠流通，四方君子發心印施多部，福有攸歸。若能翻刻尤慰鄙懷。
