# 火門

有餘之氣名為火，妄動須知爍至陰，實者瀉之虛者補，重升輕降理誠深。陰虛發熱陽旺盛，脈數無力屬心腎，內傷發熱乃陽虛，脈大無力肺脾分。氣從左起肝之火，陰火還從臍下生，腳下熱來侵腹者，斯人虛極藥難平。瀉火黃連解毒湯，補虛參術生草良，郁火隨經宜發散，風寒外來散之良。心火黃連肺黃芩，肝膽之火柴連親，芩連可瀉三焦火，臟火偏宜青黛尋。芍藥瀉脾知母腎，石膏胃火　滋陰，若要瀉卻膀胱火，須加黃柏與細辛。木通專瀉小腸火，郁火升麻與葛根，若治無根游行火，劑中何可失玄參。

黃連解毒湯（詳）

余論非實火不可驟用涼藥，必先溫散。蓋風寒外來者，宜散，郁火宜散。生甘草能緩火邪，山梔仁大能降火。
