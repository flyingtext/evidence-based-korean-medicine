# 頭痛門

頭疼即非真頭疼，氣火虛風痰火盛，若是真疼手足青，旦發夕兮歸幽冥。加味芎歸治諸痛，治頭痛妙方　土茯苓四兩（忌鐵器）　金銀花三錢　蔓荊子一錢　玄參八分　防風一錢明天麻一錢　辛夷花五分　川芎五分　黑豆四十九粒　燈心三十根　牙茶五錢。

河水井水各一鐘半，煎一鐘服。

羌吳湯　羌吳湯　麻升　，黃柏芩連芎與歸，細蔓紅花蒼朮半，頭頂項痛即時移。

單方鬧楊花、川芎各等分。為極細末，左痛吹左鼻，右痛吹右鼻，連打數嚏鼻清水，即愈又方頭風偏正最堪憐，近日奇方治遠年，可取黃牛腦一個，川芎白芷各三錢，共為細末擦於腦，瓷器盛末加酒煎，頓熱食之酒盡量，醉目酒醒痛安然。（一方用豬腦）

余論王節齋云：久病頭痛，略感風寒便發者，內郁熱而標寒也。本有郁熱，毛竅常疏，故風易入，寒束其熱，故痛愈甚。世人用辛散之劑，雖能散其標之寒邪，然以熱濟本病益深，當瀉火涼血，而佐以辛溫，則痛可愈，而根可除。
