# 脾胃門

脾胃屬土居中位，受納水穀滋營衛，水穀盡兮營衛亡，安穀則昌絕則斃。一有不足為內傷，醫家值此須審詳，勿作外感有餘治，交泄之時定見殃。六君子湯蓋調理，白朮參苓甘草比，陳皮半夏炒砂仁，三斤生薑二鐘水。內傷之症何所成，飲食勞倦並七情，治須先用補元氣，看所挾者而加增。挾痰挾邪挾郁熱，補中益氣湯多用，甘草參　為操縱，陳皮白朮當歸身。

柴胡升麻八味共，或停飲食將如何，不足之中繼有飲，氣口脈來而緊盛，先須道者自然除。
