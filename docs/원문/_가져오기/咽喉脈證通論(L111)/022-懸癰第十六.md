# 懸癰第十六

此證乃脾家熱毒，外感風熱而成。其狀忽於上顎生一紫泡，垂下抵舌，疼痛異常，口不能言，舌不能伸，頭不能低，仰面而立，鼻出紅涕，若不速治，毒入於腦即死。急以小刀刺破癰頭，出盡紫血，不可咽下，用菊花湯漱淨，先以菊花葉搗汁一碗，和酒送下，次進牛黃解毒丸，煎以荊防敗毒散，加地丁、半枝蓮甚效。
