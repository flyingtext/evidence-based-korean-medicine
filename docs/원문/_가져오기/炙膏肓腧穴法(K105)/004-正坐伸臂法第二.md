# 正坐伸臂法第二

<!-- source-id: K105:p004 -->
> 서명: 炙膏肓腧穴法
> 원본 파일: `K/K105.txt`
> 원본 SHA-256: `4e250ac253675b7b4ccbc4dbe6e515f08e187bc5d4790a392b07fbf65b371960`
> 상태: 자동 변환 원문·정본 미대조

令患人用墩椅正坐，兩足平蹋至地，膝與髀股高下俱平，兩足相並，足趾前齊，盡脫去上體衣服(若不盡脫，則衣袖束臂，不能使胛骨相離，取穴不得。若氣怯畏寒，則反著衣，以臂穿袖，令領在胸前頸下，以襟交覆腰間，墨點定穴。灸時更著背心，以帶束近穴處，勿令與坐炷下火相礙。)曲脊伸臂，以兩手按膝上，令中指當膝蓋中，兩大指緊相並，指頭與膝蓋骨前齊，微用力直舉。腕中勿令斜屈動搖(段彥聰仲謀大夫云：石藏用謂以左手按右膝，右手按左膝，則胛骨開。嘗試用其說，則兩手相交，腕有高下胛骨亦蹈之，偏側當止，如舊法以左手按左膝為是。)
