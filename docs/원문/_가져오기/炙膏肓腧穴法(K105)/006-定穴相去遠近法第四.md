# 定穴相去遠近法第四

<!-- source-id: K105:p006 -->

用先截量下同身六寸蠟紙或篾，橫置脊骨第五　上中央，墨圈定處。令寸數界盡當墨圈中心兩頭，平直各三寸，勿令展縮，於紙篾兩頭盡處，以墨圈之。令圈大小直徑三分(《千金方》云：黃帝曰，灸不三分，是謂徒灸。炷務大也，小弱炷乃小作，以意商度之。小謂小兒，弱謂虛弱之人也。)一半在紙篾頭內，一半在紙篾頭外，令與脊中第五　二墨圈定高下處。

三圈相直，以為兩穴相去遠近之準。
