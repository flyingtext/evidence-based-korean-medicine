# 出血不止

《九靈山房集》云: 湖心寺僧履者, 一日偶搔膕（音國, 曲腳也. ）中疥, 忽自血出, 汩汩如湧泉. （肌衄者, 《內經》名之血汗是也. 《集驗方》用黃芩漬水擦之, 屢試良方也. ）竟日不止. 瘍醫治療勿效. 邀呂元膺往視, 履時已困極, 無氣可語, 及持其脈, 惟尺部如蛛絲, 他部皆無. 即告之曰: 夫脈氣血之先也, 今血妄溢, 故榮氣暴衰, 然兩尺尚可按, 惟當益營以瀉其陰火, 乃作四神湯加荊芥穗、防風, 不間晨夜並進, 明日脈漸出, 更服十全大補湯, 一劑遂痊.
