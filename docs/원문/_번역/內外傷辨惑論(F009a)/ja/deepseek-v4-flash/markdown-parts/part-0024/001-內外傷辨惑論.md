## 隨時用藥。

### 原文

治傷冷飲者，以五苓散，每服三錢或四錢匕，加生薑煎服之。

治傷食兼傷冷飲者，煎五苓散送下半夏枳朮丸服之。

治傷冷飲不惡寒者，腹中亦不覺寒，惟覺夯悶身重，飲食不化者，或小便利，煎去桂五苓散，依前斟酌服之。

假令所傷前後不同，以三分為率，熱物二分，傷生冷硬物一分，用寒藥三黃丸二停，用熱藥木香見睍丸一停，合而服之，又如傷生冷物二分，傷熱物一分，用熱藥木香見睍丸二停，用寒藥三黃丸一停合而服之。

假令夏月大熱之時，傷生冷硬物，當用熱藥木香見睍丸治之，須少加三黃丸，謂天時不可伐，故加寒藥以順時令，若傷熱物，只用三黃丸，何謂？此三黃時藥丸也。

假令冬天大寒之時，傷羊肉濕麵等熱物，當用三黃丸治之，須加熱藥少許，草豆蔻丸之類是也，為引用又為時藥，經云：必先歲氣無伐，天和此之謂也，餘皆倣此。

傷冷飲を治するは、五苓散を以て、毎服三銭或いは四銭匕、生薑を加えて煎服す。

傷食兼ねて傷冷飲を治するは、五苓散を煎じ、半夏枳朮丸を送下して之れを服す。

傷冷飲にして悪寒せざる者は、腹中も亦た寒を覚えず、惟だ夯悶身重、飲食化せざるを覚え、或いは小便利する者は、桂を去りたる五苓散を煎じ、前に依り斟酌して之れを服す。

仮令、傷るる所の前後同じからざるは、三分を以て率と為し、熱物二分、生冷硬物一分を傷り、寒薬三黄丸二停を用い、熱薬木香見睍丸一停を用い、合して之れを服す。又如し生冷物二分を傷り、熱物一分を傷れば、熱薬木香見睍丸二停を用い、寒薬三黄丸一停を用い、合して之れを服す。

仮令、夏月大熱の時、生冷硬物を傷れば、当に熱薬木香見睍丸を用いて之れを治すべし。須く少しく三黄丸を加うべし。天時は伐すべからざるを謂い、故に寒薬を加えて時令に順う。若し熱物を傷れば、只だ三黄丸を用う。何を謂うや。此の三黄は時薬の丸なり。

仮令、冬天大寒の時、羊肉湿麵等の熱物を傷れば、当に三黄丸を用いて之れを治すべし。須く熱薬少許を加うべし。草豆蔻丸の類は是れなり。引用の為に又た時薬と為す。経に云う：必ず先ず歳気をして伐たず、天和を。此れ之れを謂うなり。余は皆此れに倣う。
