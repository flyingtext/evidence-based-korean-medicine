## 防葵

### Source Text

一名房慈，一名爵離，一名農果，一名利茹，一名方蓋。生臨淄，及嵩山少室。三月三日采根，曝乾。

### Literal Translation

One name is Fangci [房慈], one name is Jueli [爵離], one name is Nongguo [農果], one name is Liru [利茹], one name is Fangai [方蓋]. It grows in Linzi, and on Mount Song and Shaoshi. Gather the root on the third day of the third month and dry in the sun.
