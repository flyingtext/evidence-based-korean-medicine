## 桔梗

### Source Text

味苦，有小毒。主利五臟腸胃，補血氣，除寒熱風痹，溫中，消穀，治喉咽痛，下蠱一名利如，一名房圖，一名白藥，一名梗草，一名薺　。生嵩高及宛朐。

### Literal Translation

Flavor bitter, slightly poisonous. Its chief actions are to benefit the five viscera, intestines and stomach, supplement blood qi, dispel cold-heat wind-impediment, warm the center, digest grain, treat sore throat, and down-drive ...gu. One name is 利如, one name is 房圖, one name is 白藥, one name is 梗草, one name is 薺 [苨].
