## 王孫

### Source Text

無毒。主治百病，益氣。吳名白功草，楚名王孫，齊名長孫，一名黃孫，一名黃昏，名海孫，一名蔓延。

### Literal Translation

Not poisonous. Its chief actions are to treat the hundred diseases and boost qi. In Wu it is named 白功草, in Chu 王孫, in Qi 長孫; one name is 黃孫, one name is 黃昏, one name 海孫, one name 蔓延.

### Translator's Notes

- 王孫 = Paris polyphylla.
