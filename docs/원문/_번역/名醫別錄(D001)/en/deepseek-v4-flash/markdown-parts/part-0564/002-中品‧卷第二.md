## 石脾

### Source Text

一名胃石，一名膏石，一名硝石。生隱蕃山谷石間，黑如大豆，有赤文，色微黃，而輕薄如棋子，采無時。

### Literal Translation

One name is 胃石, one name is 膏石, one name is 硝石. It grows among stones in the valleys of Yinli (隱蕃); black like a soybean, with red veining and a slightly yellow color, light and thin like a chess piece; gather without a fixed time.
