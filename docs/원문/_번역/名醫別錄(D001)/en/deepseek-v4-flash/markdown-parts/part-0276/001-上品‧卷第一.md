## 茜根

### Source Text

可以染絳名地血，一名茹　，一名茅搜，一名茜。生喬山。二月、三月采根，曝乾。

It can be used to dye a deep red color and is named Dixue; one name is Rulu, one name is Maosou, one name is Qian. It grows on Qiaoshan. The root is harvested in the second and third months and dried in the sun.
