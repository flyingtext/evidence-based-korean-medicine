## 菟絲子

### Source Text

味甘，無毒。主養肌，強陰，堅筋骨，主治莖中寒，精自出，溺有餘瀝，口苦，燥寒血為積。一名菟縷，一名　蒙，一名玉女，一名赤網，一名菟累。

### Literal Translation

Flavor sweet, non-toxic. It mainly nourishes the flesh, strengthens yin, firms the sinews and bones, mainly treats cold in the penis, spontaneous emission of essence, residual dribbling of urine, bitter mouth, and dryness and cold congealing blood into accumulations. One name is Tulü [菟縷], one name is [蒙], one name is Yunü [玉女], one name is Chiwang [赤網], one name is Tulei [菟累].
