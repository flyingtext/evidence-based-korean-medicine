## 水蘇

### Source Text

無毒。主治吐血、衄血、血崩。一名雞蘇，一名勞祖，一名芥苴，一名瓜苴，一名道華。

### Literal Translation

Non-toxic. It treats vomiting of blood (吐血), nose-bleeding (衄血), and blood-collapse (血崩). One name is Jisu (雞蘇), one is Laozu (勞祖), one is Jieju (芥苴), one is Guaju (瓜苴), one is Daohua (道華).
