## 絡石

### Source Text

一名石蹉，一名略石，一名明石，一名領石，一名懸石。生太山，或石山之陰，高山岩石上，或生人間。正月采。

### Literal Translation

One name is Shicuo [石蹉], one name is Lüeshi [略石], one name is Mingshi [明石], one name is Lingshi [領石], one name is Xuanshi [懸石]. It grows on Mount Tai, or on the shady side of rocky mountains, on high mountain rocks, or among human dwellings. Gather it in the first month.
