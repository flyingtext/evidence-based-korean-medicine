## 黃

### Source Text

其莖、葉，治渴及筋攣，癰腫，疽瘡。一名戴椹，名獨椹，一名⿲禾呈糸草，一名蜀脂，一名百本。生蜀郡、白水、漢中。

### Literal Translation

Its stem and leaf treat thirst and sinew spasm, abscesses and swellings, carbuncles and ulcers. One name is 戴椹, one name 獨椹, one name 草, one name 蜀脂, one name 百本. It grows at Shujun, Baishui, and Hanzhong.

### Translator's Notes

- ⿲禾呈糸草 is an unusual character; transliterated as 草.
