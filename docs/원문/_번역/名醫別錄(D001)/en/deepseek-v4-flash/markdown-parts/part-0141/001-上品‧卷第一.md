## 菊花

### Source Text

味甘，無毒。主治腰痛去來陶陶，除胸中煩熱，安腸胃，利五脈，調四肢。一名曰精一名女節，一名女華，一名女莖，一名更生，一名周盈，一名傅延年，一名陰成。

### Literal Translation

Flavor sweet, non-toxic. It mainly treats lower back pain that comes and goes with a swaying [陶陶] feeling, removes vexation and heat in the chest, settles the intestines and stomach, frees the five vessels, and harmonizes the four limbs. One name is Yuejing [曰精], one name is Nvjie [女節], one name is Nvhua [女華], one name is Nvjing [女莖], one name is Gengsheng [更生], one name is Zhouying [周盈], one name is Fu Yannian [傅延年], one name is Yincheng [陰成].
