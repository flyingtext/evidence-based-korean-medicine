## 特生石

### Source Text

味甘，溫，有毒。主明目，利耳，腹內絕寒，破堅結及鼠　，殺百蟲惡獸。久服一名倉　石，一名　石，一名鼠毒。

### Literal Translation

Flavor sweet, warm, toxic. It governs brightening the eyes, benefiting the ears, extreme cold within the abdomen, breaking hard bindings and rat fistula (鼠瘻), and killing the hundred insects and evil beasts. Taken for a long time, one name is 倉石 (cāngshí), one name is 石 (yùshí), one name is 鼠毒 (shǔdú).
