## 甘遂

### Source Text

味甘，大寒，有毒。主下五水，散膀胱留熱，皮中痞，熱氣腫滿。一名甘　，一名陵一名陵澤，一名重澤。

### Literal Translation

Flavor sweet, greatly cold, toxic. It governs descending the five waters (下五水), dispersing retained heat of the bladder, hardness within the skin (皮中痞), and heat-qi swelling and fullness. One name is 甘 (gān), one name is 陵澤 (língzé), one name is 重澤 (chóngzé).
