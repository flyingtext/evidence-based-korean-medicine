## 沙參

### Source Text

無毒。主治胃痹，心腹痛，結熱，邪氣，頭痛，皮間邪熱，安五臟，補中。一名苦心一名志取，一名虎須，一名白參，一名識美，一名文希。

### Literal Translation

Not poisonous. Its chief actions are to treat stomach-impediment (胃痹), heart and abdominal pain, bound heat, pathogenic qi, headache, pathogenic heat between the skin, calm the five viscera, and supplement the center. One name is 苦心, one name 志取, one name 虎須, one name 白參, one name 識美, one name 文 [希].
