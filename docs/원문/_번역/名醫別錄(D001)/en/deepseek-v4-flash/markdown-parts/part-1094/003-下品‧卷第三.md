## 石

### Source Text

火煉百日，服一刀圭，不煉服，則殺人及百獸。一名石，一名大白石，一名澤乳，一名食鹽。生漢中山谷及少室，采無時。

### Literal Translation

Refined by fire for a hundred days, take one knife-blade measure (一刀圭); if taken unrefined, it kills people and the hundred beasts. One name is 石 (yùshí), one name is 大白石 (dàbáishí), one name is 澤乳 (zérǔ), one name is 食鹽 (shíyán). It grows in the mountain valleys of Hanzhong and at Shaoshi; gathered at no fixed time.
