## 滑石

### Source Text

大寒，無毒。通九竅、六腑、津液，去留結，止渴，令人利中。一名液石，一名共石，一名脆石，一名番石。

### Literal Translation

Greatly cold, non-toxic. It frees the nine orifices, the six bowels and the fluids [津液], removes retained binding, stops thirst, and makes one's center free-flowing. One name is Liquid Stone [液石], one name is Gong Stone [共石], one name is Cui Stone [脆石], one name is Fan Stone [番石].
