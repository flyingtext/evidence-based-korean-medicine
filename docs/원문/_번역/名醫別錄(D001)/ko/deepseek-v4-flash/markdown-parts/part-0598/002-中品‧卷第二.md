## 決明子

### 원문

十月十日采，陰乾（蓍實為之使，惡大麻子。）

《本經》原文：決明子，味鹹，平。主青盲，目淫膚，赤白膜，眼赤痛淚出。

### 직역

시월십일(十月十日)에 채취하여, 그늘에서 말린다. (시실(蓍實)이 사(使)가 되고, 대마자(大麻子)를 꺼린다.)

《본경(本經)》 원문: 결명자(決明子)는 맛이 짜고(鹹), 평(平)하다. 주로 청맹(青盲), 목음부(目淫膚), 적백막(赤白膜), 안적통(眼赤痛)·루출(淚出)을 다스린다.
