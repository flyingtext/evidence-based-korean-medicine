## 三時伏氣外感篇

### 원문

斯時若以肺藥少加一味清降，使藥力不致直趨腸中，而上痹可開，諸竅自爽，無如市醫僉云結胸，皆用連、蔞、柴、枳苦寒直降，致閉塞愈甚，告斃者多。

### 직역

이때 만약 폐약(肺藥)에 청강(清降)하는 한 가지를 조금 더하여 약력(藥力)이 곧장 장(腸) 속으로 달려가지 않게 하면, 위의 비(痹)가 열리고 여러 규(竅)가 저절로 시원해진다. 그러나 시중 의사들이 모두 결흉(結胸)이라 하여 연(連)·루(蔞)·시호(柴)·지실(枳)의 고한(苦寒) 직강(直降)을 써서 폐색(閉塞)이 더욱 심해져 죽음을 고하는 경우가 많다.
