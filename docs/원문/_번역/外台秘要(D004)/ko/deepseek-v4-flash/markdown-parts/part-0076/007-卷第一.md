## 論傷寒日數病源並方二十一首

### 원문

若大便硬，小便自利者，附子白朮湯。

桂枝附子湯方桂心（四兩）　附子（三枚炮去皮）　生薑（三兩）　甘草（二兩炙）　大棗（十二枚擘）

上五味切，以水六升，煮取二升，去滓，溫分三服。忌生蔥豬肉海藻菘菜。

### 직역

만약 대변(大便)이 단단하고, 소변(小便)이 스스로 이(利)한 자는, 부자백출탕(附子白朮湯)이다.

계지부자탕(桂枝附子湯) 방(方) 계심(桂心) (사냥)　부자(附子) (세 개 구운 것 껍질 벗긴 것)　생강(生薑) (삼냥)　감초(甘草) (이냥 구운 것)　대조(大棗) (열두 개 쪼갠 것)

위 다섯 가지를 썰어, 물 여섯 되로, 두 되를 끓여 취하고, 찌꺼기를 버리고, 따뜻하게 세 번에 나누어 복용한다. 생총(生蔥)과 돼지고기와 해조(海藻)와 송채(菘菜)를 꺼린다.
