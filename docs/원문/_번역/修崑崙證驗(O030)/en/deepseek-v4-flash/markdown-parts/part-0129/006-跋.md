## 跋

### Source Text

世休我乎？世不休我，我休世也。休已乎休矣！休乎其所當休，休乎其所樂休，休乎其所不得不休，何所謂肯休與不肯休耶？獨不意六十年前，嚮往欲見之人而身蹈之也。理耶？數耶？天耶？人耶？莫之為而為者，天也，莫之致而致者，人也。

### Literal Translation

Does the world rest me? If the world does not rest me, I rest the world. Rest, and rest! Rest where one should rest, rest where one joyfully rests, rest where one cannot but rest; what is called willing to rest and not willing to rest? Only I did not expect that sixty years ago, the person I yearned to see, I would come to embody. Is it principle? Is it fate? Is it Heaven? Is it man? What is done without doing is Heaven; what is brought about without bringing is man.
