## 跋

### Source Text

堅其爐，多其炭，去其灰，火自旺，焰自明，出不竭，用不窮，至誠無息之謂也。今火而不焰，非火故也，灰蔽之也。不蔽焰明，輕蔽焰微，重則不焰，再重則熄，去灰則復焰矣。

### Literal Translation

Strengthen the furnace, increase the charcoal, remove the ashes, and the fire naturally flourishes, the flame naturally brightens, coming out without exhaustion and being used without end; this is what is meant by utmost sincerity without rest. Now if there is fire but no flame, it is not the fault of the fire but the ashes obscuring it. If not obscured, the flame is bright; if lightly obscured, the flame is faint; if heavily, there is no flame; if even more heavily, it is extinguished; remove the ashes and the flame returns.
