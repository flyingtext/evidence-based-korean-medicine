# 治諸鯁咒法八

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

子和云：大凡魚骨麥芒，一切竹木刺鯁於喉間，及發絆不能下；用《道藏經》中一咒法：取東方無根水一碗，先以左手結三臺印，將水置印上，後將右手持一劍，訣於水上，虛書一龍字，密咒九遍；咒曰：吾從東方來，路傍一池水，水裡一條龍，九頭十八尾，問君治何物，專用此間水。連誦九遍，患者飲之，即愈。
