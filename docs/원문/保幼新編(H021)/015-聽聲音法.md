# 聽聲音法

聲音輕清者，氣也，弱也（保元湯主之）。重濁者，痛也，風也（惺惺散主之）。濁而沉靜者，疳積也（消食丸主之）。聲急者，神驚也（鎮心安神湯主之）。聲塞者，痰也（膽星抱龍丸主之）。聲戰者，寒也（惺惺散主之）。聲噎者，氣不順也（蘇合丸主之）。聲喘者，氣促也（保元湯加貝母、杏仁、黃連、香附子各五分服之）。高喊者，熱也（小兒清心丸主之）。噴嚏者，傷風也（惺惺散加柴胡、防風各五六分服之）。猝然語訥者，風中舌本也（加減養榮湯加細辛、犀角、石菖蒲各四五分服之）。猝然驚叫者，火動氣虛也，難治（人參七、八分煎茶，調牛黃抱龍丸服之）。
