# 坐點坐灸法第七

<!-- source-id: K105:p009 -->
> 서명: 炙膏肓腧穴法
> 원본 파일: `K/K105.txt`
> 원본 SHA-256: `4e250ac253675b7b4ccbc4dbe6e515f08e187bc5d4790a392b07fbf65b371960`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

坐炷下火時，令患人一依點穴時，正坐伸臂、頭、項、肩、背、手、足、腕、膝不得少有欹側，伸縮改易。即及臂中舉按用力輕重，亦常令勻。若一事稍異於前，胛骨便輒相近，覆閉灸穴艾炷，即在骨上；或胛骨開而相遠，動爭寸余，火氣不入穴竅，徒受苦楚，無所益也。

若不失其穴，灸至數壯，覺胛骨中通熱而不甚痛，意自快暢(石用之云：當覺臂中習習然也。)至數十壯後，或若腕中酸辛，若以機支，或用軟帛於肘上腕中連束二臂，令緩急得所，亦能少助。蓋手欲按而臂欲舉，故腕中費力，或少休頃刻亦無害，但要安頓身體四肢一如前耳。如日灸五十壯，累至數百為佳。《千金方》云：灸六百壯，至千壯，當覺氣下礱礱然如流水狀，亦當有所下，其治疾之效甚眾且敏(有上氣喘滿，即時平減者，有婦人經候不通已八月，灸兩日而下者，如此之類甚多。)穴至在上而最能下氣，非它穴藥石之比，而又無所不治，有疾者宜留意焉。
