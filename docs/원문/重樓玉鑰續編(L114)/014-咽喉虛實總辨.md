# 咽喉虛實總辨

<!-- source-id: L114:p014 -->
> 서명: 重樓玉鑰續編
> 원본 파일: `L/L114.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

書云：咽喉十八症，皆屬於火，此言其大略也。然火有虛實之分，證有寒熱之別，尤有內因、外因之殊，及看舌胎蒼老嬌嫩之辨，臨證審明，復切脈之虛實，有力，無力脈與症合，然後立方施治，未可概執為風熱實症也。今時之人，本質腎陰不足居多，而喉症屬實者少。或虛中兼實，實中兼虛，或下焦陰火發為咽痛口瘡者，亦復不少。然六氣之中，感發喉患，不獨風寒與火，而暑濕燥亦然。唯暑濕成咽痛者特稀，每感燥而發者多，蓋因腎水不足故也。若臨證不辨明，一見發熱，便施表散，凡屬風者，雖得其宜，或由寒者，則非辛溫不可。其屬火者，固宜清降，亦當辨其虛實與郁，唯實火宜清降，虛火則當壯水，郁火則宜升發，至濕與燥，又豈可表散耶﹗在他症虛實或難辨，而喉症最最易明，可一望而虛實立判，蓋有形可據，有色可參，有舌胎可辨。且痰涎有清濁之分，必須臨證者，潛心參究，乃得其竅。至於機巧權變，雖存乎其人，亦要從方脈中理會得來，庶無貽誤耳。
