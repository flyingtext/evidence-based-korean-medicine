# 陽維脈

陽維起於諸陽之會,其脈發於足太陽金門穴,在足外踝下一寸五分.上外踝七寸會足少陽於陽交,為陽維之郄.（在外踝上七寸,斜屬二陽之間）循膝外廉,上<ins>髀厭</ins>,抵少腹側,會足少陽於居髎.（在章門下八寸,監骨上陷中）循脅肋,斜上肘上,會手陽明、手足太陽於臂臑.（在肘上七寸,兩筋<ins>罅</ins>陷中,肩髃下一寸）過肩前,與手少陽會幹臑會、天髎.（臑會在肩前廉,去肩端三寸宛宛中.天髎在缺盆中,上<ins>毖</ins>骨際,陷中央）卻會手足少陽、足陽明於肩井.（在肩上陷中,缺盆上大骨前一寸五分）入肩後,會手太陽、陽蹺於臑腧.（在肩後大骨下<ins>胛</ins>上廉陷中）上循耳後,會手足少陽於風池.（在耳後髮際陷中）上腦空、（承靈後一寸半.夾玉枕骨下陷中）承靈、（正營後一寸半）正營、（目窗後一寸）目窗、（臨泣後一寸）臨泣.（在瞳人直上,入髮際五分陷中）下額與手足少陽、陽明,五脈會於陽白.（眉上一寸,直瞳人相對）循頭,入耳,上至本神而止.（本神直耳上入髮際中）凡三十二穴.
