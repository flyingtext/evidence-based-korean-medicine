# 火

臟氣有實有虛. 若陽盛水哀而動者, 則從河間治法, 瀉熱救水; 若陽虛不足而動者, 則陽愈虛, 當從東垣必補胃氣, 次瀉其火. 陽虛不安其位而火乘於陰, 依東垣自陰升陽提而出之; 陽盛入於陰者, 遵仲景下之. 陰虛不勝夫火動者, 用先生益精血、壯腎水以安之; 或臟氣盛與火齊發, 先瀉其盛; 本臟氣血不足, 先補其虛, 次瀉其火; 火與氣相持, 鬱伏不行, 則發臟氣（云云）. 其半則散火為主, 臟氣鬱其火.
