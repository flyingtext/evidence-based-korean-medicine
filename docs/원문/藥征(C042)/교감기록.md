# 藥征 교감 기록

## 현재 상태

jicheng.tw 해당 서명 URL의 404를 확인하고 독립 공개 전사와 대조했다. 근거가 불충분한 부분은 원자료를 보존하는 방식으로 교감을 완료했다.

## 대조 범위

- 원자료: `C/C042.txt`
- 적용 내역: `corrections-applied.json`
- 판정 방법: 독립 공개 전사의 문자 순서·장절 구조·앞뒤 문맥을 대조하고 감사 JSON에 전각 공백과 태그 판정을 기록
