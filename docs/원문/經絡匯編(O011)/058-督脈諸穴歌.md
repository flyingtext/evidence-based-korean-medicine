# 督脈諸穴歌

督脈在背之中行, 二十八穴始長強, 舞腰俞兮歌陽關, 入命門兮懸樞間. 脊中中樞筋束, 乃造至陽靈臺, 上神道身柱陶道, 以大椎而駐, 症門風府兮, 腦戶強間; 後頂百會兮, 前頂在前. 囟會近上星之照, 神庭見素髎之妙. 水溝至兌端而無差, 齦交居唇內而病療.
