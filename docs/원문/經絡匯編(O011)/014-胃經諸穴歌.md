# 胃經諸穴歌

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

足陽明四十五, 自承泣四白而數, 巨髎有地倉之積, 大迎來頰車之夥; 下關頭維以人迎, 水突氣舍與缺盆, 氣戶兮庫房屋翳, 膺窗兮乳中乳根, 不容承滿, 梁門關門, 太乙滑肉, 天樞外陵; 大巨從水道歸來, 氣衝入髀關之境, 伏兔至陰市梁丘, 犢鼻自三里而行; 上巨虛兮（即上廉）條口, 下巨虛兮（即下廉）豐隆, 解谿衝陽入陷谷, 下內庭厲兌而終.
