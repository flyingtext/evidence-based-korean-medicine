# 陰蹺脈論

陰蹺脈亦起於跟中, 循內踝上行, 至咽喉, 交貫衝脈, 亦長八尺. 生於足少陰然谷之後, 上內踝, 循陰股入陰, 至胸裡, 入缺盆, 出胃經人迎之前, 入鼻, 屬目內眥, 合於太陽. 女子以為之經, 男子以為之絡. 其見證也, 令人陽緩而陰急. 此經之病, 多取足少陽之交信（內踝上二寸）, 蓋以交信為郄云.
