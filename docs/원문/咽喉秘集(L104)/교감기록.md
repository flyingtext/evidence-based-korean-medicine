# 咽喉秘集 교감 기록

## 현재 상태

jicheng.tw 최신 전문과 별도 공개 전사를 대조해 결락·OCR 오기·자동변환 자형을 교정하고 표점을 검증했다.

## 대조 범위

- 원자료: `L/L104.txt`
- 전각 공백: 31자리 전수 판정(결자·오염 후보 31, 미해결 0)
- 적용 내역: `corrections-applied.json`
- 표점 검증: `punctuation-report.json`

## 대조 판본

- https://jicheng.tw/tcm/book/%E5%92%BD%E5%96%89%E7%A7%98%E9%9B%86/index.html
- https://wenxiaoguo.cn/book/05e9a63a58a2

## 유보 사항

미해결 교감 후보는 없다. 후속 영인본의 이문은 별도 기록한다.
