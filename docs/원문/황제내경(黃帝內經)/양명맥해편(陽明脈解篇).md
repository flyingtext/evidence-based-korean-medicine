# 양명맥해편(陽明脈解篇) — 素問 卷第8 第30篇

> **출처**: 『重廣補注黃帝內經素問』(王冰 注, 北宋 新校正) — 明 嘉靖 刊本 계통, [中醫笈成(jicheng.tw)](https://jicheng.tw/tcm/book/%E9%87%8D%E5%BB%A3%E8%A3%9C%E6%B3%A8%E9%BB%83%E5%B8%9D%E5%85%A7%E7%B6%93%E7%B4%A0%E5%95%8F/index.html) 전자화 판본을 저본으로 함.
> **정본 대조 원칙**: 이 문서는 위 저본을 그대로 전재(轉載)한 것이며, 이체자(古版/今版) 표기는 금판(今版, 통용 정자체)을 기준으로 정리했다. 왕빙주(王冰注)와 신교정(新校正)은 원문과 구분해 인용부호(> )로 표기한다.

## 원문

### 제1단

黃帝問曰 : 「足陽明之脈病, 惡人與火, 聞木音則惕然而驚, 鐘鼓不為動, 聞木音而驚, 何也?願聞其故.」

> **왕빙주**: 前篇言入六府則身熱, 不時臥, 上為喘呼.然陽明者, 胃脈也, 今病不如前篇之旨, 而反聞木音而驚, 故問其異也.

### 제2단

歧伯對曰 : 「陽明者, 胃脈也, 胃者, 土也, 故聞木音而驚者, 土惡木也.」

> **왕빙주**: 《陰陽書》曰 : 木剋土, 故土惡木也.

### 제3단

帝曰 : 「善.其惡火, 何也?」

### 제4단

歧伯曰 : 「陽明主肉, 其脈血氣盛, 邪客之則熱, 熱甚則惡火.」

> **신교정**: 按《甲乙經》『脈』作『肌』.

### 제5단

帝曰 : 「其惡人, 何也?」

### 제6단

歧伯曰 : 「陽明厥則喘而惋, 惋則惡人.」

> **왕빙주**: 惋熱內鬱, 故惡人耳.

> **신교정**: 按〈脈解〉云 : 『欲獨閉戶牖而處, 何也?陰陽相搏, 陽盡陰盛, 故獨閉戶牖而處.』

### 제7단

帝曰 : 「或喘而死者, 或喘而生者, 何也?」

### 제8단

歧伯曰 : 「厥逆連藏則死, 連經則生.」

> **왕빙주**: 經, 謂經脈.藏, 謂五神藏, 所以連藏則死者, 神去故也.

### 제9단

帝曰 : 「善.病甚則棄衣而走, 登高而歌, 或至不食數日, 踰垣上屋, 所上之處, 皆非其素所能也, 病反能者, 何也?」

> **왕빙주**: 素, 本也.踰垣, 謂驀牆也, 怪其稍異於常.

### 제10단

歧伯曰 : 「四支者, 諸陽之本也.陽盛則四支實, 實則能登高也.」

> **왕빙주**: 陽受氣於四支, 故四支為諸陽之本也.

> **신교정**: 按〈脈解〉云 : 『陰陽爭而外并於陽』.

### 제11단

帝曰 : 「其棄衣而走者, 何也?」

> **왕빙주**: 棄, 不用也.

### 제12단

歧伯曰 : 「熱盛於身, 故棄衣欲走也.」

### 제13단

帝曰 : 「其妄言, 罵詈不避親疏而歌者, 何也?」

### 제14단

歧伯曰 : 「陽盛則使人妄言, 罵詈不避親疏而不欲食, 不欲食故妄走也.」

> **왕빙주**: 足陽明胃脈下膈, 屬胃, 絡脾, 足太陰脾脈入腹, 屬脾, 絡胃, 上膈, 俠咽, 連舌本, 散舌下, 故病如是.

## 학습 메모

- 이 편은 족양명위경(足陽明胃經) 병변에서 나타나는 특이 증상들(木音을 들으면 놀람, 불을 싫어함, 사람을 싫어함, 옷을 벗고 달아나거나 높은 곳에 오름, 망언·욕설)의 병리 기전을 오행생극(土惡木)과 경맥 순행으로 설명한다.
- "四支者, 諸陽之本也.陽盛則四支實, 實則能登高也"는 양명 경맥의 실증(實證)이 조광(躁狂) 증상으로 발현되는 기전을 설명하며, 후대 정신질환(광증狂症) 변증의 원전적 근거가 된다.
- 열궐(厥逆)이 오장(五藏)까지 미치면 죽고 경맥(經)에 그치면 산다는 예후 판단은 사기(邪氣)의 심천(深淺)에 따른 예후론의 사례다.
