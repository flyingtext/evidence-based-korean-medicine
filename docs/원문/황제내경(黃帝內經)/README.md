# 황제내경(黃帝內經) — 원문(原文)

이 폴더는 『황제내경(黃帝內經)』의 원문(原文)을 편(篇)·조문(條文) 단위로 발췌·정리하는 곳이다. 저본은 『重廣補注黃帝內經素問』(王冰 注, 北宋 新校正) 明 嘉靖 刊本 계통이며, [中醫笈成(jicheng.tw)](https://jicheng.tw/tcm/book/%E9%87%8D%E5%BB%A3%E8%A3%9C%E6%B3%A8%E9%BB%83%E5%B8%9D%E5%85%A7%E7%B6%93%E7%B4%A0%E5%95%8F/index.html) 전자화 판본을 참조한다.
