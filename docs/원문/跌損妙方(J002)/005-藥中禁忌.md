# 藥中禁忌

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

乳香、沒藥二味，方中屢用，務要去油，若不去油，恐其再發。小兒骨一味，方中亦間用之，余謂小兒何辜，甫離母腹，骨化形銷，以人治人，殘忍殊甚，大造丸有紫河車。張景岳以為戕厥子之先天，勸人少用，況兒骨乎。余輯諸方，見有用此者，悉行裁去，以猴骨代之。
