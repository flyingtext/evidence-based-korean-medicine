# 左右論

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

凡受傷不知左右，若有吐血症，見血自明。血黑者左受傷，血鮮者右受傷，若無血吐出，即看眼珠，亦可知其定所。烏珠包醜者傷在左。白珠包醜又加紅大者傷在右。左屬肝，右屬肺。烏珠屬肝，白睛屬肺，瞳仁屬腎。常見右邊受傷，發時左邊便痛。不可單治一邊，必左右兼治，其病始愈。
