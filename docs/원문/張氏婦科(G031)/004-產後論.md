# 產後論

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

夫產後之患多起於風寒、飲食之間，其余則血氣為患。夏月之病多因於風，冬月之病多因於寒，惟飲食之患無定時也。蓋易產之後，其病易治；難產之後，其病難治。難產必深感風寒，兼氣血極虛，雖略進飲食，力不能勝，亦為之患也。產後諸症，多類傷寒，莫作傷寒治之，更莫作雜症治之。此乃女科不傳之訣，醫者切莫狐疑。其治法前後不同，二十日前氣血未定，惡露未盡，當破血為主；二十日外氣血已定，各歸經絡，雖有惡露，驅逐不行。凡有諸症要補氣血，更兼活血，諸書以月外作雜症治之，其言謬矣。
