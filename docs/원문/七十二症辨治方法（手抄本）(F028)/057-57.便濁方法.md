# 57.便濁方法

<!-- source-id: F028:p057 -->

> 원본 파일: `F/F028.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

小便流濁白和紅，白如米泔赤如膿；脾胃濕熱痰流滲，歸入膀胱氣化成。
譬之天地沖和候，凡水澄波徹底清；天氣炎蒸水混濁，濕熱道理了然明。
又有當泄不泄致，也有忘想沖閃因；更有清濁牽絲膩，萆薢分清飲可尋。
萆薢分清飲最靈，豬苓澤瀉赤茯苓，石蒲遠志車前子，麥門甘草地黃蒸。
