# 54.五癇方法

<!-- source-id: F028:p054 -->

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

癇症方書列五名，今呼諸癇作癢眩；未生母腹沾驚怪，已出娘胎痰氣侵。
忽然僵仆流涎沫，口眼歪斜肢屈伸；聲為畜叫因為號，須臾蘇醒不知情。
天若失職濁居上，木部將軍可肅清；清心溫膽湯無讓，治法難逃內外因。
清心溫膽二陳全，人參遠志芎麥門；石蒲香附白芍朮，黃連枳實竹茹全。
