# 7.痞滿、結胸、胸膈滿

<!-- source-id: F028:p007 -->
> 서명: 七十二症辨治方法（手抄本）
> 원본 파일: `F/F028.txt`
> 원본 SHA-256: `4ab9091e42f990a6247df75a25af93fb72f881e4298b74509e430b60e977285a`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

無熱惡寒發於陰，反不招來痞滿形；按之不痛傷寒血，胸膈滿分降無升。
發熱惡寒發於陽，誤下開門損寇然；按之方痛結胸小，不按自痛大堪傷。
熱結胸兮煩且渴，寒結胸兮悶怕涼；水結胸中腫且汗，不輕誤下別相商。
