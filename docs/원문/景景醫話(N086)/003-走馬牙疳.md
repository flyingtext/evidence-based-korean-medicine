# 走馬牙疳

<!-- source-id: N086:p003 -->
> 서명: 景景醫話
> 원본 파일: `N/N086.txt`
> 원본 SHA-256: `c022fb83a384a092bd75e322f95e7e8f339a77531639ee79aaa6824fcce10e66`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

佘友范某，其岳〔父〕走方醫也，有草研爛，以少許貼山根，取泡挑破，治走馬牙疳極效。範識其草，到處皆有，而不知其名，余曾囑其覓來植諸盆，不久即萎，繼余侄女患是病，兄來索此草，無以應，但以意會之，矚其用喉科中異功散少許，和蒜搗爛，亦於山根取泡，果效。記得張舜欽傳方，用斑蝥、麝香、白胡椒，調薄荷油，貼兩太陽〔穴〕取泡，治頭痛如刀劈者，亦此意也。病之經絡不同，則貼之穴道亦異，以此類推，當再可以治他病之宜拔毒外散者。
