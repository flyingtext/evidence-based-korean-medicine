# 劑字解

讀書必先識字，為醫亦何獨不然。古者造宇之初，義寓於聲，劑從齊聲，即有齊義，齊者平也，藥稱劑者，即虛者補之，實者瀉之，熱者寒之，寒者溫之之旨．故六淫之外因，飲食傷之不內外因，於我身所本無者，則必散之、瀉之、消之、下之而後安；七情之內因傷及我身所本有者，則必血虧益以血、氣虧益以氣而後可。凡所以劑其平也，俗稱一劑，日一帖意亦猶是。
