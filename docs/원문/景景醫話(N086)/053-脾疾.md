# 脾疾

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

禾水包公剡汝輯《南中紀聞》載：靖州南二十裏飛山砦，相傳為元末朱都督屯兵之所，牆礫間時有米粒，色微黑而不腐，云是朱公所遺兵糧，遊客謁神祠，取輒得之，至今尚有，服之可療脾疾。此亦一段奇跡。聞衡山有仙人糧，斯其仿佛歟。燧按：相傳黑米能治膈症，治脾胃也頗有理在。
