# 第十八則·髃骨骱失

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

髃骨者，肩端之骨，即肩胛骨也。其臼含納臑骨上端，其處名肩解，即肩䯋與臑骨合縫處也。俗名吞口，一名肩頭，其下附於脊骨成片如翅者。其骱若脫，手不能舉。使患人低坐，一人抱住其身，將手拔直，用推拿法，酌其重輕，待其筋舒，一手捏其肩，抵住骱頭，齊力拔出，骱內有響聲者，乃復其位矣。用布帶落其項下，服舒筋活血湯。凡上骱時，骱內必有響聲活動，其骱以上；若無響聲活動者，其骱未上也，不可誤人。
