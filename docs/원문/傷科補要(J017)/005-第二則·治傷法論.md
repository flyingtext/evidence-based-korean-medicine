# 第二則·治傷法論

<!-- source-id: J017:p005 -->
> 서명: 傷科補要
> 원본 파일: `J/J017.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

夫跌打損傷，墜墮磕磞之證，專從血論。或有瘀血停積，或為亡血過多，然後施治，庶不有誤。若皮不破而內損者，多有瘀血停滯。或積於臟腑者，宜攻利之；或皮開肉綻，亡血過多者，宜補而行之。更察其所傷上下輕重淺深之異，經絡氣血多少之殊，先逐其瘀，而後和營止痛，自無不效。《內經》云：形傷則痛，氣傷則腫。又曰：先腫而後痛者，形傷氣也；先痛而後腫者，氣傷形也。凡打撲閃錯，或惱怒氣滯、血凝腫痛，或因叫號血氣損傷，或過服克伐之劑，或外敷寒涼之藥，致氣血凝結者，宜活血順氣之法。夫損傷雜證，不及備載，俱分門晰類，詳列於後，學者宜盡心焉。
