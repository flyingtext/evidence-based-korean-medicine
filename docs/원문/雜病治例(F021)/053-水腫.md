# 水腫

五臟水, 為證不同. 皮水、正水、石水、風水. 內因氣、濕、食.

<ins>行氣削積</ins>　重者蹋腫丸, 輕者大橘皮湯、神金散.

<ins>下</ins>　三聖散, 枳實、蘿蔔子、牽牛, 為末, 看大小與服. 氣實, 三花、神佑、舟車、禹功選用之, 苦瓠丸.

<ins>利機關</ins>　用腎氣, 須茯苓與地黃對用, 平胃為衣, 稍實者, 下後用此潔淨府也.

<ins>實脾土</ins>　脾虛不能制水, 水漬妄行, 當燥脾補虛為主, 切不可下. 對金飲子、脾積丸.

<ins>滲泄</ins>　桑白、葶藶、大橘皮湯、五苓之類, 苤苢.

<ins>蒸</ins>　用湯以法坐熏之.

<ins>繆刺</ins>　脈盛氣實者, 可用胃倉穴、合谷、石門、水溝、三里、復溜、曲泉、四滿.

<ins>消導</ins>　有食傷太陰而浮腫如水者, 因積滯, 看寒熱, 分消丸.

<ins>開鬼門</ins>　謂發汗也.
