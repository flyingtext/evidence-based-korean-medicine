# 癖塊

在中為痰飲, 在右為食積, 在左為血積. 氣積、癥、瘕、聚.

<ins>消削</ins>　五臟積, 隨證治之, 見《玉機微義》積聚門.

血:醋煮海石、三稜、蓬朮、桃仁、紅花、五靈脂、香附、歸鬚、乾漆之類.

氣:御藥院方助氣丸.

痰:滌痰丸.

癥瘕:宣明積氣丹.

肉:丹溪阿魏丸.

酒:鄧山房感應丸.

食:丹溪保和丸、脾積丸, 見瀉痢例中.

<ins>下</ins>　因熱, 千金硝石大丸. 積:蹋腫神應丸. 鬼物:八毒赤丸, 白馬尿亦能行, 或單服之.

<ins>消導</ins>　用行氣和血煎藥, 下磨積藥, 從湯蕩之. 秘方脾積丸, 因氣血弱者, 攻補兼之.

<ins>鉤邪</ins>　有鬼物, 必須鬼物以鉤之, 用死人枕煮服.

<ins>敷貼</ins>　以大黃、朴硝、大蒜、鴿糞為膏, 敷痞上. 又煮蝦蟆, 食法見前鼓脹例中.

<ins>熨蒸</ins>　牽牛、蘿蔔子、枳實為末, 置於上, 以艾火蒸之.

<ins>養正</ins>　養正氣實, 而積自除. 有隻用舊砂鍋為末, 作丸服之效.

<ins>針</ins>　中脘、建里、石關、商曲.

<ins>倒倉</ins>　見《玉機微義》積聚門.

<ins>灸</ins>

<ins>外貼</ins>　以一葉梅貼印堂, 起泡去之.
