# 腹痛

有實、有虛、寒、氣滯、死血、積、熱、風、濕痰、清痰、驚痰. 脈滑者痰, 弦者食痹、瘡、痧、疝.

<ins>發汗</ins>　大抵風寒與濕痰在表之裡作痛, 宜汗之.

<ins>溫</ins>　寒入中脘痛, 理中. 少腹小腹, 四逆, 厥陰, 當歸四逆湯、吳茱.

<ins>熨</ins>　寒在內急痛, 宜灰包熨之.

<ins>逐熱</ins>　有濕熱作痢者, 宜導氣湯下之. 濕熱怫鬱, 痛隨利減.

<ins>針</ins>　大抵實痛宜刺瀉之, 太衝、三陰交、太白、太淵、太陵.

<ins>消積</ins>　脾積丸. 見瀉例中.

<ins>下食</ins>　食積停滯, 與內消脾積, 看冷熱物下之.

<ins>通利</ins>　墜肭瘡疝之類. 皆宜下之. 有懸飲為痛, 當下之, 見痰例中.

<ins>軟</ins>　諸痛未可用參朮, 蓋補氣則氣痛轉甚. 虛者須咸以耎之.

<ins>灸</ins>　邪客經絡, 藥不能及者, 宜灸氣海穴、關元穴、中脘穴.

<ins>外接法</ins>　治陰毒.

牡蠣（燒）　不灰木（燒）　良薑（炒）　川烏（炮）　白芍（各一錢）　麝（少許）

上為細末, 每服一錢. 男病用女唾津調, 塗外腎. 女病用男唾調, 塗兩乳.

<ins>摩按</ins>　風寒濕宜按摩之, 或用油線絞括奪命、委中等處. 俗謂之括痧.

<ins>逐血</ins>　有積血奔豚, 皆以活血通經藥逐之.

<ins>補</ins>　傷寒腹痛, 臍下築動者, 理中丸加人參主之.

<ins>消郁導痰</ins>　清痰多作腹痛, 用茗、芎、仙術、香附、白芷、薑汁入湯調服.

<ins>托瘡</ins>　有瘡在肺或腸癰, 脈來數而實.
