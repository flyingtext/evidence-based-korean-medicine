# 嘔吐

有熱, 有痰、寒、停食.

<ins>清熱</ins>　胃口有熱, 膈上有痰, 二陳加薑、黃連.

<ins>滋陰</ins>　還少丹、腎氣丸.

<ins>溫</ins>　理中丸、不二丸.

<ins>導滯</ins>　有積滯毒氣上攻而嘔者.

<ins>下</ins>　有食用內消丸.

<ins>清鎮</ins>　燒針丸必用之.

<ins>滲泄</ins>　水逆者, 五苓散主之.

<ins>補</ins>　久病者, 胃虛不納穀也, 人參、黃耆、白朮、陳皮之類.
