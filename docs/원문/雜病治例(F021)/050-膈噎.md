# 膈噎

即翻胃. 血虛、氣虛、熱、痰兼病血積、癖積.

<ins>補氣</ins>　四君子加蘆根、童便, 或參苓白朮散, 或韭汁、牛羊乳, 或入駁驢尿.

<ins>補血</ins>　四物加童便. 血病不可服香燥之藥, 服之必死.

<ins>消積</ins>　有用阿魏、香附、砂仁、仙術、陳皮、山豆、枳實、木香、歸鬚、桃仁、黃連之類.

<ins>溫胃</ins>　以馬雹兒燒灰存性, 每服一錢, 用棗肉、平胃散二錢和入酒調下. 丁沉透膈湯, 小七香丸.

逐滯血　多有積血停於內而致, 當消息逐之. 大便澀者多難治, 常令食兔肉, 則便利.

<ins>行氣</ins>　木香流氣飲、嘉禾散.

<ins>清鎮</ins>　燒針丸.

針　初病者, 取天突穴導之, 石關二穴.
