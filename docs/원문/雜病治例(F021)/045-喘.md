# 喘

未發, 以扶正氣為主. 已發, 以攻邪為主. 有外感邪盛.

<ins>補</ins>　氣虛短氣, 用人參、蜜炙黃柏、麥門冬、地骨、阿膠、桑白皮.

<ins>降痰</ins>　有痰亦短氣而喘. 導痰湯方:

半夏、南星、陳皮、枳實、茯苓、甘草.

<ins>滋陰</ins>　陰虛, 自小腹下火起而上者, 地黃丸. 年高痰喘不定者, 必用此, 仍茯菟與地黃等分.

<ins>疏利風痰</ins>　《婦人大全良方》千緡湯方:

半夏、皂角、炙草、生薑.

<ins>降火</ins>　有熱甚而喘.

<ins>泄水</ins>　有水乘肺而喘, 葶藶、牽牛之類.

<ins>降氣</ins>　導氣湯、蘇子降氣湯, 氣實導氣下行.

<ins>潤燥</ins>　款花膏.

<ins>下</ins>　有胃實壅遏, 以承氣湯下之, 氣實者下之.

<ins>劫</ins>　椒目為細末一二錢, 用薑汁調下止之. 又蘿蔔蒸熟為君、皂角燒灰等分、薑汁, 煉蜜丸, 梧桐子大, 服五六十丸. 劫後, 看證用藥.

<ins>溫</ins>　外感心下有水氣, 乾嘔而喘, 小青龍去麻黃加杏仁主之.
