表惡寒者溫之, 內中者劫之. 表證見傷寒例.

<ins>正治</ins>　主乎溫散, 桂枝、四逆輩. 甚者, 三建霹靂散. 有卒中天地之寒, 口傷生冷之物.

<ins>從治</ins>　熱藥加涼劑引之, 或熱藥冷飲. 經曰從而逆之.

<ins>反攻</ins>　蜜煎烏頭之類.

<ins>灸</ins>　陰寒及下陷脈絕者, 宜灸之.

<ins>熨</ins>　寒鬱作痛, 灰包熨之.

<ins>補</ins>　氣虛中寒, 脈沉遲弱, 於補中益氣加桂, 甚者加附子.

<ins>下</ins>　寒積怫鬱作痛, 桂枝大黃湯, 逆而從之.

<ins>劫</ins>　寒氣結搏, 附子類. 溫熱而不回者, 用金液丹、二氣丹, 壯益陽氣.
