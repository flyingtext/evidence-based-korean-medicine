# 牙疼

或出血屬熱, 胃口有熱. 有風寒、濕熱蟲蛀.

<ins>疏風</ins>　川芎、石膏、升麻、細辛、草烏、白芷、防風、羌活擦之, 或單用鶴蝨. 一方用升麻、石膏、細辛、藁本、檀香、麝香、皂角.

<ins>行濕</ins>　細辛、芫花、蒼耳葉、大戟、小麥、川椒煎水漱之.

<ins>清熱</ins>　石膏、升麻、地骨皮、羊脛骨灰.

<ins>解鐵雜之邪</ins>　東垣當歸龍膽散. 治寒熱, 用元戎梧桐淚散.

<ins>下</ins>　神功丸、涼膈散、調胃承氣湯為末, 蜜丸服之.

<ins>行血</ins>　牙疳蝕臭出血, 當作陽明蓄血治之, 桃仁承氣湯蜜丸服之. 東垣清胃散. 有服牛尿, 漱而得血者, 立愈.

<ins>散寒</ins>　草豆蔻、白芷、細辛、草烏、丁香、蠍梢.

<ins>取</ins>　皂角樹上蛾子, 或白馬蛆, 或用草烏、川椒、細辛.

<ins>益腎</ins>　腎虛者, 骨熱而蘇蘇然痛者, 滋腎丸.

<ins>灸</ins>　頰車、聽會、曲池.

<ins>熏</ins>　用韭子.

<ins>治蟲</ins>　天仙子燒煙. 用竹筒抵牙, 引煙燻之, 其蟲即死.

<ins>針</ins>　合谷、內庭、浮白、陽谷、三間.

<ins>擦藥</ins>　元戎問玉散方:

醋榴皮　訶子（各二兩）　升麻　何首烏　綠礬（枯）　青鹽　百藥煎　五倍子　沒石子（各兩半）　麝（一錢）　白茯菟（一兩）　細辛　石膽礬（各半兩）　荷葉灰　白檀　芎　芷　甘粉　苓苓香　茴香　藿香　豬牙皂角灰　木別子（各二錢）　青黛（一錢半）　共為末.
