# 消渴

上消則多飲水而少食. 渴而飲食多, 便赤, 為中消. 下消則膏淋, 面色黑而瘦.

<ins>養肺降火</ins>　人參白虎湯、東垣蘭香飲子、麥門冬飲子.

<ins>滋陰</ins>　八味丸、丹溪補陰丸.

<ins>清鎮</ins>　硃砂黃連丸、三因珍珠丸.

<ins>生津補氣血</ins>　東垣生津甘露飲子.

<ins>下</ins>　謂胃承氣湯.

<ins>潤燥</ins>　黃連末、天花粉末、生地汁、生藕葉和入牛乳, 佐以薑汁、蜜, 或單用浮萍汁.
