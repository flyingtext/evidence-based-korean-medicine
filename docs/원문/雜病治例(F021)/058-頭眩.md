# 頭眩

或運. 痰挾氣虛, 火積其痰. 脈大是久病.

<ins>利痰清熱</ins>　南星、半夏、桔梗、枳殼、陳皮、甘草、茯苓、黃芩之類.

<ins>疏風</ins>　川芎茶調散. 兼熱痰, 二陳加羌活、仙術、黃芩, 青州白丸子.

<ins>降火</ins>　滾痰丸、清空膏.

<ins>導飲</ins>　蠲痰丸.

<ins>消食</ins>　有內傷停食挾痰而致.

<ins>活血</ins>　脈澀有死血.

<ins>補氣</ins>　虛者, 參、朮、耆、歸、陳皮、甘草之類.

<ins>搐鼻</ins>　濕甚者, 牛末吹之.

<ins>針</ins>　上星、風池二穴、天柱.
