# 陰陽痞格論第六

陽氣上而不下曰痞. 陰氣下而不上. 亦曰痞. 陽氣下而不上曰格. 陰氣上而不下. 亦曰格. 痞格者謂陰陽不相從也. 陽奔於上則燔. 脾肺生其疽也. 其色黃赤. 皆起於陽極也. 陰走於下則冰. 腎肝生其厥也. 其色青黑. 皆發於陰極也. 疽為黃疽也. 厥為寒厥也. 由陰陽痞格不通而生焉. 陽燔則治以水. 陰厥則助以火. 乃陰陽相濟之道耳.
