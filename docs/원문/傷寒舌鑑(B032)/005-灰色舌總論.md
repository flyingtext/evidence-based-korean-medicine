# 灰色舌總論

灰色舌、有陰陽之異。若直中陰經。則即時舌便灰黑而無積苔。若熱傳三陰。必四五日表證罷而苔變灰色也。有在根在尖在中者。有渾舌俱灰黑者。大抵傳經熱證。則有灰黑干苔。皆當攻下泄熱。若直中三陰之灰黑無苔者。即當溫經散寒。又有蓄血證。其人如狂。或瞑目譫語。亦有不狂不語。不知人事。而面黑舌灰者。當分輕重以攻其血。切勿誤與冷水。引領敗血入心而致不救也。

*純灰舌\pt108a61.bmp*

舌灰色無苔者。直中三陰而夾冷食也。脈必沉細而遲。不渴不煩者。

附子理中四逆湯救之。次日。舌變灰中有微黃色者生。如漸漸灰縮干黑者死。

*灰中舌\pt108a62.bmp*

灰色現於中央。而消渴、氣上衝心、飢不欲食、食即吐蛔者。此熱傳厥陰之候。烏梅丸主之。

*灰黑苔干紋裂舌\pt108a63.bmp*

土邪勝水。而舌見灰黑紋裂。涼膈調胃皆可下之。十中可救二三。下後。渴不止熱不退者。不治。

*灰根黃尖中赤舌\pt108a64.bmp*

舌根灰色而中紅尖黃。乃腸胃燥熱之證。若大渴譫語。五六日不大便。轉矢氣者。下之。如溫病熱病。惡寒脈浮者。涼膈、雙解選用。

*灰色重暈舌\pt108a65.bmp*

此瘟病熱毒。傳遍三陰也。熱毒傳內一次。舌即灰暈一層。毒盛故有重暈。最危之證。急宜涼膈、雙解解毒。承氣下之。一暈尚輕。二暈為重。三暈必死。亦有橫紋二三層者。與此重暈不殊。

*灰黑干刺舌\pt108a66.bmp*

灰黑舌中又有干刺。而見咽乾、口燥、喘滿。乃邪熱結於少陰。當下之。然必待其轉矢氣者。方可下。若下之早。令人小便難。

*灰黑尖舌\pt108a67.bmp*

已經汗解而見舌尖灰黑。有宿食未消。或又傷飲食。邪熱復盛之故。調胃承氣湯下之。

*灰黑尖干刺舌\pt108a68.bmp*

舌尖灰黑有刺而干。是得病後猶加飲食之故。雖證見耳聾、脅痛、發熱、口苦。不得用小柴胡。必大柴胡或調胃承氣加消導藥。方可取效。

*灰中墨滑舌\pt108a69.bmp*

淡淡灰色中間。有滑苔四五點如墨汁。此熱邪傳裡。而中有宿食未化也。大柴胡湯。

*灰黑多黃根少舌\pt108a70.bmp*

舌灰色而根黃。乃熱傳厥陰。而胃中復有停滯也。傷寒六七日不利。便發熱而利、汗出不止者死。正氣脫也。

*邊灰中紫舌\pt108a71.bmp*

舌邊灰黑而中淡紫。時時自齧舌尖為爽。乃少陰厥氣逆上。非藥可治。
