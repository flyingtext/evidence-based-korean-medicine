# 脈法

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

勞極諸虛，浮軟微弱（虛症宜見虛脈為順）。土敗雙弦，（兩手俱弦，木剋土敗。若左手脈細，右手浮大勁急，亦木剋土敗，而主死也。知之。）火炎則數，（勞症必帶虛數，所以難治，若六至以上必死。）骨蒸發熱，脈數為虛，（虛數二脈，是其本象。）熱而澀小，必殞其軀，（發熱脈靜，不可救藥。）氣結或代，亦死何疑！失血諸症，脈必見芤，緩小可喜，（身涼脈靜易治。）數大堪憂，（身熱脈大者，為難治。）
