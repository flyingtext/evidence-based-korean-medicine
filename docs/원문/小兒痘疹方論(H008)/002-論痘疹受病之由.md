# 論痘疹受病之由

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

夫小兒在胎之時。乃母五臟之液所養成形也。其母不知禁戒。縱情厚味。好啖辛酸。或食毒物。其氣傳於胞胎之中。此毒發為瘡疹。名曰三穢液毒。。一、五臟六腑穢液之毒。發為水泡瘡。。二、皮膜筋肉穢液之毒。發為膿血水疱瘡。三、毒既出。發為疹痘瘡也。子母俱忌食蔥韮、薤蒜、醋酒、鹽醬、獐兔、雞犬、魚腥等物。世俗未曉。將為發舉。往往不顧其後。誤傷者多矣。
