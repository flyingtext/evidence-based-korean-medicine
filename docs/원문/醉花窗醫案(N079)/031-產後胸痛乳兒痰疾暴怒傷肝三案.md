# 產後胸痛乳兒痰疾暴怒傷肝三案

<!-- source-id: N079:p031 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

內人之妹適武舉張某之長子，產後患心胃痛。發則飲食俱絕，氣促口乾。其翁延人視之，皆曰虛，況產婦尤無實症，當培其氣血，氣血流通，則痛止。始服八珍湯，繼服十全大補湯，月余不止。乃來外家求余治。診其左寸關脈，堅凝而澀，知為瘀血停於胸膈。乃曰，胸膈痛，非心胃痛也。發則內如針刺，口渴氣喘，宜散瘀以定痛，不宜補氣以益瘀也。前服多補藥，何能有效。乃命服失笑散二劑，而痛若失。三日後視之，則其兒始歲余，手足發熱，神癡氣粗，乳食不進，喉中時時如鋸聲，眾以為驚風，延一鄰媼針灸之。余曰：此痰也，針灸則益甚，必平日多置曖處，其母臥而乳之所致也。矚服白玉餅（方：滑石半夏巴霜朱砂苦礬各一錢神麯糊為丸，滑石為衣）數粒，至晚則下綠色糞如許，乳食進熱退而安。後返其家未逾月，乃婿忽來，下車入門，面目黑膩，胸高氣喘。問係吐血疾，自言心中時時作嘔，兩脅刺痛發咳。來求治之。診其脈弦而滑，乃曰：此氣秘也，必有大遂事，暴怒傷肝，乃致是疾。張曰：然。余曰：曾施治否？張曰：有村醫以余為陰虧，命服地黃湯，轉增腹張，乃辭，而求閣下。余為開蘇子降氣湯，又開逍遙散方，付之曰：路遠病勞，歸先服降氣湯，氣當舒，再服逍遙散，血當止，十數日保無恙，無煩再來也。張謝而去，如言服之，月余，遣人來言，主人病痊癒，恐在念，令小人先告知，有暇必衣冠來謝也，余固止之。
