# 年老血崩陰陽兩虛

<!-- source-id: N079:p046 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

鄰人劉錫慶之姊，三醮而仍寡，年近五旬，忽患血崩，村醫以為蹉跌，用發灰地榆類澀之而不效。經月余，來邀余治，見其面白如灰，氣息僅屬，甚不堪。視其脈則沉細遲弱，凡虛象無所不有。乃曰，此病危如朝露，過半月，恐不救也。又貧寒難事藥餌，急欲辭歸，其婿忽止之曰：岳母病如可愈，藥錢我任之，萬一不救，則不必矣。余感其義，乃告之曰：君熱腸如是，余當竭力，雖無旦夕效，然性命或無礙也。投以大劑六味回陽飲（方：附子炮薑甘草當歸黨參肉桂），二日而精神起，然崩則如故。其婿來曰，命似可救，而血崩不止。余曰，君無慮，止血崩實易事，但岳母陽陰兩虛，不固其氣，血崩難止。今有回陽飲以作其氣，再用提補，靡不效矣。又投人參養榮丸，加柴胡，升麻以提之，又加芡實、龍骨以澀之，凡五進而血止，因命專服人參養榮丸，兩月後，偕其婿來斂衽拜謝。就內人取針線數事而去。越數日精心密縷，封而呈焉。並云貧無可酬，聊以手指答救命之恩云耳。
