# 陰火大熾清下無功

<!-- source-id: N079:p056 -->
> 서명: 醉花窗醫案

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

病之奇，有不可解者，徒執方藥論之，輒不效。同譜弟王丹文之母，春仲忽患熱，口渴神昏，發暈出汗，熱如火，幾發狂。其母家弟以茂才業醫，視之知為熱。曰，此陽明正病也。投白虎湯用石膏至一兩，而熱如故。又有鄰人李茂才亦業醫，用承氣湯下之，二便少利，而熱如故。丹文邀余往視，按其脈極沉數，知陰火大熾，而腸胃燥甚。告丹文曰，中無實物，火熱熏心，下之無可下，宜清降之。急用地黃湯加山梔，三黃進。藥服而心頗清，熱如故。是夜忽大雪，天甫明，病者知之，要食雪。丹文以其年老，靳不與。逾時，丹文外出，匍匐出戶，就階取雪，臥啖之，凡三碗許，覺心境頓清；又啖之，歸而臥於床。至夕則熱退身涼，越日而起。三日後，病若失矣。噫！藥則罔效而天降雪以除其病。蓋雪陰寒，不假煙火，較藥之清降勝萬倍矣。醫家無此法，亦不敢用也。
