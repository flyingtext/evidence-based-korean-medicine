# 濕熱內淫實證遺精

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

黃庚垣先生，江西人，以捐餉奉特旨議敘舉人加藩司銜並賞花翎，補西安糧道。道缺甚優，兼家貲優厚，而觀察性尚清廉，接下以寬，故屬下皆頌之。年五十許，曾患遺精病。觀察侍妾數人，幕友有善醫者，以為許多姬妾，必致虛損。用三才封髓丹補之，而觀察又講頤養。日食燕窩、東參以調之，然遺精如故。幕友以為已成虛勞，不可救藥。

一日午後無事，忽召余至署，且命便服，余急趨命，觀察便衣而出，揖而延之上座，余驚問故，觀察曰：患遺精數年矣，曾服湯藥百余付，丸藥數斤，而毫無效。余問飲食何如？觀察曰：雖不能多，然尚非不能食者。老夫子以我為虛癆，故不敢多食也。問咳嗽氣少、發熱自汗乎？曰否。乃告之曰，既無此數者，恐有餘症，非不足證也。觀察驚曰，遺精尚有實症乎？余對曰，大人未窺醫書，兼脾胃虛弱，不特醫者不敢以實論，即大人亦自疑其虛也。豈知遺精之由有數端，相火太旺，夜夢失遺，陽必壯健，宜滋之；飲食厚味濕熱內淫，則迫而失精，宜銷導之；久曠氣充，精滿而溢，宜疏泄之。此外，中氣下陷，清陽不升，則亦遺；色欲過度，心腎不交，則亦遺。又有恐懼暴怒，精竅滑而不澀，皆能致遺。若或坐或臥，無故遺精，則為虛極之症，最為危險。俗醫不細求其故，不分虛寒實熱，見遺精者，則曰色欲過度也；又曰年少好淫也。致病者，多受不白之冤，而治之多不效。遂歸咎於病之不可治，不亦惑乎。

觀察蹶然起曰：聞君講解，無不確當曉暢，心為之開，然則我之遺精絕非虛症，請一視之。乃診其脈，緩而堅，右關尤甚。告之曰，大人之病，所謂濕熱內淫是也。胸膈常患悶滯，大便頗形後重，當消導之。進以震亨滲濕湯。觀察閱方內有黃連恐不宜，且厚朴、蒼朮恐傷胃氣。告曰，胃苓湯是濕熱要藥。平胃散者，培卑監而使之平，非削平之謂也，前輩言之甚明，此方用黃連川芎素亦疑之，細思其理，苦能燥濕用黃連而焦炒之，用其苦非用其涼也。濕熱能瘀血，用川芎以行之，震亨此方，具有深意。大人成見在胸，一誤豈容再誤，他人必謂此方，非治遺之藥，豈知治病必求其本，本治而末不治者，未之有也。請放心照服四付，常服香砂六君丸以調之，不但精不遺，即飲食亦當倍也。觀察如言服之，五日後，約晚飯，至則告曰，前聞君言甚有理，而心竊疑之，今服君藥，遺已止，果覺精神增健，食量亦佳，並陽事亦壯。非君妙達精微，幾乎冤我，可見醫道無方，在究其理而變通之耳。後余諸蒙獎許，即內艱而歸，猶寄函問訊者數四。
