# 痰厥頭痛

<!-- source-id: N079:p093 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

里中王云集夫婦，習天主教，精於技藝，大而土木之工，小而鐘錶之細，以致裁衣治膳，騎射技擊之術無不通，亦無不精也。而清貧如冼，夫婦誦經奉佛，意氣淡泊，鄉黨皆敬之。壬戊春，得腦後疼，起臥不敢轉側，動則如針刺。請王槐堂茂才治之，以為風也，散之不效，乃邀余治。診其六脈浮滑，兩寸俱出魚際者半寸。告曰，此痰厥頭痛，非外感也。甚則為剛痙，必至角弓反張，身體強直；緩則半身不遂，口眼歪斜，實大症也。止頭痛，極易事，但此病須服藥數十付，乃除根。不然疼雖止，將復發。王以貧辭，乃曰：但能止頭痛則舉動自如，余聽之可也。乃示以東垣通氣太陽湯（柴胡、升麻、黃耆各一錢，防風、羌活、陳皮、人參、甘草各五分，槁木、青皮各三分，黃柏一分，白豆蔻仁二分）二服，痛果減，遣人告余，擬余易方，余曰，方無可易，但服至五六付，痛全止矣。王遵之，痛遂已。其妻勸其再治，其夫苦無藥資，遂止。余近聞其手足遲重，飲食不思，且皮膚疼痛不自覺。噫！貧人獲此大病，若跌撲而痰壅以死，猶為了當，不然恐沉綿床褥，累月經年，其罪狀有不可以言語者，傷哉貧也。
