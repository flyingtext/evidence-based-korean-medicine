# 長夏熱病

<!-- source-id: N079:p098 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

楊清禮之女，年六七歲亦得熱症，請江湖士常治之，常以為溫，用荊防敗毒湯不效。又請朱醫治之，朱素作賈，粗知藥性，又以為風，用通聖散而熱仍不退。楊不得已，邀余治之，見其脈象沉數，身熱如火，告曰，此與余舅母同病，並非風，亦非溫，但清其血，熱自止。若用荊防等發之，要知春冬腠理為風寒所閉，故用散藥解之。此時皮膚皆開，長夏酷熱，散之不益耗其氣乎。楊曰，醫者意在發汗。余曰，無汗，汗之可也。有汗，何容發也。楊又謂，醫以為此汗是熱天之汗，非應出之汗也，故發之。乃曉之曰，汗無非人身精液，容有二乎。此時之汗從令愛身上流出，難道以藥發出之汗，從他人身上出乎！必以為此時之汗為非汗，以藥發出之汗為真汗，必使用麻黃柴葛，使汗出不已，真氣耗竭而後已。醫道不通至此，幾何不誤人性命耶。楊語塞。請一方，乃仍用三黃解毒湯。楊癡物，久不見，未知應效否，余不願問之，然亦難保也。
