# 風痰昏亂

<!-- source-id: N079:p029 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

里中段某之妻，年廿餘，忽患昏亂，渾身顫汗，口蹇不能言，腹中滿悶，顛倒欲絕。其家以為祟，招女巫驅之。女巫多索粟帛，用香褚祈禳之，病不減。三日後，求余視之，診其六脈亂動，沸如泉湧，且手足乍屈乍伸，不可把握。乃告之曰，此風痰也。少年氣盛，下之則愈。乃命服祛風至寶丹（滑石川芎當歸甘草白芍防風白朮石膏黃芩桔梗熟地天麻人參羌活獨活梔子連翹薄荷麻黃大黃芒硝川連黃柏細辛全蠍）。至晚則大便出紅黃穢物數筒，次早而安。又請往視，六脈俱平，神氣清爽。告曰，病已去，不必服藥，但避風寒，節飲食，不久痊癒。半月後酒肉來謝，余知其貧，卻之。
