# 脾濕停痰上擾心包

<!-- source-id: N079:p077 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

又司徒芝鄰方伯藩秦時，體素肥。時各省提拔軍餉，員弁充集會垣，而庫款支絀，芝翁憂形於色。至夏，得癡呆病。坐臥不安，時而獨言獨語，時而渾身癢搔。又合眼則睡，睡則夢二鬼在前：一自縊者，索掛於項；一無首者，以手提頭，發蓬蓬，血模糊。以是，不能獨臥，不接屬員者十餘日。延醫治之，皆曰冤業，恐不起。又易一醫，則曰心血虧損，用天王補心丹，飲食頓減，及飭門者請余，余入見，則曰：病至此，恐不能治，但請君決之，果何經受病，須詳悉言之，勿隱護也。按其脈，則六部弦緩而滑，寸部浮取尤甚，知是痰證，乃啟芝翁曰，大人乃脾濕停痰，又加以勞倦傷脾，心火浮動，以致痰涎繞心包絡，故時迷時悟，平時必喜唾痰，唾則胸腹寬舒。此時痰涎停結，必不能唾。且時而發煩，時而動躁，時而口渴，時而心顫並手足，時而二便不利，皆痰為之。芝翁曰：二鬼何物？余曰：二鬼亦神魂煩亂所致，其實無之，大人不必多慮。病雖多端，卑職保能愈也。芝翁喜，問服何藥？余曰：大人病非湯藥可療，須先以礬鬱丸吐之，次以控涎丹通之，再多服去痰健脾諸藥則無慮矣。芝翁急索礬鬱丸，余以此藥市中多無，乃制而送之。服數粒，則刻許而吐痰絮膠黏，色兼青黑，自謂心境頓開，欲再服，余曰：痰已吐，再服恐傷胃氣。繼以控涎丹投之。兩日後，設便飯邀余，扶杖告余曰，兩夜二鬼不見，神氣亦清，君之高名實所佩服，敢問不治成何症？余曰，若不治，不癲則癇，甚則成痰厥。其幕友皆來周旋，飯後面歸。不數日，余以內艱、聞訃回籍辭喪。至八月，芝翁以官錢案發，奉旨革職。案定，其閽人黃五絞死，就刑之際，芝翁聞之，痰厥而歿於館。後小梅來書，猶道芝翁之死如君言焉。
