# 憂鬱致疾腿目漸廢

<!-- source-id: N079:p055 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

李蓮芳茂才，少與余共筆硯，後以童軍屢蹶，商於楚。後失業歸，復矢志功名，遂入縣癢。蓮芳少失怗恃，三娶而仍鰥，煢無子嗣。丙辰余自京歸，已敗累矣。以憂鬱故，腿漸廢，目漸瞀。然步履出入，尚可作字，憫其貧，攜之入秦，經理館事。繼，余以內艱旋里，念蓮芳無依，因薦於朝邑主薄馮子安作幕，馮亦同鄉，又雜職，蓮芳雖非素優，然小心持算，無不井井有條，賓東相得。而蓮芳私念年逾五旬，妻子全無，顧影增淒，倍形憂鬱，明年秋，單車而歸。余以為賓東不合，急視之，則蓮芳兩目起外翳，腿遲重不可曲伸，且馮以缺瘠告病，不得不歸矣。因求余治其目與腿。余診之，心肝弦急，兩尺似有似無。倉卒難顯言，因勸曠懷自慰，病非旦夕可療，靜心凋攝數月，再作計議。蓮芳聽之，而家計寥寥，益不自釋，目益盲，腿益滯。

有趙城眼醫，名家也．一年來介兩次，凡外障雖數年，無不針之而愈者。余甚佩服。急請視蓮芳眼。醫審視之曰，障皮尚嫩，恐不勝針，再數月，皮厚色蒼，一撥而去矣。眼醫出告余曰，瞳仁已壞，治之亦斷不效，不如聽之。前乃托言耳。半年許，果歿。余挽一聯云：「君罪伊何，乃如左邱盲目，孫子病足。天心莫測，竟使黔婁失婦，伯道無兒。」
