# 肝木克土

<!-- source-id: N079:p088 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

介之城東，馬如村郭某，在城貨燭，人素迂謹。夏間由介赴祁，往返數四，以躁急故，患胸滿不食。時我介疫氣流行，自以為染疫，急服散藥，而氣乏聲微，愈不可耐，別易一醫以為腎虛，用醫家腎氣丸補之，服四五劑轉益甚，幾至昏不知人，乃轉人延余治，至其家，問何病？則曰，成虛癆矣。問午熱自汗，咳嗽氣喘乎？曰否。然則非虛癆。提腕而診之，則兩寸尺俱平平，兩關皆堅而滯，而右關微帶弦象。乃告之曰，此肝木克脾土也。病由一時氣不遂，兼發急躁，以致肝氣壅塞脾胃，因而胸滿不食，理宜平肝清燥，醫者以桂附補之，脾胃愈塞，不增甚何待乎。此時宜先解桂附之藥力。然後進以疏肝健脾之品，不過半月保無事矣。病者喜急索方，乃開平胃散加山楂，麥芽以消之。病者爭曰，余素無食積，兼久不進食，君用銷食之藥，不亦悖乎。余笑曰，君第知平胃敞為銷食之藥，不知君脾胃中雖無食，卻有桂附，我之用平胃散非銷食，乃解藥毒也。藥毒不解，胸中終難爽快。人第知平胃散銷食，而不知藥亦積，非此不能開脾胃之路，此俗醫拘其方，而不究其理，所以多誤也。病者欣然服之。越三日又請視之，則胸中寬展，漸思食矣。乃繼以逍遙散理其脾而清其肝。告曰，不五劑君必起，但服香砂六君子丸半斤，便更壯健。郭如言服之，半月後仍入城貨燭矣。
