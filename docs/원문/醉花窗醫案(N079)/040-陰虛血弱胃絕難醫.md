# 陰虛血弱胃絕難醫

<!-- source-id: N079:p040 -->

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

鄰人劉錫慶，商於楚，年三十餘無子，父母共憂之。娶妻數年，百方調補終莫效。一日劉忽患腹痛，邀余往視。眾以為霍亂，服霍香正氣散不效。診其六脈沉弱，知為陰虛。因曰，君腹痛必喜按，且時作時止，非常病也，且痛發必在臍下。劉曰，然。乃投以七味都氣湯(方：熟地山芋山藥丹皮澤瀉茯苓五味子)加肉桂二錢，兩服而痛止。歸後家人問其病，余曰，此陰虛血弱，腹痛易治，惟兩尺細僅如絲，毫無胃氣，恐命之不久也。越年許，余白京師歸，已於數月前，以瘵終矣。劉本孤子，家極貧，以劉賈少裕，劉歿後雙親衰獨，撫養無人，兼兩餐不繼。見者皆惻惻云。
