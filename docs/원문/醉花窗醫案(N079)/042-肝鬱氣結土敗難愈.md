# 肝鬱氣結土敗難愈

<!-- source-id: N079:p042 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

里中田大授，家少裕，而年老無子，妻悍不敢置妾，後以失業窘於財，鬱而為病。城中有老醫名榮同者，田素信之，請其診視。榮曰：風寒外感也，散之不效。又視之曰年老氣虛也，補之益甚。榮窮於朮，乃邀余治。診其肝脈滑數，脾部見弦急，且三至一息。乃曰，君所患為肝氣鬱結，木來侮土，土已敗矣。病可小愈，命不可保也。田似嫌其唐突，請示一方，余以逍遙散合左金丸進之。數服而病減，進飲食矣。又請視之，診其肝脈稍長，而脾脈如故。知不能愈，乃以逍遙散敷衍之。半月，精神爽健，出入遊行。值村中演優戲，相見於廟廡，告余曰，病已全除，當無恐。余曰，脈至不息方可，後半年，余赴都，及來春歸，詢之，已欹歿數月矣。
