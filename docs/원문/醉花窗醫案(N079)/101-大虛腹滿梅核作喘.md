# 大虛腹滿梅核作喘

<!-- source-id: N079:p101 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

鄰人楊本檀之岳母，貧不能自存，衣食悉仰給其婿，而楊亦失業家居，日用頗窘，面目相覷，日抱憂鬱，以愛女故，遂增咳喘，肚腹脹滿，飲食不思，楊不忍坐視，邀余治之。至則面目黃瘦，氣息僅屬。告余曰，不食數日，喉中如有物塞者，咽之不下，唾之不出，他人以為時氣，請一決之。診之則六脈沉弱，兩尺如絲。告曰，此大虛證也，須大劑峻補之方可，且藥必得數十付，再能節思忍氣，可保萬全。若喉中之物，即所謂梅核氣，並非時氣，藥不三服可去之。楊曰，但使喉中通利，飲食能進，其余緩緩保養。至精神大虛，用藥調補，弟近況實艱，藥資無從出也。余曰：亦是，乃開四七湯加桔皮，香附以疏之，藥入口至夜覺喉中之物如墜於腹者，呼吸通利，藥兩進則思食，而精神作矣。楊疾告余曰：家岳病似全愈。余曰：不然，四七湯只能疏通道路，與其本病毫無干涉。蓋病日久，故覺爽快，若再遲數日，恐飲食仍不進也。且脈象甚不佳，不如聽之，徒費銀錢無益也。楊然之。
