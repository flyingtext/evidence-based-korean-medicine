# 邪風中府卒然昏噤

<!-- source-id: N079:p008 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

商人穆棲桐，吾介東鄉人也。在京為號中司事。體素肥胖，又兼不節飲食。夏有友人招飲，灑後出飯肆，卒然錯噤，口不能言，四肢不能運動，胸腹滿閉，命在旦夕，車載而歸。其契友南方人，頗知醫，以為癱也，用續命湯治之，數日無效。乃轉托其同事延余視之，余診其六脈緩大，惟右關堅欲搏指，問其症，則不食、不便、不言數日矣。時指其腹，作反側之狀。余曰：癱則癱矣，然邪風中府，非續命湯所能療，必先用三化湯下之，然後可療，蓋有餘症也。南醫意不謂然，曰：下之亦恐不動。余曰：下之不動，當不業此。因立進三化湯，留南醫共守之。一飯之際，病者欲起，腸中漉漉，大解穢物數次，腹小而氣定，聲亦出矣。惟舌根蹇澀，語不甚可辨，伏枕視余，叩頭求命。因問南醫曰：何如？南醫面赤如丹，轉瞬間鼠竄而去。因命再服二劑，神氣益清。用龜尿點其舌，言亦漸出。不十日鋪東逼之歸家。余在京供職，今不知其如何也。
