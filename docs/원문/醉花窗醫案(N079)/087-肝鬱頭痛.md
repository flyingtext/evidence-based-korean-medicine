# 肝鬱頭痛

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

又有楊姓名清禮者，鞋賈也，家頗居積，性好符咒逢人輒談丁甲，並以法水治病，時有小效，而其實胸中齷齪，塊然癡物也。與其弟每同居，弟性好揮霍，然善理財，以故日用應酬諸費能源源接濟無缺，兄則不能沾手。辛酉冬，其弟應武童子試赴府，禮忽大病，頭痛如裂，身熱如火。急請余治。燈下診之，肝滑而數。告曰，此必有大不遂事，以致肝鬱頭痛，平肝痛自止。然何忽至此，暗詢之乃知狎邪（妓院）之費，內外交迫也。乃處以左金丸，三更後頗可，適其弟入武庠。報馬絡繹。禮不顧嚴寒，單衣而出，又召外感，次日病益甚。又請余治，余不耐與此輩交，峻絕之。楊日日易醫，且醫者日數人，而病轉甚，將近狂。其弟問余，余曰，此係心病。非藥石可療。置而不問，過年當自已也。其弟笑頷之。除夕果減，元旦後日愈矣。知者見余無不服，余言觀此二病，知此等症候，雖華扁亦無可如何也。不失人情之論，不益信哉。
