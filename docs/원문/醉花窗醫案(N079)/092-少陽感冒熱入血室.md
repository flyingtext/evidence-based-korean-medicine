# 少陽感冒熱入血室

<!-- source-id: N079:p092 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

同譜王丹文，續弦至四而仍病。始以為不禮於姑，鬱症也。清陰雨蒼茂才治之，用逍遙散或效或否。月余又請李笛仙茂才治之，問其癸水不至者兩月矣，始疑為孕，繼覺其非，以瘵治之，用十全大補湯加桂附，初服則可，繼服而熱增矣。遷延之久，無計可施，專車迎余。診之脈細數，而肺部尤兼滑象。告曰，此熱入血室症也。初因少陽感冒而起，宜小柴胡湯加生地、丹皮等，以涼其血，則病當愈。陰之逍遙尚近理，李之桂附，則直陰本虛，又加熱藥以熬煎之，是油沃火也。此時必喘咳並作，午後發熱，頭目昏暈，精神倦怠。解外感，則外感已散；清內熱，則真金久為銷爍，恐無效也。丹文急請一方，乃以東垣拯陰理癆湯進。告曰，服後當有效，然此病總以癸水為主，癸水至則可治，若癸水不至，雖效亦無益也。越兩日，丹文來喜曰：服兄藥凡兩劑，病已減半，再服可乎？余曰：可再服兩劑，再看可也。又兩日，迎余去，診之，數象稍變，而虛弱特甚。惟肺部火不退，乃易以人參救肺湯。三服後，丹文又迎余，問其癸水仍不至，乃辭焉。……午月末，余由定回介，問之，則四月中已歿矣。
