# 脾勞過食誤下致危

<!-- source-id: N079:p013 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

商友王定安庵，幼在京，權子母，工於心計而貪詐蝟鎖，兼嗜麵食，年四十後，得脾勞病，遇冬更甚，醫藥數年矣。余常勸其節食節勞，而以經營生息，刻無暇晷。每食過飽，則痰嗽喘滿，終夜不寢。壬子冬，疾增劇，乃俯余治。余進以健脾諸品，痰嗽少止，而狂啖如故，因之時發時愈。病甚則服藥，稍痊則不肯，余以其不能調攝，置之不問。年終，風事匆匆，勞擾更甚，一日早起，則面目四肢俱浮腫，而煩滿益不堪，余告其同事曰：脾絕矣。尚未立春，雖交木令，尚可到家，立春後則不能矣。蓋肝木克脾土，促春必難過也。同事者不為意，延之。繼請一同鄉醫視之，則曰：此水病，下之則愈矣。問用何藥？則曰：舟車丸。余力陳不可，而病者誤信之，急服三錢，腫未減，而臥不能興。診其脈若有若無。同事惟恐其歿於鋪，急覓車傅人送還，出京甫數日，歿於松林店。計其時，立春後五日也。籲！人生固有命，而始則不知愛養，繼則不信良言，迨疾不可為，又信庸醫，以速成其烈屬，亦愚之甚至矣。故錄之，以為不知調攝者戒。
