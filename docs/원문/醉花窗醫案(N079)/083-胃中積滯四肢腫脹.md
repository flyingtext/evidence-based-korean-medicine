# 胃中積滯四肢腫脹

<!-- source-id: N079:p083 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

李賡堂先生以武進土為溫州都司，後升江西參將，缺甚瘠，告而歸里。其長子號東樵，以北元作戶郎，次子號蓮峰，屢薦未售，博極群書，在里中與余往來甚契，賡堂先生雖林下，而性情伉爽，排難解紛，里黨中多賴之，庚申春，東樵以都中官錢鋪案發，下刑部獄，越年許，案未結，賡翁在家憂之。辛酉夏，忽患胸膈滿悶，飲食不進，遂致手足腫脹。延醫視之，疑為水腫，用利水藥不效。繼更一醫以為虛，用腎氣丸仍不效，而腫益甚。適余以其族人喪葬遇蓮峰，即請余治。診其六脈堅實，右關硬欲搏指。乃告日，此飲食傷胃，有餘病也。平日多食厚味，積滯胃中，胃主四肢，胃氣和，則四肢安；胃氣滯，則四肢脹。必至之勢也。況胃氣既滯，杯勺茶湯皆能停積，雖見小便不利，其實非水能氾濫發為水腫，徒利水，必不效。且此病由濕熱內蘊，再用熟地以澀之，跗子以塞之，不增脹何待乎！惟年老陽虛，脾胃素弱，治無速效，但欲消腫，則易易耳。用滲濕湯加枳實、木通、牛膝銷導之。蓮峰似嫌其峻，余曰：此急則治標之法，但令胃氣通，則積自銷，腫自愈，不必專治小便，小便必無不利。後再用健脾養胃藥治之，須三五月乃成功也。乃服之，一劑而腫皺，三服而十去其六。蓮峰來書云：不意君久持文譽，出其余技，竟使頓失沉屙。昔人云：事親者不可不知醫，弟真赭顏無地矣。明日更煩一視，敬當執帚一待。余往視之，脈稍和，而右關如故。告曰，胃氣已行，尚未通也。問小便利否？曰，未利，乃加葶藶，二醜疏之，即小便十餘碗，肚腹寬舒，飲食亦進。繼以資生健脾丸方，湯服之。告曰：必厭湯藥，服丸可也。蓮峰以秋試在即，欲赴省，恐再發腫。余曰：但令勿服附子、東參、熟地之類，漸而培養之，必無恐，惟老人氣虛，多需時日耳。蓮峰見無礙，遂束裝赴試。賡翁之長女亦知醫識字，又有舊僕亦業醫，蓮峰走後見其羸瘠不堪，力勸其服熟地、麥冬並燕窩、東參等，大補氣血；又見其能食，以雞鴨魚肉日日調養之。未半月，腫雖不作，而胸腹仍滯，小便仍不利矣。

蓮峰出闈而歸，又邀余視，則兩尺如絲，左關有促象，知非吉象，以六君子丸敷衍之，遂辭而不治焉。
