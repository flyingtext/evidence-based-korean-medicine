# 肝氣凝結而致寒疝

<!-- source-id: N079:p025 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

常少張炳堂同鄉，甲寅得疝病，腎囊重墜，膀胱時作痛楚，適入值圓明園，出城門路砌以石，長數十里，行者車傾側，車中人四肢竭力支持，多以為苦。炳翁一往返，疝痛甚，腎囊欲腫。延醫視之，倉卒不暇細詰病狀。因曰：腎囊腫多是濕熱下陷，利水清火痛自除。炳翁於歧黃素憒憒，急服其藥，痛增甚，腰脅不可屈伸。乃命余視，診其脈象沉遲，季肋丸丸，直上直下。乃曰，此寒疝也，病由肝氣凝結，脅下如柱，非溫血養脅不可，利水清火，不增甚何為。乃為合茴香丸一料送之，服未一兩而痛減。適有盛京視學之命，炳翁即束裝出關。冬季來函，則曰，藥已服完，疝不再發，余猶以溫養告之云。
