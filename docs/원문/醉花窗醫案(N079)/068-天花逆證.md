# 天花逆證

<!-- source-id: N079:p068 -->

> 원본 파일: `N/N079.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

鄰人趙楚仁，天津典商也，家小康而婦甚悍，生數女一男，極鍾愛之。戊午夏，其五女，年六七歲，發天花。遣人邀余視之，見其形密如蠶種，平板細碎，幾乎遍體。而口唇外，尤環繞無隙，且手足發厥，飲食不進。問幾日？曰，兩日矣。余曰：發熱否？曰，不甚發熱。問二便如常否？曰：大便溏，小便過多。告曰，痘症發熱，三朝自頭至足，漸次見點，須顆粒分明，形色紅潤，飲食二便如常方好。今令嬡之痘，不兩日一齊擁出，且形色、飲食、二便如此，兼帶鎖口，真逆症也，恐治亦不效。其婦嫌余言唐突，語涉怨懟，其夫目怒之，乃止，余曰：來看病非生氣，請待以十日，果有能治之者，余當師之，拂衣欲出。其夫力求一方，乃以升麻葛根湯加參耆付之曰，此敷衍法也。趙服之，越日而痘稍起，急遣人告余曰，痘有轉機，可再視之，余力卻之，趙似怨余，乃請他醫。不十日，痘靨而斃。其家乃信余言，後遇趙於街，長揖作謝。余曰，病不能治，何謝為？趙曰：早聽君言，可省藥錢數貫。余曰，此亦有定數，不費此錢，恐不歿也。趙含淚而去。
