# 診脈如審案

昔人謂用藥如用兵，余嘗謂診脈如審案。其微言妙旨，前輩論之詳矣。惟仕才先生四言要訣，簡明切當。其云：四時之脈，胃氣為本，尤為診家要著。蓋胃氣者，脈之神也。所謂神者，極力形容而總歸之曰有力。竊謂有力二字，尚不足盡神字之義。蓋有力而兼活動，不疾不徐，不軟不硬，方是如春風弱柳氣象。本此參之，百不失一。審時，有正兇，有佐證，有致事之由，有受害之所，有連坐，有掛誣。審之既確，而刑罰之輕重隨之。姑就一端言之，如脾濕停痰一證，脈必沉滑。則沉滑者，正兇也。而脾濕必便難，停痰必減食，此佐證也。濕或飲水過多則兼弦，勞倦思慮則兼弱，此致事之由也。或因濕而泄瀉，或因痰而咳嗽，則泄瀉者，右尺必虛；咳嗽者，右寸亦滑，此連坐也。且脾濕者，飲食不能健運，精液必致不充，則左尺必澀，此掛誣也。但識定正兇，健脾銷痰，病皆自己。若治泄瀉而止之，治咳嗽而清之，則拋卻正兇，誅伐無過，必至不能治病，而反增他病也。故用藥不過古人成方數十，傳之於世，而用之或效或不效者，非筆下之憒憒，實指下之未了了也。

吾嘗謂診脈，須合三部十二臟腑，參考而斟酌之，方有定見。若診寸而忘尺，診右而忘左；滑則治其痰，數則去其火，雖有小效，亦難去病，況審之不清，而未必效乎。俟高明斟酌之。
