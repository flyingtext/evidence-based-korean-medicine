# 審證與慎藥

治病之道，如鑰之啟鎖，無論顯然相反，即相近者，辨之不明，治之不當而亦無效驗。其間毫釐之差，千里之謬，如痰之與飲，皆水也，而有陰陽之分。溫之與熱，皆火也，而有微甚之別。其間或虛、或實、在腑、在臟，尤須詳審。審之奈何？形、氣、脈、證是也。合而參之，斷無背謬。俗醫知有心肝脾肺腎。而置六腑於不問，不知人生全以胃氣為主，胃氣盛，則臟腑皆盈，胃氣衰則臟腑皆敗。不但飲食穀氣，全憑胃經生髮，即病者服藥，亦先入胃腑，而後達於它臟，故曰：「得胃者生。」又診脈以胃氣為驗。然則胃者生死之關也，不明乎此，而能達精妙者，未有也。且一病只有一法，故余治病未嘗私自立方，所開皆古人成方，又不敢妄為增減。每見病者粗識字，則厭故喜新、求日易方藥，不知藥之為物，非五穀平和之氣，利此則害彼，醫士用之不當，必有誅伐無過之慮。久之，胸中混淆。病者非病病，乃藥病也，富貴之家，尤易犯此，曾屢屢言之，以為以藥餌調養者成。
