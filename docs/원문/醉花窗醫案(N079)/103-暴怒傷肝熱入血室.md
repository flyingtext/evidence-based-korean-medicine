# 暴怒傷肝熱入血室

<!-- source-id: N079:p103 -->
> 서명: 醉花窗醫案
> 원본 파일: `N/N079.txt`
> 원본 SHA-256: `101552b89979b1d41f1d755781f87603f52b5240c002b9e2888edbc49cedb256`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

同譜弟李曉圃，以茂才得廣文，後隨其堂兄裕州牧理幕事。裕州多得其力，後其堂兄以撚匪滋擾罷任，曉圃隨後任守城出力，保舉五品銜。辛酉回介，與余往來甚契。一日余至其家，適其侄在坐，似有所求。曉圃代白曰，舍侄因侄孫婦病甚危，已閱十數醫矣。愈治癒甚。而此時尚不知何病，擬請大兄一視，果不可為，好備一切。余以至好隨入視之，見病者蒙衾側臥，形如露骨雞，而面唇甲爪俱白無色。即曰，此血脫象也，得毋產後乎。其母在旁曰，自四月小產後至今不起數月矣。因私計曰，此血大虛之症，用聖愈湯當有效。細視其頭面，血絡帶紫色而棱起，又疑其血分有熱，診之，則六部沉數，左關肝堅欲搏指。乃頓悟曰，此暴怒傷肝，熱入血室之候。其人必性情素暴，此病因忿怒而生，此時必兩脅脹痛，目赤耳鳴。且土受木克，脾經大虛，脾虛則肺亦傷，當時而咳嗽，時而泄瀉，時而發熱，時而心驚，雖非癆瘵相離不遠。趕緊施治尚有轉機，若再遲延，恐無及也。病者就枕點首，嫗婢亦以為然。出而告曉圃，大家皆稱快，因以加味逍遙散合左金丸並處之。告曰，雖不全愈，亦當有效四服後再視也，越五日，遇曉圃於酒市，問之，則病人不願服藥，緣家務不齊，曉圃亦只聽之而已。
