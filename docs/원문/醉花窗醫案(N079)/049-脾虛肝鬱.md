# 脾虛肝鬱

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

先生之弟婦，患頭痛發嘔，飲食不思．時瘟疫盛行，疑為時症，余偶到塾，其侄蘭芬兄言其狀，並邀之治。問身覺憎寒壯熱乎？曰，否。問身痛鼻塞乎？曰，否。然則非時症。診其脈，則左關弦滑，余俱細弱。告蘭芬曰：此脾虛肝鬱也，作時證治，必散之，虛而散，則大誤矣。蘭芬請一方，因以逍遙散進。余過而忘之，越數日，見蘭芬，告余曰，藥才二服，病全除矣。
