# 思慮傷脾痰擾心包

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

備三之夫人，工詩善畫，刺繡尤冠一時，人亦風流自喜，詞辯滔滔。余在備三處閒談，諸寅作斗葉之戲，余不喜此事作壁上觀，晚餐甫設，有媼自內出，啟備三日，太太不知何故，忽患心煩發嘔，坐臥不安，聞王大老善醫，急請入視。余偕備三入，則二婢扶坐，粉汗淫淫，作捧心狀。急診其脈，脾部細弱，左寸滑數特甚。乃曰，夫人所患是脾虛停痰症也。蓋由思慮傷脾，飲食不化，平日必有健忘驚悸之疾。此時痰涎繞心包絡，故煩嘔交作。須先清其痰，後理其脾。清痰須用蓮子清心飲（黃芩麥冬地骨皮車前子甘草石蓮子人參黃耆茯苓），理脾須用人參歸脾丸。病以漸來，亦以漸去，旦夕難全愈也。乃先以清心飲投之，二日而煩嘔止。再進歸脾湯，十日而四視之，病若失矣。
