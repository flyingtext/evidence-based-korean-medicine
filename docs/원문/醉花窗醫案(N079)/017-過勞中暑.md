# 過勞中暑

<!-- source-id: N079:p017 -->

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

伶人某，忘其名，四喜部名旦也，六月初，演泗州城劇，眾稱善。有某官愛其藝，又出錢命演賣武一折，身體束縛，刀矛劍戟之類，旋舞越二時許，卸妝入後臺，則大吐不已，腹中絞痛，急載歸家，吐止而昏不知人，推之不醒。其師怒，遣人尋某官，某官知余名，又轉同鄉請余診視，乃偕之往，則剩粉殘脂，猶暈面頰，汗出如油，氣息促迫，呼之不應。提其腕，則六脈浮濡，按之反不見。余曰：此中署陽邪也，命守者以熱鞋熨其臍，刻許，稍醒。逐以大劑香薷飲進之，二日而安。後三日，有投小片者，不知其人，問閽人，乃知其伶來謝也，余卻而避之。
