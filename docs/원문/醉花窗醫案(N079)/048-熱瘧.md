# 熱瘧

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

先生之母，余太師女也，年過八旬，頗壯健。夏秋，忽得瘧疾，發則如火燒身，狂叫反側，他醫用藥截之不效。招余治之，見其目如赤珠，口乾唇破，時時呼冷水。問二便，則小便如血，大便閉數日矣。按其脈，則六部弦數尤甚。乃告日，此熱瘧也。單熱不寒，須內清其熱則火退而瘧自止。若徒用截法，萬無效理。因投以大劑白虎湯，重用石膏至兩許，二服而熱退，四服而瘧已．
