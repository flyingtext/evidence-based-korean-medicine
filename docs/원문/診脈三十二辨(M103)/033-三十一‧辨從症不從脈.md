# 三十一‧辨從症不從脈

<!-- source-id: M103:p033 -->
> 서명: 診脈三十二辨
> 원본 파일: `M/M103.txt`
> 원본 SHA-256: `34ee6a624273c7f7c5afbd695f7a7a624d622fadaf1efa84b5dcd68e7b461dfd`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

脈語曰。脈浮為表。汗之常也。亦有宜下者。脈浮大。心下硬也。脈沉為裡。下之常也。亦有宜汗者。少陰病。始得之反發熱。麻黃附子細辛湯微汗之是也。脈促陽盛。常用葛根芩連清之矣。若脈促厥冷。為虛脫。非灸非溫不可。

此又非促為陽盛之脈也。脈遲陰寒。常用乾薑附子溫之矣。若陽明脈遲。不惡寒。身體濈濈汗出。則用大承氣。此又非諸遲為寒之脈矣。是皆從症不從脈也。世有切脈而不問症者。其失可勝言哉。
