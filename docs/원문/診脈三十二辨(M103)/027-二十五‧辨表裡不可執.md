# 二十五‧辨表裡不可執

<!-- source-id: M103:p027 -->
> 서명: 診脈三十二辨
> 원본 파일: `M/M103.txt`
> 원본 SHA-256: `34ee6a624273c7f7c5afbd695f7a7a624d622fadaf1efa84b5dcd68e7b461dfd`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

脈浮病在表。脈沉病在裡。此表裡之綱領。亦有見表症。其脈不浮。見於肌肉之間。按之不足。輕舉有餘。如波涌之狀。泛上而急。亦表也。有見裡症。其脈不沉。見於肌肉之間。舉之不足。按之有餘。如漫流之水。沉靜不急。亦裡也。又寸盛亦主表。尺盛亦主裡。如此方盡表裡之義。
