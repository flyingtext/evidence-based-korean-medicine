# 三十二‧辨形氣宜合脈

<!-- source-id: M103:p034 -->

> 원본 파일: `M/M103.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

脈為人之本。形乃人之標。標本宜相應。故形盛脈大為順。脈小為逆。形瘦脈小為順。脈大為逆。暴病有餘。形盛脈洪實為順。脈微而虛為逆久病不足。形瘦遲緩為順。脈數而實為逆。經云。形盛脈細。少氣不足息者危形瘦脈大。胸中多氣者死。信然。
