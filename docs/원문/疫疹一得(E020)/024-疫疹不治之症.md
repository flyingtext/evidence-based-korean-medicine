# 疫疹不治之症

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

疫疹初起, 六脈細數沉伏, 面顏青慘, 昏憒如迷, 四肢逆冷, 頭汗如雨, 其痛如劈, 腹內擾腸, 欲吐不吐, 欲泄不泄, 男則仰臥, 女則覆臥, 搖頭鼓頷, 百般不足. 此為悶疫, 斃不終朝矣. 如欲挽回於萬一, 非大劑清瘟不可, 醫家即或敢用, 病家決不敢服, 與其束手待斃, 不如含藥而亡. 雖然, 難矣哉!
