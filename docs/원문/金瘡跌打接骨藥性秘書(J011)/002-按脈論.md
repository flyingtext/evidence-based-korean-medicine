# 按脈論

一，凡看脈，先看左手寸、關、尺三部洪大，太陽、胸前及兩脅、小腹陰囊下，若暖可救，兩足脈起可治，肋下動可救矣。

一，凡右手寸、關、尺三部微細沉遲者為外感；身冷、大熱，頭痛及滿身疼痛為外感風寒，要避風為上。忌生冷、鮮魚、肉之類，好酒亦要忌。如此病，即該用敷藥，服宜下藥。若要下藥，過一日只好服疏風散、理氣散可也。

一，凡跌傷五臟不省人事，宜用通關散吹入鼻中，男左女右，有嚏有痰吐出者為妙。

一，凡跌傷打傷，牙關緊閉，用霜梅肉連擦三四次，而後用藥。

一，凡走骱接骨，先服接骨散，急用敷藥，次用糕匣板外面紮緊。
