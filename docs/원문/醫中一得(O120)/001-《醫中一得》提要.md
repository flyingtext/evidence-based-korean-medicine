# 《醫中一得》提要

<!-- source-id: O120:p001 -->
> 서명: 醫中一得
> 원본 파일: `O/O120.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

夫醫之為道，貴手實驗。裘君吉生藏書至數千種，不以大部湊集眾說之書為重，恒調單本小冊之著作在往出自心得，多有發明之處，如外科王洪緒《全生集》、內症王清任《醫林改增》等，立論不多，要皆獨具創見，尤以所載方法無不歷經試驗，遂有不屈不撓之學說垂示於人。此書係顧儀卿先生所著，為裘君假錄於同社曹炳章君。亦因其所論皆屬心得，刊以禆益醫林也。
