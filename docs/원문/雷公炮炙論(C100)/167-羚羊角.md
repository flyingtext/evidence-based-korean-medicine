# 羚羊角

雷公云: 凡所用, 亦有神羊角. 其神羊角長, 有二十四節, 內有天生木胎. 此角有神力, 可抵千牛之力也.

凡修事之時, 勿令單用, 不復有驗, 須要不拆元對. 以繩縛之, 將鐵錯子錯之, 旋旋取用, 勿令犯風. 錯末盡處, 須三重紙裹, 恐力散也. 錯得了, 即單搗, 搗盡, 背風頭重篩過, 然入藥中用之. 若更研萬匝了, 用之更妙, 免刮人腸也.
