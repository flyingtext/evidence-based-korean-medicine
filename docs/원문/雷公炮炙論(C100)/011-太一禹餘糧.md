# 太一禹餘糧

雷公云: 凡使, 勿誤用石中黃並卵石黃, 此二名石真似太一禹餘糧也. 其石中黃向里赤黑黃, 味淡微跙. 卵石黃味酸, 個個如卵, 內有子一塊, 不堪用也. 若誤餌之, 令人腸干. 太一禹餘糧, 看即如石, 輕敲便碎, 可如粉也; 兼重重如葉子雌黃, 此能益脾, 安臟氣.

凡修事四兩, 先用黑豆五合, 黃精五合, 水二斗, 煮取五升; 置於瓷堝中, 下太一禹餘糧, 著火煮, 旋添, 汁盡為度; 其藥氣自然香如新米, 搗了, 又研一萬杵方用.
