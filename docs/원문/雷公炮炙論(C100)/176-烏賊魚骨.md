# 烏賊魚骨

雷公云: 凡使, 勿用沙魚骨, 緣真相似, 只是上文橫, 不入藥中用. 凡使, 要上文順渾. 用血滷作水浸, 並煮一伏時了, 漉出, 於屋下掘一地坑, 可盛得前件烏賊魚骨多少, 先燒坑子, 去炭火了, 盛藥, 一宿至明, 取出用之, 其效倍多.
