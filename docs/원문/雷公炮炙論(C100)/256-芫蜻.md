# 芫蜻

雷公云: 芫蜻、斑蝥、亭長、赤頭等四件, 其樣各不同, 所居、所食、所效各不同. 其芫蜻觜尖, 背上有一畫黃; 斑蝥背上一畫黃、一畫黑, 觜尖處一小點赤, 在豆葉上居, 食豆葉汁; 亭長形黑黃, 在蔓葉上居, 食蔓膠汁; 赤頭額上有大紅一點, 身黑. 用各有處.

凡修事芫蜻, 用糯米、小麻子相拌, 同炒, 待米黃黑出, 去麻子等, 去兩翅、足並頭, 用血餘裹, 懸於東牆角上一夜, 至明取用.
