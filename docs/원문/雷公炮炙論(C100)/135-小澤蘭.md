# 小澤蘭

雷公云: 凡使, 須要別識雄、雌, 其形不同. 大澤蘭形葉皆圓, 根青黃, 能生血、調氣、養榮合; 小澤蘭迥別, 採得後看, 葉上斑, 根鬚尖, 此藥能破血, 通久積.

凡修事小澤蘭, 須細銼之, 用絹袋盛, 懸於屋南畔角上, 令乾用.
