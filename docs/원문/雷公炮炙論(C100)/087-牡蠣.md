# 牡蠣

雷公云: 有石牡蠣、石魚蠣、真海牡蠣. 石牡蠣者, 頭邊背大, 小甲沙石, 真似牡蠣, 只是圓如龜殼; 海牡蠣使得, 只是丈夫不得服, 令人無髭; 真牡蠣, 火煅白炮, 並用瑿試之, 隨手走起, 可認真是. 萬年珀, 號曰瑿, 用之妙.

凡修事, 先用二十個, 東流水, 鹽一兩, 煮一伏時; 後, 入火中燒令通赤; 然後入缽中研如粉用也.
