# 茱萸

雷公云: 凡使, 先去葉、核並雜物, 了, 用大盆一口, 使鹽水洗一百轉, 自然無涎, 日乾, 任入丸散中用.

凡修事十兩, 用鹽二兩, 研作末, 投東流水四斗中, 分作一百度洗, 別有大效.

若用醋煮, 即先沸醋三十餘沸, 後入茱萸, 待醋盡, 曬乾.

每用十兩, 使醋一鎰為度.
