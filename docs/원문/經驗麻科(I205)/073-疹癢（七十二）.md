# 疹癢（七十二）

疹出遍身作癢, 爬搔不寧者, 此毒氣火邪傳於肌膚之間, 不能發出, 與傷寒汗不出而作癢者, 同也. 況諸瘡痛癢皆屬心火, 《經》云:癢者, 火之變也. 又肝木主風, 爬搔不寧者, 風使然也. 肝主筋而運乎爪, 皆心肝二臟之症, 藥宜清風化毒湯主之. 荊芥、防風、升麻、羌活、大力、乾葛、麻黃、桂枝.
