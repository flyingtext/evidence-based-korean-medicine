# 眼赤腫痛（六十六）

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

眼者, 五臟血氣之精華也. 毒氣鬱滯於肌膚者為癰為癤, 而其留滯於精華者則發為眼患矣. 其毒火發露在表, 又在至高之地, 宜用麥冬清肺飲或蟬化散治之. 蟬衣、荊芥、防風、甘菊、川芎、黃芩、柴胡、車前、桔梗、山梔、升麻、木通、膽草, 再加蒺藜、蕤仁、蒙花.
