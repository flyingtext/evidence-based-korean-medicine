# 胃爛發斑（九十一）

胃爛發斑者, 熱甚血復, 里極表虛則發斑, 輕如疥子, 重如錦紋. 紫黑者, 熱極而胃爛也, 十有九死. 如赤斑煩痛宜犀角大青湯化之. 若後有因傷寒者, 或當下不下, 宜汗不汗, 以致熱毒蒸於內, 胃受熱毒而發於皮膚之間. 赤者為斑, 以化斑湯解之;黑者為胃爛發斑, 十無一生也.
