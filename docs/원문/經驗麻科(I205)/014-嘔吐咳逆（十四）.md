# 嘔吐咳逆（十四）

嘔吐者, 胃火也. 胃火上衝, 嘔吐而食不下咽. 咳逆者, 肺火也. 肺火上衝而咳逆不止也. 《經》云:嘔吐者, 邪甚於上. 順其氣, 清其火, 則自止矣, 切勿用薑汁, 有痰在膈, 在經絡非吐不可, 吐中亦有發散之義, 《經》所謂:因其高者因而越之也.

嘔吐不止者, 用葛根煎汁服之, 不能下氣消痰. 嘔噦不止者, 用枇杷葉煎服之, 能止痰嗽咳逆.
