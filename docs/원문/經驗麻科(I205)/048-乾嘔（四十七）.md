# 乾嘔（四十七）

肝肺有毒, 而毒衝於胃, 肺胃受毒在內, 故發乾嘔也.

衝任之火, 上犯清道, 乾嘔無物者, 此臟腑內傷. 若飲食而嘔, 此熱嘔也, 宜用陳皮、黃芩、石膏、竹茹. 飲食而硬塞嘔者, 此咽中作痛閉塞而嘔也, 加味大力子湯. 甘草、射干、豆根、荊芥、防風、陳皮、連翹、苦參、大力、桔梗.
