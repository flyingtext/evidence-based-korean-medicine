# 疹後痢（五十八）

瘄出之後, 食物不謹, 風寒不避, 致傷脾胃, 遂傳於肺, 肺與大腸為表裡, 故成痢疾矣. 又有餘毒未盡, 餘火未清, 則毒移熱於大腸, 而成痢矣, 必須清金涼腸主之. 行血則使膿愈, 調氣則後重除. 膀胱之氣不通則癃秘, 大腸之氣凝滯則後重, 其理一也. 須加杏仁、升麻, 兼消積治之.
