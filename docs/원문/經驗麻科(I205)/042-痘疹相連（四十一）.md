# 痘疹相連（四十一）

痘若現形之後, 有碎密如芥子者, 疹也. 皮肉鮮紅成塊者, 斑也. 此火毒薰灼於中, 急宜解毒, 使斑疹消散, 痘得成功. 《經》云:痘疹連呈甚是奇, 夾斑夾疹總為非, 斑消疹散先解毒, 芩母石膏玄參宜.

又云:疹先痘後小兒哭, 退疹方能痘自來, 莫道寒涼憂冰伏, 時師一見便癡呆.

又云:治疹不治痘, 惟要開其腠, 腠開毒自出, 毒出為寧候.

又云:先退其麻疹, 痘瘡自然發越, 宜服生甘草、防風、黃芩、荊芥、黃柏、玄參、大力、石膏, 再加升麻.
