# 五經熱症（八十三）

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

五經熱症病原分, 熱氣熏蒸上衝心, 譫語妄言神志亂, 犀角黃連可定神. 熱蒸於肝, 則搐搦如驚, 治宜天麻、羌活、膽星. 熱蒸於脾, 則腹脹, 渴飲, 目腫, 大便閉, 宜投枳殼、山梔、大黃. 熱蒸於肺, 喘嗽鼻涕, 兜鈴、貝母、桑皮. 熱蒸於腎, 玄參、知母.
