# 大便秘結（十二）

血氣下行, 大便自無阻滯, 苟熱氣燥結於下, 毒火流住於大腸, 以致津液乾枯不得潤滑, 故大便有秘結之症. 苟不攻其胃則胃實, 胃實則生譫語, 腹脹目赤者有之. 《經》云:毒氣歸胃, 胃氣閉塞, 喘急煩躁不免矣. 急用大黃、栝蔞仁、枳殼潤下以去毒, 外導亦可, 加升麻提之更好, 蓋清氣提上, 而濁氣自下也.
