# 疹後氣喘發熱（一百十二）

大便秘結, 庸醫以為宜投大黃, 二次仍不能通, 但此症非瀉不能回生矣, 速進濟川煎, 內加肉蓯蓉、枳殼、牛膝, 以泄大便秘結. 又加升麻五六分之數, 隨用大黃七八錢之, 則頃刻黑糞先出, 而後大便通泄即安矣. 故用升麻一提則清氣上升, 用大黃一瀉則濁氣下降也.
