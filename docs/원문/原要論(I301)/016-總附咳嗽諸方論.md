# 總附咳嗽諸方論

凡疹回後, 有咳嗽者, 是火氣旺燥, 肺金受克故也. 治宜<ins>清金降火湯</ins>, 用黃芩、黃連、山梔、石膏、花粉、貝母、陳皮、桑皮、杏仁、蘇子、甘草、麥冬、栝蔞仁. 如不應, 外加葶藶、枳殼. 若聲不出, 以清金降火湯作主, 再加葶藶. 倘有煩躁腹脹, 瀉痢不止, 聲啞唇青紫黑者, 宜用<ins><ins>黃連解毒湯</ins></ins>, 藥用黃芩、黃連、枳殼、歸尾、紅花、赤芍、生甘草、大黃. 或用<ins>甘桔湯</ins>, 甘草、桔梗、力子、玄參、連翹、知母、杏仁、乾薑. 若痰中帶血, 喘促悶亂, 用涼膈散, 黃芩、山梔、薄荷、連翹、生甘草、大黃.
