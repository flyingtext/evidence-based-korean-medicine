# 論咳嗽

麻症之乾咳, 連聲不斷也, 因火旺肺躍. 凡疹先時喜咳, 咳甚則毛竅開而易透, 咳微則腠理閉而難透, 故方出之時欲其咳. 至既出之後, 欲其不咳為佳, 如仍有咳, 當以清痰降火為要. 若初起時不咳, 麻必不出, 於發散中加半夏, 以助其嗽, 使麻可出.
