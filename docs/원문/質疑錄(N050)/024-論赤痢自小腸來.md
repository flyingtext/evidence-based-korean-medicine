# 論赤痢自小腸來

<!-- source-id: N050:p024 -->
> 서명: 質疑錄
> 원본 파일: `N/N050.txt`
> 원본 SHA-256: `d97b404f426d47b222ae85ee0ca359b2094413e7e810276fc1f80b95698564f3`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

白痢自大腸來，赤痢自小腸來，此丹溪以赤白分氣血為言也。然大腸為傳導之官，痢屬動臟腑之脂膏，傷腸胃之血絡，故赤白俱併入大腸而下。若小腸則為出溺，而赤痢何云自小腸來？謂心主血，心與小腸為表裡，故赤痢本小腸之所化則可，若謂從小腸而來，未見小腸為下痢之腑也。其言不可以辭害意。
