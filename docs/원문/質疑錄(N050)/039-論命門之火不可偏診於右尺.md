# 論命門之火不可偏診於右尺

<!-- source-id: N050:p039 -->
> 서명: 質疑錄
> 원본 파일: `N/N050.txt`
> 원본 SHA-256: `d97b404f426d47b222ae85ee0ca359b2094413e7e810276fc1f80b95698564f3`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

人生有兩腎，兩腎並診於左右尺，而命門則居兩腎之中。所謂命門之火者，即兩腎中之元氣也。元氣生於命門，而不偏於右。自《難經》有云：腎有兩，左為腎，右為命門。命門遂專屬之右，而華元化因之，始分左腎屬水，右腎屬火，故以命門之火歸之右腎。後世醫者，不詳其義，論命門之火，則必以右之尺部為診，豈知兩尺為兩腎？腎者水也，俱藏精之舍也，故越人云：命門為男子藏精。精屬水，不屬火，火在水中，所謂一陽居二陰之間者是也。豈可以命門之火，偏診於右尺耶？舉世夢夢，是可嗤也。然則論命門之火者，當於何診？仍診之於兩尺可也。以兩尺之強弱，驗命門之火之衰旺為得耳！若以右尺之腎論命門，而遺乎左尺之腎，是習俗之弊，不可不亟正者也。至有以男子之命門在右，女子之命門在左，而曰：丈夫以右為命門，左為腎；女子以左為命門，右為腎。則又顛倒乖離，而不可稽矣！
