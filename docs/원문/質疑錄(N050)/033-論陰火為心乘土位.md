# 論陰火為心乘土位

<!-- source-id: N050:p033 -->
> 서명: 質疑錄
> 원본 파일: `N/N050.txt`
> 원본 SHA-256: `d97b404f426d47b222ae85ee0ca359b2094413e7e810276fc1f80b95698564f3`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

《內經》論火，止有君火、相火、少火、壯火、五志之火之名，而並無有以陰火名者。其以陰火名者，自東垣始。東垣謂心火者，陰火也，起於下焦，其繫上繫於心。夫心在膻中氣海之中，為足厥陰包絡之經，所謂陽中之太陽也，而何得以陰火名之？既指心火為陰火，心本在上焦，而何以云起於下焦？起於下焦，則不當指為心火矣！且土者，脾胃也。火為土之母，補土必先補火。上蒸丹田以腐熟水穀者，此心火也，即此陰火也。豈可謂陰火來乘土位，以傷脾胃生髮之氣乎？火乘土以傷脾土生髮之氣者，必陽邪之火，而非心君之陰火也。少陰心火，正補太陰脾土，此虛則補母之義，但不可大旺。夫火旺則土反燥，又當壯水以制之。
