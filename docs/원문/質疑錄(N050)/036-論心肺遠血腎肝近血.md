# 論心肺遠血腎肝近血

<!-- source-id: N050:p036 -->
> 서명: 質疑錄
> 원본 파일: `N/N050.txt`
> 원본 SHA-256: `d97b404f426d47b222ae85ee0ca359b2094413e7e810276fc1f80b95698564f3`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

《金匱要略》論大便下血，分糞前為近血，糞後為遠血。此以血來有遲早，而分遠近，未嘗主於心肺、腎肝之所出為遠近也。丹溪乃言血在糞後者，出於心肺，心肺在上，故血來遲；血在糞前者，出於腎肝，腎肝在下，故血來早。夫心主血，肺則主乎氣矣；肝藏血，腎則藏乎精矣。大便所下之血，本於濕熱之氣，傷於大腸而為病。此血總屬大腸經來，故人有終年患之，而不見其形痿體憊者。此濕熱之邪，而非四臟所傷之血。若四臟有傷，而頻下無度，必心肺損而色敗，腎肝損而形痿，而可以云無患乎？故以便下之血，以先後分遠近則可，以便下之血分心肺與腎肝，則鑿矣！
