# 重刊宋本洪氏集驗方序

此集驗方五卷，南宋·洪文安所手輯。文安名遵字景嚴，皓之仲子，以博學鴻詞中選，起家為秘書省正字，孝宗朝，官至資政殿學士。方遵登制科時，高宗因皓遠使，推恩即命遵入館。詞科中選即入館，蓋自遵始，非故事也。宋祖宗之朝，君相以愛民為務，官設惠濟局，以醫藥旋舍貧人，故士大夫亦多留心方書。如世所傳《蘇沈良方》，許學士《本事方》之類，蓋一時風尚使然。夫古人立方各有深義，今世庸醫不知其理，妄行增損，遂有學醫人費之誚。憶孫淵如先生有言：今世外科每奏奇功，而內科不能者，外科用古方，而內科不用古方之故也。余往日刻新安程氏《易簡方論》一書，亦欲世人稍知古方本義，今復翁此書之刻，殆與余有同心也夫。

吳縣石韞玉序
