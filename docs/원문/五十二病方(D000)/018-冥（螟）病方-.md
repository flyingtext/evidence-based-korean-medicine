# 冥（螟）病方:

冥（螟）者,蟲,所齧穿者〔原帛缺文1字〕,其所發毋恆處,或在鼻,或在口旁,或齒齦,或在手指〔原帛缺文2字〕（一三四）,使人鼻抉（缺）指斷.治之以鮮產魚,〔原帛缺文1字〕而以鹽財和之,以敷蟲所齧〔原帛缺文3字〕（一三五）〔原帛缺文3字〕之.病已,止.嘗試,毋禁.【●】令（一三六）.
