# 犬筮（噬）人傷者:

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

取丘（蚯）引（蚓）矢二升,以井上罋斷處土與等,並熬之,而以美【醯】〔原帛缺文4字〕（六一）之,稍垸,以熨其傷.犬毛盡,敷傷而已（六二）.

一,煮莖,以汁灑之.冬日煮其本（六三）.

一,犬所齧,令毋痛及易瘳方,令【齧】者臥,而令人以酒財沃其傷.已沃而〔原帛缺文1字〕（六四）越之.嘗試.毋禁（六五）.
