# 顛（癲）疾:

先侍（偫）白雞、犬矢.發,即以刀剶（劙）其頭,從顛到項,即以犬矢【濕】之,而中剶（劙）雞〔原帛缺文1字〕（一一二）,冒其所以犬矢濕者,三日而已.已,即孰（熟）所冒雞而食之,〔原帛缺文1字〕已（一一三）.

一,瘨（癲）疾者,取犬尾及禾在圈垣上【者】,段治,湮汲以飲之（一一四）.
