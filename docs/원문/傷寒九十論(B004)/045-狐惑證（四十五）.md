# 狐惑證（四十五）

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

句容縣東豪子李姓者。得傷寒數日。村落無醫。易師巫者五六日矣。或汗下。雜治百出。遂成壞病。予時自江北避寇。遁伏江左。求宿於其家。夜半聞呻吟聲。詢之。云患傷寒逾旬矣。予為診視。其脈見於上下唇皆已蠧蝕。聲嘶而咽乾。舌上白苔。齒無色。予曰病名狐惑。殺人甚急。秉燭為作雄黃丸瀉心湯。投之。數日瘥。
