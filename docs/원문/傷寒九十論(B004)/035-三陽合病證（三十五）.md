# 三陽合病證（三十五）

<!-- source-id: B004:p035 -->

> 원본 파일: `B/B004.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

有市人李九妻。患腹痛。身體重。不能轉側。小便遺失。或作中濕治。予曰。非是也。三陽合病證。仲景云。見陽明篇第十證。三陽合病。腹滿。身重難轉側。口不仁。面垢。譫語。遺尿不可汗。汗則譫語。下則額上汗出。手足逆冷。乃三投白虎湯而愈。
