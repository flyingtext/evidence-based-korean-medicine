# 衄血證（六十三）

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

睢陽張士美病傷寒七八日。口燥飲水而不咽入。俄而衄血。脈浮緊。身熱。醫者云傷寒。脈浮緊。不發汗。因致衄血者。屬麻黃湯。予曰。不可。古人雖云當汗不汗。熱化為血。此證亦有不可汗者。仲景云陽明病。口燥。但欲飲水而不咽者。必發衄。衄家不可發汗。發汗則額上陷。不得眠。不能眴。此只可用犀角湯。地黃湯。若當時行麻黃。必額上陷。直視不眠也。
