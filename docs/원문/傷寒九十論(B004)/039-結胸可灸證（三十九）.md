# 結胸可灸證（三十九）

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

城東李氏子。年十八。病傷寒結胸。狀如痓。自心至臍。手不可近。短氣心煩。真結胸也。醫者便欲下之。予適過其門。見其愴惶面無色。予曰公有憂色何也。曰以長子病傷寒作結胸證。醫者將下之。而猶豫。予就為診之。自關以上浮大。表證未罷。不可下也。曰事急矣。予以黃連餅子。灸臍中數十壯。得氣下。心腹軟。繼以和氣解肌藥。數日瘥。當時若下。定是醫殺。
