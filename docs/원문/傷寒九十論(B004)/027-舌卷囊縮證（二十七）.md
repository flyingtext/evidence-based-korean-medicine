# 舌卷囊縮證（二十七）

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

句容縣豪子李姓。初得傷寒。手足冷。氣上衝心。飢不欲食。脈緊而弦。予診曰。厥陰悉具。脈有刑剋。最忌舌卷囊縮。翌日捲舌而死。

論曰。內經云。厥陰者肝也。肝者筋合之。筋者聚於陰器。絡於舌本。厥陰之氣。故舌卷而囊縮也。
