# 叉手冒心證（五十八）

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

乙巳六月。吉水譚商人寓城南。得傷寒。八九日。心下惕惕然。以兩手捫心。身體振振動搖。他醫以心痛治之。不效。予曰。此汗過多之所致也。仲景云持脈時。病人叉手自冒心。心下悸。所以然者以重獲汗。虛。故如此。又云發汗過多。其人叉手自冒心。心下悸。欲得按者。桂枝甘草湯證。予投黃耆建中真武。及甘草桂枝。漸得平復。
