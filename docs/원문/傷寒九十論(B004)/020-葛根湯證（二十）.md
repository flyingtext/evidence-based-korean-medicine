# 葛根湯證（二十）

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

市人楊姓者。病傷寒。無汗。惡風。項雖屈而強。醫者以桂枝麻黃各半湯與之。予曰。非其治也。是謂項強𠘧𠘧。葛根證也。三投。濈濈然微汗解。翌日項不強。脈已和矣。

論曰。何謂𠘧𠘧。如短羽鳥之狀。雖屈而強也。謝復古謂病人羸弱。須憑几而起。非是。此與成氏解不同。
