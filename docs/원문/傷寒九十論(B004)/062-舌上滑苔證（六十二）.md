# 舌上滑苔證（六十二）

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

丁未五月。鄉人邢原暉病傷寒。寒熱往來。心下鬱悶。舌上白滑苔。予曰。舌上滑苔有數證。有陰陽脈緊。鼻出涕者。有臟結而不可治者。有溫瘴。丹田有熱者。有陽明。脅下堅者。此證屬陽明。宜梔子湯吐之於前。小柴胡繼於其後。數日汗解而愈。
