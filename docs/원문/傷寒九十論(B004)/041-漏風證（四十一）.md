# 漏風證（四十一）

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

癸卯秋九月。牒試淮南僧臺。同試有建陽彭子靜。得疾。身熱頭痛。嘔逆。自汗如洗。已數日矣。召予診視。謂予曰。去試不數日。而疾勢如此。為之奈何。予曰。誤服藥多矣。此證當先止汗。幸無憂也。予作朮附湯與之。三投而汗止。次日微汗漐漐。身涼。五日而得愈。
