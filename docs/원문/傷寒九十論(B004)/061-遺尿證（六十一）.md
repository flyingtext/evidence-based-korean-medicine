# 遺尿證（六十一）

城南婦人。腹滿身重。遺尿。言語失常。他醫曰。不可治也。腎絕矣。其家驚憂無措。密召予至。則醫尚在座。乃診之曰。何謂腎絕。醫家曰仲景謂溲便遺失。狂言。反目直視。此謂腎絕也。予曰。今脈浮大而長。此三陽合病也。胡為腎絕。仲景云腹滿身重。難以轉側。口不仁。譫語。遺尿。發汗則譫語。下之則額上生汗。手足厥冷。白虎證也。今病人譫語者。以不當汗而汗之。非狂言反目直視。須是腎絕脈。方可言此證。乃投以白虎加人參湯。數服而病悉除。
