# 藥品異名括

大清尊者朴硝爾　偷蜜珊瑚甘草名

脾家瑞氣內豆蔻　抱靈居士香附更

羽⿰石圼羽澤皆礬石　銅華精即是銅青

干胭脂做片胚子　苦督郵只為黃芩

痰宮霹靂當半夏　大通綠染木香形

蠻龍古血沒藥也　鎖眉根號曰苦參

茅君寶篋蒼朮鮮　連翹便是度厄錢

顛勒羊韭天麥冬　熟地生地為芭苄

黃香影子山梔子　赤鉛華煉作黃丹

雄黃異名黃食石　麝香和作拔萃團

溺中垽號人中白　金釵石斛成林蘭

百蟲倉即五倍子　松脂化作琥珀絲

獨活號稱兩平章　珠子香焚即乳香

風兒肉喚大風子　崑崙黃配作硫黃

陳皮久曰陳貴老　無聲虎畏伏大黃

洞庭奴隸為枳殼　甘草又名國老當

黃芩亦可為腐賜　黑金屑即鐵屑稱

風稜御史使君子　黑麵是散雪玉塵

綬米帶乃麥芽號　神麯乃化米先生

滴膽芝即是黃連　諸般藥品多異名
