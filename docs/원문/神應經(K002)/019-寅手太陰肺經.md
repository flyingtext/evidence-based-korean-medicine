# 寅手太陰肺經

尺澤　在肘中約紋上，兩筋間動脈。針三分，不可針深，灸五壯。

列缺　在手側腕上寸半，以手交中指頭末，兩筋兩骨鏬中。針三分，灸五壯。

經渠　在寸口陷中，動脈應手。針二分，禁灸。

太淵　在掌後內側橫紋頭動脈。針二分，灸三壯。

魚際　在大指本節後白肉際，針三分。

少商　在手大指內側，去爪甲如韭葉。針一分，禁灸。可鋒針。
