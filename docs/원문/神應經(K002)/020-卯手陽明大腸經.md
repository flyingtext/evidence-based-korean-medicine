# 卯手陽明大腸經

商陽　在手大指次指內側，去爪甲角如韭葉。針一分，灸三壯。

二間　在手大指次指本節前，內側陷中。針三分，灸三壯。

三間　在手太指次指本節後，內側陷中。針三分，灸三壯。

合谷　在手大指次指歧骨間陷中。針三分，灸三壯。孕婦不可針。

陽谿　在手腕中上側，兩筋間陷中。針三分，灸三壯。

手三里　在曲池下三寸，按之肉起，兌肉端。針三分，灸三壯。

曲池　在肘外輔骨，屈肘橫紋頭陷中，拱胸取之。針七分，灸七壯，可日七至二百。
