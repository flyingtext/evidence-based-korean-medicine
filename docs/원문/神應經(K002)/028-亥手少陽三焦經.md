# 亥手少陽三焦經

液門　在手小指次指間，屈拳取之。針三分，灸三壯。

中渚　在手小指次指本節後陷中。針三分，灸三壯。

陽池　在手表腕上，同骨陷中。針二分，不宜多灸，可三壯。

外關　在腕後二寸，兩骨間陷中。針三分，灸五壯。

支溝　在腕後三寸，兩骨間陷中。針二分，灸二七壯。

天井　在肘外大骨後，肘上一寸，兩筋間陷中。又手按膝頭取之，屈肘取亦可。針一寸，灸三壯。
