# 疹脈

> 상태: 인터넷 판본·독립 자료 대조 교감 완료

凡候疹脈，自初熱見形，以及收沒，但看右手一指脈洪大有力，雖有雜症，亦無大害，蓋右手一指脈，太陰肺脈也。肺主皮毛，脈氣通，自能載毒外出，是以無害。若肺脈沉小無力，大非所宜，疹發於陽經，脈反沉小，是為陽症陰脈。司命者於此處最要留心，不得謂疹症無虛寒，而固執清熱解毒，以敗乃事也。
