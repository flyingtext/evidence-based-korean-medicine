# 熱入厥陰

喻（年十五歲, 七月十日）　病經旬余, 熱傷營陰, 暑濕熱邪, 深入厥陰, 內熱煩渴, 體力疲憊, 眩暈昏黑, 四支厥逆, 時有潮熱, 肌腠曾有白㾦, 未得宣達, 風動痙厥, 慎防厥脫之變, 脈弦滑數, 按之均少神韻. 治宜清心滌痰兼平肝宣竅, 附方請正.

臺參鬚玫瑰花三朵同燉沖　純嫩鉤　青蒿子　竹瀝　牛黃清心丸　真滁菊　石決明　真川連三分拌　川鬱金　膽星　丹皮　朱茯神　薄荷

益元散（方中有膽星牛黃川連可勿用也）

又次日厥逆已平, 喘汗已止, 而肺津胃液已被熱邪劫耗, 潮熱未退, 大便挾熱旁流, 左脅痞痛拒按, 神疲支倦, 不飢不納, 脈虛數近弦, 苔黃糙. 治宜滋清以撤餘邪, 還須節食避風, 勿使反復, 另紙錄方請正.

臺參鬚玫瑰花三朵同燉沖　東白芍　青蒿子　車前草　小青皮　連心麥冬　左牡蠣　丹皮　生穀芽　金扁石斛　淡鱉甲　純嫩鉤　朱茯神. 如舌胎黃糙, 遺邪尚未清淨, 參麥滯膩用宜斟量, 見症不飢不納, 膩補更宜加意審辨為重.
