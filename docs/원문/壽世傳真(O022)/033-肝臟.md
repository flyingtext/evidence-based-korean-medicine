# 肝臟

形如懸瓠, 有七葉, 左三右四. 位居背脊第九椎, 乃背中間脊骨第九節也.

屬木, 旺於春正、二月, 色主青, 酸味入肝. 外通竅於目. 出汁液為淚. 在七情主怒, 在身主筋與爪. 所統者血, 所藏者魂, 所惡者風.

肝有病, 眼生蒙翳, 兩眼角赤癢, 流冷淚, 眼下青, 轉筋, 昏睡, 善恐, 如人將捕之.

面色青者, 肝盛也. 好食酸者, 肝不足也. 多怯者, 肝虛也. 多怒者, 肝實也.
