# 難經十三卷

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

秦越人祖述黃帝內經，設為問答之辭，以示學者，所引經言，多非靈素本文，
蓋古有其書，而今亡之耳！隋時有呂博望註本不傳，宋王惟一集五家之說，
而醇疵或相亂，惟虞氏粗為可觀，紀齊卿註稍密，乃附辯楊玄操。呂廣，
王宗正三子之非，周仲立頗加訂易，而考證未明，李子野亦為句解，而無所啟發，
近代張潔古註後附藥，殊非經義，王少卿演繹其說，目曰重玄，亦未足以發前人之蘊。
○滑伯仁氏取長棄短，折衷以己意，作難經本義。
