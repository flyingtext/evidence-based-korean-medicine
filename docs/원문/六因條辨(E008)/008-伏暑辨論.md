# 伏暑辨論

嘗觀醫書林立，並無伏暑之名。惟（己任編）有秋時晚發，以感證之法治之一語，因著伏暑之稱。蓋人於盛暑之際，汗洩氣疏，百節弛漲，設或有隙，邪乘虛入，《內經》所謂至虛之處，便是容邪之處也(1)。又云：春傷於風，夏必餐(2)洩，夏傷於暑，秋必發瘧;秋傷於燥(3)，冬生咳嗽;冬傷於寒，春必病溫。

可知四時伏氣，皆能為病。即伏寒、伏風、伏燥，皆可與伏暑立名主病。故春溫為冬令之伏寒，腸風為春令之伏風，瘧痢為夏間之伏暑，咳嗽為秋天之伏燥，以類而推。古人治病立法，良有以也，藉後人語焉不察，漫不關心耳。予苦心斯道，廿載虛名，何敢妄為(1)至虛之處，便是容邪之處也：按《內經》有此文‧但無此語。

(2)餐：此處音、義俱同，飧，下問。

(3)燥：（內經）中俱作"濕"。

議論。特前賢既啟其端，後人末窮其旨，聊為引伸，以備葑菲之遺，庶可測伏暑之有由名。且不但可測伏暑之有由名，更可測伏暑之有由病，而有由治焉矣。
