# 血厥醫案

<!-- source-id: N070:p022 -->

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

郡城七星橋翁氏女經前發厥，厥必數日不醒人事，醫用朱、黃、膽星之屬，經年不效。己卯六月，延予診治。脈象搏指，余謂此系經血內瘀，久而發厥，非痰迷心竅也。朱、黃、膽星，焉能破瘀生新耶。乃合《內經》烏鰂骨丸，仲景旋覆花湯，河間金鈴子散為一方，數劑全痊，竟不再發。
