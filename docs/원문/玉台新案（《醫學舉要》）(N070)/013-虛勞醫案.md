# 虛勞醫案

<!-- source-id: N070:p013 -->

> 원본 파일: `N/N070.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

亭林鎮北陸某，素患勞嗽，時作時止，至是益加氣喘，偏臥不能轉側，脈象細弱，有似氣虛痰飲，醫用補脾理氣，久而不效，遂以本證為辭。予適在鎮中顧宅，延予一判安危。余謂此屬肺腎陰虧，非氣虛也，初用錢氏阿膠散，繼用六味地黃湯而愈。
