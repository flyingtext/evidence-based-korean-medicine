# 頭痛醫案

<!-- source-id: N070:p018 -->
> 서명: 玉台新案（《醫學舉要》）

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

嘉定陳嫗年五十有七，病頭痛數年，額上為甚，額屬陽明部分，久痛必虛，須填補陽明，之法治之，久不見效。漸至食則易饑，心火上亢，腎水下趨，形消腰折，寒熱頻頻，督脈陽維交病。余謂此系精濁。非便濁也。用鹿角菟絲骨脂等溫補下焦，兼服威喜丸而愈。

提憲稿房陳壽昌病濁，醫者疑其腎陰虧損而致此疾，早投補腎藥，少腹脹痛欲死。余用左金清火，合雄鼠糞湯攻濁而愈。兼鼓舞胃中清陽之氣，用玉屏風散加炙草葛根，二劑全愈。推此而太陽頭頂痛，少陽頭角痛，厥陰頭巔痛，皆可按法而治矣。

高橋鎮曹連珍室，操持家事頗勞，兼多暴怒，孟夏得疾，自天柱至頭巔，忽然強痛，堅重難移，兩耳赤腫，胃中嘈雜，脈象洪數。宗喻氏治吳添官母例而愈。
