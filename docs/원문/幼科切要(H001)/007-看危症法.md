# 看危症法

小兒渾身熱似火, 手足如冰真難過. 黑掩太陰口角青, 盧醫一見也須驚. 黑色如針垂眼下, 醫如扁鵲也須怕. 黑色目中總不良, 小兒十日必然亡. 水腫之病準頭黑, 此兒應知腎氣絕. 咳嗽最忌白入眉, 肺虛氣絕報君知. 目暗無光不轉睛, 三朝必定命難存. 眼似開而又不開, 能言也是死之媒. 嘔吐不止止又吐, 胃虛脾敗何須顧. 搖頭咬齒欲齧入, 看看定是鬼為鄰. 囟門或腫或深沉, 元氣虧而命難存. 蛇蟲吐出腐而敗, 脾絕小兒終是害. 五心忽腫為何因, 假火發外實驚人. 四肢無事忽搖動, 醫人到此無藥用. 此是小兒危急症, 說與醫人莫須情.
