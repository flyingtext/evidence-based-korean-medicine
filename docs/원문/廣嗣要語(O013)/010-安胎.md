# 安胎

胎痛。乃血少。四物加童便制香附。共為末。紫蘇湯調下。有所激觸而痛者。芎歸湯探之。

胎動屬火。四物加條芩之類。

胎動不安及下血。集驗方秦艽湯。

胎動下血。或因房室不節。有所觸動。四物加膠艾條芩白朮之類。

妊娠惡阻。肥人有疾。瘦人有熱。胃氣不安。人參橘皮湯。保生湯。集驗青竹茹湯。懷胎不問幾個月日。但覺胎氣不安。腰腹微痛。飲食不美。用安胎飲。
