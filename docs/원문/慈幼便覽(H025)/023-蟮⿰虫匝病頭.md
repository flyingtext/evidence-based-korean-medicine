# 蟮⿰虫匝病頭

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

蟮⿰虫匝頭，一名蟮黃頭：在小兒頂心腫起，先白後紅，如不治，愈黃愈多，旁添小者，如百鳥朝王。照其腫之大小，用枳殼半個，去瓤，以生灰面調為糊，塗在枳殼沿上，如道冠一樣戴在毒上，其毒水自能吊出。俟其脫下，其腫處小，再用小枳殼半個，如前法糊面戴之，水亦干矣。俟其自脫，不過六七日，腫平而發茸茸矣。又方，活蝦蟆一個，剝一整皮貼瘡上，奇效。又方，大蛙肉搗爛，加冰片少許，攤患處立效。
