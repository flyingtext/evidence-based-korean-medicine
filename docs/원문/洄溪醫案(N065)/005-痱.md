# 痱

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

新郭沈又高，續娶少艾，未免不節，忽患氣喘厥逆，語澀神昏，手足不舉。醫者以中風法治之，病益甚。余診之曰：此《內經》所謂痱證也。少陰虛而精氣不續，與大概偏中風、中風、痰厥、風厥等病，絕不相類。劉河間所立地黃飲子，正為此而設，何醫者反忌之耶？一劑而喘逆定，神氣清，聲音出，四肢展動。三劑而病除八九，調以養精益氣之品而愈。余所見類中而宜溫補者，止此一人。識之以見余並非禁用補藥，但必對證，乃可施治耳。

雄按：古云真中屬實，類中多虛，其實不然。若其人素稟陽盛，過啖肥甘，積熱釀痰，壅塞隧絡，多患類中。治宜化痰清熱，流利機關，自始至終，忌投補滯。徐氏謂宜於溫補者不多見，洵閱歷之言也。
