# 暑邪熱呃

<!-- source-id: N065:p015 -->
> 서명: 洄溪醫案
> 원본 파일: `N/N065.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

東山席士後者，暑月感冒，邪留上焦，神昏呃逆，醫者以為壞證不治，進以參附等藥，呃益甚。余曰：此熱呃也。呃在上焦，令食西瓜，群醫大譁。病者聞余言即欲食，食之呃漸止，進以清降之藥，二劑而諸病漸愈。

又有戚沈君倫者，年七十，時邪內陷而呃逆，是時余有揚州之行，乃囑相好尤君在涇曰：此熱呃也，君以枇杷葉、鮮蘆根等清降之品飲之必愈。尤君依余治之亦痊。蓋呃逆本有二因：由於虛寒，逆從臍下而起，其根在腎，為難治。由於熱者，逆止在胸臆間，其根在胃，為易治，輕重懸絕。世人謂之冷呃，而概從寒治，無不死者，死之後，則云凡呃逆者，俱為絕證。不知無病之人，先冷物，後熱物，冷熱相爭，亦可呃逆，不治自愈，人所共見，何不思也。
