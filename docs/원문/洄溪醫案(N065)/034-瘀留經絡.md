# 瘀留經絡

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

烏鎮莫秀東，患奇病，痛始於背，達於胸脅，晝則飲食如常，暮乃痛發，呼號徹夜，鄰里慘聞。醫治五年，家資蕩盡，秀東欲自縊。其母曰：汝有子女之累，尚須冀念，不如我死，免聞哀號之聲。欲赴水，其戚憐之，引來就醫。余曰：此瘀血留經絡也。因謂餘子曦曰：此怪病也。廣求治法以療之，非但濟人，正可造就已之學問。因留於家，用針灸熨拓煎丸之法，無所不備，其痛漸輕亦漸短，一月而愈，其人感謝不置。余曰：我方欲謝子耳。凡病深者，須盡我之技而後奏功。今人必欲一劑見效，三劑不驗，則易他醫。子獨始終相信，我之知己也，能無感乎。
