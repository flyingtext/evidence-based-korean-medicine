# 惡寒

惡寒發熱發於陽。陰病憎寒身體涼。解表桂枝並越婢。溫中須索理中湯。

惡寒一症。即前云寒邪外束。則惡寒也。此復舉以言之。分別三陽三陰之不同也。若在三陽、則必發熱。若在三陰、則專惡寒而不發熱。在三陽則宜解表。如羌活湯、解肌湯、小柴胡湯、各隨證用之。如中三陰則宜理中湯、或四逆湯、皆可選用也。如桂枝湯越婢湯未可輕用。
