# 太陰經直中寒症

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

直中陰經不發熱。腹痛惡寒四肢厥。唇青面黑是真陰。四逆理中真妙訣。（此太陰直中寒症其脈沉細無力宜溫之）

四逆湯中姜一兩。生附減半去皮尖。一兩甘草水煎服。厥而下利用之痊。理中甘草用乾薑。白朮人參是的當。若是內中加附子。更名附子理中湯。
