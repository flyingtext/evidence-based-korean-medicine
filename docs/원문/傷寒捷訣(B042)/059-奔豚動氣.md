# 奔豚動氣

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

奔豚動氣有奇方。左右高低細揣量。去朮理中兼用桂。不堪汗下應須詳。

奔豚者。腎積也。動氣者。謂臟氣不調。肌膚間築築跳動。遂藏所主。見於臍之左右上下。獨不言當臍者。脾為中州。以行四臟之津液。左右上下皆不可汗下。何況中州。其敢輕動乎。古通用理中湯去朮加桂苓為主。以茯苓利水。桂泄奔豚。故宜加用。白朮滯氣。故去之。
