# 千金保胎丸

凡受孕三月而胎墮者。雖氣血不足。乃中衝脈有傷。中衝脈即陽明胃經。供應胎孕至此時。必須節飲食。絕欲。戒怒。兼服此藥。庶免小產之患矣。

白朮（土炒）　生地　杜仲（俱薑汁炒各四兩）　當歸　續斷（俱酒炒）　阿膠（蛤粉炒）　益母草炒條芩（各二兩）　四制香附末　陳皮　川芎　艾葉（各一兩）　炒砂仁（五錢）　老蘇梗（三錢）

共為末。棗肉為丸。空心每服二錢。
