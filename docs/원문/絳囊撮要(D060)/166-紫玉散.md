# 紫玉散

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

專圍癰疽腫痛。大小一切外症。

白芨（八錢）　黃柏（四錢）　大黃（四錢）　薑黃（三錢）　南星（四錢）　東丹（五錢）　礬紅（二錢）　土貝（四錢）　血竭（一錢）

共為細末。用井水調敷。留頭。火紙摘碎蓋上。干則連紙自落。再敷不必水洗。並不可用天落水調。

又方

芙蓉花（或葉或根皮）　或生搗。或乾研。和白蜜調塗四圍。中留頭。干則頻易。
