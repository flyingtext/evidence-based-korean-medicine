# 蜘絲線

<!-- source-id: D060:p072 -->
> 서명: 絳囊撮要
> 원본 파일: `D/D060.txt`
> 원본 SHA-256: `433905665251f564d59a2499e411aeb1df7b4b76911683348865d5b5dbbccd35`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

專治口舌生菌。遲治菌大。塞滿不能飲食。而死。

先做一小竹弓。弓口約三寸許。於荒野間。覓極大蜘蛛一個。將蛛絲盤在弓口上。盤盡絲蜘蛛放去。即以絲搓作線一條。打圈套在菌根上。其絲自漸收緊。收至極痛耐定菌自落。血出。用止血散敷之立愈。已效過落後。服清血熱煎劑妙。
