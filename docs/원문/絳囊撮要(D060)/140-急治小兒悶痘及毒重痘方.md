# 急治小兒悶痘及毒重痘方

<!-- source-id: D060:p140 -->
> 서명: 絳囊撮要
> 원본 파일: `D/D060.txt`
> 원본 SHA-256: `433905665251f564d59a2499e411aeb1df7b4b76911683348865d5b5dbbccd35`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

小兒出痘三四朝時。或系悶症。或系火重。甚至二便下血。危急之至者。急覓活蟾蜍。至少四五十隻。將小兒脫盡著身衣服。蓋好被內。赤身側臥。輕輕將蟾蜍推至前後心。以次排放至下身。蟾蜍得溫氣。自能將頭向小兒身上頂住。小兒得蟾酥開竅。自然漸次痘點透發。不要驚動。安放一晝夜。然後取出。將蟾蜍冷水頻浴之。以解蟾蜍受痘之毒。即以保全物命。（此方得自異傳經驗已久錄出布告共相備急倘遇嚴冬蟾蜍無處覓取可在野間向陽桑樹根頭掘下三四尺深即可得之蟾蜍蝦蟆俗名癩團）
