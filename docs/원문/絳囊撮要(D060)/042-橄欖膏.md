# 橄欖膏

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

治癲癡立效。兼治肝火上逆之症。

橄欖（十斤）　砂鍋內煮數滾。去核入石臼搗爛。仍入原湯煎膩出汁。易水再煎。煎至無味去渣。以汁共歸一鍋。煎濃成膏。用白明礬（八錢）。研細入膏和勻。每日早晚各取膏三錢。開水送服。或初起輕者。取橄欖咬破一頭。蘸礬末入口。味美易食。至愈乃止。
