# 吞鴉片煙毒

<!-- source-id: D035:p016 -->
> 서명: 急救便方
> 원본 파일: `D/D035.txt`
> 원본 SHA-256: `cba71ec2295177b1b5543a8b0c940cc79783b55ed50ab26a486799cc0e126929`
> 상태: 인터넷 판본·독립 자료 대조 교감 완료

輕則心中發燥,急用活鴨血或鵝血灌之,或醬油或涼水多灌之,吐出鴉片煙即愈.或用白礬、雄黃同研末,清水調灌亦效.若服多毒重,則身冷氣絕,似乎已死.若肢體柔軟,實未死也,乃鴉片性烈醉迷之故.將其人放在潮濕陰地,用筷撬開牙齒,又以竹筷一枝橫放口內,令口常開,時以冷水一杯灌之,有金汁灌之更妙,外以冷水在胸前摩蕩,每日夜十餘次,又用冷水一盆,將頭髮散放水盆內漂之,三四日後,鴉片之氣退盡即活.（切勿見太陽,若一經日照,便不可救.）但身不僵硬不變色,七日以內毋遽棺斂,曾見以此法救之皆活.又方,用燈油頻灌,吐即愈.（蓋煙膏見油不散.）惟調酒服者難救.
