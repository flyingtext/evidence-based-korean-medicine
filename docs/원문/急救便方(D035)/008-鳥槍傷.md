# 鳥槍傷

<!-- source-id: D035:p008 -->
> 서명: 急救便方
> 원본 파일: `D/D035.txt`
> 원본 SHA-256: `cba71ec2295177b1b5543a8b0c940cc79783b55ed50ab26a486799cc0e126929`
> 상태: 인터넷 판본·독립 자료 대조 교감 완료

凡槍子打入皮肉,用生南瓜切片,貼患處即出.又方,用蜂蜜半斤煎滾,入好頭燒酒一斤（好黃酒亦可）,隨量熱服,其子當黏衣被上出.鐵子不出,用陳肥臘肉蘸真磁石末,貼之自出.鉛子若在肉內未入腹中者,用水銀灌入瘡熔化成水,再以金器貼近瘡口,徐徐轉揩數十次;或以小金條兩根,連換檢插瘡中,水銀蝕金而出.
