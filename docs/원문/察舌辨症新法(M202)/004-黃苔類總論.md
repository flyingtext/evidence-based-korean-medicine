# 黃苔類總論

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

黃色有深淺老嫩之殊，其形似亦有燥潤滑澀之異。有正黃色者；有老黃色者；有黃如炒枳殼色者；有黃黑相間如鍋焦黃色者；有嫩黃色者；有牙黃色者；有如裱心紙兼灰青色者；有黃如粟米染著者；有黃如虎斑紋者；有黃如黃蠟敷舌上者；有水黃苔如雞子黃白相兼染成者；有黃腐苔如豆渣炒黃堆舌者；此皆黃色之類，而症候之殊詳後。
