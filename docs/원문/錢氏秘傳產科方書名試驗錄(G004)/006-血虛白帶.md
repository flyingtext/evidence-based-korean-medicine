# 血虛白帶

丹溪云：白帶是胸中痰積滲入膀胱。無人知此，宜升。甚者，上必用吐以提元氣，下用蒼朮、白朮、二陳。如赤白相兼者，皆屬血出於大小腸之分。肥人多痰，宜南星、半夏、海石、蒼朮、香椿皮、青黛；瘦人白帶因多熱，宜黃柏、滑石、海石、橙皮、川芎、蛤粉、青黛，作丸服之。赤白帶下，皆因七情內傷，下元虛弱，感非一端。叔和云：崩中日久為白帶，漏下多時滑水枯，崩中血少無元陽，故白滑之物下流不止，血海枯乾，不能滋養筋骨。治法用審寒熱虛勞，不可類治。婦人之心，以血為主，有血則心寧，血少則心火旺，火旺則心亂、撞搖、提拮、戰惚、悶亂。惟婦人多有此症，治法用清心降火，四物加天門、麥門、貝母、黃芩。夫天門鎮心之要藥，切不可缺。

治赤白帶：龜板　乾薑　黃柏　白芷

如氣虛白帶：人參　白朮　黃耆　當歸　川芎　蒼朮　黃柏　乾薑（煨）　白芷

如瘦人多熱：人參　川歸　芍藥　黃柏　茯苓　黃連　黃耆　陳皮　甘草　前胡　椿皮　青黛
