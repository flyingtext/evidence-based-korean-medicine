# 舌岩

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

心脾之火夾痰上升，舌岩堅腫，破碎，飲咽不能，症非輕淺。擬清火化痰。

麥冬　粉蛤　海藻　大貝　元參　殭蠶　桔梗　橘紅　生甘草　連翹　蒲黃　地慄　竹茹

吹青陽柳華散，加琥珀、橄欖灰、蒲黃、冰片，已漸軟，然未可恃，原方加羚羊片、丹皮。
