# 胞漏並小產論

凡妊娠經水，壅之以養胎，蓄之以為乳，其衝任氣虛。不能約制，故月水時下，名曰胞漏，血盡子死。然亦有妊娠血盛，月信常來而胎不動。俗呼狗兒胎也。若以漏胎治之，則胎必墜；若不以漏胎治之，其胎未必墜。亦有脈見滑數，而別無風熱病，經脈如常，但較前略少，此因胎小，血盛有餘而然，俟遲至三、四月外，兒大能飲，經脈自止。又有壯盛孕婦，按月去血點滴，若無腰酸胎動，不須服藥，此血氣強盛，孕至四、五月後，自然經止。如孕婦虛羸，腰常酸痛，並胎動而按月下血點滴，或下血不止，此非血有餘，乃胎漏也。宜服加味補中安胎飲。又云：胎漏多因於血熱，然亦有氣虛血少。服涼藥而下血益甚，食少體倦者，此脾氣虛而不能攝血也，宜歸脾等方加減。當以脈候察之，凡墜胎之病，多在三、五、七月，如前次三月會墜，後必如期乘其所虛而亦墜，必預服尊生安胎飲，或胎元飲加減用之，當服過七月，可無患矣。更宜戒房欲、氣惱、勞役、　炙諸食，至於頓仆傷動胎氣，宜服膠艾安胎散。總屬妊娠氣血虛弱，胎元不固。蓋氣虛則提攝不固，血弱則灌溉不周，多致小產。況婦人腎以系胞，而腰為腎之腑，腰痛則墜，不可不防。大凡妊娠三月後，尺脈或澀或微弱，胎必不固，惟脈洪盛者，胎不墜耳。所以《脈訣》內云：胎脈弦牢滑利安，沉細而微歸泉路。正此之謂也。總之，三月以前宜養脾胃，四月以後宜壯腰腎，補血順氣，佐以清熱，此大法也。
