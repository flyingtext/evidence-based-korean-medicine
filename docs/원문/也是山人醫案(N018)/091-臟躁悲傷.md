# 臟躁悲傷

吳（六三）肝陽亢為頭暈。腎陰虛則耳鳴。此晚年肝腎氣餒。下虛上實明甚。但忽驚悸。汗大泄。有時寤不肯寐。

竟有悲傷欲哭之象。明系臟陰少藏。厥陽鼓動。內風上冒。舞於太陰。每有是症。病自情志中生。所以清之攻之。均屬無益。議仲景婦人篇。參臟躁悲傷之旨。用藥自有準繩。但王道未能速效。
