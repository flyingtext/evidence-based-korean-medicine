# 虛勞當治其未成

<!-- source-id: F012:p031 -->
> 서명: 理虛元鑑
> 원본 파일: `F/F012.txt`
> 원본 SHA-256: `94fa4cef83e5b968de1980665d9d8729a4120e3bd6e8a269f40fc475dd1f132b`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

患虛勞者，若待其已成而後治之，病雖愈，亦是不經風浪，不堪辛苦的人，在富貴者猶有生理，貧者終難保也。是當於未成之先，審其現何機兆，中何病根，爾時即以要言一二語指示之，令其善為調攝，隨用湯液十數劑，或用丸劑膠劑二三斤，以斷其根，豈非先事之善策哉。
