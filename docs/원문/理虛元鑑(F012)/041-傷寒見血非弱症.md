# 傷寒見血非弱症

<!-- source-id: F012:p041 -->
> 서명: 理虛元鑑
> 원본 파일: `F/F012.txt`
> 원본 SHA-256: `94fa4cef83e5b968de1980665d9d8729a4120e3bd6e8a269f40fc475dd1f132b`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

有勞倦傷血，瘀積胃絡，兼受風寒，寒邪迫血，火不能降，以致吐血、衄血，不可以弱症施治。若誤投涼劑，則寒愈結而血難止，只宜散其風寒，少加調血歸經之品，使邪外泄而火下降，則血自止矣。或問何以辨之？曰：頭痛、惡寒、戰慄、手足逆冷，而其人素無虛症，如虛火上炎，不足之候，身體不瘦，突然而起者是也。
