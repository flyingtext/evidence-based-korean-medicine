# 嘔吐見血非弱症

<!-- source-id: F012:p040 -->
> 서명: 理虛元鑑
> 원본 파일: `F/F012.txt`
> 원본 SHA-256: `94fa4cef83e5b968de1980665d9d8729a4120e3bd6e8a269f40fc475dd1f132b`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

往往有人患嘔血甚多，醫者遂認為弱症，誤也。此先傷於怒，怒氣傷肝，肝臟原有血積於中，後傷於寒，寒入胃，故嘔吐，嘔吐傷氣，氣帶血而暴厥耳。是不可與怯症之血同論。當於治嘔藥中，加楂肉先行其瘀，止其吐；後再徐調其他症，自可萬全也。
