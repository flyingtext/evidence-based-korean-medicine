# 心腎論

夫心主血而藏神者也，腎主志而藏精者也。以先天生成之體論，則精生氣，氣生神；以後天運用之主宰論，則神役氣，氣役精。精、氣、神，養生家謂之三寶。治之原不相離，故於滑精、夢泄種種精病者，必本於神治；於怔忡、驚悸種種神病者，必本於氣治。蓋安神必益其氣，益氣必補其精。
