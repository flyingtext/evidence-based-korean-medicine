# 點藥藥性

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

甘石，止痛淚。乳香、沒藥，止痛散血。

青鹽，去障眵翳，能涼血。銅青，去風障，正瞳神。

白丁香，去胬肉扳睛。石蟹，去脹眵，消腫。

硃砂，正瞳神。蕤仁，去障眵，解毒還睛。

明礬，去障風翳，硼砂，涼血去障。

枯礬，去風障干爛弦。膽礬，去翳。

血竭，散血住痛。輕粉，住痛殺蟲。

巴豆，去胬肉翳膜。水粉，止淚生光。

瑪瑙，去障。連末，解藥毒，通竅散血。

熊膽，分塵去垢，散血臀膜眵脹。琥珀，去障生光。

龍骨，去翳障膜止淚。珊瑚，去障塵。

硇砂，熟用去翳膜，生用爛肉。珍珠，生用傷爛肉，熟用去膜生光。

牛黃，正瞳生光，清心止痛，去障膜。
