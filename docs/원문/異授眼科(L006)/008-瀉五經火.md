# 瀉五經火

<!-- source-id: L006:p008 -->
> 서명: 異授眼科
> 원본 파일: `L/L006.txt`

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

心火甘梢生地翹，獨引黃連犀角超。肺火桑皮麥冬梔，芷引元參杏石膏。脾火只連生地芩，麻引黃甘用要勤。肝火尾荊赤柏明，柴引薄荷補姜陳。腎火熟地知澤柏，獨活引經增大黃。胃火梔子膏乾葛，補胃白朮與生薑。補心遠智茯苓鹽，提肺升麻白芷桔，補肺車天五味參，補肝姜枸芍芎熟，補腎斛柏知芍煎。杜枸牛絲戟破蓉，寬腸芒硝殼大黃，寬小木通及羌活，瀉膀胱芎羌活柏，瀉三焦兮柴胡芩。止吐藿香及生薑，止淚芥芩香附菊，更有決榔附子辛，陳皮朴硝麻黃並，去翳蒙葙款菊明，龍膽蛻賊及穀精，退膜榔賊及穀精，白蒺為君用要勤，去風蒺藜白僵蟲，防風蟬蛻亦相仿，退熱芩梔黃柏連，連翹大黃正相兼，破瘀芒硝丹大黃，槐紅桃實最相當，內障兩明蔓歸尾，朴硝葙子及大黃，外障菊花牛蒡蛻，石菖元細蒺藜芎，蔓羌草決防黃柏，黃連葙子生地羚，犀角款冬白芷柏，赤芍車前覆盆楮，木賊穀精及菟絲，龍膽諸醫須要知。
