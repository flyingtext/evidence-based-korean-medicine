# 眼目虛實冷熱論

一眼上午不痛，下午大痛，是虛熱也。

一眼上午大痛，下午不痛，是實熱也。

一眼淚多者是虛熱，少者是實熱也。

一眼淡白紅者，是虛熱也。

一眼不痛不疼，翳膜漸漸遮睛，冷也。

一眼內膜翳帶白色，冷也。

一眼有疼痛，翳膜漸漸遮睛，熱也。

一眼神腎水脫歸瞳子者，氣連清淨府也，午前為陽，午後為陰，冷也。

虛實寒熱歌

虛熱淚多淡白紅，上午不痛下午痛。實熱淚少鮮紅腫，午後不痛午前痛。

不痛翳膜漸遮睛，翳帶白色冷可定。疼痛翳膜漸遮睛，更帶紅色熱始審。
