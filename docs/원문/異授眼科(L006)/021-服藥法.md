# 服藥法

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

目疾眼藥，每每不得速應，故服藥者鮮矣。古云：鍋中點水，不如灶底抽薪，點藥服藥，此為內應外合之意也。服於食前固不可，服於食後，皆是運動之際，藥行四散，亦不得取效。惟於臨臥之時，臥而服之，兩眼皆合，精神潛伏，藥性上升，必走空竅，故於兩目皆應。
