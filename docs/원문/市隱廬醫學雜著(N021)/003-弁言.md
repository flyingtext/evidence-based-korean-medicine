# 弁言

> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

不侫父兄師友，莫不知醫。自幼見聞，略識門徑，中年以往，餬口四方。稍稍涉獵方書，窺測《素》、《靈》微旨。家人有恙，藉以自治。親故見招，不能固卻。世方多故，遂棄青氈。二十年來，漸深閱歷。爰抒心得，用告病家。不能阿傳時流，安敢背違先哲？亦聊資考鏡云爾!

<ins>玉峰歲居士書於吳門市隱廬時在癸丑清和月</ins>
