# 蕪菁說

蕪菁者，一名九英菘，即蔓菁也。南北隨地可蒔，而北方為多。《毛詩》為之葑，其性易生而滋長。故武侯行軍，教士卒種之以備饑，蜀人呼為諸葛萊。馬毀攜入南中猺狫，今猶呼為馬王萊。而蒙古則稱為沙吉木兒。其葉似芥，闊大而厚，莖短而租。夏初起台，開黃花，四出結角，子似芥子，而色紫赤，勻圓根，如蘿蔔，青白而圓長。六月種者，根大而葉蠹。八月種者，葉美而根小。惟七月初種，則根葉俱佳。京師人家以瓶醃藏，名閉甕菜，差似撇蘭耳。其性苦平，利氣消食，治嗽通淋，殆清熱祛滯之品。其子大能明目，而榨油然燈又損目，此物理之變幻也。李時珍稱其可升可降，能汗能吐，能解蜘蛛毒，其根解酒止衄，拔疔根，消陰腫如斗。亦日用恒需之藥，非特僅於療饑而已。且於立春後庚子日，搗根汁，闔家以次溫飲之，可辟時疾。其有裨於世，非淺鮮用為之說，以揚其功用云。

附：治青盲方？但瞳子不壞者，十可療九。用蔓菁子六升蒸之，氣遍合甑，掇下，以釜中熱湯淋之，乃曝乾，如是三蒸三淋三曬，杵為末，食後清酒服方寸匕。

又方　常服能洞視臟腑。蕪菁子三升，苦酒三升(苦酒，醋也)，煮熟曬乾為末，以井華水服方寸匕，日三服，盡一斗，夜視有光云。

煮蔓菁菜作食，先用水炸熟，漉出，另用冷水浸一宿，去水加油鹽炒食之，否則味苦不堪食。
