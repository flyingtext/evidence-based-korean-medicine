# 附子吳茱萸乾薑論

<!-- source-id: O117:p006 -->
> 서명: 鱠殘篇
> 원본 파일: `O/O117.txt`
> 원본 SHA-256: `7f80f013094f47fd7170e98c31bedb3bade2b4c62e3fd148c5d75d1b65c131c0`
> 상태: 자동 변환 원문·정본 미대조

經曰：大毒治病，十去其五；無毒治病，十去其九。二者相形，而時尚何多惑焉？蓋直達少陰，祛寒救敗，誰如附子：善走厥陰，燥濕定痛，莫過吳萸；散表溫中，快脾利膈，更尚乾薑。此三者誠三陰斬關奪命之將也，然於諸熱藥中為最烈，過劑誤施必有動血僭上之患跡，其功能直朱家郭解遊俠之流言，信行果急人之急，捐軀赴難，可存亡生死而收效旦夕者耶？然一不善馭，未免以武犯禁，而取笑同類矣。蓋其氣雄性毒走疾而悍，或氣味俱厚，偏陽少陰。故附得薑而愈熱，得桂而善走；茱得薑而益散，非以甘緩監之，難免疾馳銜橛之變也。故八味丸用桂、附以消陰翳，不過全料中之什一；左金丸用吳萸以開肝鬱，而黃連五倍之。王好古有補火須防涸水，烏、附非身涼肢厥脈沉遲者不可擅投之，戒其慎始要終之道歟。然古人亦有終身餌烏、附、椒、萸而年登耄耋無恙，此又稟賦之殊，偶有之事，不可以為訓。昔子產論政，以水懦弱，慮民玩而多死，今之用藥反狎玩猛烈之火，至噬臍而弗悔，何哉？其必曰：砒礐鴆鱷方為毒，而不思中病即止之戒與。
