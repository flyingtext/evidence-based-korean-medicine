# 左金丸

川黃連炒，六兩　吳茱萸滾湯泡炒，一兩　水跌為丸

《醫宗金鑒》胡天錫曰：治肝之法有數種，水衰而木無以生，用地黃丸，乙癸同源是也。土衰而木無以植，用參、苓、朮、草，緩肝培土是也，本經血虛有火，用逍遙散清火；本經血虛無水，用四物湯養陰。至於補火之法，亦下同於腎。而瀉火之法，則上類乎心。左金丸獨用黃連為君，從實則瀉子之法，以直折其上炎之勢。吳茱萸從類相求，引熱下行，並以辛燥開其肝鬱，懲其捍格，故以為佐。然必以本氣實而土不虛若，庶乎相宜。左金者，木從左而制從金也，特治肝藏實火左脅痛者。

按；時下凡遇脅肋脹痛，肝脾不調之症，動輒以左金投之，是未察左金之義也。《金匱要略》有云：見肝之病，以先實脾。若脾虛，為肝木所乘。再用黃連以瀉心火。但知瀉肝之子，不顧瀉睥之母乎？當衡其輕重緩急而施治，慎勿偏任也。
