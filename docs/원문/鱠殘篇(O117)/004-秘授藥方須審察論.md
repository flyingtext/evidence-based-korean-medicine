# 秘授藥方須審察論

> 서명: 鱠殘篇
> 원본 파일: `O/O117.txt`
> 원본 SHA-256: `7f80f013094f47fd7170e98c31bedb3bade2b4c62e3fd148c5d75d1b65c131c0`
> 상태: 자동 변환 원문·정본 미대조

孟子曰：居移氣，養移體。《素問》曰：東方濱海，食魚而嗜鹹，其人黑色疏理，病多瘡瘍，治宜砭石；西方陵居，風多而土剛，其人華食肥脂，病生於內，治宜毒藥；北方地高，風寒而冰冽，其人野處乳食，病多藏寒，治宜灸嫡；南方地下，土弱而霧聚，其人嗜酸致理，病多攣痹，治宜微針，中央地平濕，其人雜食而不勞，病多痿蹲，治宜導引按蹻。《家語》曰：堅土之人剛，弱土之人懦，壚土之人細，息土之人美，耗土之人醜。觀此則人之形質皆由水土飲食之所變生，而於起居服食可不慎所擇哉？故枸菊之鄉多壽，而酒色之戕致夭。五行更迭，生克乘除，有常道焉。亢則害，承乃制，不可偏倚也。是以腎氣過強則妨心，而驚悸愴恍生；心氣過旺則戕肺，而咳嗽煩冤生；肺氣過實則傷肝，而目眵涕淚生；肝氣過盛則克脾，而飧瀉(月真)脹生；脾氣過滿則害腎，而痿躃重膇生。皆亢害而失其平易也．聖人制為藥餌，針灸、按摩、導引、祝由以平治之，救其偏也。至於湯液之方，創於伊尹，盛於長沙，後賢遞興，則有七方十劑之等差，君臣佐使之配合，而尤當審其反畏惡欲之性以劑之，始可以為方。方之所以為方者，使之方向而不違，平易大方而雅俗共賞也。故其表表於醫籍者，桂枝、麻黃、青龍、白虎、三承氣、四瀉心之祛邪返正也；四君、八物、十全、六味、五子、七寶、建中、補中，以及虎潛、河車等之培元扶弱也。藥品不多於十味，對症取效於頃刻。亦何曾探奇搜異，必致力於赤箭、青芝、牛黃、狗寶方形神效也？乃今多有聚集鱗介毛倮中一切臊膻熱澀，如肭臍、狗腎、海馬、蛤蚧、全蠍、紅鉛之屬，輔之以桂、附、椒、茱、腦、麝之類，辛香臭腐數十種雜為一方，亦不問其反畏惡欲、君臣佐使之謂何，豔稱其名號，可奪造化，極贊其功能克轉乾坤。一藉捷劫之性，取效片時，暢人欲志，不顧流禍於隱微，積久而大患突起，駭人聞見而不遑救者多矣。總由術士之眩惑，貴介之樂聞，而不察天地有常道，聖人有至論。所謂五穀為養，五菜為充，五果為助，五行相生，五藏以安，順其天常，安其地利。而必欲強其詞曰、人定可以勝天者，殊不知服全鱉丸久，而腹生小鱉以戕軀，餌龍骨粉多，而腸腑生癰以斃命，前人已受害者矣。夫子曰：未達不嘗。所謂達者，非徒達藥而已，意必達藥性之良劣，與吾身之宜否，而後敢服。詎可不察吾身之固有，而漫為嘗試？致犯虛虛實實之禁，失其平易而生偏勝之災，甚至亢火消陰，變幻非常者有之。經曰：芳草發狂，石藥發癲。可不慎諸？況恬淡虛無，真氣從之。黃帝養生之妙訣可師。肉食者鄙，未能遠謀。曹劌論戰之快談堪取。苟能毋搖爾精，毋勞爾神，起居有節，自可長生。是故氣足則不饑，神足則不睡，精足則不淫。克寶吾身之寶，亦何有於外物哉？然而天地之間，土為萬物之母，人身之中，胃為水穀之海。語云：節飲食者，卻病之良方；理脾胃者，醫中之王道。脫欲綢繆於未雨，請從事於脾胃。庶飲食強而穀氣化精，則神氣不期足而自足，又何籍於藥餌之扶吾也耶？附詩：寒夜無聊遺漏長，挑燈起坐讀岐黃，至人精論皆金石，朮士誇談屬老莊，咀嚼素靈非好辨，揶榆朱紫慎推詳，螽斯自古稱西伯，不見流傳種子方。
