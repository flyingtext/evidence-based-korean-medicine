# 癉瘧

<!-- source-id: O117:p011 -->

> 원본 SHA-256: `7f80f013094f47fd7170e98c31bedb3bade2b4c62e3fd148c5d75d1b65c131c0`
> 상태: 자동 변환 원문·정본 미대조

經曰：癉瘧者，肺素有熱，氣盛於身，厥逆上衝，中氣實而不外泄，因有所用力，腠理開，風寒舍於皮膚之內，分肉之間而發，發則陽氣盛而不衰，不及於陰，故伹熱不寒，氣內藏於心，外舍於分肉，令人消爍脫肉。

按：此則治癉瘧主於肺熱，實者白虎湯，虛者竹葉石膏湯，或君以知母，佐以人參，但二味更專功也。
