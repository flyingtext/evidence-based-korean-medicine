# 羊毛疹子辨論

余客金陵四十餘年，舟車經遊十一省，所交四方知醫之土不下百什人，從未聞所謂羊毛疹者。乾隆辛卯壬辰間，有客醫倡是說以語人，用蕎麥面搓人胸背而治之，金陵逾甲老醫亦未曾見是症是治也，故疑信相半。客醫乃援《證治準繩》療瘡門所載羊毛疔，及《醫宗金鑒》療瘡門注釋所述，並《說鈴談往》所紀三條以示人，在明理者雖未之全信，然不能詰其原以究其理，好事者乃從而和之，稍稍昌熾其說矣。余甚慨焉，因即其示人書逐條明辨之，非余好為揶揄其說也。蓋恐亥豕魚魯之不分，將以為人生性命之患，然猶未敢自信為所辨減是也，特引經據理而疏述之質諸。考古君子定其然否，知我罪我，弗遑顧焉。

王肯堂《證治準繩》療瘡門載濮陽傳云：萬曆了亥，金台有婦人遍以羊毛鬻干市，忽不見。繼而，都下人身生泡瘤，漸大痛死者甚眾。瘤內包有羊毛，後一道人傳方，用黑豆、蕎麥為粉，塗擦之，毛落而愈。

《說鈴談往》云：崇禎癸未，京師時疫，病起必有紅點在背中，包羊毛一縷，無得活者，疫死無算。

《醫宗金鑒》疔瘡注釋下云，有羊毛療症，身發寒熱，狀類傷寒。但前心後心有紅點如疹形，視其癍紫黑者為老，淡紅者為嫩。宜蟾酥丸汗之，五味消毒飲汗之。愚按以上三條，一則為天行疫癘之成療者，一則為災疫毒發於背而似癍疹之類者，一則為療瘡中有紅點發於前後心如疹形者，並未實指為疹也，況有可救者，有必死者，有以藥汗之而可愈者，輕重奇恒之階判然，豈可不逐一明辨之而混曰羊毛疹子為四時常有之疾乎？蓋首條有婦人鬻毛於市而生泡瘤，痛死毛現，此之謂天行疫邪也。況泡瘤狀大，發無定處，內包有毛類於羊毛，名之曰羊毛療猶近似也。原未曾曰羊毛疹也，然亦必在春秋行疫時有之。萬曆丁亥偶有之，前乎此後乎此未之聞也，次條乃疫癘極甚，毒發於背，紅點似疹、含毛、此之謂災眚怪症，呼曰羊毛疫可也，未可呼曰羊毛疹也。且法無可治麗必死，否則萬歷時道人方為時末甚遠，豈人盡不知而一試治之？若謂療可治疹不可治，則今之養麥，又何益耶！第三條乃疔瘡中兼見前後心發紅點者，並末指明毛在疔抑在點，當去毛與否。蓋《金鑒》乃禦纂書，太醫秉筆，因《準繩》等書載有前條，不敢遺又不敢信，故於注釋內載此數語，要知吳太醫亦未嘗經見是症也，意其發於膻中背俞之分，散示人以汗解之。亦只曰羊毛疔面末日羊毛疹也。總而論之病有奇恒，時有治亂，事當尋理。疔與疹懸殊也，疔痛疹不痛，疔大而疹細，疔無定處，疹及遍身，豈得以療有羊毛之症而渾曰羊毛疹乎？即據《說鈴》所紀，紅點發於背而病疫生毛，《金鑒》所述紅點發於前後心而患疔生斑，可見獨發於此而不及他處者，始可斷曰羊毛疫，羊毛疔亦未曾直書曰羊毛疹也。今若以肺經鬱熱咳嗽而發疹亦遽曰羊毛疹可乎？若傷寒熱干陽明面發癍亦是紅點，亦概曰羊毛疹乎？若然，則凡痧麻癮痤其中皆有羊毛乎？倡是說者固非鑿空無本之談，然察理欠明，不當以明季災異之怪症而侈談為盛世常有之疾病，致使痤疹痧麻鹹混羊毛之說，惟以去毛為治，滋害深矣。明理者當慎察之。查《本草》大豆條下云；能制牛馬瘟毒。《夷堅志》云：靖康二年春京師疫，有異人傳方用黑大豆二合，炒熟炙甘草一錢，煎湯時時飲之立愈，可見大豆能治天行瘟疫之毒也。又蕎麥條下云；苦蓧性寒能脫人鬚髮還生，亦稀道人用此二物，一以治毒，一以去毛，拯一時之災也。今客醫見人胸背偶有痱痤之類，輒教以荍面，連旬累月而搓擦之，寧不毫毛隨面而黏落，遂指人身之毫毛為羊毛，妄矣！然毛疹固屬牽混，而毛疔、毛疫之災究何自生，查《宋太史書》云：山林之人毛而瘦，得木氣多也，《素問》云：毛蟲屬木，則毛之為災乃少陽木氣強盛，得濕熱蒸溽而生，譬如罨醬曲於夏暑少陽工時之候，不數日而毛生，氣變矣。經又云；肝膽屆木，其氣臊，剛毛秉木氣而生，是羊毛疔疫之患為少陽經病。木邪侮金髮於肺部之膻中背俞之分，生毛而氣臊，有類於羊，面名之。豈人之身而真有羊毛耶？且夫少陽為樞，太陽為開，陽明為闔。樞運而外辟達於太陽，可汗而愈。毛其化矣。樞滯面內閉歸於陽明，入於腑臟，昏冒惑亂，人死而毛見矣。假遇是證，理應達木鬱，疏肺邪。初感為淺者，荊防敗毒散加豆豉之類汗之。日久而深者，防風通聖散表裏雙解之。若果皮破毛現，時氣鹹若，即道人方原不可廢。總之為疔為疹咸皮也，不可與凡百常病同視也。謂疫厲中有此毛療毛疹之症，則可謂疹症中常有，羊毛之症則不可也，又查五常政大淪曰：敷和之紀，木德周行，云云。其蟲毛。委和之紀，是謂勝生，生氣不治，化氣乃揚，其蟲毛介，其病支廢癰腫瘡瘍，眚於三。發生之紀，是謂啟敕，土疏泄，蒼氣達，其病怒，太角與上商同(上商、陽明司天)，其蟲毛介。又曰厥陰司天，毛蟲靜，羽蟲育，介蟲不成。在泉，毛蟲育，介蟲耗，羽蟲不育。少陽司天，羽蟲靜，毛蟲育，倮蟲不成。在泉，羽蟲育，介蟲耗，毛蟲不成。氣交變大論曰：歲金太過，燥氣流行，胸痛引肩，歲金不及病，內舍騰脅，外在皮毛。又曰：有德有化、有政有令，有變有災，而物由之而人應之也。又曰：以道留久，邊守而小，是謂省下；以道而去，去而速來，曲而過之，是謂省遺過也：久留而環，或離或附，是謂議災與其德也。

按：木平曰敷和，不及曰委和，太過曰發生，災病曰眚，留守曲環星象，省察分野，審德罪而降災福也。故本子歲，其蟲毛，得木氣專而靜也，不及則毛介，介乃金屬，金來兼化而介蟲同生也。太過亦毛介者，木盛淩金面齊化，毛介並生也。尋繹各經文，則木邪無不關於金也，症未有不發於胸背部分也。若盛朝熙皞之際，歲氣縱有災侵，德化可以消弭，此留守曲環之所以遺省者也。如丁亥乃委和之紀，金兼木化，歲運丁王化木，司天厥陰風，木運與天符二木，比助轉委而強，接交春分二氣，後太徵，火客運來，臨木火過強，金受其制，勝復之作疵厲盛行而生，毛疔木之眚也。婦人鬻毛亦歲運災星之脫化，豈真有婦人耶？泡瘤腫痛即經所云癰腫瘡瘍也，瘤內有毛即經所云眚於三，三乃木之生數，而見災異病也。迨後癸未乃小逆之歲，立春初氣主客同為厥陰，木春分二氣，主客同為少陰火，歲運戊癸化火，木火相生而熾。至小滿三氣客氣濕土，臨主氣相火之上，濕熱蒸溽而疵厲起，均歲運節氣之所致。當明季末運，尚有何德化而弭此災變也耶？至於運氣，雖六甲一周而災祥乃因時而變，前此之丁亥癸，未曾未聞有此毛疔毛疫也。後此之丁亥癸未，又屢更矣，而熙皞承平更未知有疢疾，乃者忽倡為異說以惑人，其不審也甚矣。值此德化，覃敷萬邦，和洽編氓，隱瘼久被，南薰之解慍，何業醫者不守常而好異是為哉？

天行時疫，本不常有，索隱行怪者偶倡惑世。誣民之說，知醫者少，以訛傳訛，始則妄指怪症，繼則妄投謬藥，為害不淺矣。萍如先生哀之，條晰明辨，灑灑干言，洞若觀火，如秦人照膽鏡，表裏明徹。吾知心不正者，見之卻走，為功斯世，豈淺鮮哉？亟勸付梓，俾戶誦家弦，齊登壽域，勝刻《太上感應篇》、《文昌陰騭文》千百紙也。

乾隆癸巳落燈後三日同學弟古漁陳毅跋。

加減參蘇飲

治四時感冒、風寒、頭痛、發熱、憎寒、咳嗽、涕唾、稠黏、胸隔滿悶、脈弱、無汗並停滯飲食、腹痛、欲作瀉痢等症。歌曰：蘇葛前胡合二陳，枳香甘桔共云苓，人參特為虛人設，加減推洋要性靈。

紫蘇　葛根　前胡各二錢　陳橘皮　製半夏　枳殼各一錢　廣木香　炙甘草　桔梗各八分　茯苓錢半　人參酌用，連須蔥頭三個生薑六七分，隨時增減　紅棗三枚

按：風寒感在太陽膀胱經，則能傳經以其主一身，極表浮陽之地。故遞傳三陽而病陽行速也。占法用桂枝麻黃二湯，發營衛之汗，不使再傳者。以佳麻辛甘發散純陽之晶，寒邪容於太陽寒水之經用此純陽迅速之藥，以氣相從而奏效捷也。若已傳他經者投非其時，即禍不旋踵。故後人以九味羌活湯、人參敗毒散代之誠詳慎矣。若風寒感在太陰肺經則不傳經非太陽之可比。蓋肺主氣，經云：邪之所湊其氣必虛，氣虛之人不拘四時，易於感冒。不與傷寒時行之際強弱均受者同日而語也。此方於發散藥中，用參、苓、草以固氣，即沖和湯中，用生地以養血，同意知非可徒恃峻表而愈也。況應用桂麻之症，而用蘇、葛、柴前失之不及，猶無傷害。若只須蘇、葛可療而過，用桂麻為害多矣。方中蘇、葛、前胡，清熱解肌；陳、夏、枳、香，利痰疏氣；苓，草安胃和中；桔梗載藥。上浮直達胸中表裏兼行，若形體素弱或年高久病之人，則人參臨時酌用。總之肺為太陰燥金，清肅之地宜於清散。不同太陽寒水之經，可施辛溫猛悍之藥。經絡不同當詳識之，且此等症候，最多切勿小題大做。

加減法

傷飲食、胸脅脹滿、噯氣不舒者，加山楂肉，麥芽．神麯，倍木香；大便難者加杏仁泥，血虛而大便秘結者，加歸尾、桃仁泥；小便少者加澤瀉、倍茯苓，頭痛因火者加甘菊花，因血虛者加當歸、川芎。如一二劑後，表解熱除而咳嗽不止，喉干舌燥者，加百合、天花粉或貝母，除去半夏、木香、蔥、薑、棗，本方除去人參、前胡，用川芎、柴胡、名芎蘇飲，則入厥陰少陽而宜於血虛火盛者，減參恐其助氣而動火也。本方除去人參，半夏加芎．歸治新產後，感冒、發熱、頭疼及虛損吐血人。感冒、發熱、咳嗽，無汗者，養血則汗作也。半夏有三禁：產後，汗後、血家，俱不可投。其他如玉竹、荊芥、博荷，俱可量加。利熱則梔子、連翹，亦可擇網。鄉村旅次乏醫之處，偶值微屙照方揀投，最為穩妥，用疏之以公諸世，亦方便之一端耳。
