# 醫門經論

神農本草曰《本經》，黃帝靈樞、素問曰《內經》，皆聖經也。仲景先師，著卒病曰《傷寒》，著雜病曰《金匱》，此賢論也。醫門聖經、賢論，猶儒者之五經、四書也。故醫門經論，乃醫學正傳，其餘《難經》、《脈訣》及後人一切方書，皆逐末亡本，膚淺不經，不可為訓。何世之醫者，於聖賢經論，從未嘗讀，即讀亦未解，解未能明，明未能用。悲夫！
