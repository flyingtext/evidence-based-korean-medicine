# 霍亂與少陰寒熱同候

<!-- source-id: F007:p013 -->
> 서명: 陰證略例
> 원본 파일: `F/F007.txt`
> 원본 SHA-256: `0a4321df1257c8183a0bdbac48fb8a36ddd52eb0554b17019343dc740145a37c`
> 상태: 인터넷 판본 1차 결자 대조 완료·전면 교감 전

海藏云：霍亂頭痛發熱，其邪自風寒而來。中焦為寒熱相半之分，邪稍高者居陽分，則為熱，熱多飲水者，五苓散以散之；邪稍下者居陰分，則為寒，寒多不飲水者，理中丸以溫之。所以同少陰入里，與手經接為熱，大承氣湯下之；與足經接為寒，四逆湯溫之。
