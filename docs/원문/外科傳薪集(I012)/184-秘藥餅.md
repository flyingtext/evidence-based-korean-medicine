# 秘藥餅

秘藥餅六枚三錢. 臨用時研極細末. 每二分加後藥七味.　大梅片（四分）　珍珠（四分）　西黃（二分）　麝香（六分）　輕粉（一釐）　硼砂（二分）　共為細末. 和勻收貯. 吹之.　此餅誠不可解. 七味又只六味而云臨用再加. 則似尚有上藥數味也.
