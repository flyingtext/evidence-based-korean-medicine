# 한약의 안전성과 독성

한약·본초·처방의 안전성과 독성을**KCD-8(한국표준질병사인분류 제8차 개정) 질환군별**로 정리한다. 한약 독성이 임상적으로 문제가 되는 상황은 세 가지 측면으로 구분한다.

-**측면 ① — 약재 자체 독성**: 본초·성분 자체가 장기별 손상(간·신·심·생식 등)을 일으키는 경우. 용량·기간·변증과 무관하게 발현 가능.
-**측면 ② — 양한방 협진 시 조건부 사용**: 양약 치료 중 한약 병용이 상호작용 위험을 갖되, 적정 범위·모니터링 하에 사용이 가능한 경우.
-**측면 ③ — 절대 금기**: 양약 치료 regime(항암·면역억제·항응고 등)과 병용 시 치명적 위험, 또는 질환 자체가 한약 사용을 원천 배제하는 경우.

각 질환군 문서는 다음 하위 목차를 원칙으로 전개한다.

1.**KCD 코드와 질환군 정의**
2.**병태생리(病態生理)**
3.**표준 의학적 intervention(양약·시술·수술)**
4.**의학적 intervention의 약리학**(작용 기전·대사·치료역·안전역)
5.**한약재와의 독성학적 상호작용 검토**(측면 ①②③별 정리)
6.**협진 시 한방 개입 여지와 금기 역치**
7.**근거(논문·사례 보고·규제)와 한계**

> 이 폴더는 조사 단계이므로 아래 KCD 장(章) 전체를 펼쳐놓되, 각 장의 하위 질환군 코드는 실제 조사를 진행하며 점진적으로 채운다. 본초 자체 독성(간독성·신독성 등) 관련 별도 정리는 문서 내 '측면 ①' 절에서 통합 다룬다.
