# 산부인과 (産婦人科)

한의학 산부인과 이론(충임(衝任)·포궁(胞宮)·천계(天癸) 이론에 기반한 여성 생리·병리론)과 현대 산부인과학을 통합적으로 다루는 임상 각과 문서군. 월경·임신·산욕·부인과 종양 등 여성 생식기 관련 질환을 KCD-8(한국표준질병사인분류 제8차 개정) 체계에 따라 정리하는 것을 목표로 한다. 파일명은 한글 표준명, KCD-8 코드는 본문에 명시한다.

**목차 구성 원칙**: 산부인과 질환은 KCD-8상 크게 ① 여성생식기 비염증성 장애(N80-N98), ② 내분비계 이상에 의한 부인과 질환(E00-E90 중 배란·난소 기능 관련), ③ 임신·출산·산욕(O00-O99), ④ 여성생식기 및 유방 종양(C50, D25-D28)의 네 챕터에 걸쳐 분포한다. 이에 따라 이 폴더의 목차는 위 네 챕터 순으로 구성하며, 각 항목에는 KCD-8 코드와 파일 존재 여부에 따른 "**작성됨**"/"(작성 예정)" 상태를 명시한다.
