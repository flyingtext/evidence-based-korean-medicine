# 재활의학 (再活醫學)

한의학적 추나·침구·약침 치료와 현대 재활의학(물리의학·전기진단·중재적 통증시술·운동치료·보조기 등)을 통합적으로 다루는 임상 각과 문서군. 근골격계 통증 질환을 중심으로 척추·상지·하지·전신성 류마티스 질환, 신경계·심폐·소아 재활 등 재활의학의 전 영역을 망라하는 것을 목표로 한다. 개별 질환의 육안 해부학적 배경은 기초한의학 해부학 폴더, 경혈 자침 기법은 경락경혈학·침구학 폴더에서 다루며, 이 폴더는 질환 단위의 진단·변증·치료·예후·관리에 집중한다.

**목차 구성 원칙**: 아래 "1. 근골격계통 질환(KCD-8 M00-M99)"은 KCD-8(한국표준질병사인분류 8차) 근골격계통 및 결합조직의 질환 대챕터를 코드 블록 순서대로 전수 대조하여 구성했다. 각 블록 아래 개별 질환에 기존 작성 문서를 매칭하고, 미작성 항목은 "(작성 예정)"으로 명시해 누락 없이 목록화했다. M-챕터 밖의 재활 관련 질환(신경계 후유증 G-코드, 손상 후유증 S-코드)과 진단·치료 방법론·안전성 문서는 2~5절에 별도로 정리한다.

- 도수·이학적 검사(Physical Examination) — (작성 예정) 관절별 유발검사(Special test)·근력·감각·반사 검사와 추나 변증의 상관
- 근골격계 초음파 유도 시술(Ultrasound-Guided Procedure) — (작성 예정) 초음파 유도 약침·건단독술(needle tenotomy)·신경블록의 근거와 안전성
- 통증 평가·척도(Pain Assessment) — (작성 예정) VAS·NRS·McGill 통증 설문지·기능장애지수(ODI·NDI·DASH 등)의 임상 활용
- 추나요법(推拿療法, Chuna Manual Therapy) 총론 — (작성 예정) 근골격계 질환별 추나 기법 분류·근거·안전성 총론
- 약침요법(藥鍼療法, Pharmacopuncture) 총론 — (작성 예정) 봉약침·중성어혈침·신바로약침 등 제제별 근거와 안전성
- 도침(刀鍼, Acupotomy) — 침구과 문서(`docs/임상한의학/침구과/도침(刀鍼, Acupotomy).md`)에서 만성 유착성 병변에 대한 도침 근거·시술 기법·안전성을 다룸
- 물리치료 양식(物理治療樣式, Physical Modalities) — (작성 예정) 전기자극치료(TENS·간섭파)·초음파치료·체외충격파(ESWT)·견인치료·냉온열치료
- 운동치료(運動治療, Therapeutic Exercise) — (작성 예정) 근력강화·신장·고유수용성감각 운동의 질환별 처방 원칙
- 중재적 통증시술(中在的 痛症施術, Interventional Pain Procedures) — (작성 예정) 신경차단술·경막외강 주사·프롤로테라피의 한의 임상 접점과 안전성
