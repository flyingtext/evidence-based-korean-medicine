# 사상의학 (四象醫學, Sasang Constitutional Medicine)

이제마(李濟馬)의 《동의수세보원》에서 정립된 한국 고유의 체질의학.

**목차 구성 원칙(사상의학의 특수성)**: 사상의학은 소아과·순환기 등 대부분의 임상 각과 폴더와 달리 질환명이 아니라 체질(태양인·태음인·소양인·소음인)로 1차 분류된다. 체질명 자체는 단일 KCD-8 코드를 갖지 않으며, 각 체질 문서 내부의 "KCD 질환군별 각론"(또는 이에 준하는 절)에서 실제로 다루는 개별 질환군에 KCD-8 코드를 부여한다. 이 README의 문서 목록에는 각 체질 문서가 본문에서 실제로 다루는 KCD-8 코드를 표기하고, 아래 "체질별 KCD 취약질환 대응표"에서 4체질을 병렬 비교한다. 소음인 위수한리한병·소음인 신수열표열병처럼 체질보다 하위 단위인 전통 병증 문서는 병증 자체가 서양의학 진단명과 일대일로 대응하지 않으므로, 해당 문서 안에서 코드가 명시된 부분만 표기하고 그렇지 않은 병기 개념은 "KCD 코드 미대응(전통 병기 개념)"으로 정직하게 남긴다.
