# 신경정신과 (神經精神科)

한의학적 정신(情志)·심신(心身) 이론(칠정七情·오지五志·심주신명心主神明)과 현대 정신의학·신경과학의 진단·치료를 통합적으로 다루는 임상 각과 문서군. 정신 및 행동장애(KCD-8 F챕터)와 신경계통 질환(KCD-8 G챕터)을 망라하는 것을 목표로 한다. 개별 신경계 구조의 육안 해부학적 배경은 기초한의학 해부학 폴더(신경계·신경), 변증 이론은 한방병리학 폴더에서 다루며, 이 폴더는 질환 단위의 진단·변증·치료·예후·관리에 집중한다.

**목차 구성 원칙**: 아래 목차는 KCD-8(한국표준질병사인분류 8차) 정신 및 행동장애(F00-F99)와 신경계통의 질환(G00-G99) 두 대챕터를 코드 블록 순서대로 전수 대조하여 구성했다. 각 블록 아래 개별 질환에 기존 작성 문서를 매칭하고, 미작성 항목은 "(작성 예정)"으로 명시해 누락 없이 목록화했다. 두통·어지럼증처럼 여러 원인 질환을 아우르는 증상 기반 표제어는 별도 절(3절)에 정리한다.
