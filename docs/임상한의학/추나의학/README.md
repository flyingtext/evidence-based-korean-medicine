# 추나의학 (推拿醫學)

추나 등 수기 요법 문서. 한의과대학 교과서적 표준 명칭(한글 + 한자)을 사용한다.

## 문서 목록

- 추나의학(推拿醫學, Chuna Manual Therapy)
  - 하위 표제어: 척추 교정 추나 · 관절 추나 · 연부조직·근막 추나 · 소아 추나 · 안면 추나
- 소아추나(小兒推拿, Pediatric Tuina)

## 적응증 KCD 코드 대응표

추나의학은 질환이 아닌 치료 기법(수기요법)을 다루므로, 이 폴더 자체에는 단일 KCD 대챕터가 대응하지 않는다. 대신 각 문서 본문(제3편·제4편)이 실제로 인용하는 KCD-8 적응증 코드를 기법 계열별로 정리한다. 코드·명칭은 각 문서에 명시된 것만 반영하며, 상세 근거(치법·병행요법·예후)는 원문서를 참조한다.
