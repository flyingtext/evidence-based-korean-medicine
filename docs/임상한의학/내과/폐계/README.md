# 폐계 (肺系)

한의학 오장변증(五臟辨證)의 폐(肺) 계통 이론(폐주기肺主氣·폐주치절肺主治節·폐주피모肺主皮毛)과 현대 호흡기 내과학을 통합적으로 다루는 임상 각과 문서군. 상기도·하기도·폐실질·흉막의 현대 질환을 망라하는 것을 목표로 한다. 파일명은 한글 표준명, KCD-8 코드는 본문에 명시한다. 폐(肺)의 생리 기능 이론은 한방생리학 폴더(폐주기·폐주치절), 호흡기계 육안 해부학은 기초한의학 해부학 폴더에서 다루며, 이 폴더는 질환 단위의 진단·변증·치료·예후·관리에 집중한다.

**목차 구성 원칙**: 아래 목차는 KCD-8(한국표준질병사인분류 8차) 호흡계통의 질환(J00-J99)을 코드 블록 순서대로 전수 대조하여 구성했다. 각 블록 아래 개별 질환에 기존 작성 문서를 매칭하고, 미작성 항목은 "(작성 예정)"으로 명시해 누락 없이 목록화했다. 상기도 질환 중 코·인후 관련 세부 질환(비염·부비동염·인후통 등)은 안이비인후피부과 폴더에서 이미 다루므로 이 폴더에서는 하기도·폐실질·흉막 질환과 감기 등 전신 감염성 질환에 집중한다.
