# 비계 (脾胃系)

한의학 오장변증(五臟辨證)의 비(脾)·위(胃) 계통 이론(비주운화脾主運化·비주통혈脾主統血)과 현대 소화기 내과학·대사내분비학을 통합적으로 다루는 임상 각과 문서군. 위장관·췌장·대사질환·조혈계 악성종양의 현대 질환을 망라하는 것을 목표로 한다. 파일명은 한글 표준명, KCD-8 코드는 본문에 명시한다. 비(脾)의 생리 기능 이론은 한방생리학 폴더(비주운화·비주통혈), 변증 이론은 한방병리학 폴더(비기허·비양허·비음허 등)에서 다루며, 이 폴더는 질환 단위의 진단·변증·치료·예후·관리에 집중한다.

**목차 구성 원칙**: 아래 목차는 KCD-8(한국표준질병사인분류 8차) 소화계통의 질환(K20-K93 중 간·담낭 제외 블록)을 코드 순서로 전수 대조하고, 대사·영양 질환(E65-E88 일부)과 조혈기관 악성종양(C81-C96)을 챕터 경계 절로 추가해 구성했다. 간·담낭·담도 질환(K70-K87 중 간·담도부)은 간계 폴더, 구강·타액선 질환(K00-K14)은 안이비인후피부과 폴더(구내염·구강건조증)에서 다루므로 이 폴더에서는 다루지 않는다. 치핵(I84)은 순환계통 챕터 코드지만 관행상 이 폴더에서 다룬다.
