# 신계 (腎系)

한의학 오장변증(五臟辨證)의 신(腎)·방광(膀胱) 계통 이론(신주수腎主水·신주골腎主骨·신주생식腎主生殖·방광기화膀胱氣化)과 현대 신장내과학·비뇨기과학·내분비대사학·류마티스면역학을 통합적으로 다루는 임상 각과 문서군. 신(腎)이 골(骨)·생식(生殖)·수액대사(水液代謝)·선천지본(先天之本)을 폭넓게 주관한다는 한의학 이론에 따라, 비뇨기계통 질환뿐 아니라 골대사·당뇨병·자가면역/결합조직 질환까지 포괄하는 것을 목표로 한다. 파일명은 한글 표준명, KCD-8 코드는 본문에 명시한다. 신(腎)의 생리 기능 이론은 한방생리학 폴더(신주골腎主骨·신주납기腎主納氣), 비뇨기계 육안 해부학은 기초한의학 해부학 폴더에서 다루며, 이 폴더는 질환 단위의 진단·변증·치료·예후·관리에 집중한다.

**목차 구성 원칙**: 아래 목차는 KCD-8(한국표준질병사인분류 8차) 비뇨생식계통의 질환(N00-N51 중 신·요로·남성생식기 부분) 대챕터를 코드 블록 순서대로 전수 대조하여 구성했다. 각 블록 아래 개별 질환에 기존 작성 문서를 매칭하고, 미작성 항목은 "(작성 예정)"으로 명시했다. 신(腎) 이론의 파급 범위를 반영해 골대사(M80/M81)·통풍(M10)·당뇨병(E10-E14)·전신 결합조직질환(M30-M36)은 챕터 경계 절로 포함한다. 여성생식기 질환은 산부인과 폴더에서 다루므로 이 폴더에서는 다루지 않는다.
