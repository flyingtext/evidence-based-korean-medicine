# 심계 (心系)

한의학 오장변증(五臟辨證)의 심(心) 계통 이론(심주혈맥心主血脈·심주신명心主神明)과 현대 순환기 내과학·혈액학을 통합적으로 다루는 임상 각과 문서군. 심장·혈관·뇌혈관·혈액의 현대 질환을 망라하는 것을 목표로 한다. 파일명은 한글 표준명, KCD-8 코드는 본문에 명시한다. 심(心)의 생리 기능 이론은 한방생리학 폴더(심주혈맥), 순환계 육안 해부학은 기초한의학 해부학 폴더에서 다루며, 이 폴더는 질환 단위의 진단·변증·치료·예후·관리에 집중한다.

**목차 구성 원칙**: 아래 목차는 KCD-8(한국표준질병사인분류 8차) 순환계통의 질환(I00-I99)과 혈액 및 조혈기관의 질환(D50-D89) 두 대챕터를 코드 블록 순서대로 전수 대조하여 구성했다. 각 블록 아래 개별 질환에 기존 작성 문서를 매칭하고, 미작성 항목은 "(작성 예정)"으로 명시해 누락 없이 목록화했다. 치핵(I84)은 오장변증상 비계(脾胃系)에 속하므로 비계 폴더에서 다루며, 통풍(M10)·요로결석(N20) 등 신계 질환은 신계 폴더에서 다룬다.
