# 안이비인후피부과 (眼耳鼻咽喉皮膚科)

한의학적 침구·한약·외치법과 현대 안과·이비인후과·피부과 진단·치료를 통합적으로 다루는 임상 각과 문서군. 눈·귀·코·인후·피부 5개 감각·외피 계통의 질환을 망라하는 것을 목표로 한다. 개별 기관의 육안 해부학적 배경은 기초한의학 해부학 폴더(감각기관·외피계), 경혈 자침 기법은 경락경혈학·침구학 폴더에서 다루며, 이 폴더는 질환 단위의 진단·변증·치료·예후·관리에 집중한다.

**목차 구성 원칙**: 이 진료과는 눈·귀·코·인후·피부 5개 계통을 포괄하므로, 아래 목차는 대분류를 ① **안과 질환(KCD-8 H00-H59, 눈 및 눈부속기의 질환)**, ② **이비인후과 질환(KCD-8 H60-H95 귀 및 유돌의 질환 / J30-J39 상기도의 기타 질환)**, ③ **피부과 질환(KCD-8 L00-L99, 피부 및 피부밑조직의 질환)** 세 영역으로 나누고, 각 대분류 안에서 다시 KCD 코드 블록 순서대로 세부 챕터를 그룹화하여 구성했다. 이비인후과 질환은 이과(耳科, H60-H95)와 비인후과(鼻咽喉科, J00-J39 상기도) 두 세부영역을 하나의 대분류 아래 통합했다. 각 블록 아래 개별 질환에 기존 작성 문서를 매칭하고, 미작성 항목은 "(작성 예정)"으로 명시해 누락 없이 목록화했다. 챕터 경계를 넘나드는 질환(대상포진 B02, 안면신경마비 G51.0, 구강점막 질환 K11-K12, 화상 T20-T32 등)은 임상적으로 이 진료과에서 다루므로 3대 분류 뒤에 별도 절로 구분해 포함한다.
