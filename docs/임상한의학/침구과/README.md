## 적응증 KCD 코드 대응표

침구과는 질환이 아니라 치료 기법(침·전침·이침·뜸·도침·약침)을 다루는 진료과이므로 단일 KCD-8 챕터에 대응하지 않는다. 각 기법 문서는 "치료 기법 자체에는 특정 질환 코드가 없으며, 주요 적응증 코드를 참조한다"는 원칙을 본문 서두에 명시하고, 각 문서 제4~6편의 "KCD 질환군별 각론"에서 기법별로 실제로 다룬 적응증을 KCD-8 코드와 함께 정리하고 있다. 아래 표는 각 문서 본문(적응증 코드 요약 및 질환군별 각론)에 실제로 등장하는 코드만을 발췌해 기법별로 재정리한 것이며, 문서에 없는 코드는 포함하지 않았다.
