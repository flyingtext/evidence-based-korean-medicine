# 소아과 (小兒科)

한의학 소아과 이론(소아는 순양지체純陽之體·장부교눈臟腑嬌嫩·형기미충形氣未充하다는 소아 생리 특성론)과 현대 소아청소년과학을 통합적으로 다루는 임상 각과 문서군. 소아·청소년기에 특유하거나 호발하는 질환을 망라하는 것을 목표로 한다. 파일명은 한글 표준명, KCD-8 코드는 본문에 명시한다.

**목차 구성 원칙**: 소아과는 KCD-8의 단일 대챕터에 대응하지 않으며, 신생아기 특유 질환(P00-P96)·선천기형(Q00-Q99)을 제외한 대부분의 소아 질환은 다른 진료과 챕터(호흡계통·소화계통·정신 및 행동장애 등)에 성인 질환과 함께 분류되어 있다. 이에 따라 이 폴더의 목차는 ① 신생아·주산기 질환, ② 선천기형·유전질환, ③ 소아 성장·발달, ④ 이후 소아과 임상 아분과(호흡기·소화기·알레르기면역·신경정신행동·비뇨생식·감염·근골격·혈액종양·심장) 순으로 구성한다. 이미 성인과 공통되는 질환 문서에 소아 하위 표제어가 포함되어 있는 경우(예: 폐계 폴더의 폐렴 문서 내 "소아 폐렴") 이 폴더에서 중복 작성하지 않고 교차 참조로 대신하며, 소아 고유의 병태생리·용량·안전성이 충분히 달라 독립 문서가 필요한 경우에만 이 폴더에 별도 문서를 둔다.
