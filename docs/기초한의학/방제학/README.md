# 방제학 (方劑學)

한의과대학 교과서적 표준 명칭을 사용한다. 파일명 예: `보중익기탕(補中益氣湯).md`

**목차 구성 원칙**: 아래 목차는 한의과대학 공통 방제학 교재의 치법(治法)·방제(方劑) 분류 체계(해표제부터 구충제까지 17개 대분류)를 따라 구성했다. 각 분류 아래 기존 작성 문서를 매칭하고, 미작성 처방은 "(작성 예정)"으로 병기해 교과서 목차 대비 누락을 확인할 수 있게 했다.

- 처방 제형 방법에 따른 효능 효과 차이의 근거 기반 정량 분석
