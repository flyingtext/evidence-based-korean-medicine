# 십사경혈 표준 표기표(十四經穴 標準表記表, Standard Notation Table of the 361 Acupuncture Points)

이 문서는 십사경(十四經)에 속한 361개 경혈의 **코드 · 한자 · 한국 표준 독음** 대조표다. 세계보건기구(WHO)의 『Standard Acupuncture Point Locations in the Western Pacific Region』(2008)이 확정한 경혈 코드와 한자 표기를 기준으로 하고, 독음은 한국 표준 한자음 규정(두음법칙 포함)에 따랐다.

이 표를 두는 목적은 서술의 편의가 아니라 **표기 오류의 예방**이다. 경혈은 이름·한자·코드 세 가지가 서로를 검증하는 구조여서, 셋 중 하나만 어긋나도 다른 혈을 가리키게 된다. 실제로 이 저장소에서는 코드에 다른 혈의 이름이 붙거나(`陰陵泉`에 SP10, `伏兔`에 ST34), 한자가 존재하지 않는 자형으로 적히거나(`陽老`, `格兪`, `腎數穴`), 병음을 음차한 뒤 한자를 지어낸 표기(`足痛孔`, `舒股`)가 발견되었다. 새로 경혈을 서술할 때는 이 표에서 세 요소를 함께 옮겨 적는 것이 안전하다.

## 1. 표기 원칙

**① 세 요소를 함께 쓴다.** 본문 최초 등장 시 `독음(漢字, 코드)` 형식으로 적는다 — 예: `합곡(合谷, LI4)`, `차료(次髎, BL32)`.

**② 한자에 `穴`을 넣지 않는다.** `합곡혈(合谷穴, LI4)`이 아니라 `합곡(合谷, LI4)`이다. 우리말 서술에서 `합곡혈에 자침`처럼 접미사 `혈`을 붙이는 것은 자연스러우나, 한자 표기에는 혈명만 적는다.

**③ 두음법칙을 지킨다.** `足臨泣`은 족림읍이 아니라 **족임읍**, `蠡溝`는 려구가 아니라 **여구**, `梁門`은 량문이 아니라 **양문**이다.

**④ 배수혈(背兪穴)의 `兪`는 `수`로 읽는다.** `肺兪`는 폐유가 아니라 **폐수**, `腎兪`는 **신수**, `膈兪`는 **격수**, `白環兪`는 **백환수**다. `臑兪`(SI10)는 **노수**, `肓兪`(KI16)는 **황수**, `兪府`(KI27)는 **수부**, `腰兪`(GV2)는 **요수**다.

**⑤ `髎`는 `료`로 읽는다.** `次髎` 차료, `顴髎` 관료, `肩髎` 견료, `口禾髎` 구화료.

**⑥ `臑`는 `노`로 읽는다.** `臂臑`(LI14) 비노, `臑會`(TE13) 노회.

**⑦ 삼초경 코드는 `TE`를 쓴다.** 구(舊) 표기 `SJ`(San Jiao)와 `TB`(Triple Burner)는 쓰지 않는다. 간경은 `LR`을 쓰고 `LV`는 쓰지 않는다.

**⑧ 정자(正字)로 통일한다.** 이 표의 자형을 따른다 — `肺兪`(俞·腧 아님), `太谿`(太溪 아님), `俠谿`(俠溪 아님), `湧泉`(涌泉 아님), `長強`(長强 아님), `豐隆`(豊隆 아님), `懸鍾`(懸鐘 아님), `絡卻`(絡却 아님), `璇璣`(璿璣 아님), `伏兔`(伏兎 아님), `鳩尾`(간체 鸠尾 아님).

## 16. 반복 적발된 오류 유형

아래는 이 저장소에서 실제로 발견되어 정정한 사례다. 같은 유형이 재발하지 않도록 기록해 둔다.

| 유형 | 실제 사례 | 정정 |
|---|---|---|
| 코드에 다른 혈의 이름 | `음릉천(陰陵泉, SP10)`, `지기(地機, SP10)` | SP9, SP8 |
| 코드가 연쇄로 밀림 | `髀關(ST32)·伏兎(ST34)·地機(SP10)` | ST31·ST32·SP8 |
| 두 혈이 서로 뒤바뀜 | `束骨(BL66)`↔`足通谷(BL65)`, `天牖(SI17)`↔`天容(TE16)` | 상호 교체 |
| 존재하지 않는 한자 | `陽老`, `格兪`, `腎數穴`, `天定`, `外門`, `後兪`, `陰白`, `禮門` | 養老, 膈兪, 腎兪, 手三里, 郄門, 後谿, 隱白, 液門 |
| 병음 음차 후 한자 창작 | `족통구(足痛孔)`, `슈구(舒股)`, `샹구(相股)` | 足通谷, 束骨, 陷谷·俠谿 |
| 兪 독음 | `백환유`, `폐유`, `신유`, `격유`, `간유`, `대장유` | 백환수, 폐수, 신수, 격수, 간수, 대장수 |
| 두음법칙 | `족림읍`, `려구`, `량문`, `전련천` | 족임읍, 여구, 양문, 전염천 |
| 독음 오독 | `차침`, `중요혈`, `질료`, `환요`, `양능천`, `현훈`, `비요`, `전중` | 차료, 중료, 질변, 환도, 양릉천, 현종, 비노, 단중 |
| 이체자 | `肺俞`, `太溪`, `俠溪`, `涌泉`, `長强`, `豊隆`, `絡却`, `璿璣`, `伏兎` | 肺兪, 太谿, 俠谿, 湧泉, 長強, 豐隆, 絡卻, 璇璣, 伏兔 |
| 한자에 `穴` 중복 | `합곡혈(合谷穴, LI4)` | `합곡(合谷, LI4)` |
| 구 코드 표기 | `SJ5`, `SJ14` | TE5, TE14 |

이 표는 십사경혈에 한정한다. 경외기혈(經外奇穴)은 WHO가 별도 코드 체계(`EX-HN`, `EX-CA`, `EX-B`, `EX-UE`, `EX-LE`)로 정하고 있으며 이 표의 범위 밖이다. 저장소에서는 경외기혈에 `EX-` 코드를 쓴다 — 예: `인당(印堂, EX-HN3)`, `사신총(四神聰, EX-HN1)`. 중국 국가표준(GB/T)의 `GV29`(印堂) 같은 표기는 쓰지 않는다.
