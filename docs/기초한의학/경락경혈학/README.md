## 동음이의 분류

- 명문(命門) — 이 폴더의 명문(命門, GV4)은 독맥의 구체적 경혈(취혈·자침·구법·배혈)을 다룬다. 한방생리학 폴더의 명문(命門, Gate of Vitality)은 신(腎)의 생리를 뿌리에서 규정하는 이론적 개념(명문학설·명문지화·원기)을 다루는 별개 문서다.
- 견정(肩貞/肩井) — 소장경의 견정(肩貞, SI9, 어깨 관절 후하방)과 담경의 견정(肩井, GB21, 어깨 정상부. 이 폴더에 별도 문서로 수록)은 한글 발음만 같을 뿐 한자·소속 경락·해부학적 위치가 모두 다른 별개의 경혈이다.
- 소해(小海/少海) — 소장경의 소해(小海, SI8, 팔꿈치 척골 주두-상완골 내상과 사이, 합혈)와 심경의 소해(少海, HT3, 팔꿈치 주름 안쪽 끝, 합혈)는 한글 발음만 같을 뿐 한자·소속 경락·위치가 다른 별개의 경혈이다.
