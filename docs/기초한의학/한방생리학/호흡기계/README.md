# 호흡기계 (呼吸器系, Respiratory System)

한방생리학 폴더 아래 호흡기계 하위 폴더. 서양의학 계통생리학 관점에서 환기·가스교환·산염기평형 생리를 정리한다. 총론의 폐(肺)·폐주기(肺主氣)·폐주치절(肺主治節)·신주납기(腎主納氣) 문서와 교차 참조하되, 내용을 위임하지 않고 이 폴더에서 서양의학적 생리 기전을 독립적으로 서술한다.
