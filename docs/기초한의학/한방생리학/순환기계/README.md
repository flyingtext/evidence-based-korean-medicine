# 순환기계 (循環器系, Circulatory System)

한방생리학 폴더 아래 순환기계 하위 폴더. 서양의학 계통생리학 관점에서 심장·혈관·미세순환 생리를 정리한다. 총론의 심(心)·심주혈맥(心主血脈)·맥(脈) 문서와 교차 참조하되, 내용을 위임하지 않고 이 폴더에서 서양의학적 생리 기전을 독립적으로 서술한다.
