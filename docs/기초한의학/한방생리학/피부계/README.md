# 피부계 (皮膚系, Integumentary System)

한방생리학 폴더 아래 피부계 하위 폴더. 서양의학 계통생리학 관점에서 피부장벽·체온조절·분비선 생리를 정리한다. 총론의 폐주피모(肺主皮毛)·위기(衛氣) 문서와 교차 참조하되, 내용을 위임하지 않고 이 폴더에서 서양의학적 생리 기전을 독립적으로 서술한다.
