# 흉부 (胸部, Thorax)

가슴(흉부)의 국소해부학. 흉벽·흉곽·흉막·종격·심장·대혈관·기관·기관지·폐·식도·신경계(미주신경·교감신경간) 등 흉부 구조물을 통합 정리. 자침 관련 기흉 위험 구조물 포함.

## 문서 목록

- 흉벽(胸壁, Thoracic Wall) — 흉곽 골격(늑골·흉골·흉추)·늑간근·흉막벽층, 늑간신경·늑간동맥·늑간정맥 주행, 늑간 취혈 자침 안전성
- 흉곽상구(胸廓上口, Superior Thoracic Aperture) — 제1늑골·흉골병·제1흉추로 경계되는 흉곽 상부 개구부, 쇄골하동맥·쇄골하정맥·완신경총·미주신경·교감신경·기관·식도 주행
- 흉곽하구(胸廓下口, Inferior Thoracic Aperture) — 제12흉추·제12늑골·늑궁·흉골검돌기로 경계되는 흉곽 하부 개구부, 가로막에 의해 폐쇄
- 가로막(橫膈膜, Diaphragm) — 흉곽과 복강의 경계, 호흡근, 주요 혈관·신경·식도 통과부(대동맥열·식도열·대정맥공), 자침 시 관련 구조물
- 종격(縱膈, Mediastinum) — 양측 흉막강 사이 중앙 구획, 전종격·상종격·후종격·하종격 구분, 심장·대혈관·기관·기관지·식도·미주신경·교감신경간·흉선 등
- 흉막강(胸膜腔, Pleural Cavity) — 벽측흉막·장측흉막, 늑막강(흉막강), 기흉(氣胸) 발생 기전, 자침 시 흉막 천공 위험과 안전 자침 깊이
