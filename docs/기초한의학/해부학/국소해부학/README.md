# 국소해부학 (局所解剖學, Regional Anatomy)

계통해부학이 인체를 기관계(골격·근육·신경·혈관 등) 단위로 정리한다면, 국소해부학은** 신체의 특정 부위를 기준으로 그 부위에 속하는 모든 구조물(골·관절·근육·신경·혈관·장기·근막 등)을 통합적으로 다루는** 해부학 영역이다. 침구·추나 임상에서 경혈의 안전 자침 깊이·주변 위험 구조물 파악·국소 감염·손상 예방에 직결되므로, 계통해부학 문서와 상호 보완적으로 활용한다.
