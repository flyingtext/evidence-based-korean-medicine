# 면역계 (免疫系, Immune System)

면역계의 육안 해부학. 림프기관(골수·흉선·비장·림프절·점막연관림프조직)과 림프관계.

면역의 생리·기능(선천·획득면역, 사이토카인, 면역조절)과 한의학 상관·KCD 질환군별 각론은 한방생리학 각론 면역계 폴더의 총론 문서「면역(免疫, Immunity)」과 개별 세포·분자 문서에서 다루고, 이 폴더는 면역계 기관의 해부학적 위치·구조·혈관·신경 분포에 집중한다.

## 문서 목록

- 면역계(免疫系, Immune System) — 총론: 골수·흉선·비장·림프절·MALT의 육안 해부와 림프관계, 침구·한의학의 면역계 관련 임상 근거 (작성 예정)
- 흉선(胸腺, Thymus) — T세포 성숙의 중추림프기관: 흉골 후방 위치·엽 구조·연령별 퇴화, 흉선의 혈관·신경 분포 (작성 예정)
- 비장(脾臟, Spleen) — 좌상복부의 혈액 여과·면역기관: 유문·비동맥·비정맥, 백수질·적수질의 해부학적 분업과 비장 손상·비장절제 임상 (작성 예정)
- 림프절(淋巴結, Lymph Node) — 말초림프기관의 기본 단위: 피질(B세포 여포)·수질(T세포 구역) 미세구조, 입력·출력림프관, 신체 부위별 림프절 군(경부·액와·서혜부)과 림프 배분 경로 (작성 예정)
- 림프관(淋巴管, Lymphatic Vessel) — 림프모세혈관·집합림프관·림프간(胸導管·우림프간)과 정맥각 회귀, 림프순환의 해부학적 경로 (작성 예정)
- 편도(扁桃, Tonsil) — 구인두·인두완륭·설비·이관 편도의 점막면역 해부와 발다이어 면역환(작성 예정)
- 막창자충수(盲腸蟲垂, Vermiform Appendix) — 점막연관림프조직이 풍부한 소화관 부속기관 (작성 예정)
- 림프구 재순환(淋巴球再循環) — 고림대정맥-림프절 회로와 장기별 호밍(homing)의 해부학적 기초 (작성 예정)
