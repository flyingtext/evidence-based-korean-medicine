# 해부학 (解剖學)

한의학적 인체 구조 이론과 현대 해부학적 상관을 다루는 문서군. 전통 해부 개념(골도촌법·인체 부위 명칭·장부 형태 등)과 침구·추나 임상에 필요한 국소해부를 계통별·부위별로 정리한다. 개별 장부의 생리 기능은 한방생리학 폴더, 조직의 미세구조는 조직학 폴더에서 다루며, 이 폴더는 육안 해부학적 구조(위치·형태·주행·관계)에 집중한다.

해부학 폴더는**계통해부학(系統解剖學)**과**국소해부학(局所解剖學)**두 하위 폴더로 구성된다.

-**계통해부학**— 인체를 기관계(골격·관절·근육·신경·혈관·호흡·소화·비뇨·생식·내분비·외피) 단위로 정리
-**국소해부학**— 신체 부위(두·경·흉·복·골반·상지·하지)별로 그 부위의 모든 구조물을 통합 정리

- [국소해부학 폴더](국소해부학/) — 부위별 통합 해부학
