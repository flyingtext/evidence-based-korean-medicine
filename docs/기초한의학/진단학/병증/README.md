# 병증(病症) — 『동의보감(東醫寶鑑)』 목차 편제

허준(許浚)의 『동의보감(東醫寶鑑, 1613)』은 내경편(內景篇)·외형편(外形篇)·잡병편(雜病篇)·탕액편(湯液篇)·침구편(鍼灸篇)의 5대 편으로 구성되며, 이 중 병증(病症) 자체를 인체 부위·병인(病因)별로 분류하여 다루는 것은 내경편·외형편·잡병편 세 편이다. 이 폴더는 그 세 편의 목차 체계를 그대로 따라 병증을 편제하고, 각 병증이 현재 저장소 어디에서(주로 임상한의학 각과 폴더) 다뤄지고 있는지를 교차 참조하는 색인 역할을 한다.

탕액편(湯液篇, 본초 총론)은 본초학 폴더에서, 침구편(鍼灸篇, 경혈·자법·구법)은 경락경혈학·침구과 폴더에서 별도로 다루므로 이 폴더에서는 목차만 참고로 표기하고 본문은 두지 않는다.

**목차 구성 원칙**: 아래 표는 『동의보감』 각 편·문(門)의 표준 순서를 그대로 따른다. 각 문(門) 아래에는 그 문에서 다루는 대표 병증·병기(病機) 개념을 나열하고, 현재 이 저장소(주로 `임상한의학/` 각과 폴더)에 대응 문서가 있으면 "**작성됨**"과 함께 경로를, 없으면 "(작성 예정)"을 표기한다. 원전의 문·병증 명칭은 현대 KCD-8 질병명과 일대일로 대응하지 않는 경우가 많으므로, 대응이 불확실하거나 순수 전통 병기 개념인 경우 "**KCD 코드 미대응(전통 병기 개념)**"으로 정직하게 표기한다.
