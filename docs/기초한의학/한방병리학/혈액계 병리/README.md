# 혈액계 병리 (血液系 病理, Hematologic Pathology)

한방병리학 폴더 아래 각론(각론 — 서양의학 계통병리학) 하위 폴더. 조혈·응고·혈구 이상의 서양의학적 병태생리를 계열별로 정리하는 자리다. 개별 질환의 임상적 세부는 향후 문서에서 KCD-8 코드별로 다룬다.
