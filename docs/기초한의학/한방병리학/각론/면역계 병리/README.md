# 면역계 병리 (免疫系 病理, Immunopathology)

한방병리학 폴더 아래 각론(각론 — 서양의학 계통병리학) 하위 폴더. 자가면역·과민반응·면역결핍의 서양의학적 병태생리를 계열별로 정리하는 자리다. 개별 질환의 임상적 세부는 향후 문서에서 KCD-8 코드별로 다룬다. 면역계의 생리학적 각론은 한방생리학 폴더의 면역계 하위 폴더에서 다루며, 이 폴더는 병리(자가면역·과민·결핍) 관점에 집중한다.
