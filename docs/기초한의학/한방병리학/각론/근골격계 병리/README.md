# 근골격계 병리 (筋骨格系 病理, Musculoskeletal Pathology)

한방병리학 폴더 아래 각론(각론 — 서양의학 계통병리학) 하위 폴더. 골·관절·근육의 서양의학적 병태생리를 계열별로 정리하는 자리다. 개별 질환의 임상적 세부는 향후 문서에서 KCD-8 코드별로 다룬다. 이 저장소의 비증(痺證) 문서(총론)가 다루는 관절·근골 통증 병리와 상호 참조되는 계통이다.
