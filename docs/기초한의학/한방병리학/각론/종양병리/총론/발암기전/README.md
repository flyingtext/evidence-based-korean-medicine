# 발암기전 (發癌機轉, Carcinogenesis Mechanisms)

종양병리 총론 하위 폴더. 종양이 발생하는 분자·유전·후성유전학적 기전을 다룬다. 발암 단계(개시·촉진·진행), 원암유전자·종양억제유전자·DNA 수리 유전자, 돌연변이 서명, 후성유전학적 변화, 염증·산화스트레스·면역회피, 발암원(화학·방사선·바이러스·호르몬), 한의학의 기울화화(氣鬱化火)·열독(熱毒)·담어(痰瘀) 호불(互結)과의 대응 논점을 정리한다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.** 관련 문서가 이미 존재한다는 이유로 서술을 위임하지 않으며, 표제어 간 내용이 겹치는 것은 문제가 되지 않는다.
- **대응 논점을 별도 항목으로 명시한다.** 한의학 병리 서술과 겹치는 지점뿐 아니라 벌어지는 지점도 함께 기록한다. 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

## 대응 논점

한의학의 기울화화(氣鬱化火)·열독(熱毒)·담어(痰瘀) 호불(互結)이 발암 기전과 개념적 접점을 갖는다. 만성 자극→기체→화화→열독 축적→담어 호결→종물 형성이라는 병리 전변이 발암 단계(개시·촉진·진행)와 구조적 유사성을 갖는다. 다만 한의학 병리가 특정 분자 기전(원암유전자·종양억제유전자·돌연변이)과 일대일 대응하지 않으며, 대응은 서술적 유비다.

- 기울화화(氣鬱化火)·열독(熱毒)과 발암 단계 — 만성 자극이 기체를 만들고 기체가 화화하여 열독이 축적되어 종물을 형성하는 병리가 발암 단계(개시·촉진·진행)와 구조적 유사성을 갖는다는 점 — (작성 예정)
- 담어(痰瘀) 호불(互結)과 미세환경 — 담·어가 호결하여 종물을 형성한다는 서술이 종양 미세환경·섬유화·혈관 신생과 개념적 접점을 갖는다는 점 — (작성 예정)
