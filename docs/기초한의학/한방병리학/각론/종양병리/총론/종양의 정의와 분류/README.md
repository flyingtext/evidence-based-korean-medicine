# 종양의 정의와 분류 (腫瘍의 定義와 分類, Definition and Classification of Neoplasia)

종양병리 총론 하위 폴더. 종양(신생물, neoplasm)의 정의·분류·명명법·양성·악성 구분·조직학적 분류를 다룬다. 종양이 무엇인지, 어떻게 분류되는지, 양성과 악성의 차이는 무엇인지, 한의학의 징가(癥瘕)·적취(積聚)·암(癌) 개념과 어떻게 대응하는지를 정리한다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.** 관련 문서가 이미 존재한다는 이유로 서술을 위임하지 않으며, 표제어 간 내용이 겹치는 것은 문제가 되지 않는다.
- **대응 논점을 별도 항목으로 명시한다.** 한의학 병리 서술과 겹치는 지점뿐 아니라 벌어지는 지점도 함께 기록한다. 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

## 대응 논점

한의학의 징가(癥瘕)·적취(積聚)·암(癌)·석(巖) 개념이 종양 분류와 개념적 접점을 갖는다. 다만 한의학 분류가 현대 종양 분류(양성·악성·조직학적 기원·분화도)와 일대일 대응하지 않으며, 대응은 서술적 유비다.

- 징가(癥瘕)·적취(積聚)와 종양 분류 — 징(癥)·적(積)의 고정성·가단성이 악성·양성 종양의 특징과 개념적 접점, 한의학 분류가 현대 종양 분류와 다른 축을 기술한다는 점 — (작성 예정)
- 암(癌)·암(巖)과 악성 종양 — 암·석이 고정·요혈(凹凸)·침윤성 종괴를 의미한다는 점에서 악성 종양과 접점, 한의학의 암이 특정 조직학적 분류와 대응하지 않는다는 한계 — (작성 예정)
