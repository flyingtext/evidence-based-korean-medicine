# 종양생물학과 암의 표지 (腫瘍生物學과 癌의 標識, Tumor Biology and Hallmarks of Cancer)

종양병리 총론 하위 폴더. 종양 세포의 생물학적 특성 — 자율적 증식·세포사 회피·무한 복제·혈관 신생·침습·전이·대사 재편성·면역 회피·유전체 불안정성·염증·종양 미세환경 — 과 암의 표지(hallmarks of cancer)를 다룬다. 한의학의 정기(正氣)·사기(邪氣) 상쟁·허실(虛實) 전병·음양(陰陽) 역란과의 대응 논점을 정리한다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.**
- **대응 논점을 별도 항목으로 명시한다.** 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.
