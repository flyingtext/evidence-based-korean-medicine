# 항암치료 부작용 병태생리 (抗癌治療副作用 病態生理, Pathophysiology of Cancer Treatment Adverse Effects)

종양병리 총론 하위 폴더. 항암 치료 — 화학요법·방사선·면역관문억제제·표적치료·내분비치료 — 의 부작용 병태생리를 다룬다. 골수 억제·구내염·위장관 독성·심독성·신 독성·간 독성·신경 독성·피부 독성·방사선 손상·면역관련이상반응(irAE)·표적치료 부작용이 핵심 영역이다. 한의학의 약독(藥毒)·화열작혈(火熱灼血)·비위손상(脾胃損傷)·기혈허(氣血虛)·음허(陰虛)와 항암치료 부작용의 대응 논점을 정리한다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.**
- **대응 논점을 별도 항목으로 명시한다.** 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

**개별 문서 상태 범례**: ✅ 작성 완료 · 🔄 작성 진행 중 · — 미작성(작성 예정)
