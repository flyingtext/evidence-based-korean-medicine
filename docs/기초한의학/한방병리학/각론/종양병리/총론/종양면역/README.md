# 종양면역 (腫瘍免疫, Tumor Immunology)

종양병리 총론 하위 폴더. 종양과 면역계의 상호작용 — 종양항원·면역 감시·선천·획득 면역·면역 회피·면역 편집·면역 치료(면역관문억제제·CAR-T) — 을 다룬다. 한의학의 정기(正氣)·사기(邪氣) 상쟁·영위(營衛)·해독(解毒)과 종양면역의 대응 논점을 정리한다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.**
- **대응 논점을 별도 항목으로 명시한다.** 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

## 대응 논점

- 정기(正氣)와 면역 감시 — "正氣存內, 邪不可干"이 종양 면역 감시와 구조적 유사성을 갖는다는 점, 정기가 특정 면역 지표로 환원되지 않는다는 한계 — (작성 예정)
- 영위(營衛)·해독(解毒)와 종양면역 — 위기(衛氣)가 선천 면역·종양 감시에, 영기(營氣)가 획득 면역에 대응할 수 있다는 점, 청열해독 치법이 항종양 면역에 기여할 수 있다는 간접 근거 — (작성 예정)
