# 침습과 전이 (侵襲과 轉移, Invasion and Metastasis)

종양병리 총론 하위 폴더. 종양 세포의 국소 침습·혈관·림프관 침투·순환 종양 세포(CTC)·정착·증식·기관 특이적 전이의 분자 기전을 다룬다. 상피-간엽 전환(EMT)·기질 분해·혈관 신생·면역 회피·정착 미세환경·전이 휴면이 핵심 기전이다. 한의학의 혈어(瘀血)·담결(痰結)·기체혈어(氣滯血瘀)·복류(伏流)·전주(傳注)와의 대응 논점을 정리한다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.**
- **대응 논점을 별도 항목으로 명시한다.** 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.
