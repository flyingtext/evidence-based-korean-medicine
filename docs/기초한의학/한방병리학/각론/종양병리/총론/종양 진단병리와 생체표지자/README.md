# 종양 진단병리와 생체표지자 (腫瘍診斷病理와 生體標識子, Tumor Diagnostic Pathology and Biomarkers)

종양병리 총론 하위 폴더. 종양의 진단병리 — 조직검사·세포검사·면역조직화학·분자병리·유전체·액체생검 — 와 종양 표지자(tumor marker) — CEA·CA19-9·AFP·PSA·CA125·ctDNA·CTC·외소체 — 의 임상 활용을 다룬다. 한의학의 사진(四診)·설맥·복진과 종양 진단의 대응 논점을 정리한다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.**
- **대응 논점을 별도 항목으로 명시한다.** 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.
