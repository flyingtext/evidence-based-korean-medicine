# 암의 전신 영향 (癌의 全身影響, Systemic Effects of Cancer)

종양병리 총론 하위 폴더. 종양이 국소 증식을 넘어 전신에 미치는 영향 — 악액질(cachexia)·빈혈·응고이상·전해질 이상·내분비 증후(이종호르몬 분비)·신경병증·면역저하·전신 염증 — 을 다룬다. 한의학의 기혈양휴(氣血兩虧)·음허화왕(陰虛火旺)·비위허(脾胃虛)·신정부족(腎精不足)과 암 전신 영향의 대응 논점을 정리한다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.**
- **대응 논점을 별도 항목으로 명시한다.** 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.
