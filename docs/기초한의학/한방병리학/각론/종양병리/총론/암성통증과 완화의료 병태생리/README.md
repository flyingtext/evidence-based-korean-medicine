# 암성통증과 완화의료 병태생리 (癌性疼痛과 緩和醫療 病態生理, Pathophysiology of Cancer Pain and Palliative Care)

종양병리 총론 하위 폴더. 암성 통증 — 체성통·내장통·신경병성통·골전이통·약물성통 — 의 병태생리와 완화의료의 병태생리를 다룬다. 통증 기전·통증 평가·통증 관리·완화의료·말기 관리·사별 케어가 핵심 영역이다. 한의학의 통증 서술 — "通則不痛, 不通則痛"·혈어작통(瘀血作痛)·기체작통(氣滯作痛)·한습비통(寒濕痺痛) — 과 암성 통증의 대응 논점, 침구·한약·외치가 암성 통증 관리에 기여할 수 있는 근거를 정리한다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.**
- **대응 논점을 별도 항목으로 명시한다.** 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.
