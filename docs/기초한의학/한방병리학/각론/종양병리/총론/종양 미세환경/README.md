# 종양 미세환경 (腫瘍微小環境, Tumor Microenvironment)

종양병리 총론 하위 폴더. 종양 세포 주위의 미세환경 — 섬유아세포·혈관·면역 세포·세포외 기질(ECM)·저산소·산도·영양 — 이 종양 증식·침습·전이·치료 저항에 미치는 영향을 다룬다. 한의학의 담(痰)·습(濕)·어(瘀)·기체(氣滯)가 조직 미세환경을 형성한다는 접점과의 대응 논점을 정리한다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.**
- **대응 논점을 별도 항목으로 명시한다.** 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

**개별 문서 상태 범례**: ✅ 작성 완료 · 🔄 작성 진행 중 · — 미작성(작성 예정)
