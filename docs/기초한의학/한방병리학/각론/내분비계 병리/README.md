# 내분비계 병리 (內分泌系 病理, Endocrine Pathology)

한방병리학 폴더 아래 각론(각론 — 서양의학 계통병리학) 하위 폴더. 호르몬 분비·신호전달 이상의 서양의학적 병태생리를 계열별로 정리하는 자리다. 개별 질환의 임상적 세부는 향후 문서에서 KCD-8 코드별로 다룬다. 호르몬 자체의 생리학적 각론은 한방생리학 폴더의 내분비계 하위 폴더에서 다루며, 이 폴더는 병리(기능항진·저하·저항성) 관점에 집중한다.
