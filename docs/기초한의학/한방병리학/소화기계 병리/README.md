# 소화기계 병리 (消化器系 病理, Digestive Pathology)

한방병리학 폴더 아래 각론(각론 — 서양의학 계통병리학) 하위 폴더. 소화관·간·췌장·담도의 서양의학적 병태생리를 계열별로 정리하는 자리다. 염증·궤양·종양 등 소화기계 질환의 공통 병태생리 총론을 다루며, 개별 질환의 임상적 세부는 향후 문서에서 KCD-8 코드별로 다룬다.
