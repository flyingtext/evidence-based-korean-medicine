# 노화의 병리 (老化 病理, Pathology of Aging)

한방병리학 총론 제2부(서양의학 일반병리학) 하위 폴더. 노화를 "시간이 지나 낡는 것"이 아니라 **항상성 예비능이 줄어드는 과정** 으로 다룬다. 같은 스트레스에도 회복하지 못하게 되는 지점이 노쇠(frailty)이며, 이 관점이 고령 환자 진료의 판단 기준을 바꾼다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.** 관련 문서가 이미 존재한다는 이유로 서술을 위임하지 않으며, 표제어 간 내용이 겹치는 것은 문제가 되지 않는다.
- **대응 논점을 별도 항목으로 명시한다.** 한의학 병리 서술과 겹치는 지점뿐 아니라 벌어지는 지점도 함께 기록한다. 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

**개별 문서 상태 범례**: ✅ 작성 완료 · 🔄 작성 진행 중 · — 미작성(작성 예정)

## 대응 논점

신정휴허(腎精虧虛)·천계갈(天癸竭) 서술과 노화 기전의 대응 논의, 보신(補腎)·항노화 연구의 근거 수준과 대리지표 해석의 한계를 다룬다.

- 신정휴허(腎精虧虛)·천계갈(天癸竭)과 노화 기전 — 고전의 생애 주기 서술과 세포·조직 노화 기전의 대응 논의 — (작성 예정)
- 노쇠(frailty)와 허손(虛損) — 예비능 감소 개념과 허손 서술의 접점, 노쇠 평가 도구와 변증의 상관을 검증한 인간 연구의 수준 — (작성 예정)
- 보신(補腎)·항노화 연구의 근거 평가 — 대리지표(텔로미어·염증 지표·호르몬) 변화가 임상 결과로 번역되는지에 대한 검증 수준, 노화를 질병으로 볼 것인가라는 개념 논쟁 — (작성 예정)
