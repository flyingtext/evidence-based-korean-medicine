# 세포사 (細胞死, Cell Death)

한방병리학 총론 제2부(서양의학 일반병리학) 하위 폴더. 세포가 죽는 방식이 하나가 아니라는 사실에서 출발한다. 괴사와 세포자멸사의 고전적 이분법은 파이롭토시스·네크롭토시스·페롭토시스가 밝혀지면서 여러 갈래로 확장되었고, **어떤 방식으로 죽는가가 뒤이은 염증 반응의 크기를 결정한다.**

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.** 관련 문서가 이미 존재한다는 이유로 서술을 위임하지 않으며, 표제어 간 내용이 겹치는 것은 문제가 되지 않는다.
- **대응 논점을 별도 항목으로 명시한다.** 한의학 병리 서술과 겹치는 지점뿐 아니라 벌어지는 지점도 함께 기록한다. 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

**개별 문서 상태 범례**: ✅ 작성 완료 · 🔄 작성 진행 중 · — 미작성(작성 예정)

## 문서 목록

- 괴사(壞死, necrosis)의 유형 — 응고괴사·액화괴사·건락괴사·지방괴사·섬유소양괴사·괴저의 형태학과 대표 상황, 각 유형이 시사하는 원인 — ✅ 작성 완료
- 세포자멸사(apoptosis) — 내인성·외인성 경로, 카스파아제 연쇄, 형태학적 특징과 염증을 유발하지 않는 이유, 생리적 세포사의 역할 — (작성 예정)
- 조절세포사의 확장 — 파이롭토시스(인플라마솜·가스더민), 네크롭토시스, 페롭토시스(철·지질과산화), 자가포식 의존 세포사의 구분과 임상적 의미 — (작성 예정)
- 자가포식(autophagy) — 생존 기전이자 세포사 경로라는 이중성, 영양 결핍·감염·단백 응집에서의 역할 — (작성 예정)
- 세포 노쇠(senescence) — 복제 노쇠와 스트레스 유발 노쇠, 노쇠연관분비표현형(SASP)이 조직 환경을 바꾸는 방식 — (작성 예정)

## 대응 논점

형(形)의 소멸과 기(氣)의 이탈이라는 고전 서술, 탈증(脫證)·망양(亡陽)과 대량 세포사 상태의 대응 논의를 다룬다. 고전 서술은 개체 수준의 위중 상태를 기술한 것이지 세포 수준 기전을 기술한 것이 아니라는 층위 차이를 명시한다.

- 형(形)의 소멸과 기(氣)의 이탈 — 고전의 사망 서술이 개체 수준을 기술한 것이지 세포 수준 기전을 기술한 것이 아니라는 층위 차이 — (작성 예정)
- 탈증(脫證)·망양(亡陽)과 대량 세포사 — 위중 상태의 임상 표현형과 조직 수준 세포사의 대응 논의, 회양구역(回陽救逆) 치법 연구의 근거 수준 — (작성 예정)
- 세포사 방식의 차이가 갖는 함의 — 염증을 유발하는 세포사와 그렇지 않은 세포사의 구분이 열독(熱毒) 발생 여부 서술과 갖는 개념적 접점 — (작성 예정)
