# 혈역학 장애와 순환병리 (血力學 障碍·循環病理, Hemodynamic Disorders)

한방병리학 총론 제2부(서양의학 일반병리학) 하위 폴더. 체액이 어디에 얼마나 있어야 하는가, 혈액이 굳어야 할 때와 굳지 말아야 할 때를 다룬다. 부종·출혈·혈전·색전·경색·쇼크는 모두 **같은 순환 항상성의 서로 다른 붕괴 양상** 이다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.** 관련 문서가 이미 존재한다는 이유로 서술을 위임하지 않으며, 표제어 간 내용이 겹치는 것은 문제가 되지 않는다.
- **대응 논점을 별도 항목으로 명시한다.** 한의학 병리 서술과 겹치는 지점뿐 아니라 벌어지는 지점도 함께 기록한다. 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

**개별 문서 상태 범례**: ✅ 작성 완료 · 🔄 작성 진행 중 · — 미작성(작성 예정)

## 대응 논점

어혈(瘀血)과 혈전·미세순환 장애의 대응 및 어혈이 유변학 지표로 환원되지 않는다는 점, 수습정체(水濕停滯)·수종(水腫)과 부종 기전, 망양(亡陽)·탈증(脫證)과 쇼크 진행의 대응 논의를 다룬다.

- 어혈(瘀血)과 혈전·미세순환 장애 — 겹치는 지점과, 어혈이 혈액유변학 지표만으로 정의되지 않는다는 점, 어혈 변증과 응고 지표의 상관을 검증한 인간 연구의 수준 — (작성 예정)
- 수습정체(水濕停滯)·수종(水腫)과 부종 기전 — 정수압·교질삼투압·림프 배액·투과성의 네 축이 수습 서술과 대응하는 방식 및 그 한계 — (작성 예정)
- 망양(亡陽)·탈증(脫證)과 쇼크 진행 — 위중 단계 서술과 쇼크 분류의 유비, 회양구역 치법이 표준 소생 치료를 대체할 수 없다는 원칙 — (작성 예정)
- 기허혈어(氣虛血瘀)·기체혈어(氣滯血瘀)와 혈류 이상 — 비르효 삼징 가운데 혈류 이상 축과의 대응 논의 — (작성 예정)
