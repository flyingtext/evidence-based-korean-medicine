# 진단병리와 검사 해석 총론 (診斷病理·檢査 解釋, Diagnostic Pathology)

한방병리학 총론 제2부(서양의학 일반병리학) 하위 폴더. 병리 소견과 검사 수치가 무엇을 반영하는가, 그리고 무엇을 반영하지 못하는가를 다룬다. 한의 진료에서 검사 결과지를 읽고 **의뢰가 필요한 소견을 식별하는 실무** 가 이 폴더의 실용적 목표다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.** 관련 문서가 이미 존재한다는 이유로 서술을 위임하지 않으며, 표제어 간 내용이 겹치는 것은 문제가 되지 않는다.
- **대응 논점을 별도 항목으로 명시한다.** 한의학 병리 서술과 겹치는 지점뿐 아니라 벌어지는 지점도 함께 기록한다. 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

**개별 문서 상태 범례**: ✅ 작성 완료 · 🔄 작성 진행 중 · — 미작성(작성 예정)

## 대응 논점

사진(四診)으로 얻은 정보와 검사 소견이 서로 다른 층위의 자료라는 점, 두 자료를 함께 쓰되 하나를 다른 하나의 근거로 환원하지 않는 원칙을 다룬다.

- 사진(四診) 자료와 검사 소견의 층위 차이 — 두 자료를 함께 쓰되 하나를 다른 하나의 근거로 환원하지 않는 원칙 — (작성 예정)
- 설진(舌診)·맥진(脈診)의 재현성과 객관화 연구 — 검사자 간 일치도, 계측 기기 기반 객관화 시도가 도달한 수준과 방법론적 한계 — (작성 예정)
- 변증(辨證)과 진단(diagnosis)의 관계 — 증(證)과 병(病)이 서로 다른 축이라는 점, 병증 결합 진료의 실무 구조 — (작성 예정)
- 검사 결과지를 읽는 한의 임상 실무 — 의뢰가 필요한 소견의 식별, 임의 판단·약물 조절을 피해야 하는 영역 — (작성 예정)
