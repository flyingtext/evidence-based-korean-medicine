# 면역병리 총론 (免疫病理 總論, General Immunopathology)

한방병리학 총론 제2부(서양의학 일반병리학) 하위 폴더. 과민반응·자가면역·면역결핍·이식 거부의 일반 기전을 다룬다. 계통 각론의 면역계 병리 폴더가 질환별 각론을 맡으므로, 이 폴더는 **기전의 문법** 에 집중한다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.** 관련 문서가 이미 존재한다는 이유로 서술을 위임하지 않으며, 표제어 간 내용이 겹치는 것은 문제가 되지 않는다.
- **대응 논점을 별도 항목으로 명시한다.** 한의학 병리 서술과 겹치는 지점뿐 아니라 벌어지는 지점도 함께 기록한다. 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

**개별 문서 상태 범례**: ✅ 작성 완료 · 🔄 작성 진행 중 · — 미작성(작성 예정)

## 대응 논점

정기(正氣) 개념이 방어력만이 아니라 자기와 비자기를 분별하는 조절 능력까지 함축하는지에 대한 검토, "면역력 증강"이라는 방향 없는 서술의 문제를 다룬다.

- 정기(正氣)가 함축하는 것 — 방어력만이 아니라 자기와 비자기를 분별하는 조절 능력까지 포함하는가에 대한 검토, 자가면역을 "정기 부족"으로만 서술할 때의 방향 오류 — (작성 예정)
- "면역력 증강"이라는 방향 없는 서술의 문제 — 면역결핍·자가면역·알레르기·자가염증이 서로 다른 방향의 교정을 요구한다는 점, 부정(扶正)을 논할 때 대상 환자군과 작용 방향을 특정해야 하는 이유 — (작성 예정)
- 위기(衛氣)·위기불고(衛氣不固)와 장벽·선천면역 — 체표 방어 서술과 상피 장벽·선천면역의 대응, 옥병풍산(玉屛風散) 계열 연구의 대리지표 해석 한계 — (작성 예정)
- 풍(風)과 즉시형 과민반응 — 유주성·소양·속발속퇴(速發速退)라는 풍의 성질과 I형 과민반응 표현형의 유비 — (작성 예정)
