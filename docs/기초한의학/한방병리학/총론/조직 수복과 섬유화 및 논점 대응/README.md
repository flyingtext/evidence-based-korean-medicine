# 조직 수복과 섬유화 (組織 修復·纖維化, Tissue Repair and Fibrosis)

한방병리학 총론 제2부(서양의학 일반병리학) 하위 폴더. 손상 이후 조직이 원래 모습으로 돌아가는가(재생), 아니면 흉터로 대체되는가(반흔)를 가르는 조건을 다룬다. 섬유화는 수복의 실패가 아니라 **수복이 과도하게 성공한 결과** 라는 관점이 이 폴더의 축이다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.** 관련 문서가 이미 존재한다는 이유로 서술을 위임하지 않으며, 표제어 간 내용이 겹치는 것은 문제가 되지 않는다.
- **대응 논점을 별도 항목으로 명시한다.** 한의학 병리 서술과 겹치는 지점뿐 아니라 벌어지는 지점도 함께 기록한다. 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

**개별 문서 상태 범례**: ✅ 작성 완료 · 🔄 작성 진행 중 · — 미작성(작성 예정)

## 문서 목록

- 재생과 반흔의 갈림길 — 조직의 재생 능력에 따른 분류(불안정·안정·영구 세포), 기질 골격의 보존 여부가 결말을 가르는 구조 — (작성 예정)
- 육아조직 형성과 혈관신생 — 근섬유아세포, 신생혈관, 세포외기질 침착의 순서 — (작성 예정)
- 세포외기질의 구성과 재구성 — 교원질·엘라스틴·프로테오글리칸·접착당단백, MMP와 TIMP의 균형 — (작성 예정)
- 창상 치유 — 일차 유합과 이차 유합, 치유를 지연시키는 국소·전신 요인(감염·이물·허혈·당뇨·영양결핍·스테로이드), 비대흉터와 켈로이드 — (작성 예정)
- 병적 섬유화 — 만성 손상에서 섬유화가 기능을 대체하는 과정, 간경변·폐섬유화·신섬유화의 공통 기전과 장기별 차이 — (작성 예정)

## 대응 논점

생기(生肌)·염창(斂瘡) 서술과 창상 치유 단계, 기혈양허(氣血兩虛)와 치유 지연, 담어호결(痰瘀互結)과 병적 섬유화의 대응 논의를 다룬다.

- 생기(生肌)·염창(斂瘡)과 창상 치유 단계 — 고전 외과 치법의 단계 구분과 염증기·증식기·재형성기의 대응 — (작성 예정)
- 기혈양허(氣血兩虛)와 치유 지연 — 영양·혈류·전신 상태가 치유를 좌우한다는 관찰과 기혈 이론의 접점, 보익(補益) 개입 연구의 근거 수준 — (작성 예정)
- 담어호결(痰瘀互結)과 병적 섬유화 — 결취(結聚) 서술과 세포외기질 축적의 대응 논의, 활혈화어(活血化瘀) 항섬유화 연구의 근거 층화 — (작성 예정)
