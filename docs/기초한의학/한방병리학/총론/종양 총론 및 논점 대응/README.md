# 종양 총론 (腫瘍 總論, General Neoplasia)

한방병리학 총론 제2부(서양의학 일반병리학) 하위 폴더. 신생물의 정의·명명·이형성·등급·병기라는 개념 틀을 다룬다. **발암기전·종양생물학·전이·종양면역의 상세는 각론의 종양병리 폴더에서 다루므로 이 폴더는 개념 틀에 한정** 하며, 두 폴더는 서로에게 서술을 위임하지 않는다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.** 관련 문서가 이미 존재한다는 이유로 서술을 위임하지 않으며, 표제어 간 내용이 겹치는 것은 문제가 되지 않는다.
- **대응 논점을 별도 항목으로 명시한다.** 한의학 병리 서술과 겹치는 지점뿐 아니라 벌어지는 지점도 함께 기록한다. 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

**개별 문서 상태 범례**: ✅ 작성 완료 · 🔄 작성 진행 중 · — 미작성(작성 예정)

## 대응 논점

적취(積聚)·징가(癥瘕)의 유형(有形)·무형(無形) 구분과 양성·악성 종괴 구분의 접점 및 불일치, 고전 병명이 현대 암종과 일대일 대응하지 않는다는 점을 다룬다.

- 적취(積聚)·징가(癥瘕)와 종괴 개념 — 유형(有形)의 적과 무형(無形)의 취를 나누는 고전 도식이 양성·악성 구분과 갖는 접점 및 불일치 — (작성 예정)
- 고전 병명과 현대 암종의 대응 한계 — 유암(乳巖)·열격(噎膈)·석저(石疽) 등이 현대 진단명과 일대일 대응하지 않는다는 점, 대응을 시도할 때의 방법론적 주의 — (작성 예정)
- 이형성-제자리암-침습암 연속선과 미병(未病) 개념 — 발병 이전 단계 개입이라는 문제의식의 접점, 다만 선별검사가 겨냥하는 시간 창과 미병 개념의 층위 차이 — (작성 예정)
