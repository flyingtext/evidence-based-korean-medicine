# 급성 염증과 만성 염증 (炎症, Acute and Chronic Inflammation)

한방병리학 총론 제2부(서양의학 일반병리학) 하위 폴더. 염증 그 자체의 일반 문법을 다룬다. 감염병리 폴더가 감염 맥락의 염증을, 각 계통 각론이 장기별 염증을 다루므로, 이 폴더는 **어느 조직에서든 반복되는 염증의 문법** 에 집중하며 서로에게 서술을 위임하지 않는다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.** 관련 문서가 이미 존재한다는 이유로 서술을 위임하지 않으며, 표제어 간 내용이 겹치는 것은 문제가 되지 않는다.
- **대응 논점을 별도 항목으로 명시한다.** 한의학 병리 서술과 겹치는 지점뿐 아니라 벌어지는 지점도 함께 기록한다. 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

**개별 문서 상태 범례**: ✅ 작성 완료 · 🔄 작성 진행 중 · — 미작성(작성 예정)

## 문서 목록

- 급성 염증의 혈관 반응 — 혈관 확장, 투과성 증가의 네 기전, 삼출액과 누출액의 감별, 부종의 성립 — (작성 예정)
- 급성 염증의 세포 반응 — 백혈구 동원의 다단계(변연화·구르기·부착·통과·주화성), 탐식과 살균, 호중구세포외덫 — (작성 예정)
- 염증 화학매개체 — 혈관작용 아민, 아라키돈산 대사산물, 사이토카인·케모카인, 보체·키닌·응고계의 상호 증폭 — (작성 예정)
- 급성 염증의 형태학적 유형 — 장액성·섬유소성·화농성·궤양성·위막성 염증과 각 유형의 대표 상황 — (작성 예정)
- 염증의 종결과 소산 — 소산 매개체(리폭신·레졸빈), 대식세포 표현형 전환, 소산 실패가 만성화로 이어지는 경로 — (작성 예정)
- 만성 염증 — 유발 경로(지속 감염·지속 노출·자가면역), 단핵구·림프구·형질세포 침윤, 조직 파괴와 수복의 동시 진행 — (작성 예정)
- 육아종성 염증 — 유상피세포·다핵거대세포의 구성, 건락괴사 동반 여부에 따른 감별, 감염성·이물성·원인불명 육아종 — (작성 예정)
- 염증의 전신 효과 — 발열, 급성기 반응과 급성기 단백, 백혈구 반응, 만성 염증에서의 소모와 빈혈 — (작성 예정)

## 대응 논점

홍종열통(紅腫熱痛) 사징과 급성 염증 징후, 열독(熱毒)·창양(瘡瘍)과 화농성 염증, 담습(痰濕)·어혈(瘀血)의 결취와 만성 염증·섬유화의 대응 논의를 다룬다.

- 홍종열통(紅腫熱痛) 사징과 급성 염증 징후 — 고전 서술과 현대 5대 징후의 대응, 기능장애 항목의 유무 — (작성 예정)
- 열독(熱毒)·창양(瘡瘍)과 화농성 염증 — 배농(排膿) 치법과 농양의 외과적 처치의 대응, 농양벽이 항생제 침투를 막는다는 사실이 갖는 임상적 함의 — (작성 예정)
- 담습(痰濕)·어혈(瘀血)의 결취와 만성 염증·섬유화 — 병리산물 개념과 만성 염증의 조직 결과의 대응 논의 및 검증 한계 — (작성 예정)
- 한열(寒熱) 변증과 염증 활성도 — 열증(熱證)을 염증 활성과 등치할 수 있는가에 대한 검토, 한증(寒證)을 동반한 염증 상태의 존재 — (작성 예정)
