# 세포 손상과 적응 (細胞 損傷·適應, Cellular Adaptation and Injury)

한방병리학 총론 제2부(서양의학 일반병리학) 하위 폴더. 세포가 스트레스를 감당해 적응하는 방식과, 적응의 한계를 넘어 손상에 이르는 지점을 다룬다. 이 폴더가 답해야 할 물음은 하나다 — **무엇이 가역이고 무엇이 비가역인가.** 이 경계가 임상에서 개입 시점을 결정하기 때문이다.

이 폴더의 문서는 다음 원칙을 따른다.

- **자기 표제어 범위 안에서 독립적으로 완결한다.** 관련 문서가 이미 존재한다는 이유로 서술을 위임하지 않으며, 표제어 간 내용이 겹치는 것은 문제가 되지 않는다.
- **대응 논점을 별도 항목으로 명시한다.** 한의학 병리 서술과 겹치는 지점뿐 아니라 벌어지는 지점도 함께 기록한다. 대응은 서술적 유비이며 검증된 등가 관계가 아니다.
- **근거를 3층으로 층화한다.** ①인체 임상 연구 ②인체 시료·기전 연구 ③이론적 유비를 구분해 표기하며, 세포·동물 수준 결과를 임상 효과로 번역하지 않는다.

**개별 문서 상태 범례**: ✅ 작성 완료 · 🔄 작성 진행 중 · — 미작성(작성 예정)

## 대응 논점

정기(正氣)와 사기(邪氣)의 상쟁 도식이 "부담과 감당 능력의 균형"을 말한다는 점에서 세포 적응 이론과 마주 앉는다. 다만 정기는 세포 수준 지표로 환원되지 않으며, 사기의 분류(육음)와 현대 손상 원인 분류는 서로 다른 축을 기술한다.

- 정기(正氣)와 세포 적응 예비능 — 정기허약(正氣虛弱) 서술이 "감당 능력의 한계"를 말한다는 점에서 적응 한계 개념과 갖는 접점, 정기가 특정 세포 지표로 환원되지 않는다는 한계 — ✅ 작성 완료
- 사기(邪氣) 분류와 세포 손상 원인 분류의 대응 — 육음(六淫)·역려지기(疫癘之氣)·불내외인과 저산소·물리화학적 인자·감염·영양 불균형의 대응 시도, 두 분류가 서로 다른 축(발병 상황 대 분자 기전)을 기술한다는 점 — ✅ 작성 완료
- 허실(虛實) 도식과 적응·손상의 구분 — 위축과 비대가 모두 적응이라는 사실이 허실 이원 도식에 포섭되지 않는 지점 — ✅ 작성 완료
