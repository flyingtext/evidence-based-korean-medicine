# 예방한의학

## 문서 목록

- 미병(未病, Preventive Treatment)
  - 하위 표제어: 미병선방(未病先防) · 욕병(欲病) · 기병방변(既病防變) · 차후방복(瘥後防復) · 준건강상태(sub-health) · 체질-미병-질병 관계 발달 축
- 스트레스 관리(Stress Management)
  - 하위 표제어: 침·전침 기반 관리 · 이침·지압 기반 관리 · 한약 기반 관리 · 기공·팔단금·마음챙김 기반 관리 · 아로마테라피·기타 병용 요법
- 예방접종(豫防接種, Vaccination)
  - 능동·수동면역의 구분과 백신이 유도하는 면역 반응, 백신 플랫폼별 특성(생백신·불활화·톡소이드·소단위·단백결합·벡터/mRNA), 면역증강제, 생애주기별 접종과 주요 백신 각론, 특수 집단(면역저하자·자가면역질환자·임신부·투석·암 환자) 접종, 이상반응과 인과성 평가, 금기와 오인된 금기를 다룬다. 아울러 보완대체의학 이용과 예방접종 망설임의 연관을 보여주는 국제 자료를 정면으로 검토하고, 한의사가 접종력 확인·정보 제공·연계라는 일차 진료자 역할에서 지는 책임을 정리한다. 미병선방(未病先防)·정기존내(正氣存內)·위기(衛氣) 이론과의 대응 논점, 한의학사 안의 인두법(人痘法) 계보, 백신 면역원성에 대한 한약 병용 연구의 근거 수준과 한계를 함께 다룬다. **한약·침구를 필수 예방접종의 대체물로 서술하지 않는다** 는 원칙을 명시한다
  - 하위 표제어: 능동면역·수동면역 · 백신 플랫폼 · 면역증강제 · 집단면역 · 국가예방접종 · 예방접종 후 이상반응(AEFI) · 예방접종 망설임 · 인두법(人痘法)
