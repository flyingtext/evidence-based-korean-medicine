# 기초한의학

한의과대학 예과·본과의 기초 이론 과목군. 원전, 진단학, 한방생리학, 한방병리학, 경락경혈학, 본초학, 방제학, 의사학 등을 다루며, 해부학·조직학·약리학·미생물학 등 기초의학 과목군도 한의학 이론과의 접점을 함께 서술하는 방식으로 포함한다.

## 중분류

| 폴더 | 내용 |
|---|---|
| 원전 | 경전 해설 (황제내경, 상한론, 동의보감 등) |
| 진단학 | 사진(望聞問切), 변증론치 등 |
| 한방생리학 | 장부생리, 기혈진액, 경락생리 등 |
| 한방병리학 | 병인병기, 변증, 장부병리 등 |
| 경락경혈학 | 경락·경혈 이론 |
| 해부학 | 전통 인체 구조 이론과 임상 국소해부 |
| 조직학 | 4대 기본조직(상피·결합·근·신경)의 미세 구조와 한의학적 상관 |
| 미생물학 | 세균·바이러스·진균·기생충의 생물학, 감염 성립 기전, 항미생물제 내성, 진단·감염관리와 온병(溫病)·역려지기(疫癘之氣) 이론의 대응 |
| 본초학 | 약재·단미재료 |
| 약리학 | 양방 약리학 총론·계통별 약물군 각론과 본초·방제를 가로지르는 배오이론·한약-양약 상호작용 원리 |
| 방제학 | 처방(방제) |
| 기공학 | 도인·기공 등 수기·운동 요법 |
| 의사학 | 한의학사 |
| 예방한의학 | 예방·보건 한의학 |
