# 약리학 (藥理學)

본초·방제가 인체에 작용하는 기전을 다루는 문서군. 개별 본초의 전통적 성미귀경·효능은 본초학 폴더에서, 개별 처방의 구성·주치는 방제학 폴더에서 다루며, 이 폴더는 양방 약리학의 표준 분류 체계(총론·약동학·약력학·계통별 약물군 각론)를 뼈대로 삼아 **본초·방제를 가로지르는 약리학적 원리와 양방 약물 계통 전반** 을 함께 다룬다.

## 문서 목록

### 총론

- 약리학 총론(藥理學 總論, General Pharmacology) — 정의·역사, 신약 개발 과정 개관, 양방 약리학과 한의학 약리학의 관계 설정
- 약동학(藥動學, Pharmacokinetics) — 흡수·분포·대사·배설(ADME), 한약 복합처방의 다성분 약동학적 특수성
- 약력학(藥力學, Pharmacodynamics) — 수용체 이론, 용량-반응 관계, 효현제·길항제, 귀경(歸經) 이론과의 대응
- 약물유전학(藥物遺傳學, Pharmacogenomics) — 대사효소(CYP450) 유전다형성과 개인차, 체질(사상의학)과의 접점
- 약물독성학(藥物毒性學, Toxicology) — 용량-독성 관계, 간독성·신독성 기전, 한약재 안전역 평가
- 약물상호작용(藥物相互作用) 총론 — 대사효소·수송체 매개 상호작용의 일반 원리, 한약-양약 상호작용 대표 사례
- 제형(劑型)과 생체이용률 — 정제·주사제 등 양방 제형과 탕제·환제 등 한약 제형의 약동학적 비교

### 약물군별 각론 (계통별)

- 자율신경계 약물(自律神經系 藥物) — 교감신경흥분제(카테콜아민·β2작용제·α작용제·β3작용제)·교감신경차단제(α차단제·β차단제), 부교감신경흥분제(직접작용제·콜린에스테라제억제제)·부교감신경차단제(항콜린제), 무스카린/니코틴/아드레날린 수용체 아형 비교, 마황(麻黃)-에페드린 계열의 연속성과 기허(氣虛)·양허(陽虛) 접점, KCD 질환군 8개 각론 (하위 폴더 `자율신경계 약물/README.md`)
- 중추신경계 약물(中樞神經系 藥物) — 진통제(마약성·비마약성), 마취제, 항불안제·수면제, 항우울제, 항정신병제, 항경련제, 파킨슨병 치료제
- 심혈관계 약물(心血管系 藥物) — 항고혈압제(이뇨제·ACE억제제/ARB·칼슘채널차단제·베타차단제), 항부정맥제(Vaughan-Williams 분류), 항협심증제, 강심제, 항응고제·항혈소판제·혈전용해제(활혈화어 한약 병용 안전성 포함), 이상지질혈증 치료제(스타틴·에제티미브·PCSK9억제제)
- 호흡기계 약물(呼吸器系 藥物) — 기관지확장제, 항히스타민제, 진해거담제
- 소화기계 약물(消化器系 藥物) — 제산제·위산분비억제제, 소화성궤양 치료제, 지사제·완하제, 항구토제
- 내분비계 약물(內分泌系 藥物) — 인슐린·경구혈당강하제, 갑상선호르몬제·항갑상선제, 부신피질호르몬제(스테로이드), 성호르몬제
- 신장·이뇨제(利尿劑) — 각 계열 이뇨제와 수분·전해질 대사
- 항미생물제(抗微生物劑) — 항생제, 항바이러스제, 항진균제, 항결핵제
- 항암제(抗癌劑, Chemotherapy) — 세포독성 항암제, 표적치료제, 면역항암제 개관
- 면역계 약물(免疫系 藥物) — 면역억제제, 생물학적 제제(단클론항체 등), 백신
- 비스테로이드성 소염진통제(NSAIDs)와 스테로이드 — 작용기전 비교, 한약 병용 시 고려사항

### 한의학 통합 관점

- 배오이론(配伍理論)의 약리학적 검증 — 군신좌사(君臣佐使), 칠정화합(七情合和: 상수·상사·상외·상쇄·상오·상반)의 현대 약리학적 근거
- 네트워크 약리학(Network Pharmacology) — 다성분-다표적-다경로 분석 방법론과 대표 방제 적용 사례
- 한약-양약 병용 시 안전성 각론 — 주요 만성질환 표준 약물(항응고제·항암제·면역억제제 등)과 한약의 상호작용 근거
