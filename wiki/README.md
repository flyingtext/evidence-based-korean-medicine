# 근거기반 한의학 위키

**Evidence-Based Korean Medicine Wiki**

PubMed · Crossref의 논문 데이터를 AI로 분석해 만든 근거기반 한의학 위키입니다.

## 개요

모든 문서는 [med.symbolicinfo.com](https://med.symbolicinfo.com) 검색 API로 수집한 논문 근거에 기반합니다.
임상적 주장에는 출처(DOI/PMID)를 명시하고, 연구 유형에 따라 근거 수준을 구분합니다.

> 운영 원칙: 근거 우선 · 출처 명시 · 근거수준 구분 · AI 생성물 명시 · 과장 금지
> (자세한 규칙은 [AGENTS.md](../AGENTS.md) 참조)

## 분류 체계 (한의과대학 교과과정 기반)

대분류(학문 분야) → 중분류(과목) → 소분류(개별 문서) 3단계로 구성한다.

| 대분류 | 중분류 | 소분류(예시) |
|---|---|---|
| [1. 기초한의학](./1_기초한의학/README.md) | 원전 · 진단학 · 한방생리학 · 한방병리학 · 경락경혈학 · 본초학 · 방제학 · 기공학 · 의사학 | 황제내경, 사진, 합곡(合谷, LI4), 보중익기탕(補中益氣湯) |
| [2. 임상한의학](./4_임상한의학/README.md) | 내과(장부) · 외과 · 산부인과 · 소아과 · 신경정신과 · 안이비인후피부과 · 침구과 · 추나의학 · 재활의학 · 사상의학 | 요통, 불면증 |
| [3. 보건·기타](./6_보건기타/README.md) | 예방한의학 | 예방한의학 |

## 근거 수준 라벨

체계적 고찰/메타분석 > 임상시험(RCT) > 관찰연구 > 증례

## 작성 워크플로우

1. 주제 선정 → `GET /search`로 논문 수집 (`analyzed=1` 우선)
2. 논문 메타데이터와 `clinical_summary` 기반으로 문서 작성 ([템플릿](./_template.md))
3. 검증 스크립트로 링크·근거·표기 점검
4. MkDocs로 빌드

자세한 명령어는 [RUN.md](../RUN.md) 참조.
