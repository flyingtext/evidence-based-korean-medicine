# 한방생리학 (韓方生理學)

기(氣)·혈(血)·진액(津液)·정(精)·신(神) 등 인체 생리 물질과 장부(臟腑) 기능 이론 문서. 한의과대학 교과서적 표준 명칭(한글 + 한자)을 사용한다.

## 문서 목록

- 기혈(氣血, Qi and Blood)
  - 하위 표제어: 기허(氣虛) · 혈허(血虛) · 기체(氣滯) · 혈어(血瘀) · 기혈양허(氣血兩虛) · 기체혈어(氣滯血瘀) · 기허혈어(氣虛血瘀)

### 오장(五臟) 장부 개론

- 간(肝, Liver) — 장부 총론(장군지관·강강지관·간체음이용양), 간주근·간개규어목·재지위노·화재조, 타 장부 관계, 병리 총람
  - 세부 기능 문서: 간장혈(肝藏血, Liver Stores Blood) · 간주소설(肝主疏泄, Liver Governs Free-Flow)
- 심(心, Heart) — 장부 총론(군주지관), 심주혈맥, 심장신/심주신명, 외후, 타 장부 관계, 병리 총람
- 비(脾, Spleen) — 장부 총론(후천지본·창름지관), 비주운화, 비주승청, 비주기육사지·개규어구, 타 장부 관계, 병리 총람
  - 세부 기능 문서: 비주통혈(脾主統血, Spleen Governs Blood)
- 폐(肺, Lung) — 장부 총론(상전지관·화개·교장), 폐주기사호흡, 폐주선발숙강, 폐주통조수도·조백맥·주치절, 폐주피모, 타 장부 관계, 병리 총람
- 신(腎, Kidney) — 장부 총론(선천지본·작강지관), 신장정, 신주수·신주납기, 신주골생수·통어뇌·개규어이급이음, 타 장부 관계, 병리 총람
