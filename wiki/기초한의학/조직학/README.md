# 조직학 (組織學)

인체를 구성하는 4대 기본조직(상피조직·결합조직·근조직·신경조직)의 미세 구조를 다루는 형태학 문서군. 각 조직의 양방 조직학적 표준 분류를 정리하고, 경락경혈학·진단학 등 한의학 이론과 접점을 이루는 지점(설진의 생물학적 기초, 경락-결합조직/근막 상관, 경혈-신경 인터페이스 등)에 근거를 결합해 서술한다.
