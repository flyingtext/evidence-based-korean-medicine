# 기초한의학

한의과대학 예과·본과의 기초 이론 과목군. 원전, 진단학, 한방생리학, 한방병리학, 경락경혈학, 본초학, 방제학, 의사학 등을 다룬다.

## 중분류

| 폴더 | 내용 |
|---|---|
| 원전 | 경전 해설 (황제내경, 상한론, 동의보감 등) |
| 진단학 | 사진(望聞問切), 변증론치 등 |
| 한방생리학 | 장부생리, 기혈진액, 경락생리 등 |
| 한방병리학 | 병인병기, 변증, 장부병리 등 |
| 경락경혈학 | 경락·경혈 이론 |
| 해부학 | 전통 인체 구조 이론과 임상 국소해부 |
| 조직학 | 4대 기본조직(상피·결합·근·신경)의 미세 구조와 한의학적 상관 |
| 본초학 | 약재·단미재료 |
| 방제학 | 처방(방제) |
| 기공학 | 도인·기공 등 수기·운동 요법 |
| 의사학 | 한의학사 |
| 예방한의학 | 예방·보건 한의학 |
