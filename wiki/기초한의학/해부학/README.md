# 해부학 (解剖學)

한의학적 인체 구조 이론과 현대 해부학적 상관을 다루는 문서군. 전통 해부 개념(골도촌법·인체 부위 명칭·장부 형태 등)과 침구·추나 임상에 필요한 근골격계·신경계·혈관계 국소해부를 함께 정리한다.

## 문서 목록

- `인대(靭帶, Ligament).md` — 인대의 정의·미세구조, 「근주속골이리기관(筋主束骨而利機關)」과 인대의 관절 안정화 기능 대응, 척추·상지·하지 주요 인대 해부, 염좌 등급·치유·만성 불안정성, 침구·추나·프롤로테라피와의 임상 접점.
