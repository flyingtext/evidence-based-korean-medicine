# 제목 (한자, 영문/코드)

> 출처: 근거 기반 한의학 위키 · 작성일: YYYY-MM-DD
> 질환 문서인 경우: `# 제목 (KCD-8: XXXX.X)` 형식으로 KCD 코드를 개요 첫 문단에 명시.

## 개요

주제에 대한 정의와 개괄. 임상적 주장은 반드시 각주로 연결된 논문에 기반한다.

## 근거 요약

핵심 근거 논문 기반 요약. (검색 API `answer`/`clinical_summary`를 대조 후 작성) 각 임상적 주장 끝에 각주 `[^n]`를 달아 출처 논문을 연결한다.

## 임상 적용

`clinical_summary` 기반 실제 임상적 함의. 각주로 근거 논문을 연결한다.

## 경혈/처방 연관

- 경혈: `method_specific_acupoint`
- 약재/처방: `method_specific_herbal` / `method_specific_herbal_formula`

## 미충족 근거 / 추가 연구 필요

근거가 부족한 영역을 명시.

## 각주 정의

[^1]: 논문 제목, 연구 유형, 저널, DOI/PMID 링크.
[^2]: 논문 제목, 연구 유형, 저널, DOI/PMID 링크.
