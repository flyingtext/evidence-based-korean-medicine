# 임상한의학

한의과대학 본과의 임상 과목군. 장부(臟腑) 중심 내과와 각 임상 분과를 다룬다.
질환 문서는 **KCD-8 코드에 근거해 분류**하며, 코드는 본문 개요 첫 문단에 명시한다.
