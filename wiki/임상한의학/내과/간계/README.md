# 간계 (肝系)

한의학 오장변증(五臟辨證)의 간(肝)·담(膽) 계통 이론(간주소설肝主疏泄·간장혈肝藏血·간개규어목肝開竅於目)과 현대 간담도 내과학을 통합적으로 다루는 임상 각과 문서군. 간(肝)·담낭(膽)·담도의 현대 질환을 망라하는 것을 목표로 한다. 파일명은 한글 표준명, KCD-8 코드는 본문에 명시한다. 간(肝)의 생리 기능 이론은 한방생리학 폴더(간주소설·간장혈), 변증 이론은 한방병리학 폴더(간기울결·간혈허·간양상항·간음허 등)에서 다루며, 이 폴더는 질환 단위의 진단·변증·치료·예후·관리에 집중한다.

**목차 구성 원칙**: 아래 목차는 KCD-8(한국표준질병사인분류 8차) 중 바이러스성 간염(B15-B19)과 간·담낭·담도의 질환(K70-K77, K80-K83) 블록을 코드 순서대로 전수 대조하여 구성했다. 각 블록 아래 개별 질환에 기존 작성 문서를 매칭하고, 미작성 항목은 "(작성 예정)"으로 명시해 누락 없이 목록화했다. 췌장 질환(K85-K86)은 오장변증상 비계(脾系)에 속하므로 비계 폴더에서 다루며(췌장염(膵臟炎, Pancreatitis).md), 이 폴더에서는 다루지 않는다.
