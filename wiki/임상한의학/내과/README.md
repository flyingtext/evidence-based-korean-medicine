# 내과

장부(臟腑) 중심으로 분류한다. 각 장부 폴더가 소분류에 해당하며, 개별 질환 문서는 파일로 둔다.

## 소분류

| 폴더 | 내용 | 예시 질환 |
|---|---|---|
| 간계 | 간(肝)·담(膽)계 | 간질환 |
| 심계 | 심(心)계 | 불면, 심계 |
| 비계 | 비(脾)·위(胃)계 | 위완통, 소화불량 |
| 폐계 | 폐(肺)계 | 감기, 천식 |
| 신계 | 신(腎)·방광(膀胱)계 | 요통, 신허 |
