# 주제 조사

한의학의 주요 주제에 대한 조사·검토 문서를 모은다. 기초·임상 분류(기초한의학·임상한의학)가 특정 학문 과목·표제어 단위의 문서를 다룬다면, 이 폴더는 **횡단적 주제(transversal topic)** — 안전성, 독성, 과학화, 표준화, 정책, 교육, 융합연구 등 — 를 다룬다.
